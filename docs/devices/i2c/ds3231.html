DS3231 I2C 실시간 시계 (RTC)

갱신: 2026-11-03 · 등급: L3(데이터시트 PDF 1건 + 드라이버 소스 1건 열람) · 출처: Maxim DS3231 데이터시트 rev.10 (https://courses.physics.illinois.edu/PHYS371/sp2023/code/DS3231.pdf), NuttX ds3231.c (https://apache.googlesource.com/nuttx/+/refs/heads/cmake/drivers/timers/ds3231.c, Apache-2.0)

인터페이스

  • I2C 슬레이브, 7비트 주소 0x68. 표준 100 kHz, 고속 400 kHz. 레지스터 포인터는 자동 증가하며 0x12 다음에 0x00으로 돌아간다.
  • 배터리 입력(VBAT) 유지, 알람 2개, 구형파 출력(데이터시트 서술). 전압 수준은 데이터시트 이 쪽에서 확인하지 않음(unverified). 보드 I/O는 3.3 V이므로 모듈 풀업이 3.3 V인지 확인한다(내 판단).

레지스터 맵 (데이터시트)

주소내용
00h-06h초, 분, 시, 요일, 날짜, 월(bit7 세기), 년 (BCD)
07h-0Ah알람1 (초, 분, 시, 요일/날짜)
0Bh-0Dh알람2 (분, 시, 요일/날짜)
0Eh제어 (발진기, 구형파, 온도 변환, 알람 인터럽트 허용)
0Fh상태 (발진기 정지, 바쁨, 알람 플래그)
10h에이징 오프셋
11h-12h온도 정수·소수 (0.25 °C, 읽기 전용)

시 레지스터 bit6이 12/24시간 모드 선택.

읽기 경계 (NuttX 드라이버 서술)

7바이트(초~년)를 읽은 뒤 초를 다시 읽어 첫 값보다 작아졌으면(자리 올림 중) 처음부터 다시 읽는다. FSM에서도 초 롤오버 재읽기가 필요하다(내 판단).

알람 주의 (Cambridge 강의 헤더 서술, https://www.cl.cam.ac.uk/teaching/1314/P31/lib/html/ds3231_8h_source.html)

알람 인터럽트는 알람 레지스터를 쓴 뒤 제어 레지스터의 허용 비트를 켜고, 발생 후 상태 레지스터에서 플래그를 지워야 한다.

unverified

  • 제어·상태 레지스터의 비트 위치별 이름(데이터시트 요약에 열거만 있음), 전기 특성, I2C 타이밍 표.

구현 사례

  • angelojacobo-fpga-i2c-implementation: DS1307(같은 계열 RTC)을 Verilog로 읽고 쓰는 예 (Spartan-6)
  • digikey-forum-mcp79410-pmod-rtcc-vhdl: 다른 칩(MCP79410)이지만 RTC 컨트롤러 구조 참고

개조 제안 (내 판단)

I2C 비트·바이트 제어는 하드웨어, 레지스터 포인터 순서·BCD 변환·롤오버 재읽기는 소프트웨어(MicroBlaze V)로 나누는 AXI4-Lite IP를 free_slots에서 한 칸 받아 설계할 수 있다. DS3231 모델(레지스터 파일 + 포인터 자동 증가)을 둔 자체 tb로 CI 시험이 가능하다.
