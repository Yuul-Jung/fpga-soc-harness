MMIO I2S 클럭 체크 하네스 (Basys3 Pmod I2S2)

100 MHz 시스템 클럭에서 I2S 클럭 계층(MCLK 12.5 MHz → BCLK 3.125 MHz → LRCLK 97.656 kHz)을 정수 분주로 생성하고, 비율과 비트 순서를 시뮬레이션에서 자동 검증한다. Pmod JA에 Pmod I2S2를 꽂으면 보드에서 직접 오디오 출력을 확인할 수 있다.

린트: 미실행시뮬레이션: 미실행합성: 미실행보드: 미실행

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • 정수 분주기로 MCLK(12.5 MHz), BCLK(3.125 MHz), LRCLK(97.656 kHz)를 생성한다.
  • 16비트 스테레오 I2S 송신기를 MMIO 레지스터로 제어한다.
  • 테스트벤치에서 클럭 비율(BCLK:MCLK=4, BCLK/LRCLK=32)과 MSB 우선 비트 순서를 PASS/FAIL로 검증한다.
  • 마스터 포트를 분리해 CPU로 교체할 수 있게 한다.

범위 밖

  • 표준 44.1/48 kHz 샘플레이트 (100 MHz에서 정수 분주로는 불가)
  • MMCM/PLL 사용 (도구 없이 시뮬레이션 가능하도록 순수 RTL 분주기 사용)
  • I2S 수신(Pmod I2S2의 ADC), DMA, FIFO
  • CPU 구현 (다음 단계)

이 패키지의 소스는 하네스가 직접 작성한 원본이며 외부 코드를 포함하지 않는다. 아이디어 I-002에서 생성됨(2026-11-04). 시뮬레이션·합성 결과는 CI가 기록한다.

2. 계통도

클럭: 100 MHz 단일 클럭 (clk, W5), 동기 리셋 (btnC, 2단 동기화). I2S 클럭(MCLK/BCLK/LRCLK)은 정수 분주기가 sys_clk에서 생성한다.

버스 규약: mmio-lite

신호방향설명

m_wemaster→slave1이면 쓰기
m_addr[31:0]master→slave바이트 주소, 4바이트 정렬

주소 [31:16]으로 슬레이브 선택, [15:0]이 슬레이브 내 오프셋. i2s_tx는 0xFFF0~FFFC(mgmt 레지스터)에 접근하므로 16비트 오프셋이 필요하다.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스mmio-lite
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 적합하지 않음
이식 계획이 패키지는 CPU 없이 시뮬레이션하려고 자체 버스(0x1002_xxxx)를 쓴다. 동결 맵(mbv-frozen-v2)에는 i2s_tx 슬롯 [14] 0x4014_0000 (intc 11)이 미리 배정되어 있다. 이식 경로: (1) 주소를 0x1002_0000 → 0x4014_0000으로 교체하고 mmio-lite → AXI4-Lite 래퍼를 붙인다. (2) IRQ를 intc 11에 연결한다. (3) MMIO 레지스터 배치(CTRL/STATUS/L_DATA/R_DATA/mgmt)는 ip_standard.json을 따르므로 AXI4-Lite 래퍼를 쓰면 드라이버 변경 없이 MicroBlaze V에서 동작한다.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

Pmod I2S2는 3.3V 단전원이며 레벨 변환이 필요 없다. Basys3 JA와 직결한다. 전기 회로도는 미작성이며 Digilent Pmod I2S2 Reference Manual(digilent.com)을 참조한다.

rtl/i2s_clk_gen.v 64줄
// i2s_clk_gen.v — I2S 클럭 계층 생성기 (순수 정수 분주기, sys_clk 동기)
// 입력: 100 MHz sys_clk
// 출력: MCLK 12.5 MHz (÷8), BCLK 3.125 MHz (÷32), LRCLK 97.656 kHz (÷1024)
// 클럭 비율: BCLK:MCLK = 1:4, BCLK/LRCLK = 32 (16비트 스테레오 LJ 포맷)
// 주의: Vivado에서 BCLK/MCLK/LRCLK를 generated clock으로 선언해야 타이밍 분석이 정확하다.
`timescale 1ns/1ps
module i2s_clk_gen (
    input  wire clk,    // 100 MHz 시스템 클럭
    input  wire rst,    // 동기 리셋 (active high)
    output wire mclk,   // 12.5 MHz = 100 MHz / 8
    output wire bclk,   // 3.125 MHz = 100 MHz / 32
    output wire lrclk   // 97.656 kHz = 100 MHz / 1024
);

    // --- MCLK: 토글 주기 4 sys_clk → 12.5 MHz ---
    reg [2:0] mclk_cnt;
    reg       mclk_r;
    always @(posedge clk) begin
        if (rst) begin
            mclk_cnt <= 3'd0;
            mclk_r   <= 1'b0;
        end else if (mclk_cnt == 3'd3) begin
            mclk_cnt <= 3'd0;
            mclk_r   <= ~mclk_r;
        end else begin
            mclk_cnt <= mclk_cnt + 3'd1;
        end
    end
    assign mclk = mclk_r;

    // --- BCLK: 토글 주기 16 sys_clk → 3.125 MHz ---
    reg [4:0] bclk_cnt;
    reg       bclk_r;
    always @(posedge clk) begin
        if (rst) begin
            bclk_cnt <= 5'd0;
            bclk_r   <= 1'b0;
        end else if (bclk_cnt == 5'd15) begin
            bclk_cnt <= 5'd0;
            bclk_r   <= ~bclk_r;
        end else begin
            bclk_cnt <= bclk_cnt + 5'd1;
        end
    end
    assign bclk = bclk_r;

    // --- LRCLK: 토글 주기 512 sys_clk → 97.656 kHz ---
    // 1 LRCLK 주기 = 1024 sys_clk = 32 BCLK 주기 = 16비트 × 2채널
    reg [9:0] lr_cnt;
    reg       lrclk_r;
    always @(posedge clk) begin
        if (rst) begin
            lr_cnt  <= 10'd0;
            lrclk_r <= 1'b0;
        end else if (lr_cnt == 10'd511) begin
            lr_cnt  <= 10'd0;
            lrclk_r <= ~lrclk_r;
        end else begin
            lr_cnt  <= lr_cnt + 10'd1;
        end
    end
    assign lrclk = lrclk_r;

endmodule
rtl/i2s_tx.v 161줄
// i2s_tx.v — I2S 송신기 + MMIO 레지스터 (ip_standard rev 1 준수)
// Left-Justified 포맷: LRCLK 변환 직후 첫 번째 BCLK 하강 에지에서 MSB 출력
// MMIO 오프셋 맵 (64KB 창, 0x1002_0000 기준):
//   0x0000 CTRL      RW  bit[0]=TX_EN
//   0x0004 STATUS    RO  bit[0]=active(=TX_EN)
//   0x0008 L_DATA    WO  [15:0] 왼쪽 채널 샘플 (다음 LRCLK 하강부터 반영)
//   0x000C R_DATA    WO  [15:0] 오른쪽 채널 샘플
//   0xFFF0 ID        RO  0x49325354 ('I2ST')
//   0xFFF4 VER       RO  0x01000001
//   0xFFF8 IRQ_STATUS W1C bit[0]=frame_done
//   0xFFFC IRQ_ENABLE RW  bit[0]=frame_done 인터럽트 활성화
`timescale 1ns/1ps
module i2s_tx (
    input  wire        clk,
    input  wire        rst,
    // mmio-lite 슬레이브 포트
    input  wire        sel,
    input  wire        we,
    input  wire [15:0] off,     // 창 내 바이트 오프셋 (addr[15:0])
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    // I2S 클럭 (i2s_clk_gen에서 공급, sys_clk 동기)
    input  wire        mclk,
    input  wire        bclk,
    input  wire        lrclk,
    // I2S 출력
    output wire        sdin,   // 직렬 데이터 (Pmod I2S2 SDIN 핀)
    // 인터럽트
    output wire        irq
);
    // -------------------------------------------------------
    // MMIO 레지스터
    // -------------------------------------------------------
    reg        tx_en;
    reg [15:0] l_reg, r_reg;      // 호스트가 쓴 샘플 버퍼
    reg        irq_status;        // frame_done 래치
    reg        irq_enable;

    // 쓰기
    always @(posedge clk) begin
        if (rst) begin
            tx_en      <= 1'b0;
            l_reg      <= 16'h0000;
            r_reg      <= 16'h0000;
            irq_enable <= 1'b0;
        end else if (sel && we) begin
            case (off)
                16'h0000: tx_en      <= wdata[0];
                16'h0008: l_reg      <= wdata[15:0];
                16'h000C: r_reg      <= wdata[15:0];
                16'hFFFC: irq_enable <= wdata[0];
                default: ;
            endcase
        end
    end

    // IRQ_STATUS: W1C
    always @(posedge clk) begin
        if (rst) begin
            irq_status <= 1'b0;
        end else begin
            if (frame_done_pulse)                 irq_status <= 1'b1;
            if (sel && we && off == 16'hFFF8)     irq_status <= irq_status & ~wdata[0];
        end
    end

    // 읽기 (조합)
    always @* begin
        case (off)
            16'h0000: rdata = {31'd0, tx_en};
            16'h0004: rdata = {31'd0, tx_en};
            16'hFFF0: rdata = 32'h4932_5354; // 'I2ST'
            16'hFFF4: rdata = 32'h0100_0001; // std_rev=1, minor=1
            16'hFFF8: rdata = {31'd0, irq_status};
            16'hFFFC: rdata = {31'd0, irq_enable};
            default:  rdata = 32'h0000_0000;
        endcase
    end

    assign irq = irq_status & irq_enable;

    // -------------------------------------------------------
    // 에지 검출 (1사이클 지연, sys_clk 동기)
    // -------------------------------------------------------
    reg bclk_d, lrclk_d;
    wire bclk_fall   = !bclk   && bclk_d;
    wire lrclk_fall  = !lrclk  && lrclk_d;
    wire lrclk_rise  =  lrclk  && !lrclk_d;

    always @(posedge clk) begin
        if (rst) begin
            bclk_d  <= 1'b0;
            lrclk_d <= 1'b0;
        end else begin
            bclk_d  <= bclk;
            lrclk_d <= lrclk;
        end
    end

    // -------------------------------------------------------
    // I2S 직렬화 (Left-Justified 포맷)
    // - LRCLK 하강: L 채널 샘플 로드, 비트 카운터 초기화
    // - LRCLK 상승: R 채널 샘플 로드, 비트 카운터 초기화
    // - BCLK 하강: 현재 채널의 다음 비트를 SDIN에 출력 (MSB 우선)
    // -------------------------------------------------------
    reg [15:0] l_shift, r_shift;  // 현재 프레임 직렬화 버퍼
    reg [4:0]  bit_cnt;           // 0..15: 유효 비트, 16+: 패딩 0
    reg        sdin_r;
    reg        frame_done_r;

    wire frame_done_pulse = frame_done_r;

    always @(posedge clk) begin
        if (rst) begin
            l_shift      <= 16'h0000;
            r_shift      <= 16'h0000;
            bit_cnt      <= 5'd0;
            sdin_r       <= 1'b0;
            frame_done_r <= 1'b0;
        end else begin
            frame_done_r <= 1'b0; // 1사이클 펄스

            if (lrclk_fall) begin
                // L 채널 시작: l_reg 래치, 카운터 초기화
                l_shift <= l_reg;
                bit_cnt <= 5'd0;
                sdin_r  <= 1'b0;
            end else if (lrclk_rise) begin
                // R 채널 시작: r_reg 래치, 카운터 초기화, frame_done 펄스
                r_shift      <= r_reg;
                bit_cnt      <= 5'd0;
                sdin_r       <= 1'b0;
                frame_done_r <= 1'b1; // 한 프레임 완료 (L+R 한 쌍)
            end else if (bclk_fall && tx_en) begin
                if (bit_cnt <= 5'd15) begin
                    // MSB 우선 출력 후 왼쪽 시프트
                    if (!lrclk) begin
                        sdin_r  <= l_shift[15];
                        l_shift <= {l_shift[14:0], 1'b0};
                    end else begin
                        sdin_r  <= r_shift[15];
                        r_shift <= {r_shift[14:0], 1'b0};
                    end
                    bit_cnt <= bit_cnt + 5'd1;
                end else begin
                    sdin_r <= 1'b0; // 비트 16 이후: 패딩 0
                end
            end else if (!tx_en) begin
                sdin_r <= 1'b0;
            end
        end
    end

    assign sdin = sdin_r;

    // mclk는 basys3_top에서 Pmod JA4로 직접 연결한다 (여기서는 무시)
    // verilator lint_off UNUSED
    wire _unused_mclk = mclk;
    // verilator lint_on UNUSED

endmodule

// mmio_bus.v — MMIO 주소 디코더 (64KB 창, addr[31:16] 기준)
// 창 크기를 64KB로 키워 i2s_tx의 0xFFF0~FFFC(mgmt 레지스터)에 접근 가능하게 한다.
// sel_X: addr[31:16]으로 슬레이브 선택
// addr[15:0]: 슬레이브 내 오프셋으로 그대로 전달
`timescale 1ns/1ps
module mmio_bus (
    input  wire        valid,
    input  wire        we,
    input  wire [31:0] addr,
    input  wire [31:0] wdata,
    // 슬레이브 선택
    output wire        sel_gpio,
    output wire        sel_uart,
    output wire        sel_i2s,
    // 슬레이브 읽기 데이터
    input  wire [31:0] rdata_gpio,
    input  wire [31:0] rdata_uart,
    input  wire [31:0] rdata_i2s,
    // 마스터 읽기 데이터
    output reg  [31:0] rdata,
    output wire        ready
);
    assign sel_gpio = valid && (addr[31:16] == 16'h1000);
    assign sel_uart = valid && (addr[31:16] == 16'h1001);
    assign sel_i2s  = valid && (addr[31:16] == 16'h1002);
    assign ready    = 1'b1; // 모든 접근은 1사이클

    always @* begin
        if      (sel_gpio) rdata = rdata_gpio;
        else if (sel_uart) rdata = rdata_uart;
        else if (sel_i2s)  rdata = rdata_i2s;
        else               rdata = 32'h0000_0000;
    end
endmodule

// GPIO: 0x00 LED(RW, 16bit), 0x04 SW(RO, 2단 동기화된 스위치 16bit)
module gpio (
    input  wire        clk,
    input  wire        rst,
    input  wire        sel,
    input  wire        we,
    input  wire [7:0]  off,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    input  wire [15:0] sw,
    output wire [15:0] led
);
    reg [15:0] led_r;
    reg [15:0] sw_s1, sw_s2;

// UART 송신(8N1): 0x00 DATA(WO, busy일 때 쓰기는 무시), 0x04 STATUS(RO, bit0=busy)
module uart_tx #(
    parameter CLK_HZ = 100_000_000,
    parameter BAUD   = 115200
) (
    input  wire        clk,
    input  wire        rst,
    input  wire        sel,
    input  wire        we,
    input  wire [7:0]  off,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    output wire        txd
);
    localparam DIV = CLK_HZ / BAUD;

    reg [9:0]  sh;
    reg [3:0]  nbit;
    reg [15:0] cnt;
    reg        busy;
    reg        tx;
    assign txd = tx;

    wire wr_data = sel && we && (off == 8'h00);

    always @(posedge clk) begin
        if (rst) begin
            busy <= 1'b0;
            tx   <= 1'b1;
            cnt  <= 16'd0;
            nbit <= 4'd0;
            sh   <= 10'h3FF;
        end else if (!busy) begin
            tx <= 1'b1;
            if (wr_data) begin
                sh   <= {1'b1, wdata[7:0], 1'b0};
                busy <= 1'b1;
                cnt  <= DIV - 1;
                nbit <= 4'd0;
                tx   <= 1'b0;
            end
        end else begin
            if (cnt == 16'd0) begin
                cnt <= DIV - 1;
                if (nbit == 4'd9) begin
                    busy <= 1'b0;
                    tx   <= 1'b1;
                end else begin
                    nbit <= nbit + 4'd1;
                    tx   <= sh[nbit + 4'd1];
                end
            end else begin
                cnt <= cnt - 16'd1;
            end
        end
    end

    always @* begin
        case (off)
            8'h04:   rdata = {31'd0, busy};
            default: rdata = 32'h0000_0000;
        endcase
    end
endmodule

// demo_master.v — I2S TX MMIO 체커 FSM (7상태)
// I2S 초기화 → IRQ 폴링 → frame_done 카운터 → LED 갱신
// 버스 주소맵 (64KB 창, addr[31:16] 기준):
//   GPIO  0x1000_xxxx: LED=0x00, SW=0x04
//   UART  0x1001_xxxx: DATA=0x00, STATUS=0x04  (미사용)
//   I2S   0x1002_xxxx: CTRL=0x0000, STATUS=0x0004,
//                      L_DATA=0x0008, R_DATA=0x000C,
//                      IRQ_STATUS=0xFFF8, IRQ_ENABLE=0xFFFC
`timescale 1ns/1ps
module demo_master (
    input  wire        clk,
    input  wire        rst,
    // mmio-lite 마스터 포트
    output reg         m_valid,
    output reg         m_we,
    output reg  [31:0] m_addr,
    output reg  [31:0] m_wdata,
    input  wire [31:0] m_rdata,
    input  wire        m_ready
);
    // 상태 인코딩
    localparam S_WR_L    = 3'd0; // L_DATA = 0xA5A5
    localparam S_WR_R    = 3'd1; // R_DATA = 0x5A5A
    localparam S_EN_TX   = 3'd2; // CTRL   = 1 (TX_EN)
    localparam S_EN_IRQ  = 3'd3; // IRQ_ENABLE = 1
    localparam S_RD_IRQ  = 3'd4; // IRQ_STATUS 읽기; bit[0]=1이면 → S_CL_IRQ
    localparam S_CL_IRQ  = 3'd5; // IRQ_STATUS W1C (bit[0]=1 써서 클리어)
    localparam S_WR_LED  = 3'd6; // GPIO LED에 frame_done 카운터 출력

    reg [2:0]  state;
    reg [15:0] frame_cnt; // frame_done 발생 횟수 카운터

    // 상태 전이 (버스 핸드셰이크: m_valid & m_ready → 완료)
    always @(posedge clk) begin
        if (rst) begin
            state     <= S_WR_L;
            frame_cnt <= 16'd0;
            m_valid   <= 1'b0;
            m_we      <= 1'b0;
            m_addr    <= 32'd0;
            m_wdata   <= 32'd0;
        end else begin
            if (m_valid && m_ready) begin
                // 현재 트랜잭션 완료
                m_valid <= 1'b0;
                case (state)
                    S_WR_L:   state <= S_WR_R;
                    S_WR_R:   state <= S_EN_TX;
                    S_EN_TX:  state <= S_EN_IRQ;
                    S_EN_IRQ: state <= S_RD_IRQ;
                    S_RD_IRQ: begin
                        // 읽기 완료 — rdata를 평가한다
                        if (m_rdata[0]) begin
                            frame_cnt <= frame_cnt + 16'd1;
                            state     <= S_CL_IRQ;
                        end
                        // bit[0]=0이면 같은 상태를 반복 (다음 사이클에 valid 다시 설정됨)
                    end
                    S_CL_IRQ: state <= S_WR_LED;
                    S_WR_LED: state <= S_RD_IRQ; // 계속 폴링
                    default:  state <= S_RD_IRQ;
                endcase
            end
        end
    end

    // 출력 조합 블록 (m_valid가 0일 때 다음 트랜잭션을 즉시 발행)
    always @(posedge clk) begin
        if (rst) begin
            // 리셋 직후 초기 트랜잭션 준비는 아래 else 블록이 처리
        end else if (!m_valid) begin
            m_valid <= 1'b1;
            case (state)
                S_WR_L: begin
                    m_we    <= 1'b1;
                    m_addr  <= 32'h1002_0008; // I2S L_DATA
                    m_wdata <= 32'h0000_A5A5;
                end
                S_WR_R: begin
                    m_we    <= 1'b1;
                    m_addr  <= 32'h1002_000C; // I2S R_DATA
                    m_wdata <= 32'h0000_5A5A;
                end
                S_EN_TX: begin
                    m_we    <= 1'b1;
                    m_addr  <= 32'h1002_0000; // I2S CTRL
                    m_wdata <= 32'h0000_0001; // TX_EN=1
                end
                S_EN_IRQ: begin
                    m_we    <= 1'b1;
                    m_addr  <= 32'h1002_FFFC; // I2S IRQ_ENABLE
                    m_wdata <= 32'h0000_0001; // frame_done IRQ 활성화
                end
                S_RD_IRQ: begin
                    m_we    <= 1'b0;
                    m_addr  <= 32'h1002_FFF8; // I2S IRQ_STATUS
                    m_wdata <= 32'd0;
                end
                S_CL_IRQ: begin
                    m_we    <= 1'b1;
                    m_addr  <= 32'h1002_FFF8; // I2S IRQ_STATUS W1C
                    m_wdata <= 32'h0000_0001; // bit[0]=1 → W1C 클리어
                end
                S_WR_LED: begin
                    m_we    <= 1'b1;
                    m_addr  <= 32'h1000_0000; // GPIO LED
                    m_wdata <= {16'd0, frame_cnt};
                end
                default: begin
                    m_we    <= 1'b0;
                    m_addr  <= 32'd0;
                    m_wdata <= 32'd0;
                end
            endcase
        end
    end

endmodule

// tb_i2s.v — I2S TX + 클럭 생성기 통합 검증 테스트벤치
// 검사 항목:
//   CHECK 1: BCLK 주기 = 320 ns (100 MHz / 32 × 2 = 3.125 MHz)
//   CHECK 2: LRCLK 주기 = 10240 ns (100 MHz / 1024 = 97.656 kHz)
//   CHECK 3: LRCLK 반주기당 BCLK 하강 에지 15~16개 (fork...join + disable)
//   CHECK 4: L_DATA=0x8001 기록 후 TX_EN 활성화; LRCLK 하강 뒤 첫 번째·두 번째
//            BCLK 하강 에지에서 SDIN = 1(bit15), 0(bit14)
// 통과하면 "PASS all checks", 실패하면 "FAIL: N check(s) failed"로 시작하는 줄 출력
// 비교는 !==을 사용해 X/Z도 실패로 센다.
`timescale 1ns/1ps
module tb_i2s;

    // -------------------------------------------------------
    // 신호 선언
    // -------------------------------------------------------
    reg         clk;
    reg         rst;
    reg         sel;
    reg         we;
    reg  [15:0] off_r;
    reg  [31:0] wdata;
    wire [31:0] rdata;
    wire        sdin;
    wire        irq;
    wire        mclk, bclk, lrclk;

    // 모듈 수준 보조 변수 (iverilog 호환)
    integer     fail_cnt;
    time        t0, t1;
    integer     bclk_half_cnt;

    // -------------------------------------------------------
    // DUT 인스턴스
    // -------------------------------------------------------
    i2s_clk_gen u_clkgen (
        .clk   (clk),
        .rst   (rst),
        .mclk  (mclk),
        .bclk  (bclk),
        .lrclk (lrclk)
    );

    i2s_tx u_dut (
        .clk   (clk),
        .rst   (rst),
        .sel   (sel),
        .we    (we),
        .off   (off_r),
        .wdata (wdata),
        .rdata (rdata),
        .mclk  (mclk),
        .bclk  (bclk),
        .lrclk (lrclk),
        .sdin  (sdin),
        .irq   (irq)
    );

    // -------------------------------------------------------
    // 100 MHz 클럭 (10 ns 주기)
    // -------------------------------------------------------
    initial clk = 1'b0;
    always  #5 clk = ~clk;

    // -------------------------------------------------------
    // do_write 태스크 — 1사이클 MMIO 쓰기
    // -------------------------------------------------------
    task do_write;
        input [15:0] addr;
        input [31:0] data;
        begin
            @(posedge clk); #1;
            sel = 1'b1; we = 1'b1; off_r = addr; wdata = data;
            @(posedge clk); #1;
            sel = 1'b0; we = 1'b0;
        end
    endtask

    // -------------------------------------------------------
    // 메인 테스트
    // -------------------------------------------------------
    initial begin
        fail_cnt = 0;
        sel  = 1'b0; we   = 1'b0;
        off_r  = 16'h0000; wdata = 32'h0;

        // 리셋
        rst = 1'b1;
        repeat (4) @(posedge clk);
        @(posedge clk); #1;
        rst = 1'b0;

        // ---- CHECK 1: BCLK 주기 = 320 ns ----
        @(posedge bclk); t0 = $time;
        @(posedge bclk); t1 = $time;
        if ((t1 - t0) !== 64'd320) begin
            $display("FAIL CHECK1: BCLK period expected 320 ns, got %0d ns", t1-t0);
            fail_cnt = fail_cnt + 1;
        end else begin
            $display("CHECK 1 PASS: BCLK period = %0d ns", t1-t0);
        end

        // ---- CHECK 2: LRCLK 주기 = 10240 ns ----
        @(posedge lrclk); t0 = $time;
        @(posedge lrclk); t1 = $time;
        if ((t1 - t0) !== 64'd10240) begin
            $display("FAIL CHECK2: LRCLK period expected 10240 ns, got %0d ns", t1-t0);
            fail_cnt = fail_cnt + 1;
        end else begin
            $display("CHECK 2 PASS: LRCLK period = %0d ns", t1-t0);
        end

        // ---- CHECK 3: LRCLK 반주기당 BCLK 하강 에지 15~16개 ----
        // bclk와 lrclk는 같은 계수기 출발점에서 동기화되어 있어
        // lrclk 에지와 bclk 에지가 같은 사이클에 겹친다.
        // @(negedge lrclk) 이후 카운트를 시작하므로 겹친 에지는 제외되고
        // @(posedge lrclk) 에서 카운터를 멈춘다. 15 또는 16을 허용한다.
        bclk_half_cnt = 0;
        @(negedge lrclk);
        fork
            begin : cnt_bclk_blk
                forever @(negedge bclk) bclk_half_cnt = bclk_half_cnt + 1;
            end
            begin
                @(posedge lrclk);
                disable cnt_bclk_blk;
            end
        join
        if (bclk_half_cnt < 15 || bclk_half_cnt > 16) begin
            $display("FAIL CHECK3: BCLK negedges per LRCLK half expected 15-16, got %0d",
                     bclk_half_cnt);
            fail_cnt = fail_cnt + 1;
        end else begin
            $display("CHECK 3 PASS: BCLK negedges per LRCLK half = %0d", bclk_half_cnt);
        end

        // ---- CHECK 4: SDIN MSB-우선 직렬화 ----
        // L_DATA = 0x8001 (bit15=1, bit14=0, ... bit1=1, bit0=0 (미전송))
        // TX_EN 활성화 → LRCLK 하강 에지 대기 → 첫 BCLK 하강 에지에서 SDIN=1(bit15)
        //                                      → 두 번째 BCLK 하강 에지에서 SDIN=0(bit14)
        do_write(16'h0008, 32'h00008001);  // L_DATA = 0x8001
        do_write(16'h0000, 32'h00000001);  // CTRL: TX_EN = 1

        @(negedge lrclk);    // lrclk 하강 → l_reg 래치됨 (동시에 bclk도 하강)
        @(negedge bclk);     // 첫 번째 유효 BCLK 하강 (bit15 출력 사이클)
        if (sdin !== 1'b1) begin
            $display("FAIL CHECK4a: SDIN[bit15] expected 1, got %b (L_DATA=0x8001)", sdin);
            fail_cnt = fail_cnt + 1;
        end else begin
            $display("CHECK 4a PASS: SDIN[bit15]=1");
        end

        @(negedge bclk);     // 두 번째 BCLK 하강 (bit14 출력 사이클)
        if (sdin !== 1'b0) begin
            $display("FAIL CHECK4b: SDIN[bit14] expected 0, got %b (L_DATA=0x8001)", sdin);
            fail_cnt = fail_cnt + 1;
        end else begin
            $display("CHECK 4b PASS: SDIN[bit14]=0");
        end

        // ---- 최종 결과 출력 ----
        repeat (10) @(posedge clk);
        if (fail_cnt === 0)
            $display("PASS all checks");
        else
            $display("FAIL: %0d check(s) failed", fail_cnt);
        $finish;
    end

    // -------------------------------------------------------
    // 타임아웃: 2 ms
    // -------------------------------------------------------
    initial begin
        #2_000_000;
        $display("FAIL: simulation timeout at 2ms");
        $finish;
    end

endmodule

## 타깃: lint (verilator), sim (iverilog+vvp), synth (yosys)
## CI는 이 파일을 사용하므로 경로·이름을 바꾸지 않는다.

RTL_DIR  = rtl

## SoC 전체 RTL (합성·린트 대상)
RTL_ALL  = $(RTL_DIR)/i2s_clk_gen.v \
           $(RTL_DIR)/i2s_tx.v \
           $(RTL_DIR)/mmio_bus.v \
           $(RTL_DIR)/gpio.v \
           $(RTL_DIR)/uart_tx.v \
           $(RTL_DIR)/demo_master.v \
           $(RTL_DIR)/soc_top.v \
           $(RTL_DIR)/basys3_top.v

## 시뮬레이션에 필요한 RTL (tb가 직접 사용하는 모듈)
TB_SRC   = $(RTL_DIR)/i2s_clk_gen.v \
           $(RTL_DIR)/i2s_tx.v

TB_FILE  = $(TB_DIR)/tb_i2s.v

.PHONY: all lint sim synth clean

all: lint sim synth

## ---- 린트 (verilator) ----
lint:
	mkdir -p $(BUILD)
	verilator --lint-only -Wall -Wno-fatal \
	    --top-module basys3_top \
	    $(RTL_ALL) \
	    2>&1 | tee $(BUILD)/lint.log
	@echo "lint done"

## ---- 시뮬레이션 (iverilog + vvp) ----
sim:
	mkdir -p $(BUILD)
	iverilog -g2005 -Wall \
	    -o $(BUILD)/sim.vvp \
	    $(TB_FILE) $(TB_SRC) \
	    2>&1 | tee $(BUILD)/iverilog.log
	vvp $(BUILD)/sim.vvp 2>&1 | tee $(BUILD)/sim.log
	@grep -q "^PASS" $(BUILD)/sim.log || \
	    (echo "FAIL: simulation did not print PASS"; exit 1)
	@echo "sim done"

## ---- 합성 (yosys, Xilinx xc7 흐름) ----
synth:
	mkdir -p $(BUILD)
	yosys -q -p " \
	    read_verilog $(RTL_ALL); \
	    synth_xilinx -top basys3_top -family xc7; \
	    stat; \
	    " 2>&1 | tee $(BUILD)/synth.log
	@echo "synth done"

clean:
	rm -rf $(BUILD)

위험·한계

  • 샘플레이트 97.656 kHz는 비표준이다. Pmod I2S2의 CS4344 DAC는 4~200 kHz를 허용하므로 동작은 가능하나 오디오 피치가 2배 이상 높게 들릴 수 있다.
  • JA Pmod 핀 배치는 Digilent 마스터 XDC(rev B 이후)와 대조가 필요하다.
  • i2s_clk_gen은 sys_clk 도메인 순수 분주기이므로 Vivado 타이밍 분석에서 BCLK·MCLK·LRCLK를 generated clock으로 선언해야 한다(create_generated_clock). XDC에 미작성 상태.
  • 표준 Philips I2S의 1 BCLK 오프셋 없이 Left-Justified 형식을 사용한다. CS4344는 LJ 모드를 지원하나 주소 세팅(MODE 핀)을 확인해야 한다.
