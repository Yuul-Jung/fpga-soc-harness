단상 풀브리지 SPWM 생성기 AXI4-Lite IP — 데드타임 레지스터 포함

32-항목 사인 LUT 기반 단상 SPWM 발생기. 소프트웨어에서 AXI4-Lite 레지스터로 반송파 주기·변조 지수·데드타임을 설정. 보완 출력(HIN_A/LIN_A, HIN_B/LIN_B)으로 풀브리지 게이트 드라이버 직접 구동. 슛스루 방지 FSM 내장.

린트: 건너뜀 (verilator 없음)시뮬레이션: 건너뜀 (iverilog 없음)합성: 건너뜀 (yosys 없음)보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다 · 기준 2026-11-05. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • AXI4-Lite 슬레이브로 CTRL/PERIOD/MOD_IDX/DEADTIME/STATUS/ID/PHASE_CTR 7개 레지스터 제공
  • 삼각파 반송파 vs 사인 LUT 기준파 비교로 raw SPWM 생성
  • 데드타임 FSM: 천이 시 HIN·LIN 모두 비활성 → 지연 후 목표 상태 → 슛스루 원천 차단
  • TRIP 입력(외부 고장) 또는 소프트웨어 비활성화 시 즉시 모든 출력 비활성
  • iverilog 시뮬레이션에서 TC1~TC5 자기점검 PASS, yosys 합성 성공

범위 밖

  • 세 상 인버터 또는 다채널 SPWM
  • 폐루프 전압/전류 제어 (I-079가 담당)
  • 게이트 드라이버 IC(IRS2110 등) 회로 설계 — 연결 절차만 문서화
  • MicroBlaze V CPU 통합 — IP 단독 동작 데모만 포함

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. 시뮬레이션·합성 결과는 CI가 기록한다.

2. 계통도

클럭: 100 MHz (Basys3 W5), 리셋 btnC active-high

diagram.svg로 따로 받을 수 있다.

버스 규약: AXI4-Lite

신호방향설명
s_awaddr[31:0]master→slave쓰기 주소
s_awvalidmaster→slave주소 유효
s_awreadyslave→master주소 수락
s_wdata[31:0]master→slave쓰기 데이터
s_wstrb[3:0]master→slave바이트 스트로브 (4'hF만 처리)
s_wvalidmaster→slave데이터 유효
s_wreadyslave→master데이터 수락
s_bresp[1:0]slave→master응답 (항상 OKAY)
s_bvalidslave→master응답 유효
s_breadymaster→slave응답 수락
s_araddr[31:0]master→slave읽기 주소
s_arvalidmaster→slave읽기 주소 유효
s_arreadyslave→master읽기 주소 수락
s_rdata[31:0]slave→master읽기 데이터
s_rresp[1:0]slave→master읽기 응답 (항상 OKAY)
s_rvalidslave→master읽기 데이터 유효
s_rreadymaster→slave읽기 데이터 수락

WSTRB는 전체 워드(4'hF)만 처리, 비트 마스크 미지원. bresp/rresp는 항상 2'b00(OKAY). 없는 주소 읽으면 0 반환.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스AXI4-Lite
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 부분 적합
이식 계획mbv-frozen-v2 free_slot [16] = 0x4016_0000 사용 제안. intc 13 사용 제안(STATUS[1] TRIP_LATCH 인터럽트). 프로젝트 인덱스 표가 동결한다.

4. 메모리맵

spwm_ip 0x4016_0000 크기 0x10000

오프셋이름접근설명
0x00CTRLRW[0]=EN(IP 활성화), [1]=TRIP_CLR(1 write → TRIP latch 해제)
0x04PERIODRW[15:0] 반송파 반주기 클럭 틱 (기본 5000 = 10 kHz @ 100 MHz)
0x08MOD_IDXRW[14:0] Q15 변조 지수 0..32767 (기본 26214 ≈ 80%)
0x0CDEADTIMERW[9:0] 데드타임 클럭 틱 (기본 50 = 500 ns @ 100 MHz)
0x10STATUSRO[0]=ACTIVE, [1]=TRIP_LATCH
0x14IDRO0x5350_5731 고정 (ASCII SPW1)
0x18PHASE_CTRRO[4:0] 현재 사인 LUT 인덱스 (디버그 읽기)

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

디지털 계통도(diagram.svg)와 별개. 게이트 드라이버 부트스트랩 회로·MOSFET H-브리지·전류 감지 저항은 미작성. 하드웨어 테스트 전 작성 필요.

id부품인터페이스신호 전압구분레벨 변환비고
gate_drvIRS2110 또는 IR2110 게이트 드라이버 (2개)PMOD JB3.3 V외부 모듈IRS2110 내장 로직 대응 (별도 레벨 시프터 불필요)Pmod 3.3V → IRS2110 HIN/LIN 입력 호환. 출력 전압(HO/LO)은 부트스트랩 회로로 15V. 레벨 변환은 IRS2110 내장 로직으로 대신한다. 별도 레벨 시프터 불필요.

Basys3 FPGA 핀은 3.3V 신호만 직접 받는다. 5V·12V·모터·릴레이는 직결하지 않는다.

7. 실행 소스

저장소의 capstones/mmio-spwm-deadtime-ip/에 있는 파일 그대로다. 이 문서는 파일에서 읽어 넣은 것이므로 항상 일치한다. 소스 전체 내려받기 (.zip) · GitHub에서 보기

rtl/spwm_ip.v 386줄
// spwm_ip.v — 단상 풀브리지 SPWM 생성기 AXI4-Lite IP
// 32-항목 Q15 사인 LUT 기반 SPWM + 데드타임 FSM (레그 A/B 각 1개).
// 소프트웨어에서 AXI4-Lite 레지스터로 반송파 주기·변조 지수·데드타임·EN/TRIP 제어.
// Verilog-2001. iverilog/verilator/yosys 호환.
// 출처: capstones/mmio-spwm-deadtime-ip/capstone.json
`default_nettype none
`timescale 1ns/1ps

// ---------------------------------------------------------------------------
// 레지스터 오프셋 (기저 주소 BASE_ADDR 기준, [3:2] 사용)
// 0x00 CTRL    [0]=EN [1]=TRIP_CLR(1-write clears latch)
// 0x04 PERIOD  [15:0] 반송파 반주기 틱 (기본 5000)
// 0x08 MOD_IDX [14:0] Q15 변조 지수 0..32767
// 0x0C DEADTIME[9:0]  데드타임 클럭 틱 (기본 50 = 500 ns)
// 0x10 STATUS  [0]=ACTIVE [1]=TRIP_LATCH  (읽기 전용)
// 0x14 ID      0x5350_5731 "SPW1"         (읽기 전용)
// 0x18 PHASE_CTR[4:0] 사인 LUT 인덱스    (읽기 전용)
// ---------------------------------------------------------------------------

module spwm_ip #(
    parameter BASE_ADDR = 32'h4016_0000
) (
    input  wire        s_axi_aclk,
    input  wire        s_axi_aresetn,
    // AW
    input  wire [31:0] s_axi_awaddr,
    input  wire        s_axi_awvalid,
    output reg         s_axi_awready,
    // W
    input  wire [31:0] s_axi_wdata,
    input  wire [3:0]  s_axi_wstrb,
    input  wire        s_axi_wvalid,
    output reg         s_axi_wready,
    // B
    output reg  [1:0]  s_axi_bresp,
    output reg         s_axi_bvalid,
    input  wire        s_axi_bready,
    // AR
    input  wire [31:0] s_axi_araddr,
    input  wire        s_axi_arvalid,
    output reg         s_axi_arready,
    // R
    output reg  [31:0] s_axi_rdata,
    output reg  [1:0]  s_axi_rresp,
    output reg         s_axi_rvalid,
    input  wire        s_axi_rready,
    // 외부 입력
    input  wire        trip_in,   // 1 = 외부 고장(즉시 트립)
    // SPWM 출력 (H-브리지 게이트 드라이버로)
    output wire        hin_a,     // 레그 A 상단
    output wire        lin_a,     // 레그 A 하단
    output wire        hin_b,     // 레그 B 상단
    output wire        lin_b,     // 레그 B 하단
    // 인터럽트
    output wire        irq        // STATUS[1] TRIP_LATCH
);

    // -----------------------------------------------------------------------
    // 레지스터
    // -----------------------------------------------------------------------
    reg         reg_en;
    reg  [15:0] reg_period;      // 반송파 반주기 (기본 5000)
    reg  [14:0] reg_mod_idx;     // Q15 변조 지수 (기본 26214)
    reg  [9:0]  reg_deadtime;    // 데드타임 틱 (기본 50)
    reg         trip_latch;      // 트립 래치

    // -----------------------------------------------------------------------
    // 사인 LUT 함수 (32항목, Q15 부호 있음)
    // sin(2π*i/32) × 32767, i=0..31
    // -----------------------------------------------------------------------
    function signed [15:0] sine_lut;
        input [4:0] idx;
        begin
            case (idx)
            5'd0:  sine_lut = 16'sd0;
            5'd1:  sine_lut = 16'sd6393;
            5'd2:  sine_lut = 16'sd12539;
            5'd3:  sine_lut = 16'sd18204;
            5'd4:  sine_lut = 16'sd23170;
            5'd5:  sine_lut = 16'sd27245;
            5'd6:  sine_lut = 16'sd30273;
            5'd7:  sine_lut = 16'sd32137;
            5'd8:  sine_lut = 16'sd32767;
            5'd9:  sine_lut = 16'sd32137;
            5'd10: sine_lut = 16'sd30273;
            5'd11: sine_lut = 16'sd27245;
            5'd12: sine_lut = 16'sd23170;
            5'd13: sine_lut = 16'sd18204;
            5'd14: sine_lut = 16'sd12539;
            5'd15: sine_lut = 16'sd6393;
            5'd16: sine_lut = 16'sd0;
            5'd17: sine_lut = -16'sd6393;
            5'd18: sine_lut = -16'sd12539;
            5'd19: sine_lut = -16'sd18204;
            5'd20: sine_lut = -16'sd23170;
            5'd21: sine_lut = -16'sd27245;
            5'd22: sine_lut = -16'sd30273;
            5'd23: sine_lut = -16'sd32137;
            5'd24: sine_lut = -16'sd32767;
            5'd25: sine_lut = -16'sd32137;
            5'd26: sine_lut = -16'sd30273;
            5'd27: sine_lut = -16'sd27245;
            5'd28: sine_lut = -16'sd23170;
            5'd29: sine_lut = -16'sd18204;
            5'd30: sine_lut = -16'sd12539;
            5'd31: sine_lut = -16'sd6393;
            default: sine_lut = 16'sd0;
            endcase
        end
    endfunction

    // -----------------------------------------------------------------------
    // SPWM 코어: 삼각 반송파 + 사인 기준파 비교 → raw_pwm
    // -----------------------------------------------------------------------
    reg  [15:0] carrier;         // 삼각파 카운터 0..reg_period
    reg         car_dir;         // 0=상승, 1=하강
    reg  [4:0]  phase_ctr;       // 사인 LUT 인덱스 0..31

    wire signed [15:0] s_q15    = sine_lut(phase_ctr);
    // 변조 지수 × 사인값 → Q30, >>15 → Q15 오프셋
    wire signed [30:0] ms_prod  = $signed({1'b0, reg_mod_idx}) * s_q15;
    // 오프셋 범위: -32767*32767 >> 15 ≈ -32767 ~ +32767
    wire signed [15:0] ref_off  = ms_prod[30:15];
    // 기준파: PERIOD/2(중심) + 오프셋
    wire signed [17:0] ref_wide = $signed({2'b00, {1'b0, reg_period[15:1]}})
                                + $signed({{2{ref_off[15]}}, ref_off});
    // 범위를 [0, reg_period]로 클램프
    wire [15:0] sine_ref = (ref_wide[17]) ? 16'd0 :          // 음수면 0
                           (ref_wide > $signed({2'b00, reg_period})) ? reg_period :
                           ref_wide[15:0];

    wire raw_pwm = reg_en && !trip_latch && (sine_ref > carrier);

    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn || !reg_en || trip_latch) begin
            carrier   <= 16'd0;
            car_dir   <= 1'b0;
            phase_ctr <= 5'd0;
        end else begin
            if (car_dir == 1'b0) begin
                if (carrier >= reg_period) begin
                    car_dir   <= 1'b1;
                    carrier   <= carrier - 1'b1;
                    phase_ctr <= phase_ctr + 1'b1; // 반주기마다 위상 전진
                end else
                    carrier <= carrier + 1'b1;
            end else begin
                if (carrier == 16'd0) begin
                    car_dir   <= 1'b0;
                    carrier   <= carrier + 1'b1;
                    phase_ctr <= phase_ctr + 1'b1;
                end else
                    carrier <= carrier - 1'b1;
            end
        end
    end

    // -----------------------------------------------------------------------
    // 데드타임 FSM (레그 A용)
    // 천이 감지 → 양쪽 비활성 → dt_ticks 카운트 → 목표 상태
    // -----------------------------------------------------------------------
    reg  [1:0] dtA_st;           // 0=STEADY 1=DT_RISE 2=DT_FALL
    reg  [9:0] dtA_cnt;
    reg        pwm_prev;
    reg        hin_a_r, lin_a_r;

    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn || trip_latch || !reg_en) begin
            dtA_st  <= 2'd0;
            dtA_cnt <= 10'd0;
            hin_a_r <= 1'b0;
            lin_a_r <= 1'b0;
            pwm_prev<= 1'b0;
        end else begin
            pwm_prev <= raw_pwm;
            case (dtA_st)
            2'd0: begin // STEADY
                if (raw_pwm && !pwm_prev) begin  // 상승 엣지 → 데드타임 후 HIN
                    hin_a_r <= 1'b0;
                    lin_a_r <= 1'b0;
                    dtA_cnt <= reg_deadtime;
                    dtA_st  <= 2'd1;
                end else if (!raw_pwm && pwm_prev) begin  // 하강 엣지 → 데드타임 후 LIN
                    hin_a_r <= 1'b0;
                    lin_a_r <= 1'b0;
                    dtA_cnt <= reg_deadtime;
                    dtA_st  <= 2'd2;
                end else begin
                    hin_a_r <= raw_pwm;
                    lin_a_r <= !raw_pwm;
                end
            end
            2'd1: begin // DT_RISE: 카운트 후 HIN=1
                if (dtA_cnt == 10'd0) begin
                    hin_a_r <= 1'b1;
                    lin_a_r <= 1'b0;
                    dtA_st  <= 2'd0;
                end else
                    dtA_cnt <= dtA_cnt - 1'b1;
            end
            2'd2: begin // DT_FALL: 카운트 후 LIN=1
                if (dtA_cnt == 10'd0) begin
                    hin_a_r <= 1'b0;
                    lin_a_r <= 1'b1;
                    dtA_st  <= 2'd0;
                end else
                    dtA_cnt <= dtA_cnt - 1'b1;
            end
            default: dtA_st <= 2'd0;
            endcase
        end
    end

    // -----------------------------------------------------------------------
    // 데드타임 FSM (레그 B용) — raw_pwm 반전 입력
    // -----------------------------------------------------------------------
    reg  [1:0] dtB_st;
    reg  [9:0] dtB_cnt;
    reg        npwm_prev;
    reg        hin_b_r, lin_b_r;
    wire       raw_pwm_b = !raw_pwm;  // 레그 B는 반전

    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn || trip_latch || !reg_en) begin
            dtB_st   <= 2'd0;
            dtB_cnt  <= 10'd0;
            hin_b_r  <= 1'b0;
            lin_b_r  <= 1'b0;
            npwm_prev<= 1'b0;
        end else begin
            npwm_prev <= raw_pwm_b;
            case (dtB_st)
            2'd0: begin
                if (raw_pwm_b && !npwm_prev) begin
                    hin_b_r <= 1'b0;
                    lin_b_r <= 1'b0;
                    dtB_cnt <= reg_deadtime;
                    dtB_st  <= 2'd1;
                end else if (!raw_pwm_b && npwm_prev) begin
                    hin_b_r <= 1'b0;
                    lin_b_r <= 1'b0;
                    dtB_cnt <= reg_deadtime;
                    dtB_st  <= 2'd2;
                end else begin
                    hin_b_r <= raw_pwm_b;
                    lin_b_r <= !raw_pwm_b;
                end
            end
            2'd1: begin
                if (dtB_cnt == 10'd0) begin
                    hin_b_r <= 1'b1;
                    lin_b_r <= 1'b0;
                    dtB_st  <= 2'd0;
                end else
                    dtB_cnt <= dtB_cnt - 1'b1;
            end
            2'd2: begin
                if (dtB_cnt == 10'd0) begin
                    hin_b_r <= 1'b0;
                    lin_b_r <= 1'b1;
                    dtB_st  <= 2'd0;
                end else
                    dtB_cnt <= dtB_cnt - 1'b1;
            end
            default: dtB_st <= 2'd0;
            endcase
        end
    end

    assign hin_a = hin_a_r;
    assign lin_a = lin_a_r;
    assign hin_b = hin_b_r;
    assign lin_b = lin_b_r;
    assign irq   = trip_latch;

    // -----------------------------------------------------------------------
    // 슛스루 감지 assertion (합성 시 무시; 시뮬레이션 전용)
    // -----------------------------------------------------------------------
    // synthesis translate_off
    always @(posedge s_axi_aclk) begin
        if (s_axi_aresetn) begin
            if (hin_a_r && lin_a_r)
                $display("SHOOT-THROUGH DETECTED: hin_a=1 lin_a=1 at time %0t", $time);
            if (hin_b_r && lin_b_r)
                $display("SHOOT-THROUGH DETECTED: hin_b=1 lin_b=1 at time %0t", $time);
        end
    end
    // synthesis translate_on

    // -----------------------------------------------------------------------
    // AXI4-Lite 슬레이브: 쓰기 채널
    // -----------------------------------------------------------------------
    reg [31:0] wr_addr_lat;
    reg [31:0] wr_data_lat;
    reg        wr_addr_valid;
    reg        wr_data_valid;

    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn) begin
            s_axi_awready  <= 1'b1;
            s_axi_wready   <= 1'b1;
            s_axi_bvalid   <= 1'b0;
            s_axi_bresp    <= 2'b00;
            wr_addr_valid  <= 1'b0;
            wr_data_valid  <= 1'b0;
            reg_en         <= 1'b0;
            reg_period     <= 16'd5000;
            reg_mod_idx    <= 15'd26214;
            reg_deadtime   <= 10'd50;
            trip_latch     <= 1'b0;
        end else begin
            // 외부 트립
            if (trip_in)
                trip_latch <= 1'b1;

            // AW 래치
            if (s_axi_awready && s_axi_awvalid) begin
                wr_addr_lat   <= s_axi_awaddr;
                wr_addr_valid <= 1'b1;
                s_axi_awready <= 1'b0;
            end
            // W 래치
            if (s_axi_wready && s_axi_wvalid) begin
                wr_data_lat   <= s_axi_wdata;
                wr_data_valid <= 1'b1;
                s_axi_wready  <= 1'b0;
            end
            // 쓰기 완료: 두 채널 모두 도착하면 처리
            if (wr_addr_valid && wr_data_valid && !s_axi_bvalid) begin
                case (wr_addr_lat[7:2])
                6'd0: begin  // CTRL
                    reg_en <= wr_data_lat[0];
                    if (wr_data_lat[1])
                        trip_latch <= 1'b0;
                end
                6'd1: reg_period   <= wr_data_lat[15:0];   // PERIOD
                6'd2: reg_mod_idx  <= wr_data_lat[14:0];   // MOD_IDX
                6'd3: reg_deadtime <= wr_data_lat[9:0];    // DEADTIME
                default: ; // STATUS/ID/PHASE_CTR는 읽기 전용
                endcase
                s_axi_bvalid   <= 1'b1;
                s_axi_bresp    <= 2'b00;
                wr_addr_valid  <= 1'b0;
                wr_data_valid  <= 1'b0;
            end
            if (s_axi_bvalid && s_axi_bready) begin
                s_axi_bvalid   <= 1'b0;
                s_axi_awready  <= 1'b1;
                s_axi_wready   <= 1'b1;
            end
        end
    end

    // -----------------------------------------------------------------------
    // AXI4-Lite 슬레이브: 읽기 채널
    // -----------------------------------------------------------------------
    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn) begin
            s_axi_arready <= 1'b1;
            s_axi_rvalid  <= 1'b0;
            s_axi_rdata   <= 32'h0;
            s_axi_rresp   <= 2'b00;
        end else begin
            if (s_axi_arready && s_axi_arvalid) begin
                s_axi_arready <= 1'b0;
                s_axi_rvalid  <= 1'b1;
                s_axi_rresp   <= 2'b00;
                case (s_axi_araddr[7:2])
                6'd0: s_axi_rdata <= {30'h0, trip_latch, reg_en};  // CTRL 미러
                6'd1: s_axi_rdata <= {16'h0, reg_period};
                6'd2: s_axi_rdata <= {17'h0, reg_mod_idx};
                6'd3: s_axi_rdata <= {22'h0, reg_deadtime};
                6'd4: s_axi_rdata <= {30'h0, trip_latch, reg_en};  // STATUS
                6'd5: s_axi_rdata <= 32'h5350_5731;                 // ID "SPW1"
                6'd6: s_axi_rdata <= {27'h0, phase_ctr};            // PHASE_CTR
                default: s_axi_rdata <= 32'hDEAD_BEEF;
                endcase
            end
            if (s_axi_rvalid && s_axi_rready) begin
                s_axi_rvalid  <= 1'b0;
                s_axi_arready <= 1'b1;
            end
        end
    end

endmodule

// ---------------------------------------------------------------------------
// demo_master: 순차 AXI4-Lite write 마스터 (CTRL/PERIOD/MOD_IDX/DEADTIME)
// ---------------------------------------------------------------------------
module demo_master #(
    parameter [31:0] BASE = 32'h4016_0000
) (
    input  wire        clk,
    input  wire        resetn,
    // AXI4-Lite write only
    output reg  [31:0] m_awaddr,
    output reg         m_awvalid,
    input  wire        m_awready,
    output reg  [31:0] m_wdata,
    output reg  [3:0]  m_wstrb,
    output reg         m_wvalid,
    input  wire        m_wready,
    input  wire        m_bvalid,
    output wire        m_bready
);
    assign m_bready = 1'b1;

    // 쓰기 목록: (offset, data)
    // 0=PERIOD=5000, 1=MOD_IDX=26214, 2=DEADTIME=50, 3=CTRL.EN=1
    reg [2:0] step;
    reg       done;

    // 각 단계 주소/데이터
    function [31:0] cfg_addr;
        input [2:0] s;
        begin
            case (s)
            3'd0: cfg_addr = BASE + 32'h04; // PERIOD
            3'd1: cfg_addr = BASE + 32'h08; // MOD_IDX
            3'd2: cfg_addr = BASE + 32'h0C; // DEADTIME
            3'd3: cfg_addr = BASE + 32'h00; // CTRL
            default: cfg_addr = BASE;
            endcase
        end
    endfunction

    function [31:0] cfg_data;
        input [2:0] s;
        begin
            case (s)
            3'd0: cfg_data = 32'd5000;  // 10 kHz 반송파 @ 100 MHz
            3'd1: cfg_data = 32'd26214; // 80% 변조 지수
            3'd2: cfg_data = 32'd50;    // 500 ns 데드타임
            3'd3: cfg_data = 32'd1;     // EN=1
            default: cfg_data = 32'd0;
            endcase
        end
    endfunction

    reg [1:0] aw_st;  // 0=전송 대기 1=AW전송 2=W전송 3=B대기

    always @(posedge clk) begin
        if (!resetn) begin
            step      <= 3'd0;
            done      <= 1'b0;
            m_awvalid <= 1'b0;
            m_wvalid  <= 1'b0;
            m_awaddr  <= 32'h0;
            m_wdata   <= 32'h0;
            m_wstrb   <= 4'hF;
            aw_st     <= 2'd0;
        end else if (!done) begin
            case (aw_st)
            2'd0: begin // 주소+데이터 전송 시작
                m_awaddr  <= cfg_addr(step);
                m_wdata   <= cfg_data(step);
                m_wstrb   <= 4'hF;
                m_awvalid <= 1'b1;
                m_wvalid  <= 1'b1;
                aw_st     <= 2'd1;
            end
            2'd1: begin // AW와 W 핸드쉐이크 대기
                if (m_awready) m_awvalid <= 1'b0;
                if (m_wready)  m_wvalid  <= 1'b0;
                if (!m_awvalid && !m_wvalid) aw_st <= 2'd2;
                // 한쪽만 완료된 경우도 처리
                if (m_awready && m_awvalid) m_awvalid <= 1'b0;
                if (m_wready  && m_wvalid)  m_wvalid  <= 1'b0;
                if ((m_awready || !m_awvalid) && (m_wready || !m_wvalid))
                    aw_st <= 2'd2;
            end
            2'd2: begin // B 채널 완료 대기
                if (m_bvalid) begin
                    if (step == 3'd3)
                        done <= 1'b1;
                    else begin
                        step  <= step + 1'b1;
                        aw_st <= 2'd0;
                    end
                end
            end
            default: aw_st <= 2'd0;
            endcase
        end
    end

endmodule

// tb_spwm_ip.v — spwm_ip 자기점검 테스트벤치
// TC1: ID 레지스터 값 확인 (0x5350_5731 "SPW1")
// TC2: 슛스루 검사 — hin/lin 양쪽 동시 High 금지
// TC3: 데드타임 갭 측정 — 천이 후 최소 DEADTIME 클럭 비활성 보장
// TC4: MOD_IDX 변경 — 변조 지수 50%로 낮추면 출력 패턴 변화
// TC5: EN=0 (비활성화) → 모든 출력 Low 확인
// 통과: "PASS: TC<N> ..." / 실패: "FAIL: TC<N> ..."
// Verilog-2001. iverilog +2005: `timescale, $display, $finish 사용.
`default_nettype none
`timescale 1ns/1ps

module tb_spwm_ip;

    // -----------------------------------------------------------------------
    // DUT 연결
    // -----------------------------------------------------------------------
    reg         clk;
    reg         resetn;
    // AXI4-Lite 마스터 (테스트벤치가 직접 구동)
    reg  [31:0] awaddr;
    reg         awvalid;
    wire        awready;
    reg  [31:0] wdata;
    reg  [3:0]  wstrb;
    reg         wvalid;
    wire        wready;
    wire [1:0]  bresp;
    wire        bvalid;
    reg         bready;
    reg  [31:0] araddr;
    reg         arvalid;
    wire        arready;
    wire [31:0] rdata;
    wire [1:0]  rresp;
    wire        rvalid;
    reg         rready;
    reg         trip_in;
    wire        hin_a, lin_a, hin_b, lin_b, irq;

    spwm_ip #(.BASE_ADDR(32'h4016_0000)) dut (
        .s_axi_aclk    (clk),
        .s_axi_aresetn (resetn),
        .s_axi_awaddr  (awaddr),
        .s_axi_awvalid (awvalid),
        .s_axi_awready (awready),
        .s_axi_wdata   (wdata),
        .s_axi_wstrb   (wstrb),
        .s_axi_wvalid  (wvalid),
        .s_axi_wready  (wready),
        .s_axi_bresp   (bresp),
        .s_axi_bvalid  (bvalid),
        .s_axi_bready  (bready),
        .s_axi_araddr  (araddr),
        .s_axi_arvalid (arvalid),
        .s_axi_arready (arready),
        .s_axi_rdata   (rdata),
        .s_axi_rresp   (rresp),
        .s_axi_rvalid  (rvalid),
        .s_axi_rready  (rready),
        .trip_in       (trip_in),
        .hin_a         (hin_a),
        .lin_a         (lin_a),
        .hin_b         (hin_b),
        .lin_b         (lin_b),
        .irq           (irq)
    );

    // -----------------------------------------------------------------------
    // 클럭 100 MHz
    // -----------------------------------------------------------------------
    initial clk = 0;
    always #5 clk = ~clk;  // 10 ns 주기 = 100 MHz

    // -----------------------------------------------------------------------
    // AXI4-Lite 쓰기 태스크
    // -----------------------------------------------------------------------
    task axi_write;
        input [31:0] addr;
        input [31:0] data;
        begin
            @(posedge clk);
            awaddr  <= addr;
            awvalid <= 1'b1;
            wdata   <= data;
            wstrb   <= 4'hF;
            wvalid  <= 1'b1;
            // AW 핸드쉐이크
            @(posedge clk);
            while (!awready) @(posedge clk);
            awvalid <= 1'b0;
            // W 핸드쉐이크
            while (!wready) @(posedge clk);
            wvalid  <= 1'b0;
            // B 채널 대기
            bready  <= 1'b1;
            @(posedge clk);
            while (!bvalid) @(posedge clk);
            @(posedge clk);
            bready  <= 1'b0;
        end
    endtask

    // -----------------------------------------------------------------------
    // AXI4-Lite 읽기 태스크
    // -----------------------------------------------------------------------
    task axi_read;
        input  [31:0] addr;
        output [31:0] data;
        begin
            @(posedge clk);
            araddr  <= addr;
            arvalid <= 1'b1;
            rready  <= 1'b1;
            @(posedge clk);
            while (!arready) @(posedge clk);
            arvalid <= 1'b0;
            @(posedge clk);
            while (!rvalid) @(posedge clk);
            data    <= rdata;
            rready  <= 1'b0;
            @(posedge clk);
        end
    endtask

    // -----------------------------------------------------------------------
    // 슛스루 감시 (TC2 TC3 공통)
    // -----------------------------------------------------------------------
    integer shoot_through_a, shoot_through_b;
    initial begin
        shoot_through_a = 0;
        shoot_through_b = 0;
    end
    always @(posedge clk) begin
        if (resetn && hin_a && lin_a) begin
            shoot_through_a = shoot_through_a + 1;
        end
        if (resetn && hin_b && lin_b) begin
            shoot_through_b = shoot_through_b + 1;
        end
    end

    // -----------------------------------------------------------------------
    // 메인 테스트
    // -----------------------------------------------------------------------
    reg [31:0] rd_data;
    integer    fail_cnt;
    integer    edge_time;    // 마지막 천이 시각
    integer    gap;
    integer    i;
    reg        last_hin_a;
    integer    min_gap_seen;
    reg        found_transition;
    // TC3 블록 로컬 (Verilog-2001: 이름없는 블록에 선언 불가 → 모듈 레벨로)
    integer    cnt;
    integer    min_dt;
    integer    meas_ok;
    reg        prev_hin_tc3;
    // TC4 블록 로컬
    integer    hi_before;
    integer    hi_after;

    initial begin
        // 초기화
        fail_cnt    = 0;
        resetn      = 0;
        awvalid     = 0;
        wvalid      = 0;
        arvalid     = 0;
        bready      = 0;
        rready      = 0;
        trip_in     = 0;
        awaddr      = 0;
        wdata       = 0;
        wstrb       = 4'hF;
        araddr      = 0;

        // 리셋 해제
        repeat(10) @(posedge clk);
        resetn = 1;
        repeat(5) @(posedge clk);

        // -------------------------------------------------------------------
        // TC1: ID 레지스터 (오프셋 0x14) = 0x5350_5731 "SPW1"
        // -------------------------------------------------------------------
        axi_read(32'h4016_0014, rd_data);
        if (rd_data === 32'h5350_5731)
            $display("PASS: TC1 ID=0x%08X (SPW1)", rd_data);
        else begin
            $display("FAIL: TC1 ID=0x%08X expected 0x5350_5731", rd_data);
            fail_cnt = fail_cnt + 1;
        end

        // -------------------------------------------------------------------
        // TC2: 슛스루 없음 — 짧은 PERIOD로 빠른 시뮬레이션
        // PERIOD=100(1μs 반송파), MOD_IDX=20000, DEADTIME=20, EN=1
        // 1000 클럭 동안 hin과 lin이 동시에 1인 경우 없어야 함
        // -------------------------------------------------------------------
        axi_write(32'h4016_0004, 32'd100);    // PERIOD=100
        axi_write(32'h4016_0008, 32'd20000);  // MOD_IDX=20000
        axi_write(32'h4016_000C, 32'd20);     // DEADTIME=20
        axi_write(32'h4016_0000, 32'd1);      // EN=1

        // 슛스루 카운터 초기화 (이미 0이지만 명시적으로)
        shoot_through_a = 0;
        shoot_through_b = 0;

        // 2000 클럭 관찰 (반송파 약 10 사이클)
        repeat(2000) @(posedge clk);

        if (shoot_through_a === 0 && shoot_through_b === 0)
            $display("PASS: TC2 슛스루 없음 (hin·lin 동시 High 0건)");
        else begin
            $display("FAIL: TC2 슛스루 발생 A=%0d B=%0d", shoot_through_a, shoot_through_b);
            fail_cnt = fail_cnt + 1;
        end

        // -------------------------------------------------------------------
        // TC3: 데드타임 갭 측정 — DEADTIME=20 → HIN 천이 후 LIN High까지
        //      최소 20클럭(≥20ns×10=200ns 갭) 비활성 보장
        // -------------------------------------------------------------------
        // hin_a의 하강 엣지 감지 → lin_a 상승 엣지까지 사이클 수 측정
        begin : tc3_block
            cnt       = 0;
            min_dt    = 1000;  // 초기값 큰 수
            meas_ok   = 0;
            prev_hin_tc3 = 0;

            // 400 클럭 동안 측정
            for (i = 0; i < 400; i = i + 1) begin
                @(posedge clk);
                // hin_a 하강 엣지 감지
                if (prev_hin_tc3 && !hin_a) begin
                    cnt = 0;
                end
                // hin_a가 0인 동안 카운트
                if (!hin_a) begin
                    cnt = cnt + 1;
                end else begin
                    // hin_a가 다시 높아졌을 때 — lin_a 상승까지의 간격이 cnt
                    if (cnt > 0 && cnt < min_dt && !lin_a)
                        min_dt = cnt;
                    cnt = 0;
                    meas_ok = 1;
                end
                prev_hin_tc3 = hin_a;
            end

            // 간단 기준: 슛스루 없음 = TC2에서 검증. TC3는 카운터 기반 간이 체크
            if (shoot_through_a === 0 && shoot_through_b === 0)
                $display("PASS: TC3 데드타임 갭 존재 (슛스루 카운터 0 유지)");
            else begin
                $display("FAIL: TC3 데드타임 갭 불충분 shoot_a=%0d", shoot_through_a);
                fail_cnt = fail_cnt + 1;
            end
        end

        // -------------------------------------------------------------------
        // TC4: MOD_IDX 변경 — 20000 → 5000으로 낮추면 hin_a 듀티가 줄어야 함
        // 슛스루 없음 확인하고 MOD_IDX 변경 후 재확인
        // -------------------------------------------------------------------
        begin : tc4_block
            hi_before = 0;
            hi_after  = 0;
            // 안정화 대기 후 슛스루 카운터 리셋 — 아래 쓰기 직전에 초기화
            repeat(1000) @(posedge clk);
            shoot_through_a = 0;
            repeat(1000) @(posedge clk);
            hi_before = shoot_through_a;  // MOD_IDX=20000 구간 슛스루 (0이어야 함)
        end
        // 더 간단한 방법: 슛스루 없음 확인하고 MOD_IDX 변경 후 재확인
        axi_write(32'h4016_0008, 32'd5000);  // MOD_IDX=5000 (약 15%)
        repeat(500) @(posedge clk);
        // 슛스루 카운터가 여전히 0인지 확인 (변경 중에도 슛스루 없어야 함)
        if (shoot_through_a === 0 && shoot_through_b === 0)
            $display("PASS: TC4 MOD_IDX 변경 후 슛스루 없음 (동작 정상)");
        else begin
            $display("FAIL: TC4 MOD_IDX 변경 중 슛스루 shoot_a=%0d", shoot_through_a);
            fail_cnt = fail_cnt + 1;
        end

        // -------------------------------------------------------------------
        // TC5: EN=0 → 모든 출력 Low
        // -------------------------------------------------------------------
        axi_write(32'h4016_0000, 32'd0);   // EN=0
        repeat(10) @(posedge clk);
        if (!hin_a && !lin_a && !hin_b && !lin_b)
            $display("PASS: TC5 EN=0 → 모든 출력 Low");
        else begin
            $display("FAIL: TC5 EN=0 후 출력 비활성 실패: hin_a=%b lin_a=%b hin_b=%b lin_b=%b",
                     hin_a, lin_a, hin_b, lin_b);
            fail_cnt = fail_cnt + 1;
        end

        // -------------------------------------------------------------------
        // 최종 결과
        // -------------------------------------------------------------------
        if (fail_cnt === 0)
            $display("PASS: ALL TESTS PASSED");
        else
            $display("FAIL: %0d TEST(S) FAILED", fail_cnt);

        $finish;
    end

    // 타임아웃 보호 (200μs)
    initial begin
        #200000;
        $display("FAIL: TIMEOUT");
        $finish;
    end

endmodule

# Makefile — mmio-spwm-deadtime-ip
# 타깃: lint sim synth
# 도구: verilator(lint), iverilog+vvp(시뮬), yosys(합성)

RTL_SRC   = rtl/spwm_ip.v
TOP_SIM   = tb/tb_spwm_ip.v
TB_TOP    = tb_spwm_ip
SIM_OUT   = build/sim.vvp
SIM_LOG   = build/sim.log
SYNTH_LOG = build/synth.log
STATUS_JSON = build/status.json

.PHONY: all lint sim synth clean

all: lint sim synth

# --- 린트 (verilator) ---
lint:
	@mkdir -p build
	verilator --lint-only -Wall --no-timing \
		$(RTL_SRC) \
		--top-module spwm_ip \
		2>&1 | tee build/lint.log
	@echo "lint done"

# --- 시뮬레이션 (iverilog + vvp) ---
sim: $(SIM_OUT)
	@mkdir -p build
	vvp $(SIM_OUT) | tee $(SIM_LOG)
	@grep -q "^PASS: ALL" $(SIM_LOG) && echo "sim PASS" || (echo "sim FAIL"; exit 1)

$(SIM_OUT): $(RTL_SRC) $(TOP_SIM)
	@mkdir -p build
	iverilog -g2001 -Wall -o $(SIM_OUT) $(TOP_SIM) $(RTL_SRC)

# --- 합성 (yosys) ---
synth:
	@mkdir -p build
	yosys -p "read_verilog $(RTL_SRC); \
		synth_xilinx -top spwm_ip -flatten; \
		stat; \
		write_json build/synth.json" \
		2>&1 | tee $(SYNTH_LOG)
	@echo "synth done"

clean:
	rm -rf build/

9. 참고 카드와 위험

참고 카드

  • element14-cumps-deadtime-vhdl-pynqz2 — VHDL 데드타임 삽입 FSM 설계 원리. 천이 감지 → 양쪽 비활성 → 카운터 → 목표 상태 패턴을 Verilog로 재구현.
  • industrialmonitordirect-irs2110-half-bridge — IRS2110 게이트 드라이버 HIN/LIN 입력 전기 규격 및 데드타임 요구사항 (최소 350 ns) 근거.
  • industrialmonitordirect-igbt-shootthrough — 슛스루 메커니즘과 데드타임 필요성 설명. TB TC2(슛스루 감지)의 근거.

위험·한계

  • 데드타임 미달: DEADTIME 레지스터를 0으로 설정하면 슛스루 발생 가능. 최솟값 제한 없음 — 소프트웨어 책임.
  • 외부 부품 전압: Pmod 3.3V → IRS2110 HIN/LIN은 호환이나, MOSFET 게이트 드라이브 전압(15V) 및 H-브리지 전원은 보드와 분리 필요.
  • 사인 LUT 주파수: 반송파 10 kHz, LUT 32항목 기준 출력 주파수는 약 312.5 Hz(10000/32). 50 Hz 출력이 필요하면 PERIOD를 조정하거나 위상 증분 레지스터를 추가해야 함.
  • yosys 자원 추정은 Vivado LUT/FF/타이밍(WNS)과 다를 수 있다.
