XADC 4채널 아날로그 입력 허브 IP

Basys3 XADC 프리미티브를 AXI4-Lite 래퍼 안에 숨기고, JXADC 헤더 4채널(VAUX0·1·8·9)을 순환 스캔하여 채널별 12비트 평균값·완료 인터럽트를 레지스터로 노출하는 T2 아날로그 입력 허브 IP.

린트: 미실행시뮬레이션: 미실행합성: 미실행보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • XADC DRP(Dynamic Reconfiguration Port)를 통해 4채널(VAUX0·1·8·9)을 순환 스캔한다.
  • 채널별 12비트 평균값(이동 평균 길이 1·2·4·8·16·32·64·128배 설정 가능)을 AXI4-Lite 레지스터로 노출한다.
  • 스캔 완료 인터럽트(W1C IRQ_STAT, IRQ_EN 마스크)를 제공한다.
  • XADC 프리미티브가 없는 iverilog/yosys 환경에서 모의 DRP 모델로 테스트벤치를 통과한다.
  • mbv-frozen-v2 xadc 동결 영역(0x4009_0000, 64KB)을 사용하고 IP 표준 AXI4-Lite 래퍼로 설계한다.

범위 밖

  • XADC 온칩 온도·공급전압 채널은 사용하지 않는다.
  • 연속 모드(continuous mode) 또는 이벤트 트리거 모드는 미구현이다.
  • 보드 보호 없이 1V 이상의 아날로그 입력은 인가하지 않는다.
  • S3(보드 동작 확인)은 사용자가 직접 한다. 에이전트는 올리지 않는다.

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. 아이디어 I-032 기반(차단조건재심사 2026-11-04 10점). mbv-frozen-v2 xadc 동결 영역(0x4009_0000) 사용. 시뮬레이션·합성 결과는 CI에서 검증한다.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

전압 분배기 회로(33kΩ+10kΩ)를 각 채널에 적용해야 함. 미작성.

7. 실행 소스

저장소의 capstones/mmio-xadc-hub/에 있는 파일 그대로다. 이 문서는 파일에서 읽어 넣은 것이므로 항상 일치한다. 소스 전체 내려받기 (.zip) · GitHub에서 보기

rtl/axil_xadc_hub.v 354줄
// axil_xadc_hub.v
// XADC 4채널 AXI4-Lite 허브 IP (DRP FSM + 레지스터 파일)
// Verilog-2001. iverilog/verilator/yosys 호환.
// XADC 프리미티브는 basys3_xadc_top.v가 담당하며 이 파일은 DRP 인터페이스만 사용.
// 출처: capstones/mmio-xadc-hub/capstone.json
`default_nettype none
`timescale 1ns/1ps

module axil_xadc_hub #(
    parameter BASE_ADDR = 32'h4009_0000
) (
    input  wire        s_axi_aclk,
    input  wire        s_axi_aresetn,
    // AW
    input  wire [31:0] s_axi_awaddr,
    input  wire        s_axi_awvalid,
    output reg         s_axi_awready,
    // W
    input  wire [31:0] s_axi_wdata,
    input  wire [3:0]  s_axi_wstrb,
    input  wire        s_axi_wvalid,
    output reg         s_axi_wready,
    // B
    output reg  [1:0]  s_axi_bresp,
    output reg         s_axi_bvalid,
    input  wire        s_axi_bready,
    // AR
    input  wire [31:0] s_axi_araddr,
    input  wire        s_axi_arvalid,
    output reg         s_axi_arready,
    // R
    output reg  [31:0] s_axi_rdata,
    output reg  [1:0]  s_axi_rresp,
    output reg         s_axi_rvalid,
    input  wire        s_axi_rready,
    // DRP interface (to XADC primitive)
    output reg         drp_den,
    output reg         drp_dwe,
    output reg  [6:0]  drp_daddr,
    output reg  [15:0] drp_di,
    input  wire [15:0] drp_do,
    input  wire        drp_drdy,
    // Interrupt
    output wire        irq
);

    // -----------------------------------------------------------------------
    // XADC 채널 주소 (Artix-7 JXADC 핀 매핑)
    // -----------------------------------------------------------------------
    localparam [6:0] VAUX0 = 7'h10;  // JXADC 핀 1(P)/7(N)
    localparam [6:0] VAUX1 = 7'h11;  // JXADC 핀 2(P)/8(N)
    localparam [6:0] VAUX8 = 7'h18;  // JXADC 핀 3(P)/9(N)
    localparam [6:0] VAUX9 = 7'h19;  // JXADC 핀 4(P)/10(N)

    // -----------------------------------------------------------------------
    // DRP FSM 상태
    // -----------------------------------------------------------------------
    localparam [2:0] S_IDLE    = 3'd0,
                     S_REQ     = 3'd1,
                     S_WAIT    = 3'd2,
                     S_ACCUM   = 3'd3,
                     S_NEXT    = 3'd4,
                     S_COMPUTE = 3'd5,
                     S_DONE    = 3'd6;

    // -----------------------------------------------------------------------
    // 레지스터 오프셋 (기저 주소 0x4009_0000 기준)
    // -----------------------------------------------------------------------
    localparam [7:0] REG_CH0    = 8'h00,  // VAUX0 평균값 RO
                     REG_CH1    = 8'h04,  // VAUX1 평균값 RO
                     REG_CH2    = 8'h08,  // VAUX8 평균값 RO
                     REG_CH3    = 8'h0C,  // VAUX9 평균값 RO
                     REG_STATUS = 8'h10,  // [7:4]=ch_valid [0]=busy RO
                     REG_CTRL   = 8'h14,  // [4:2]=avg_sel [0]=en RW
                     REG_IRQ_EN = 8'h18,  // [0]=irq_en RW
                     REG_IRQ_ST = 8'h1C,  // [0]=irq_stat W1C
                     REG_IDVER  = 8'hFC;  // 0x0032_0100 RO

    // -----------------------------------------------------------------------
    // 채널 주소 선택 함수
    // -----------------------------------------------------------------------
    function [6:0] ch_addr;
        input [1:0] ch;
        begin
            case (ch)
                2'd0: ch_addr = VAUX0;
                2'd1: ch_addr = VAUX1;
                2'd2: ch_addr = VAUX8;
                2'd3: ch_addr = VAUX9;
                default: ch_addr = VAUX0;
            endcase
        end
    endfunction

    // -----------------------------------------------------------------------
    // 이동 평균 계산 함수 (accum >> sel의 하위 12비트)
    // -----------------------------------------------------------------------
    function [11:0] avg12;
        input [19:0] sum;
        input [2:0]  sel;
        reg [19:0] tmp;
        begin
            tmp   = sum >> sel;
            avg12 = tmp[11:0];
        end
    endfunction

    // -----------------------------------------------------------------------
    // 내부 레지스터
    // -----------------------------------------------------------------------
    // AXI 쓰기 래치
    reg        aw_ok;
    reg  [7:0] aw_a;
    reg        wd_ok;
    reg [31:0] wd_d;
    reg        do_wr;

    // 제어·상태 레지스터
    reg        ctrl_en;
    reg  [2:0] ctrl_avg;
    reg        irq_en;
    reg        irq_stat;
    reg        scan_done;   // 1클럭 펄스, Block 4→Block 2 전달

    // 채널 결과
    reg [11:0] ch_avg_r [0:3];
    reg  [3:0] ch_valid_r;
    reg        fsm_busy;

    // DRP FSM
    reg  [2:0] state;
    reg  [1:0] ch_ptr;
    reg  [4:0] scan_cnt;
    reg [19:0] accum [0:3];
    reg [15:0] drp_do_lat;  // drp_drdy 클럭에서 drp_do를 래치 (다음 클럭에 DRP 모델이 소거하기 전에 포착)

    wire [4:0] avg_len = 5'd1 << ctrl_avg;

    // -----------------------------------------------------------------------
    // Block 1: AXI 쓰기 채널 래치 (aw_ok / wd_ok 패턴)
    // -----------------------------------------------------------------------
    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn) begin
            s_axi_awready <= 1'b0;
            s_axi_wready  <= 1'b0;
            s_axi_bvalid  <= 1'b0;
            s_axi_bresp   <= 2'b00;
            aw_ok  <= 1'b0;
            aw_a   <= 8'h00;
            wd_ok  <= 1'b0;
            wd_d   <= 32'h0;
            do_wr  <= 1'b0;
        end else begin
            do_wr         <= 1'b0;
            s_axi_awready <= 1'b0;
            s_axi_wready  <= 1'b0;

            if (s_axi_awvalid && !aw_ok) begin
                s_axi_awready <= 1'b1;
                aw_ok         <= 1'b1;
                aw_a          <= s_axi_awaddr[7:0];
            end

            if (s_axi_wvalid && !wd_ok) begin
                s_axi_wready <= 1'b1;
                wd_ok        <= 1'b1;
                wd_d         <= s_axi_wdata;
            end

            if (aw_ok && wd_ok) begin
                do_wr        <= 1'b1;
                aw_ok        <= 1'b0;
                wd_ok        <= 1'b0;
                s_axi_bvalid <= 1'b1;
                s_axi_bresp  <= 2'b00;
            end

            if (s_axi_bvalid && s_axi_bready)
                s_axi_bvalid <= 1'b0;
        end
    end

    // -----------------------------------------------------------------------
    // Block 2: 레지스터 파일 (단일 드라이버)
    // W1C 클리어 먼저, scan_done 세트가 같은 클럭에 오면 세트가 이긴다
    // (비차단 대입 순서: 클리어 먼저 ← scan_done 뒤에)
    // -----------------------------------------------------------------------
    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn) begin
            ctrl_en  <= 1'b0;
            ctrl_avg <= 3'd0;
            irq_en   <= 1'b0;
            irq_stat <= 1'b0;
        end else begin
            // W1C 클리어 (먼저)
            if (do_wr && (aw_a == REG_IRQ_ST))
                irq_stat <= irq_stat & ~wd_d[0];

            // scan_done 세트 (나중 → 같은 클럭이면 덮어씀)
            if (scan_done)
                irq_stat <= 1'b1;

            // CTRL 쓰기
            if (do_wr && (aw_a == REG_CTRL)) begin
                ctrl_en  <= wd_d[0];
                ctrl_avg <= wd_d[4:2];
            end

            // IRQ_EN 쓰기
            if (do_wr && (aw_a == REG_IRQ_EN))
                irq_en <= wd_d[0];
        end
    end

    // -----------------------------------------------------------------------
    // Block 3: AXI 읽기 채널
    // -----------------------------------------------------------------------
    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn) begin
            s_axi_arready <= 1'b0;
            s_axi_rvalid  <= 1'b0;
            s_axi_rdata   <= 32'h0;
            s_axi_rresp   <= 2'b00;
        end else begin
            s_axi_arready <= 1'b0;

            if (s_axi_arvalid && !s_axi_rvalid) begin
                s_axi_arready <= 1'b1;
                s_axi_rvalid  <= 1'b1;
                s_axi_rresp   <= 2'b00;
                case (s_axi_araddr[7:0])
                    REG_CH0:    s_axi_rdata <= {20'h0, ch_avg_r[0]};
                    REG_CH1:    s_axi_rdata <= {20'h0, ch_avg_r[1]};
                    REG_CH2:    s_axi_rdata <= {20'h0, ch_avg_r[2]};
                    REG_CH3:    s_axi_rdata <= {20'h0, ch_avg_r[3]};
                    REG_STATUS: s_axi_rdata <= {24'h0, ch_valid_r, 3'b000, fsm_busy};
                    REG_CTRL:   s_axi_rdata <= {27'h0, ctrl_avg, 1'b0, ctrl_en};
                    REG_IRQ_EN: s_axi_rdata <= {31'h0, irq_en};
                    REG_IRQ_ST: s_axi_rdata <= {31'h0, irq_stat};
                    REG_IDVER:  s_axi_rdata <= 32'h0032_0100;
                    default:    s_axi_rdata <= 32'h0;
                endcase
            end

            if (s_axi_rvalid && s_axi_rready)
                s_axi_rvalid <= 1'b0;
        end
    end

    // -----------------------------------------------------------------------
    // Block 4: DRP FSM (순환 스캔 + 이동 평균)
    // -----------------------------------------------------------------------
    always @(posedge s_axi_aclk) begin
        if (!s_axi_aresetn) begin
            state       <= S_IDLE;
            ch_ptr      <= 2'd0;
            scan_cnt    <= 5'd0;
            drp_den     <= 1'b0;
            drp_dwe     <= 1'b0;
            drp_daddr   <= 7'h0;
            drp_di      <= 16'h0;
            fsm_busy    <= 1'b0;
            ch_valid_r  <= 4'h0;
            scan_done   <= 1'b0;
            accum[0]    <= 20'h0;
            accum[1]    <= 20'h0;
            accum[2]    <= 20'h0;
            accum[3]    <= 20'h0;
            ch_avg_r[0] <= 12'h0;
            ch_avg_r[1] <= 12'h0;
            ch_avg_r[2] <= 12'h0;
            ch_avg_r[3] <= 12'h0;
            drp_do_lat  <= 16'h0;
        end else begin
            scan_done <= 1'b0;  // 기본: 펄스 없음

            case (state)
                S_IDLE: begin
                    fsm_busy <= 1'b0;
                    if (ctrl_en) begin
                        ch_ptr   <= 2'd0;
                        scan_cnt <= 5'd0;
                        accum[0] <= 20'h0;
                        accum[1] <= 20'h0;
                        accum[2] <= 20'h0;
                        accum[3] <= 20'h0;
                        fsm_busy <= 1'b1;
                        state    <= S_REQ;
                    end
                end

                S_REQ: begin
                    drp_den   <= 1'b1;
                    drp_dwe   <= 1'b0;
                    drp_daddr <= ch_addr(ch_ptr);
                    drp_di    <= 16'h0;
                    state     <= S_WAIT;
                end

                S_WAIT: begin
                    drp_den <= 1'b0;
                    if (drp_drdy) begin
                        drp_do_lat <= drp_do;  // drp_drdy 클럭에 drp_do 포착 (DRP 모델이 소거하기 전)
                        state      <= S_ACCUM;
                    end
                end

                S_ACCUM: begin
                    // drp_do_lat: drp_drdy 클럭에서 포착한 ADC 결과 (DO[15:4] = 12비트)
                    accum[ch_ptr] <= accum[ch_ptr] + {8'd0, drp_do_lat[15:4]};
                    state         <= S_NEXT;
                end

                S_NEXT: begin
                    if (ch_ptr == 2'd3) begin
                        // 4채널 한 패스 완료
                        scan_cnt <= scan_cnt + 5'd1;
                        ch_ptr   <= 2'd0;
                        if (scan_cnt + 5'd1 >= avg_len)
                            state <= S_COMPUTE;
                        else
                            state <= S_REQ;  // accum 초기화 없이 계속 누적
                    end else begin
                        ch_ptr <= ch_ptr + 2'd1;
                        state  <= S_REQ;
                    end
                end

                S_COMPUTE: begin
                    ch_avg_r[0] <= avg12(accum[0], ctrl_avg);
                    ch_avg_r[1] <= avg12(accum[1], ctrl_avg);
                    ch_avg_r[2] <= avg12(accum[2], ctrl_avg);
                    ch_avg_r[3] <= avg12(accum[3], ctrl_avg);
                    ch_valid_r  <= 4'hF;
                    state       <= S_DONE;
                end

                S_DONE: begin
                    scan_done <= 1'b1;  // 1클럭 펄스 → Block 2로 전달
                    state     <= S_IDLE;
                end

                default: state <= S_IDLE;
            endcase
        end
    end

    // -----------------------------------------------------------------------
    // 인터럽트 출력
    // -----------------------------------------------------------------------
    assign irq = irq_en & irq_stat;

endmodule
`default_nettype wire

// tb_axil_xadc_hub.v
// 자체 점검 테스트벤치 — axil_xadc_hub.v만 시험 (XADC 프리미티브 없음)
// 모의 DRP 모델이 채널 주소별로 고정 응답을 돌려준다.
// 통과: "PASS" 출력. 실패: "FAIL: N checks failed" 출력.
`timescale 1ns/1ps
`default_nettype none

module tb_axil_xadc_hub;

    // -----------------------------------------------------------------------
    // 클럭·리셋
    // -----------------------------------------------------------------------
    reg clk = 0;
    always #5 clk = ~clk;  // 100 MHz

    reg rst_n = 0;
    initial begin
        #12; rst_n = 1;
    end

    // -----------------------------------------------------------------------
    // DUT 포트 연결
    // -----------------------------------------------------------------------
    reg  [31:0] awaddr  = 0;
    reg         awvalid = 0;
    wire        awready;
    reg  [31:0] wdata   = 0;
    reg  [3:0]  wstrb   = 4'hF;
    reg         wvalid  = 0;
    wire        wready;
    wire [1:0]  bresp;
    wire        bvalid;
    reg         bready  = 0;
    reg  [31:0] araddr  = 0;
    reg         arvalid = 0;
    wire        arready;
    wire [31:0] rdata;
    wire [1:0]  rresp;
    wire        rvalid;
    reg         rready  = 0;
    wire        drp_den;
    wire        drp_dwe;
    wire [6:0]  drp_daddr;
    wire [15:0] drp_di;
    reg  [15:0] drp_do  = 0;
    reg         drp_drdy = 0;
    wire        irq;

    axil_xadc_hub #(
        .BASE_ADDR(32'h4009_0000)
    ) dut (
        .s_axi_aclk    (clk),
        .s_axi_aresetn (rst_n),
        .s_axi_awaddr  (awaddr),
        .s_axi_awvalid (awvalid),
        .s_axi_awready (awready),
        .s_axi_wdata   (wdata),
        .s_axi_wstrb   (wstrb),
        .s_axi_wvalid  (wvalid),
        .s_axi_wready  (wready),
        .s_axi_bresp   (bresp),
        .s_axi_bvalid  (bvalid),
        .s_axi_bready  (bready),
        .s_axi_araddr  (araddr),
        .s_axi_arvalid (arvalid),
        .s_axi_arready (arready),
        .s_axi_rdata   (rdata),
        .s_axi_rresp   (rresp),
        .s_axi_rvalid  (rvalid),
        .s_axi_rready  (rready),
        .drp_den       (drp_den),
        .drp_dwe       (drp_dwe),
        .drp_daddr     (drp_daddr),
        .drp_di        (drp_di),
        .drp_do        (drp_do),
        .drp_drdy      (drp_drdy),
        .irq           (irq)
    );

    // -----------------------------------------------------------------------
    // 모의 DRP 모델 (1클럭 지연 응답)
    // 채널 주소 → 고정 ADC 결과 (DO[15:4]에 12비트 정렬)
    // VAUX0=0x10 → 0xABC0 (12비트=0xABC)
    // VAUX1=0x11 → 0x1230 (12비트=0x123)
    // VAUX8=0x18 → 0x4560 (12비트=0x456)
    // VAUX9=0x19 → 0x7890 (12비트=0x789)
    // -----------------------------------------------------------------------
    always @(posedge clk) begin
        drp_drdy <= 1'b0;
        drp_do   <= 16'h0;
        if (drp_den) begin
            case (drp_daddr)
                7'h10: drp_do <= 16'hABC0;
                7'h11: drp_do <= 16'h1230;
                7'h18: drp_do <= 16'h4560;
                7'h19: drp_do <= 16'h7890;
                default: drp_do <= 16'h0000;
            endcase
            drp_drdy <= 1'b1;
        end
    end

    // -----------------------------------------------------------------------
    // 태스크: AXI 쓰기
    // -----------------------------------------------------------------------
    task axi_write;
        input [31:0] addr;
        input [31:0] data;
        begin
            @(posedge clk); #1;
            awaddr  <= addr; awvalid <= 1'b1;
            wdata   <= data; wvalid  <= 1'b1; wstrb <= 4'hF;
            @(posedge clk); #1;
            awvalid <= 1'b0;
            wvalid  <= 1'b0;
            bready  <= 1'b1;
            @(posedge clk); #1;
            @(posedge clk); #1;
            bready  <= 1'b0;
        end
    endtask

    // -----------------------------------------------------------------------
    // 태스크: AXI 읽기
    // -----------------------------------------------------------------------
    reg [31:0] rd_data;
    task axi_read;
        input [31:0] addr;
        begin
            @(posedge clk); #1;
            araddr  <= addr; arvalid <= 1'b1;
            rready  <= 1'b1;
            @(posedge clk); #1;
            arvalid <= 1'b0;
            @(posedge clk); #1;
            rd_data = rdata;   // 블로킹: check_eq 호출 전 rd_data가 갱신돼야 함 (NBA면 X)
            rready  <= 1'b0;
        end
    endtask

    // -----------------------------------------------------------------------
    // 검증 카운터
    // -----------------------------------------------------------------------
    integer fail_cnt = 0;

    task check_eq;
        input [31:0] got;
        input [31:0] exp;
        input [127:0] tag;
        begin
            if (got !== exp) begin
                $display("FAIL [%0s]: got=0x%08X exp=0x%08X", tag, got, exp);
                fail_cnt = fail_cnt + 1;
            end
        end
    endtask

    // -----------------------------------------------------------------------
    // IRQ 대기 (타임아웃 포함)
    // -----------------------------------------------------------------------
    integer wait_cnt;
    reg irq_ok;
    task wait_irq;
        input integer timeout;
        begin
            irq_ok   = 0;
            wait_cnt = 0;
            while (!irq && wait_cnt < timeout) begin
                @(posedge clk); #1;
                wait_cnt = wait_cnt + 1;
            end
            if (irq) irq_ok = 1;
            else begin
                $display("FAIL: IRQ timeout after %0d cycles", timeout);
                fail_cnt = fail_cnt + 1;
            end
        end
    endtask

    // -----------------------------------------------------------------------
    // 메인 시나리오
    // -----------------------------------------------------------------------
    initial begin
        // 리셋 해제 대기
        @(posedge rst_n);
        repeat(5) @(posedge clk);

        // ===================================================================
        // T1: avg_sel=0 (평균 1회, avg_len=1) 단일 스캔
        // ===================================================================
        $display("--- T1: avg_sel=0 단일 스캔 ---");
        // IRQ 활성화
        axi_write(32'h4009_0018, 32'h1);
        // CTRL: avg_sel=0, en=1
        axi_write(32'h4009_0014, 32'h1);

        // IRQ 대기 (최대 500 클럭)
        wait_irq(500);

        // 스캔 완료 후 ctrl_en 해제
        axi_write(32'h4009_0014, 32'h0);
        repeat(50) @(posedge clk);

        // 채널값 확인 (각 채널 12비트 평균 = 모의 DRP 값 그대로)
        axi_read(32'h4009_0000); check_eq(rd_data, 32'h0000_0ABC, "T1_CH0");
        axi_read(32'h4009_0004); check_eq(rd_data, 32'h0000_0123, "T1_CH1");
        axi_read(32'h4009_0008); check_eq(rd_data, 32'h0000_0456, "T1_CH2");
        axi_read(32'h4009_000C); check_eq(rd_data, 32'h0000_0789, "T1_CH3");

        // IRQ_STAT 확인 (스캔 완료 = 1)
        axi_read(32'h4009_001C); check_eq(rd_data, 32'h0000_0001, "T1_IRQ_STAT_before_W1C");
        // irq = irq_en & irq_stat = 1
        check_eq({31'h0, irq}, 32'h0000_0001, "T1_irq_high");

        // W1C: IRQ_STAT 클리어
        axi_write(32'h4009_001C, 32'h1);
        repeat(5) @(posedge clk);
        axi_read(32'h4009_001C); check_eq(rd_data, 32'h0000_0000, "T1_IRQ_STAT_after_W1C");
        check_eq({31'h0, irq}, 32'h0000_0000, "T1_irq_low");

        // ===================================================================
        // T2: avg_sel=1 (평균 2회, avg_len=2) 두 번 누적 평균
        // CH0: (0xABC + 0xABC) >> 1 = 0xABC (동일 값)
        // ===================================================================
        $display("--- T2: avg_sel=1 2회 평균 ---");
        axi_write(32'h4009_0018, 32'h1);
        // CTRL: avg_sel=1([4:2]=3'b001), en=1
        axi_write(32'h4009_0014, 32'h0000_0005);

        wait_irq(1500);

        axi_write(32'h4009_0014, 32'h0);
        repeat(50) @(posedge clk);

        // CH0 평균: (0xABC + 0xABC) >> 1 = 0xABC
        axi_read(32'h4009_0000); check_eq(rd_data, 32'h0000_0ABC, "T2_CH0_avg2");
        // CH3 평균: (0x789 + 0x789) >> 1 = 0x789
        axi_read(32'h4009_000C); check_eq(rd_data, 32'h0000_0789, "T2_CH3_avg2");

        // ID_VER 확인
        axi_read(32'h4009_00FC); check_eq(rd_data, 32'h0032_0100, "T2_ID_VER");

        // W1C 클리어
        axi_write(32'h4009_001C, 32'h1);
        repeat(5) @(posedge clk);
        axi_read(32'h4009_001C); check_eq(rd_data, 32'h0000_0000, "T2_IRQ_STAT_clear");

        // ===================================================================
        // 최종 결과
        // ===================================================================
        repeat(10) @(posedge clk);
        if (fail_cnt === 0)
            $display("PASS");
        else
            $display("FAIL: %0d checks failed", fail_cnt);
        $finish;
    end

    // 전체 타임아웃 보호
    initial begin
        #500000;
        $display("FAIL: global timeout");
        $finish;
    end

endmodule

위험·한계

  • XADC 최대 허용 아날로그 입력 1.0V를 초과하면 소자 손상 위험. 반드시 전압 분배기를 사용할 것.
  • basys3_xadc_top.v의 XADC 프리미티브는 iverilog/yosys에서 지원하지 않아 lint/sim/synth 대상에서 제외.
  • DRP 응답 타이밍은 근거 카드 열람값(DEN→DRDY 1클럭) 기준이며, 실제 Vivado 시뮬레이션에서 확인 필요.
  • avg_sel=7(128배 평균)에서 accum 비트폭 오버플로 위험: 20비트 accum으로 최대 128×4095=524160 < 2^20, 안전.
