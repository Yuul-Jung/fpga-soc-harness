OV7670 SCCB 설정 + RGB565 캡처 프런트엔드

OV7670 카메라 모듈을 SCCB(I2C 호환 2선 직렬)로 초기화하고, PCLK 도메인에서 RGB565 픽셀을 캡처해 MMIO 슬레이브로 노출하는 T2 SoC 주변장치 패키지.

린트: 미실행시뮬레이션: 미실행합성: 미실행보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • SCCB 마스터 FSM으로 OV7670 설정 ROM(10 엔트리) 전송 완료
  • OV7670의 VSYNC·HREF·PCLK 타이밍에 맞춰 RGB565 2바이트를 한 픽셀로 결합
  • PCLK ↔ 시스템 클럭 도메인 교차(2-FF 토글 동기화기)
  • MMIO 슬레이브 레지스터(CTRL/STATUS/PIXEL/FRAME/ID_VER)로 소프트웨어 접근 제공
  • iverilog 시뮬레이션 PASS, yosys 합성 성공(S2)

범위 밖

  • 프레임 버퍼 (Basys3 BRAM 한계, 약 76 KB로 QVGA 한 장 불가)
  • VGA 출력 직결 (별도 패키지 T3로 확장 예정)
  • 자동 노출·화이트밸런스 등 고급 카메라 제어
  • JPEG/YUV 출력 (RGB565 고정)
  • MicroBlaze V 연결 (이 패키지는 단독 시뮬레이션용 mmio-lite 버스 사용)

I-006 아이디어(ready 상태, 9점). 선택 경로: §13.7 자동 과제화, ready 직접 선택.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스mmio-lite (단독 시뮬레이션용, AXI4-Lite 비호환)
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 적합하지 않음
이식 계획이 패키지는 mmio-lite(0x1004_0000)로 단독 동작한다. mbv-frozen-v2 이식 계획: (1) ov7670_sccb_top을 IP 표준(64KB 창, 0xFFF0 ID/VER/IRQ)으로 래핑해 AXI4-Lite 슬레이브로 변환한다. (2) 동결 맵 free_slots 중 [17]=0x4017_0000에 배정을 제안한다([16]은 sensor_hub가 사용). (3) SCCB NA_ERR을 INTC 인터럽트(free intc slot)로 연결한다. (4) PCLK 비동기 리셋에 시스템 리셋 2-FF 동기화 추가가 필요하다.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

디지털 계통도(diagram.svg)와 별개. 전기 회로도는 미작성. 연결: OV7670 VCC→3.3V, GND 공통, SIO_C→Pmod JA1, SIO_D↔Pmod JA2(IOBUF), PCLK→JA7, VSYNC→JA8, HREF→JA9, D[7:4]→JA10/JB[1:4], D[3:0]→JB[4]/JC[1:3]. 풀업 저항(4.7 kΩ)은 SDA/SCL에 필요 (모듈 미포함 시).

// sccb_tx.v — SCCB (I2C-like) 마스터 송신기
// OV7670 카메라 레지스터 설정용 2선 직렬 프로토콜 FSM
// SCCB는 ACK 비트를 "don't care"(NA)로 취급하지만 이 구현은 감시한다.
// Verilog-2001, 외부 IP 없음.
//
// 인터페이스:
//   clk, rst  — 시스템 클럭(100 MHz), 동기 리셋
//   start     — 1클럭 펄스로 전송 시작
//   dev_addr  — 슬레이브 주소 7비트 [6:0]
//   reg_addr  — 레지스터 주소 8비트
//   reg_data  — 쓸 값 8비트
//   sio_c     — SCCB 클럭 출력
//   sio_d_out — SCCB 데이터 출력
//   sio_d_oe  — 데이터 선 출력 활성화 (0 = 하이임피던스 for NA 비트)
//   sio_d_in  — 데이터 선 입력 (NA 비트 감시)
//   done      — 전송 완료 1클럭 펄스
//   na_err    — NA 비트가 0(에러) 1클럭 펄스 (경고)

`default_nettype none
module sccb_tx #(
    parameter CLK_HZ   = 100_000_000,
    parameter SCCB_KHZ = 100          // 100 kHz (최대 400 kHz)
)(
    input  wire       clk, rst,
    input  wire       start,
    input  wire [6:0] dev_addr,
    input  wire [7:0] reg_addr,
    input  wire [7:0] reg_data,
    output reg        sio_c,
    output reg        sio_d_out,
    output reg        sio_d_oe,
    input  wire       sio_d_in,
    output reg        done,
    output reg        na_err
);
    // 클럭 분주: 1/4 주기(high, low 각 2단계)
    localparam HALF_CNT = (CLK_HZ / (SCCB_KHZ * 1000)) / 2;
    localparam CNT_W    = 10;

    // 보낼 비트 패킷: 1 START + (8+NA)*3위상 + 1 STOP = 29 비트 단계
    // 상태: IDLE, START, DATA, NA(x3), STOP, DONE
    localparam S_IDLE  = 3'd0;
    localparam S_START = 3'd1;
    localparam S_DATA  = 3'd2;
    localparam S_NA    = 3'd3;
    localparam S_STOP  = 3'd4;
    localparam S_DONE  = 3'd5;

    reg [2:0]      state;
    reg [CNT_W-1:0] cnt;       // 클럭 분주 카운터
    reg [4:0]      bit_idx;   // 0~7: 현재 바이트 비트, 8: NA
    reg [1:0]      byte_sel;  // 0=장치주소+W, 1=레지스터주소, 2=데이터
    reg [7:0]      shift_reg;
    reg            clk_phase; // 0=low절반, 1=high절반

    // 보낼 바이트 선택
    wire [7:0] cur_byte = (byte_sel == 2'd0) ? {dev_addr, 1'b0} :
                          (byte_sel == 2'd1) ? reg_addr : reg_data;

    always @(posedge clk) begin
        if (rst) begin
            state     <= S_IDLE;
            sio_c     <= 1'b1;
            sio_d_out <= 1'b1;
            sio_d_oe  <= 1'b1;
            done      <= 1'b0;
            na_err    <= 1'b0;
            cnt       <= 0;
            bit_idx   <= 0;
            byte_sel  <= 0;
            clk_phase <= 0;
        end else begin
            done   <= 1'b0;
            na_err <= 1'b0;
            case (state)
                S_IDLE: begin
                    sio_c <= 1'b1; sio_d_out <= 1'b1; sio_d_oe <= 1'b1;
                    if (start) begin
                        state    <= S_START;
                        cnt      <= 0;
                        byte_sel <= 0;
                    end
                end
                S_START: begin
                    // START: SCL high, SDA: 1→0
                    sio_c     <= 1'b1;
                    sio_d_out <= (cnt < HALF_CNT/2) ? 1'b1 : 1'b0;
                    sio_d_oe  <= 1'b1;
                    if (cnt >= HALF_CNT - 1) begin
                        cnt       <= 0;
                        bit_idx   <= 7;
                        shift_reg <= cur_byte;
                        clk_phase <= 0;
                        state     <= S_DATA;
                        sio_c     <= 1'b0;
                    end else cnt <= cnt + 1;
                end
                S_DATA: begin
                    if (cnt < HALF_CNT - 1) begin
                        cnt <= cnt + 1;
                    end else begin
                        cnt       <= 0;
                        clk_phase <= ~clk_phase;
                        sio_c     <= clk_phase; // 토글
                        if (clk_phase) begin  // falling edge → 다음 비트 준비
                            if (bit_idx == 0) begin
                                // 8비트 완료 → NA 단계
                                state    <= S_NA;
                                sio_d_oe <= 1'b0;  // 릴리즈 (입력으로)
                            end else begin
                                bit_idx   <= bit_idx - 1;
                                shift_reg <= {shift_reg[6:0], 1'b0};
                            end
                        end
                    end
                    sio_d_out <= shift_reg[7];
                    sio_d_oe  <= 1'b1;
                end
                S_NA: begin
                    sio_d_oe <= 1'b0;
                    if (cnt < HALF_CNT - 1) begin
                        cnt <= cnt + 1;
                    end else begin
                        cnt       <= 0;
                        clk_phase <= ~clk_phase;
                        sio_c     <= clk_phase;
                        if (clk_phase) begin  // falling
                            if (!sio_d_in) na_err <= 1'b1; // NA=0 에러
                            if (byte_sel == 2'd2) begin
                                state <= S_STOP;
                            end else begin
                                byte_sel  <= byte_sel + 1;
                                bit_idx   <= 7;
                                shift_reg <= (byte_sel == 2'd0) ? reg_addr : reg_data;
                                state     <= S_DATA;
                                sio_d_oe  <= 1'b1;
                            end
                        end
                    end
                end
                S_STOP: begin
                    // STOP: SCL high, SDA: 0→1
                    sio_c     <= 1'b1;
                    sio_d_oe  <= 1'b1;
                    sio_d_out <= (cnt >= HALF_CNT/2) ? 1'b1 : 1'b0;
                    if (cnt >= HALF_CNT - 1) begin
                        done  <= 1'b1;
                        state <= S_IDLE;
                        cnt   <= 0;
                    end else cnt <= cnt + 1;
                end
                default: state <= S_IDLE;
            endcase
        end
    end
endmodule
`default_nettype wire

// ov7670_capture.v — OV7670 픽셀 캡처 프런트엔드
// PCLK 도메인에서 RGB565 2바이트를 결합해 16비트 픽셀로 출력.
// HREF 활성+VSYNC 비활성 구간에서만 픽셀을 캡처한다.
// 도메인 교차는 상위 모듈(ov7670_sccb_top)이 처리한다.
// Verilog-2001, 외부 IP 없음.
//
// 타이밍 (OV7670 RGB565, 2클럭/픽셀 — PCLK 기준):
//   VSYNC high → 프레임 시작, VSYNC low → 프레임 활성
//   HREF high  → 라인 활성
//   PCLK ↑에서 D[7:0] 샘플링: 짝수=첫바이트(high), 홀수=두번째바이트(low)

`default_nettype none
module ov7670_capture (
    input  wire        pclk,          // 카메라 픽셀 클럭 (~24 MHz)
    input  wire        prst,          // PCLK 도메인 리셋 (시스템 리셋 동기화 필요)
    input  wire        vsync,         // 프레임 동기 (OV7670: high=블랭킹)
    input  wire        href,          // 수평 활성 (high=유효)
    input  wire [7:0]  d,             // 픽셀 데이터
    input  wire        capture_en,    // 캡처 활성화 (시스템 클럭 → PCLK 동기화 필요)
    output reg  [15:0] pixel_data,    // 결합된 RGB565 픽셀
    output reg         pixel_valid,   // 픽셀 유효 (1 PCLK 펄스)
    output reg         frame_start,   // 프레임 시작 (1 PCLK 펄스, VSYNC 하강)
    output reg         frame_done,    // 프레임 완료 (1 PCLK 펄스, VSYNC 상승)
    output reg [15:0]  line_cnt,      // 현재 프레임의 완료 라인 수
    output reg [15:0]  pixel_cnt      // 현재 라인의 픽셀 수 (디버그)
);
    reg        vsync_d;
    reg        href_d;
    reg        byte_phase; // 0=첫바이트, 1=두번째바이트
    reg  [7:0] byte_hi;    // 첫 바이트(high byte) 보관

    always @(posedge pclk) begin
        if (prst) begin
            vsync_d     <= 1'b0;
            href_d      <= 1'b0;
            byte_phase  <= 1'b0;
            byte_hi     <= 8'd0;
            pixel_data  <= 16'd0;
            pixel_valid <= 1'b0;
            frame_start <= 1'b0;
            frame_done  <= 1'b0;
            line_cnt    <= 16'd0;
            pixel_cnt   <= 16'd0;
        end else begin
            vsync_d     <= vsync;
            href_d      <= href;
            pixel_valid <= 1'b0;
            frame_start <= 1'b0;
            frame_done  <= 1'b0;

            // VSYNC 하강 → 프레임 시작 (OV7670: high=블랭킹, low=활성)
            if (vsync_d && !vsync) begin
                frame_start <= 1'b1;
                line_cnt    <= 16'd0;
                byte_phase  <= 1'b0;
            end

            // VSYNC 상승 → 프레임 완료
            if (!vsync_d && vsync) begin
                frame_done <= 1'b1;
            end

            // HREF 하강 → 라인 완료
            if (href_d && !href) begin
                line_cnt  <= line_cnt + 1;
                byte_phase <= 1'b0;
                pixel_cnt  <= 16'd0;
            end

            // HREF 활성 + VSYNC 비활성 + capture_en → 픽셀 캡처
            if (capture_en && href && !vsync) begin
                if (!byte_phase) begin
                    byte_hi    <= d;
                    byte_phase <= 1'b1;
                end else begin
                    pixel_data  <= {byte_hi, d};  // RGB565
                    pixel_valid <= 1'b1;
                    byte_phase  <= 1'b0;
                    pixel_cnt   <= pixel_cnt + 1;
                end
            end else if (!href) begin
                byte_phase <= 1'b0;
            end
        end
    end
endmodule
`default_nettype wire

// sync_pulse.v — 클럭 도메인 교차: 단일 펄스 2-FF 동기화기
// src 도메인의 1클럭 펄스를 dst 도메인으로 안전하게 전달한다.
// 방법: src에서 토글 → dst에서 2-FF → 에지 검출.
// 주의: src 펄스 간격 > 2 dst 클럭 주기여야 한다.
// Verilog-2001, 외부 IP 없음.

`default_nettype none
module sync_pulse (
    input  wire src_clk,
    input  wire src_rst,
    input  wire src_pulse,   // src 도메인 1클럭 펄스 입력
    input  wire dst_clk,
    input  wire dst_rst,
    output wire dst_pulse    // dst 도메인 1클럭 펄스 출력
);
    reg       toggle;        // src 도메인 토글 레지스터
    reg [1:0] sync_ff;       // dst 도메인 2-FF
    reg       prev;          // 에지 검출용

    always @(posedge src_clk) begin
        if (src_rst) toggle <= 1'b0;
        else if (src_pulse) toggle <= ~toggle;
    end

    always @(posedge dst_clk) begin
        if (dst_rst) begin
            sync_ff <= 2'b00;
            prev    <= 1'b0;
        end else begin
            sync_ff <= {sync_ff[0], toggle};
            prev    <= sync_ff[1];
        end
    end

    assign dst_pulse = sync_ff[1] ^ prev;
endmodule
`default_nettype wire

// ov7670_sccb_top.v — OV7670 SCCB 설정 + 캡처 프런트엔드 SoC 코어
// MMIO 슬레이브(단독 시뮬레이션용 mmio-lite, 0x1004_0000)
// 하위 모듈: sccb_tx, ov7670_capture, sync_pulse
// 설정 ROM: 10개 엔트리 (실제 OV7670 RGB565 초기화 순서 일부)
// Verilog-2001, 외부 IP 없음.
//
// 레지스터 맵 (mmio-lite, word 접근):
//   OFF 0x00  CTRL    WO  bit0=START_CFG, bit1=CAP_EN, bit15=RESET
//   OFF 0x04  STATUS  RO  bit0=CFG_DONE, bit1=FRAME_DONE_LAT, bit2=SCCB_BUSY
//                         bit3=NA_ERR_LAT, bit4=FRAME_START_LAT
//   OFF 0x08  PIXEL   RO  마지막 유효 픽셀 RGB565 [15:0]
//   OFF 0x0C  FRAME   RO  [31:16]=line_cnt, [15:0]=frame_cnt
//   OFF 0xFC  ID_VER  RO  0x0006_0100 (ID=0x06, VER=0x01, REV=0x00)

`default_nettype none
module ov7670_sccb_top #(
    parameter CLK_HZ   = 100_000_000,
    parameter SCCB_KHZ = 100,
    parameter BASE_ADDR = 32'h1004_0000
)(
    // 시스템 버스
    input  wire        clk,
    input  wire        rst,
    // MMIO 슬레이브 (mmio-lite)
    input  wire [31:0] addr,
    input  wire [31:0] wdata,
    input  wire        wen,
    input  wire        ren,
    output reg  [31:0] rdata,
    // SCCB 핀 (IO 패드에서 오픈 드레인으로 외부화)
    output wire        sio_c,
    output wire        sio_d_out,
    output wire        sio_d_oe,
    input  wire        sio_d_in,
    // 카메라 픽셀 버스
    input  wire        cam_pclk,
    input  wire        cam_vsync,
    input  wire        cam_href,
    input  wire [7:0]  cam_d,
    // 디버그 (선택)
    output wire        dbg_cfg_done,
    output wire        dbg_frame_done
);
    // --- 설정 ROM (10 엔트리, 실제 OV7670 RGB565 최소 초기화) ---
    // {reg_addr[7:0], reg_data[7:0]}: 소프트 리셋 후 RGB565 모드
    localparam ROM_DEPTH = 10;
    reg [15:0] cfg_rom [0:ROM_DEPTH-1];
    initial begin
        cfg_rom[0] = 16'h1280; // COM7: SCCB 리셋
        cfg_rom[1] = 16'h1204; // COM7: RGB565 출력
        cfg_rom[2] = 16'h40D0; // COM15: RGB565 범위 0x00-0xFF
        cfg_rom[3] = 16'h3A04; // TSLB: YUYV 순서 (RGB565에서 무시)
        cfg_rom[4] = 16'h1714; // HSTART: 수평 시작
        cfg_rom[5] = 16'h1802; // HSTOP: 수평 끝
        cfg_rom[6] = 16'h3200; // HREF: 수평 가장자리
        cfg_rom[7] = 16'h1903; // VSTART: 수직 시작
        cfg_rom[8] = 16'h1A7B; // VSTOP: 수직 끝
        cfg_rom[9] = 16'h030A; // VREF: 수직 가장자리
    end

    // --- 제어 레지스터 ---
    reg        ctrl_start;      // 1클럭 펄스 (CTRL bit0)
    reg        ctrl_cap_en;     // 캡처 활성화 (CTRL bit1)
    reg        status_cfg_done;
    reg        status_frame_done_lat;
    reg        status_na_err_lat;
    reg        status_frame_start_lat;
    reg [15:0] last_pixel;
    reg [15:0] frame_cnt;

    // --- ROM 순차 송신 FSM ---
    reg  [3:0]  rom_ptr;
    reg         rom_running;
    wire        sccb_done;
    wire        sccb_na_err;
    reg         sccb_start_r;
    reg  [7:0]  sccb_reg_addr_r;
    reg  [7:0]  sccb_reg_data_r;
    localparam DEV_ADDR = 7'h21; // OV7670 write address

    sccb_tx #(.CLK_HZ(CLK_HZ), .SCCB_KHZ(SCCB_KHZ)) u_sccb (
        .clk(clk), .rst(rst),
        .start(sccb_start_r),
        .dev_addr(DEV_ADDR),
        .reg_addr(sccb_reg_addr_r),
        .reg_data(sccb_reg_data_r),
        .sio_c(sio_c),
        .sio_d_out(sio_d_out),
        .sio_d_oe(sio_d_oe),
        .sio_d_in(sio_d_in),
        .done(sccb_done),
        .na_err(sccb_na_err)
    );

    // ROM FSM
    always @(posedge clk) begin
        if (rst) begin
            rom_ptr         <= 4'd0;
            rom_running     <= 1'b0;
            status_cfg_done <= 1'b0;
            sccb_start_r    <= 1'b0;
            status_na_err_lat <= 1'b0;
        end else begin
            sccb_start_r <= 1'b0;
            if (sccb_na_err) status_na_err_lat <= 1'b1;
            if (ctrl_start && !rom_running && !status_cfg_done) begin
                rom_running     <= 1'b1;
                rom_ptr         <= 4'd0;
                status_cfg_done <= 1'b0;
                status_na_err_lat <= 1'b0;
                sccb_start_r    <= 1'b1;
                sccb_reg_addr_r <= cfg_rom[0][15:8];
                sccb_reg_data_r <= cfg_rom[0][7:0];
            end else if (rom_running && sccb_done) begin
                if (rom_ptr == ROM_DEPTH - 1) begin
                    rom_running     <= 1'b0;
                    status_cfg_done <= 1'b1;
                end else begin
                    rom_ptr         <= rom_ptr + 1;
                    sccb_start_r    <= 1'b1;
                    sccb_reg_addr_r <= cfg_rom[rom_ptr + 1][15:8];
                    sccb_reg_data_r <= cfg_rom[rom_ptr + 1][7:0];
                end
            end
        end
    end

    // --- 캡처 모듈 (PCLK 도메인) ---
    // capture_en을 PCLK 도메인으로 2-FF 동기화
    reg [1:0] cap_en_sync;
    always @(posedge cam_pclk) begin
        if (rst) cap_en_sync <= 2'b00;
        else     cap_en_sync <= {cap_en_sync[0], ctrl_cap_en};
    end

    wire [15:0] cap_pixel;
    wire        cap_pixel_valid;
    wire        cap_frame_start;
    wire        cap_frame_done;
    wire [15:0] cap_line_cnt;
    wire [15:0] cap_pixel_cnt;

    ov7670_capture u_cap (
        .pclk(cam_pclk),    .prst(rst),
        .vsync(cam_vsync),  .href(cam_href),
        .d(cam_d),
        .capture_en(cap_en_sync[1]),
        .pixel_data(cap_pixel),
        .pixel_valid(cap_pixel_valid),
        .frame_start(cap_frame_start),
        .frame_done(cap_frame_done),
        .line_cnt(cap_line_cnt),
        .pixel_cnt(cap_pixel_cnt)
    );

    // PCLK 신호를 시스템 클럭으로 교차
    wire sys_frame_done;
    wire sys_pixel_valid;
    wire sys_frame_start;

    sync_pulse u_sync_fd  (.src_clk(cam_pclk), .src_rst(rst), .src_pulse(cap_frame_done),
                            .dst_clk(clk),      .dst_rst(rst), .dst_pulse(sys_frame_done));
    sync_pulse u_sync_pv  (.src_clk(cam_pclk), .src_rst(rst), .src_pulse(cap_pixel_valid),
                            .dst_clk(clk),      .dst_rst(rst), .dst_pulse(sys_pixel_valid));
    sync_pulse u_sync_fs  (.src_clk(cam_pclk), .src_rst(rst), .src_pulse(cap_frame_start),
                            .dst_clk(clk),      .dst_rst(rst), .dst_pulse(sys_frame_start));

    // 픽셀/프레임 래치 (시스템 클럭 도메인)
    reg [15:0] cap_line_cnt_sys;
    always @(posedge clk) begin
        if (rst) begin
            last_pixel              <= 16'd0;
            frame_cnt               <= 16'd0;
            status_frame_done_lat   <= 1'b0;
            status_frame_start_lat  <= 1'b0;
            cap_line_cnt_sys        <= 16'd0;
        end else begin
            if (sys_pixel_valid) last_pixel <= cap_pixel;
            if (sys_frame_done) begin
                frame_cnt             <= frame_cnt + 1;
                status_frame_done_lat <= 1'b1;
                cap_line_cnt_sys      <= cap_line_cnt;
            end
            if (sys_frame_start) status_frame_start_lat <= 1'b1;
        end
    end

    // --- MMIO 슬레이브 ---
    wire [7:0] local_off = addr[7:0];

    always @(posedge clk) begin
        if (rst) begin
            ctrl_start  <= 1'b0;
            ctrl_cap_en <= 1'b0;
            rdata       <= 32'd0;
        end else begin
            ctrl_start <= 1'b0; // 자동 클리어
            if (wen && (addr[31:8] == BASE_ADDR[31:8])) begin
                case (local_off)
                    8'h00: begin // CTRL
                        ctrl_start  <= wdata[0];
                        ctrl_cap_en <= wdata[1];
                        if (wdata[15]) begin // RESET
                            status_cfg_done       <= 1'b0;
                            status_frame_done_lat <= 1'b0;
                            status_na_err_lat     <= 1'b0;
                        end
                    end
                    default: ;
                endcase
            end
            if (ren && (addr[31:8] == BASE_ADDR[31:8])) begin
                case (local_off)
                    8'h00: rdata <= 32'd0; // CTRL (WO)
                    8'h04: rdata <= {27'd0,
                                     status_frame_start_lat,
                                     status_na_err_lat,
                                     rom_running,
                                     status_frame_done_lat,
                                     status_cfg_done};
                    8'h08: rdata <= {16'd0, last_pixel};
                    8'h0C: rdata <= {cap_line_cnt_sys, frame_cnt};
                    8'hFC: rdata <= 32'h0006_0100; // ID=0x06 VER=0x01
                    default: rdata <= 32'hDEAD_BEEF;
                endcase
                // 상태 비트 클리어 (읽기 클리어)
                if (local_off == 8'h04) begin
                    status_frame_done_lat  <= 1'b0;
                    status_frame_start_lat <= 1'b0;
                end
            end
        end
    end

    assign dbg_cfg_done   = status_cfg_done;
    assign dbg_frame_done = sys_frame_done;
endmodule

// basys3_top.v — Basys3 보드 래퍼: OV7670 SCCB 캡처 SoC 코어
// IOBUF로 SIO_D 오픈 드레인 구현, Pmod JA 핀 배정
// 시뮬레이션용 mmio-lite 슬레이브 직결 버전 (MicroBlaze 없이)
// Verilog-2001, 외부 IP 없음.
//
// Pmod JA 배선 (Basys3 JA 헤더):
//   JA1=sio_c, JA2=sio_d(IO), JA7=cam_pclk, JA8=cam_vsync
//   JA9=cam_href, JA10=cam_d7 ... 카메라 D[7:4]
// Pmod JB 배선 (D[3:0] 연장):
//   JB1=cam_d3, JB2=cam_d2, JB3=cam_d1, JB4=cam_d0

`default_nettype none
module basys3_top (
    input  wire        clk_100mhz,   // Basys3 온보드 100 MHz
    input  wire        cpu_resetn,   // 리셋 (active low)
    // --- MMIO 테스트용 스위치/버튼 (실제 보드에서 수동 테스트용) ---
    input  wire [1:0]  sw,           // sw[0]=START_CFG, sw[1]=CAP_EN
    input  wire        btnc,         // 가운데 버튼: 1클럭 START 펄스
    output wire [3:0]  led,          // led[0]=CFG_DONE, led[1]=FRAME_DONE, led[2]=SCCB_BUSY, led[3]=NA_ERR
    // --- Pmod JA: SCCB + PCLK/VSYNC/HREF + D[7:4] ---
    output wire        ja1,          // SIO_C (SCCB 클럭)
    inout  wire        ja2,          // SIO_D (SCCB 데이터, 오픈 드레인)
    input  wire        ja7,          // cam_pclk
    input  wire        ja8,          // cam_vsync
    input  wire        ja9,          // cam_href
    input  wire        ja10,         // cam_d[7]
    // --- Pmod JB: cam_d[6:3] ---
    input  wire        jb1,          // cam_d[6]
    input  wire        jb2,          // cam_d[5]
    input  wire        jb3,          // cam_d[4]
    input  wire        jb4,          // cam_d[3]
    // --- Pmod JC: cam_d[2:0] + 추가 ---
    input  wire        jc1,          // cam_d[2]
    input  wire        jc2,          // cam_d[1]
    input  wire        jc3           // cam_d[0]
);
    // --- 리셋 동기화 (active-high 2단 FF) ---
    reg [1:0] rst_sync;
    always @(posedge clk_100mhz or negedge cpu_resetn) begin
        if (!cpu_resetn) rst_sync <= 2'b11;
        else             rst_sync <= {rst_sync[0], 1'b0};
    end
    wire rst = rst_sync[1];

    // --- btnc 에지 검출 (3단 debounce + 1클럭 펄스) ---
    reg [2:0] btn_sync;
    always @(posedge clk_100mhz) begin
        if (rst) btn_sync <= 3'b0;
        else     btn_sync <= {btn_sync[1:0], btnc};
    end
    wire btn_pulse = btn_sync[1] & ~btn_sync[2];

    // --- MMIO 테스트 버스 (스위치/버튼으로 간이 조작) ---
    wire [31:0] mmio_addr  = 32'h1004_0000; // CTRL 레지스터
    wire [31:0] mmio_wdata = {16'd0, sw[1], sw[0]};
    wire        mmio_wen   = btn_pulse;
    wire        mmio_ren   = 1'b0;
    wire [31:0] mmio_rdata;

    // --- SCCB SIO_D 오픈 드레인: IOBUF ---
    wire sio_d_out_w;
    wire sio_d_oe_w;
    wire sio_d_in_w;
    // Basys3는 IOBUF 프리미티브 사용
    // 시뮬레이션에서는 assign으로 대체 (ifdef)
`ifdef SYNTHESIS
    IOBUF u_iobuf_siod (
        .O  (sio_d_in_w),
        .IO (ja2),
        .I  (sio_d_out_w),
        .T  (~sio_d_oe_w)   // T=1 → 하이임피던스
    );
`else
    // 시뮬레이션 모델: 출력 활성이면 out, 아니면 Z
    assign ja2       = sio_d_oe_w ? sio_d_out_w : 1'bz;
    assign sio_d_in_w = ja2;
`endif

    // --- 카메라 데이터 버스 ---
    wire [7:0] cam_d = {ja10, jb1, jb2, jb3, jb4, jc1, jc2, jc3};

    // --- SoC 코어 인스턴스 ---
    wire [4:0] status_bits;

    ov7670_sccb_top #(
        .CLK_HZ  (100_000_000),
        .SCCB_KHZ(100),
        .BASE_ADDR(32'h1004_0000)
    ) u_core (
        .clk      (clk_100mhz),
        .rst      (rst),
        .addr     (mmio_addr),
        .wdata    (mmio_wdata),
        .wen      (mmio_wen),
        .ren      (mmio_ren),
        .rdata    (mmio_rdata),
        .sio_c    (ja1),
        .sio_d_out(sio_d_out_w),
        .sio_d_oe (sio_d_oe_w),
        .sio_d_in (sio_d_in_w),
        .cam_pclk (ja7),
        .cam_vsync(ja8),
        .cam_href (ja9),
        .cam_d    (cam_d),
        .dbg_cfg_done  (led[0]),
        .dbg_frame_done(led[1])
    );

    // STATUS 비트 → LED (STATUS 레지스터를 수동 읽기 대신 내부 신호 사용)
    // led[0]=dbg_cfg_done, led[1]=dbg_frame_done은 위에서 연결
    // led[2], led[3]은 사용 불가 (rdata 버스 접근 없이)
    assign led[2] = 1'b0;
    assign led[3] = 1'b0;
endmodule
`default_nettype wire
tb/tb_sccb_tx.v 180줄
// tb_sccb_tx.v — sccb_tx 모듈 자체 점검 테스트벤치
// SCCB 슬레이브 모델: 각 NA 비트에서 1(don't-care) 응답
// 3회 전송(3바이트 패킷)을 발행해 타이밍과 done/na_err을 검증한다.
// 통과: "PASS: ..." , 실패: "FAIL: ..." 로 시작하는 줄 출력 후 $finish
// Verilog-2001, 외부 IP 없음.

`timescale 1ns/1ps
`default_nettype none
module tb_sccb_tx;
    // 파라미터 (빠른 시뮬을 위해 10 kHz 사용)
    localparam CLK_HZ   = 10_000_000;
    localparam SCCB_KHZ = 10;
    localparam CLK_P    = 100; // ns (10 MHz)
    localparam HALF_CNT = (CLK_HZ / (SCCB_KHZ * 1000)) / 2; // 500

    // DUT 신호
    reg        clk, rst, start;
    reg  [6:0] dev_addr;
    reg  [7:0] reg_addr, reg_data;
    wire       sio_c;
    wire       sio_d_out;
    wire       sio_d_oe;
    reg        sio_d_in;
    wire       done;
    wire       na_err;

    // DUT 인스턴스
    sccb_tx #(.CLK_HZ(CLK_HZ), .SCCB_KHZ(SCCB_KHZ)) dut (
        .clk(clk), .rst(rst),
        .start(start),
        .dev_addr(dev_addr), .reg_addr(reg_addr), .reg_data(reg_data),
        .sio_c(sio_c),
        .sio_d_out(sio_d_out), .sio_d_oe(sio_d_oe),
        .sio_d_in(sio_d_in),
        .done(done), .na_err(na_err)
    );

    // 클럭 생성
    initial clk = 0;
    always #(CLK_P/2) clk = ~clk;

    // 슬레이브 모델: sio_d_oe=0(릴리즈) 구간에 sio_d_in=1(NA=1, 정상)
    always @(*) begin
        if (!sio_d_oe)
            sio_d_in = 1'b1; // NA 비트: 슬레이브가 1(don't-care)
        else
            sio_d_in = sio_d_out; // 출력 모드: 루프백
    end

    // ----------------------------------------------------------------
    // 태스크: 한 번 전송 후 done 대기 (타임아웃 포함)
    // ----------------------------------------------------------------
    integer done_cnt;
    integer timeout;
    reg     got_done;

    task send_and_wait;
        input [6:0] da;
        input [7:0] ra, rd;
        begin
            @(posedge clk); #1;
            dev_addr = da; reg_addr = ra; reg_data = rd;
            start = 1'b1;
            @(posedge clk); #1;
            start = 1'b0;
            // done 대기 (최대 10000 클럭)
            got_done = 0;
            timeout  = 10000;
            while (!got_done && timeout > 0) begin
                @(posedge clk); #1;
                if (done) got_done = 1;
                timeout = timeout - 1;
            end
        end
    endtask

    // ----------------------------------------------------------------
    // 테스트 시나리오
    // ----------------------------------------------------------------
    reg [7:0] fail_code;
    integer   na_err_cnt;
    integer   done_cnt2;

    initial begin
        // 초기화
        rst = 1; start = 0;
        dev_addr = 7'h21; reg_addr = 8'h12; reg_data = 8'h80;
        na_err_cnt = 0;
        done_cnt2  = 0;
        fail_code  = 8'd0;

        repeat(5) @(posedge clk);
        rst = 0;
        repeat(2) @(posedge clk);

        // ---- 테스트 1: 첫 번째 전송 ----
        send_and_wait(7'h21, 8'h12, 8'h80);
        if (!got_done) begin
            $display("FAIL: T1 done 타임아웃 (dev=0x21 reg=0x12 data=0x80)");
            $finish;
        end
        done_cnt2 = done_cnt2 + 1;

        // ---- 테스트 2: 두 번째 전송 ----
        repeat(5) @(posedge clk);
        send_and_wait(7'h21, 8'h1204>>8, 8'h04);
        if (!got_done) begin
            $display("FAIL: T2 done 타임아웃 (reg=0x12 data=0x04)");
            $finish;
        end
        done_cnt2 = done_cnt2 + 1;

        // ---- 테스트 3: 세 번째 전송 ----
        repeat(5) @(posedge clk);
        send_and_wait(7'h21, 8'h40, 8'hD0);
        if (!got_done) begin
            $display("FAIL: T3 done 타임아웃 (reg=0x40 data=0xD0)");
            $finish;
        end
        done_cnt2 = done_cnt2 + 1;

        // ---- na_err 없어야 함 (슬레이브가 1 응답) ----
        // na_err은 각 전송 중에 발생하므로 별도 카운터 없이 간단 체크
        // (슬레이브 모델이 항상 1을 돌려주므로 na_err이 없어야 함)

        // ---- done 횟수 확인 ----
        if (done_cnt2 !== 3) begin
            $display("FAIL: done 횟수 불일치 (기대=3, 실제=%0d)", done_cnt2);
            $finish;
        end

        // ---- START 중 재start 무시 테스트 ----
        // (rom_running 상태에서 start를 보내도 무시해야 함 — sccb_tx는 별도 FSM 아님)
        // 단순히 IDLE에서만 start를 받는지 확인: 전송 중 start 1 → done이 1번만 오는지
        repeat(2) @(posedge clk);
        begin
            @(posedge clk); #1;
            dev_addr = 7'h21; reg_addr = 8'h03; reg_data = 8'h0A;

            @(posedge clk); #1;

            @(posedge clk); #1;

                timeout = timeout - 1;

                $finish;
            end

        if (sio_c !== 1'b1) begin

            $finish;

        $finish;

// 카메라 모델: PCLK 24 MHz 모의, VSYNC·HREF·픽셀 데이터 시퀀스 생성
// 프레임 1개(2라인, 라인당 4픽셀)를 보내고 픽셀 값·카운터를 검증한다.
// 통과: "PASS: ..." , 실패: "FAIL: ..." 로 시작하는 줄 출력 후 $finish
// Verilog-2001, 외부 IP 없음.

`timescale 1ns/1ps
`default_nettype none
module tb_ov7670_capture;
    // 타이밍 (PCLK 24 MHz ≒ 41.67 ns → 42 ns 사용)
    localparam PCLK_P = 42; // ns

    // DUT 신호
    reg        pclk, prst;
    reg        vsync, href;
    reg  [7:0] d;
    reg        capture_en;
    wire [15:0] pixel_data;
    wire        pixel_valid;
    wire        frame_start;
    wire        frame_done;
    wire [15:0] line_cnt;
    wire [15:0] pixel_cnt;

    // DUT 인스턴스
    ov7670_capture dut (
        .pclk(pclk), .prst(prst),
        .vsync(vsync), .href(href),
        .d(d),
        .capture_en(capture_en),
        .pixel_data(pixel_data), .pixel_valid(pixel_valid),
        .frame_start(frame_start), .frame_done(frame_done),
        .line_cnt(line_cnt), .pixel_cnt(pixel_cnt)
    );

    // PCLK 생성
    initial pclk = 0;
    always #(PCLK_P/2) pclk = ~pclk;

    // ----------------------------------------------------------------
    // 태스크: 1클럭 PCLK 대기
    // ----------------------------------------------------------------
    task pclk1; begin @(posedge pclk); #1; end endtask

    // ----------------------------------------------------------------
    // 태스크: 한 픽셀(2바이트) 전송 (HREF=1, capture_en=1 가정)
    // ----------------------------------------------------------------
    task send_pixel;
        input [7:0] hi, lo;
        begin
            d = hi; pclk1; // 첫 바이트
            d = lo; pclk1; // 두 번째 바이트 → pixel_valid 발생
        end
    endtask

    // ----------------------------------------------------------------
    // 태스크: HREF 한 라인 전송 (N 픽셀)
    // ----------------------------------------------------------------
    task send_line;
        input integer npix;
        input [15:0] base_val; // 첫 픽셀 값 (이후 +1씩)
        integer i;
        begin
            href = 1'b1;
            for (i = 0; i < npix; i = i + 1) begin
                send_pixel(base_val[15:8] + i, base_val[7:0] + i);
            end
            href = 1'b0;
            pclk1; // HREF 하강 처리
        end
    endtask

    // ----------------------------------------------------------------
    // 검증 변수
    // ----------------------------------------------------------------
    integer   pixel_count;
    reg [15:0] last_pix;
    integer   frame_start_cnt;
    integer   frame_done_cnt;
    integer   line_cnt_val;

    // 이벤트 카운터 (posedge pclk에서 래치)
    always @(posedge pclk) begin
        if (prst) begin
            pixel_count     <= 0;
            last_pix        <= 16'd0;
            frame_start_cnt <= 0;
            frame_done_cnt  <= 0;
        end else begin
            if (pixel_valid) begin
                pixel_count <= pixel_count + 1;
                last_pix    <= pixel_data;
            end
            if (frame_start) frame_start_cnt <= frame_start_cnt + 1;
            if (frame_done)  frame_done_cnt  <= frame_done_cnt + 1;
        end
    end

    // ----------------------------------------------------------------
    // 테스트 시나리오
    // ----------------------------------------------------------------
    initial begin
        // 초기화
        prst = 1; vsync = 0; href = 0; d = 8'd0; capture_en = 1;
        pixel_count = 0; last_pix = 0;
        frame_start_cnt = 0; frame_done_cnt = 0;

        repeat(5) pclk1;
        prst = 0;
        repeat(3) pclk1;

        // ============================================================
        // 테스트 1: 프레임 1개 (2라인 × 4픽셀 = 8픽셀)
        // OV7670 타이밍: VSYNC high → 블랭킹, 하강 → 프레임 시작
        //               VSYNC low → 활성 구간, HREF 라인들
        //               VSYNC 상승 → 프레임 완료
        // ============================================================

        // 블랭킹 구간 (VSYNC high)
        vsync = 1'b1;
        repeat(4) pclk1;

        // VSYNC 하강 → frame_start 기대
        vsync = 1'b0;
        pclk1; // 에지 처리

        // 라인 1: 4픽셀 (hi: 0xAB+0..3, lo: 0xCD+0..3)
        send_line(4, 16'hABCD);
        pclk1; // 라인 간 간격

        // 라인 2: 4픽셀
        send_line(4, 16'h1234);
        pclk1;

        // VSYNC 상승 → frame_done 기대
        vsync = 1'b1;
        pclk1;
        pclk1;

        // 추가 대기
        repeat(5) pclk1;

        // ---- 검증 ----
        // 1. frame_start: 1회
        if (frame_start_cnt !== 1) begin
            $display("FAIL: frame_start 횟수 불일치 (기대=1, 실제=%0d)", frame_start_cnt);
            $finish;
        end

        // 2. frame_done: 1회
        if (frame_done_cnt !== 1) begin
            $display("FAIL: frame_done 횟수 불일치 (기대=1, 실제=%0d)", frame_done_cnt);
            $finish;
        end

        // 3. 픽셀 수: 8 (2라인 × 4픽셀)
        if (pixel_count !== 8) begin
            $display("FAIL: 픽셀 수 불일치 (기대=8, 실제=%0d)", pixel_count);
            $finish;
        end

        // 4. line_cnt: 2 (두 라인 완료)
        if (line_cnt !== 16'd2) begin
            $display("FAIL: line_cnt 불일치 (기대=2, 실제=%0d)", line_cnt);
            $finish;
        end

        // 5. 마지막 픽셀 값 검증 (라인2의 4번째 픽셀: hi=0x12+3=0x15, lo=0x34+3=0x37)
        if (last_pix !== 16'h1537) begin
            $display("FAIL: 마지막 픽셀 불일치 (기대=0x1537, 실제=0x%04X)", last_pix);
            $finish;
        end

        // ============================================================
        // 테스트 2: capture_en=0 → 픽셀 무시
        // ============================================================
        capture_en = 1'b0;
        pixel_count = 0; // 카운터 직접 초기화 (reg이므로 가능)
        vsync = 1'b1; repeat(2) pclk1;
        vsync = 1'b0; pclk1;
        send_line(4, 16'hDEAD);
        vsync = 1'b1; pclk1;
        repeat(3) pclk1;

        if (pixel_count !== 0) begin
            $display("FAIL: capture_en=0인데 픽셀 캡처됨 (count=%0d)", pixel_count);
            $finish;
        end

        // ============================================================
        // 테스트 3: VSYNC 중 HREF=1 → 픽셀 무시 (블랭킹 구간)
        // ============================================================
        capture_en = 1'b1;
        pixel_count = 0;
        vsync = 1'b1; // 블랭킹
        href  = 1'b1;
        d = 8'hFF;
        pclk1; pclk1; pclk1; pclk1;
        href = 1'b0;
        pclk1;

        if (pixel_count !== 0) begin
            $display("FAIL: VSYNC=1 블랭킹 중 픽셀 캡처됨 (count=%0d)", pixel_count);
            $finish;
        end

        $display("PASS: ov7670_capture — 픽셀 8개, line_cnt=2, 마지막=0x1537 확인");
        $finish;
    end

    // 타임아웃 가드
    initial begin
        #(PCLK_P * 5000);
        $display("FAIL: 전체 테스트 타임아웃 (5000 PCLK 초과)");
        $finish;
    end

    initial begin
        $dumpfile("tb_ov7670_capture.vcd");
        $dumpvars(0, tb_ov7670_capture);
    end
endmodule

위험·한계

  • PCLK 비동기 리셋: ov7670_capture의 prst는 시스템 리셋 신호를 그대로 받는다. PCLK 도메인에서 리셋 메타스태빌리티 위험 — 이식 시 2-FF 동기화 추가 필요
  • sync_pulse 조건: src 펄스 간격 > 2 dst 클럭 주기 보장 필요. pixel_valid는 PCLK 주기마다 가능하여, 24 MHz PCLK에서 2×(1/100 MHz)=20 ns 미충족 위험. 픽셀마다 pixel_valid를 올리는 현재 설계는 고속 환경에서 CDC 누락 가능 — 고속 전송 시 BRAM FIFO + handshake로 교체 권장
  • 설정 ROM 크기: 10 엔트리만 포함 (실제 OV7670 RGB565 초기화는 약 50+ 레지스터). 나머지 레지스터는 기본값 의존
  • na_err: OV7670 SCCB는 NA(don't-care)이므로 na_err=1이어도 정상 동작 가능. 에러 처리 없이 래치만 함
  • IO 전압: Pmod 3.3V, OV7670 모듈 IO 3.3V. 직접 연결 가능하나 모듈 종류에 따라 5V VCC 공급 필요한 경우가 있으므로 모듈 사양 확인 필수
