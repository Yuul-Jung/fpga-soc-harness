CTRL/DATA형 W5500 UDP TX IP

W5500 Ethernet 모듈의 SPI를 직접 구동해 UDP 패킷을 송신하는 Basys3 mmio-lite IP. 초기화(Socket 0 설정), TX 버퍼 적재, SEND 커맨드 발행, SENDOK 폴링까지 FSM 한 개로 처리하고, IRQ로 완료를 알린다.

린트: pass (경고 0건)시뮬레이션: pass (PASS: W5500 UDP TX 11단계 검증 — IP_ID, TX_LEN/DATA/PTR, init_done, go, err==0, IRQ_STATUS, irq선, W1C)합성: pass (합성 성공, stat 파싱 실패로 LUT/FF 미기록)보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • mmio-lite 버스 위에서 W5500 SPI 마스터를 구동해 UDP 단일 패킷 송신 제공
  • CTRL 레지스터(GO/INIT 비트 자기 소거, BUSY·ERR·INIT_DONE 플래그)와 TX_DATA FIFO로 간단한 인터페이스 제공
  • IP 표준 Rev.1 관리 레지스터(IP_ID·VER·IRQ_STATUS·IRQ_ENABLE) 준수
  • iverilog 시뮬레이션에서 가짜 W5500 슬레이브와 SENDOK 폴링 PASS 확인

범위 밖

  • 멀티 소켓 (Socket 0 전용)
  • TCP, ICMP, ARP 등 UDP 외 프로토콜
  • 목적지 IP/MAC/포트 런타임 변경 (init ROM에 고정)
  • 400 kHz 이상 SPI 클럭 (CLK_DIV 파라미터로 조정 가능)
  • AXI4-Lite 버스 인터페이스 (mmio-lite 전용)
  • 보드 동작 확인 (S3)

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. mmio-lite 버스(AXI4-Lite 비호환, 시뮬 전용). 가짜 W5500 SPI 슬레이브를 포함한 자체 점검 테스트벤치로 SENDOK 폴링 및 IRQ 동작을 검증한다.

2. 계통도

클럭: 100 MHz 시스템 클럭(clk); SPI 클럭 = clk / (CLK_DIV * 2) → CLK_DIV=500이면 SPI 100 kHz

신호방향설명

AXI4-Lite 비호환. ready/valid 핸드셰이크 없음. 한 사이클 응답. SPI 전송 중 BUSY=1이므로 CPU가 폴링 필요.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

Pmod SPI 4선(SCK/MOSI/MISO/CSn) + VCC/GND만 연결. 별도 회로도 미작성.

id부품인터페이스신호 전압구분레벨 변환비고
ext_w5500_pmodPmod NIC100 (W5500 기반 Ethernet Pmod)SPI3.3 V외부 모듈불필요 (3.3V)Digilent Pmod NIC100 또는 호환 W5500 SPI 모듈. 직결 시 Pmod JA 핀 사용.

Basys3 FPGA 핀은 3.3V 신호만 직접 받는다. 5V·12V·모터·릴레이는 직결하지 않는다.

rtl/w5500_udp_tx_ip.v 521줄
/* w5500_udp_tx_ip.v — W5500 SPI UDP 텔레메트리 TX MMIO IP
 * Origin: capstones/mmio-w5500-udp-tx-ip/rtl/w5500_udp_tx_ip.v
 * Verilog-2001. iverilog / verilator / yosys 호환.
 *
 * MMIO 레지스터 맵 (32-bit 워드, 바이트 주소):
 *   0x0000  CTRL   [0]=go(W1P) [1]=init(W1P) [10]=busy(RO)
 *                  [11]=err(RO) [13]=init_done(RO)
 *   0x0004  TX_LEN [5:0] = 송신 바이트 수 (1..64)
 *   0x0008  TX_DATA [7:0] = TX 버퍼에 한 바이트씩 적재 (쓰기 전용)
 *   0x000C  TX_PTR  [5:0] = 현재 TX 버퍼 적재 포인터 (읽기 전용)
 *   0xFFF0  IP_ID  = 32'h5735_5544 ("W5UD")
 *   0xFFF4  IP_VER = 32'h0000_0100
 *   0xFFF8  IRQ_STATUS [0]=tx_done (W1C)
 *   0xFFFC  IRQ_ENABLE [0]=tx_done_en
 *
 * go  비트(bit0) 쓰기: UDP 송신 시작 (init_done=1, busy=0일 때만 유효)
 * init 비트(bit1) 쓰기: W5500 초기화 시작 (busy=0일 때만 유효)
 * 초기화: ROM 10개 SPI 단일 바이트 커맨드 순차 송신 → init_done=1
 * 송신: TX 버퍼→W5500 TX 블록→Sn_TX_WR 갱신→SEND 커맨드→SENDOK 폴링
 * 완료: busy=0, irq (tx_done_en=1 시)
 *
 * SPI: MODE=0 (CPOL=0, CPHA=0). CLK_DIV = SCK 반주기 클럭 수.
 * W5500 프레임: [addr_hi, addr_lo, ctrl_byte, data...]
 *   ctrl_byte = {BlockSel[4:0], W/R, LenMode[1:0]}
 *   Common regs write: {5'h00,1,2'b00} = 8'h04
 *   Socket 0 regs write: {5'h01,1,2'b00} = 8'h0C
 *   Socket 0 regs read:  {5'h01,0,2'b00} = 8'h08
 *   Socket 0 TX buf write: {5'h03,1,2'b00} = 8'h1C
 */
`timescale 1ns/1ps
module w5500_udp_tx_ip #(
    parameter CLK_DIV = 500   /* SCK 반주기 클럭 수 (100MHz→100kHz:500) */
)(
    input  wire        clk,
    input  wire        rst_n,
    /* MMIO (mmio-lite: 단일 사이클) */
    input  wire [15:0] mmio_addr,
    input  wire [31:0] mmio_wdata,
    output reg  [31:0] mmio_rdata,
    input  wire        mmio_we,
    input  wire        mmio_cs,
    /* SPI (W5500) — MODE=0 오픈 드레인 아님 */
    output reg         spi_sck,
    output reg         spi_mosi,
    output reg         spi_csn,
    input  wire        spi_miso,
    /* 인터럽트 */
    output wire        irq
);

/* ===== MMIO 레지스터 ===== */
reg        r_busy, r_err, r_init_done;
reg  [5:0] r_tx_len;
reg  [7:0] r_tx_buf [0:63];   /* 64바이트 TX 버퍼 */
reg  [5:0] r_tx_ptr;           /* TX 버퍼 적재 포인터 */
reg        r_irq_st, r_irq_en;

assign irq = r_irq_st & r_irq_en;

/* ===== 초기화 ROM ===== */
/* {addr[15:0], ctrl[7:0], data[7:0]} — 32비트 엔트리 */
localparam ROM_DEPTH = 10;
reg [31:0] init_rom [0:ROM_DEPTH-1];
initial begin
    init_rom[0] = {16'h0000, 8'h04, 8'h80}; /* MR = RST */
    init_rom[1] = {16'h000F, 8'h04, 8'hC0}; /* SIPR[0]=192 */
    init_rom[2] = {16'h0010, 8'h04, 8'hA8}; /* SIPR[1]=168 */
    init_rom[3] = {16'h0011, 8'h04, 8'h01}; /* SIPR[2]=1   */
    init_rom[4] = {16'h0012, 8'h04, 8'h64}; /* SIPR[3]=100 */
    init_rom[5] = {16'h0001, 8'h04, 8'hC0}; /* GAR[0]=192  */
    init_rom[6] = {16'h0002, 8'h04, 8'hA8}; /* GAR[1]=168  */
    init_rom[7] = {16'h0000, 8'h0C, 8'h02}; /* S0_MR=UDP   */
    init_rom[8] = {16'h0004, 8'h0C, 8'h1F}; /* S0_PORT[0]  */
    init_rom[9] = {16'h0001, 8'h0C, 8'h01}; /* S0_CR=OPEN  */
end

/* ===== SPI 마스터 ===== */
/* MODE=0: SCK 아이들=0. MOSI 세팅→SCK↑(슬레이브 샘플)→SCK↓(다음 비트) */
localparam [11:0] SPI_HALF = CLK_DIV - 1;
reg [11:0] spi_div;    /* 반주기 카운터 */
reg  [2:0] spi_bst;    /* 현재 비트 (7→0) */
reg        spi_phase;  /* 0=SCK 로우, 1=SCK 하이 */
reg        spi_bsy;    /* 바이트 송수신 중 */
reg  [7:0] spi_sreg;   /* 송신 시프트 레지스터 */
reg  [7:0] spi_rx;     /* 수신 완료 바이트 */
reg        spi_kick;   /* 1클럭 펄스 → 바이트 송신 시작 */
reg        spi_done;   /* 1클럭 펄스 → 바이트 완료 */

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        spi_sck  <= 1'b0; spi_mosi <= 1'b0;
        spi_div  <= 12'd0; spi_bst  <= 3'd7; spi_phase <= 1'b0;
        spi_bsy  <= 1'b0; spi_sreg <= 8'd0; spi_rx <= 8'd0;
        spi_done <= 1'b0;
    end else begin
        spi_done <= 1'b0;
        if (spi_kick && !spi_bsy) begin
            spi_bsy   <= 1'b1;
            spi_bst   <= 3'd7;
            spi_phase <= 1'b0;
            spi_div   <= 12'd0;
            spi_mosi  <= spi_sreg[7];  /* 첫 비트 출력 */
            spi_sck   <= 1'b0;
        end else if (spi_bsy) begin
            if (spi_div == SPI_HALF) begin
                spi_div <= 12'd0;
                if (spi_phase == 1'b0) begin
                    /* SCK 상승: 슬레이브가 MOSI 샘플, 마스터가 MISO 샘플 */
                    spi_sck   <= 1'b1;
                    spi_rx    <= {spi_rx[6:0], spi_miso};
                    spi_phase <= 1'b1;
                end else begin
                    /* SCK 하강: 다음 비트 출력 */
                    spi_sck   <= 1'b0;
                    spi_phase <= 1'b0;
                    if (spi_bst == 3'd0) begin
                        spi_bsy  <= 1'b0;
                        spi_done <= 1'b1;
                    end else begin
                        spi_bst  <= spi_bst - 3'd1;
                        spi_mosi <= spi_sreg[spi_bst - 3'd1];
                    end
                end
            end else begin
                spi_div <= spi_div + 12'd1;
            end
        end
    end
end

/* ===== 메인 FSM ===== */
localparam [3:0]
    S_IDLE      = 4'd0,
    S_ROM_FRAME = 4'd1,  /* 초기화 ROM 프레임 송신 */
    S_TX_BH     = 4'd2,  /* TX 버퍼 헤더 (3바이트) */
    S_TX_BD     = 4'd3,  /* TX 버퍼 데이터 */
    S_TX_WH     = 4'd4,  /* Sn_TX_WR 갱신 헤더 (3바이트) */
    S_TX_WD     = 4'd5,  /* Sn_TX_WR 갱신 데이터 (2바이트) */
    S_TX_SC     = 4'd6,  /* SEND 커맨드 (4바이트) */
    S_TX_PH     = 4'd7,  /* POLL Sn_IR 헤더 (3바이트) */
    S_TX_PD     = 4'd8,  /* POLL Sn_IR 데이터 (1바이트 수신) */
    S_DONE      = 4'd9,
    S_ERROR     = 4'd10;

reg  [3:0] state;
reg  [3:0] rom_idx;    /* ROM 항목 인덱스 (0..9) */
reg  [5:0] data_idx;   /* TX 데이터 인덱스 */
reg  [2:0] byte_idx;   /* 현재 프레임 내 바이트 인덱스 */
reg [15:0] tx_wr_ptr;  /* W5500 TX 쓰기 포인터 추적 */
reg [15:0] poll_cnt;   /* 폴링 타임아웃 카운터 */

/* go/init 펄스: CTRL 레지스터 bit0/bit1 쓰기, IDLE+!busy 시 유효 */
wire go_pulse   = mmio_cs && mmio_we &&
                  (mmio_addr[15:0] == 16'h0000) &&
                  mmio_wdata[0] && !r_busy && r_init_done;
wire init_pulse = mmio_cs && mmio_we &&
                  (mmio_addr[15:0] == 16'h0000) &&
                  mmio_wdata[1] && !r_busy;

always @(posedge clk or negedge rst_n) begin : main_fsm
    integer i;
    if (!rst_n) begin
        r_busy      <= 1'b0; r_err  <= 1'b0; r_init_done <= 1'b0;
        r_tx_len    <= 6'd0; r_tx_ptr <= 6'd0;
        r_irq_st    <= 1'b0; r_irq_en <= 1'b0;
        for (i = 0; i < 64; i = i + 1) r_tx_buf[i] <= 8'd0;
        state       <= S_IDLE;
        rom_idx     <= 4'd0; data_idx <= 6'd0; byte_idx <= 3'd0;
        tx_wr_ptr   <= 16'd0; poll_cnt <= 16'd0;
        spi_csn     <= 1'b1;  spi_kick  <= 1'b0; spi_sreg  <= 8'd0;
    end else begin
        spi_kick <= 1'b0;  /* default */

        /* ---- MMIO 쓰기 ---- */
        if (mmio_cs && mmio_we) begin
            case (mmio_addr[15:0])
                16'h0004: r_tx_len <= mmio_wdata[5:0];
                16'h0008: begin
                    r_tx_buf[r_tx_ptr] <= mmio_wdata[7:0];
                    if (r_tx_ptr != 6'd63) r_tx_ptr <= r_tx_ptr + 6'd1;
                end
                16'hFFF8: r_irq_st <= r_irq_st & ~mmio_wdata[0]; /* W1C */
                16'hFFFC: r_irq_en <= mmio_wdata[0];
                default: ;
            endcase
        end

        /* ---- FSM ---- */
        case (state)

            /* 유휴 */
            S_IDLE: begin
                spi_csn <= 1'b1;
                if (init_pulse) begin
                    r_busy   <= 1'b1; r_err <= 1'b0;
                    r_irq_st <= 1'b0;
                    rom_idx  <= 4'd0; byte_idx <= 3'd0;
                    tx_wr_ptr <= 16'd0;
                    state    <= S_ROM_FRAME;
                end else if (go_pulse) begin
                    r_busy   <= 1'b1; r_err <= 1'b0;
                    r_irq_st <= 1'b0;
                    r_tx_ptr <= 6'd0;  /* TX 버퍼 포인터 초기화 */
                    data_idx <= 6'd0; byte_idx <= 3'd0;
                    state    <= S_TX_BH;
                end
            end

            /* ---- 초기화 ROM 순회 ---- */
            /* 각 엔트리: CSn=0 → addr_hi → addr_lo → ctrl → data → CSn=1 */
            S_ROM_FRAME: begin
                if (!spi_bsy && !spi_kick) begin
                    case (byte_idx)
                        3'd0: begin  /* addr_hi */
                            spi_csn  <= 1'b0;
                            spi_sreg <= init_rom[rom_idx][31:24];
                            spi_kick <= 1'b1;
                            byte_idx <= 3'd1;
                        end
                        3'd1: begin  /* addr_lo */
                            if (spi_done) begin
                                spi_sreg <= init_rom[rom_idx][23:16];
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd2;
                            end
                        end
                        3'd2: begin  /* ctrl */
                            if (spi_done) begin
                                spi_sreg <= init_rom[rom_idx][15:8];
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd3;
                            end
                        end
                        3'd3: begin  /* data */
                            if (spi_done) begin
                                spi_sreg <= init_rom[rom_idx][7:0];
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd4;
                            end
                        end
                        3'd4: begin  /* 프레임 종료 대기 */
                            if (spi_done) begin
                                spi_csn <= 1'b1;
                                byte_idx <= 3'd0;
                                if (rom_idx == ROM_DEPTH - 1) begin
                                    /* 모든 ROM 완료 */
                                    r_init_done <= 1'b1;
                                    r_busy      <= 1'b0;
                                    state       <= S_IDLE;
                                end else begin
                                    rom_idx <= rom_idx + 4'd1;
                                end
                            end
                        end
                        default: byte_idx <= 3'd0;
                    endcase
                end
            end

            /* ---- TX 버퍼 → W5500 TX 블록 헤더 ---- */
            /* 3바이트: 0x00(addr_hi), 0x00(addr_lo), 0x1C(s0 TX buf write) */
            S_TX_BH: begin
                if (!spi_bsy && !spi_kick) begin
                    case (byte_idx)
                        3'd0: begin
                            spi_csn  <= 1'b0;
                            spi_sreg <= 8'h00;  /* TX 버퍼 주소 상위 */
                            spi_kick <= 1'b1;
                            byte_idx <= 3'd1;
                        end
                        3'd1: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h00;  /* TX 버퍼 주소 하위 */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd2;
                            end
                        end
                        3'd2: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h1C;  /* S0 TX buf, write */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd3;
                            end
                        end
                        3'd3: begin
                            if (spi_done) begin
                                byte_idx <= 3'd0;
                                data_idx <= 6'd0;
                                state    <= S_TX_BD;
                            end
                        end
                        default: byte_idx <= 3'd0;
                    endcase
                end
            end

            /* ---- TX 버퍼 데이터 (r_tx_len 바이트) ---- */
            S_TX_BD: begin
                if (!spi_bsy && !spi_kick) begin
                    if (data_idx < r_tx_len) begin
                        if (spi_done || data_idx == 6'd0) begin
                            spi_sreg <= r_tx_buf[data_idx];
                            spi_kick <= 1'b1;
                            data_idx <= data_idx + 6'd1;
                        end
                    end else begin
                        if (spi_done || r_tx_len == 6'd0) begin
                            spi_csn   <= 1'b1;
                            tx_wr_ptr <= tx_wr_ptr + {10'd0, r_tx_len};
                            byte_idx  <= 3'd0;
                            state     <= S_TX_WH;
                        end
                    end
                end
            end

            /* ---- Sn_TX_WR 갱신 헤더 (3바이트) ---- */
            /* Sn_TX_WR = socket 0 reg 0x0022 */
            S_TX_WH: begin
                if (!spi_bsy && !spi_kick) begin
                    case (byte_idx)
                        3'd0: begin
                            spi_csn  <= 1'b0;
                            spi_sreg <= 8'h00;  /* 0x0022 주소 상위 */
                            spi_kick <= 1'b1;
                            byte_idx <= 3'd1;
                        end
                        3'd1: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h22;  /* 0x0022 주소 하위 */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd2;
                            end
                        end
                        3'd2: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h0C;  /* S0 regs, write */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd3;
                            end
                        end
                        3'd3: begin
                            if (spi_done) begin
                                byte_idx <= 3'd0;
                                state    <= S_TX_WD;
                            end
                        end
                        default: byte_idx <= 3'd0;
                    endcase
                end
            end

            /* ---- Sn_TX_WR 갱신 데이터 (2바이트: ptr[15:8], ptr[7:0]) ---- */
            S_TX_WD: begin
                if (!spi_bsy && !spi_kick) begin
                    case (byte_idx)
                        3'd0: begin
                            spi_sreg <= tx_wr_ptr[15:8];
                            spi_kick <= 1'b1;
                            byte_idx <= 3'd1;
                        end
                        3'd1: begin
                            if (spi_done) begin
                                spi_sreg <= tx_wr_ptr[7:0];
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd2;
                            end
                        end
                        3'd2: begin
                            if (spi_done) begin
                                spi_csn  <= 1'b1;
                                byte_idx <= 3'd0;
                                state    <= S_TX_SC;
                            end
                        end
                        default: byte_idx <= 3'd0;
                    endcase
                end
            end

            /* ---- SEND 커맨드 (4바이트: 0x00,0x01,0x0C,0x20) ---- */
            /* Sn_CR at socket 0 reg 0x0001; SEND = 0x20 */
            S_TX_SC: begin
                if (!spi_bsy && !spi_kick) begin
                    case (byte_idx)
                        3'd0: begin
                            spi_csn  <= 1'b0;
                            spi_sreg <= 8'h00;
                            spi_kick <= 1'b1;
                            byte_idx <= 3'd1;
                        end
                        3'd1: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h01;
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd2;
                            end
                        end
                        3'd2: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h0C;  /* S0 regs, write */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd3;
                            end
                        end
                        3'd3: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h20;  /* SEND 커맨드 */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd4;
                            end
                        end
                        3'd4: begin
                            if (spi_done) begin
                                spi_csn  <= 1'b1;
                                byte_idx <= 3'd0;
                                poll_cnt <= 16'd0;
                                state    <= S_TX_PH;
                            end
                        end
                        default: byte_idx <= 3'd0;
                    endcase
                end
            end

            /* ---- Sn_IR 폴링 헤더 (3바이트) ---- */
            /* Sn_IR = socket 0 reg 0x0002, read */
            S_TX_PH: begin
                if (!spi_bsy && !spi_kick) begin
                    case (byte_idx)
                        3'd0: begin
                            spi_csn  <= 1'b0;
                            spi_sreg <= 8'h00;
                            spi_kick <= 1'b1;
                            byte_idx <= 3'd1;
                        end
                        3'd1: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h02;
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd2;
                            end
                        end
                        3'd2: begin
                            if (spi_done) begin
                                spi_sreg <= 8'h08;  /* S0 regs, read */
                                spi_kick <= 1'b1;
                                byte_idx <= 3'd3;
                            end
                        end
                        3'd3: begin
                            if (spi_done) begin
                                byte_idx <= 3'd0;
                                state    <= S_TX_PD;
                            end
                        end
                        default: byte_idx <= 3'd0;
                    endcase
                end
            end

            /* ---- Sn_IR 수신 (더미 TX 1바이트) ---- */
            S_TX_PD: begin
                if (!spi_bsy && !spi_kick) begin
                    if (byte_idx == 3'd0) begin
                        spi_sreg <= 8'h00;  /* 더미 */
                        spi_kick <= 1'b1;
                        byte_idx <= 3'd1;
                    end else if (byte_idx == 3'd1 && spi_done) begin
                        spi_csn  <= 1'b1;
                        byte_idx <= 3'd0;
                        if (spi_rx[4]) begin
                            /* SENDOK (bit4) 확인 */
                            state <= S_DONE;
                        end else if (poll_cnt == 16'hFFFF) begin
                            r_err <= 1'b1;
                            state <= S_ERROR;
                        end else begin
                            poll_cnt <= poll_cnt + 16'd1;
                            state    <= S_TX_PH;  /* 재폴링 */
                        end
                    end
                end
            end

            /* 완료 */
            S_DONE: begin
                r_busy   <= 1'b0;
                r_irq_st <= 1'b1;
                state    <= S_IDLE;
            end

            /* 오류 */
            S_ERROR: begin
                r_busy <= 1'b0;
                state  <= S_IDLE;
            end

            default: state <= S_IDLE;
        endcase
    end
end

/* ===== MMIO 읽기 (조합 논리) ===== */
always @(*) begin
    mmio_rdata = 32'd0;
    if (mmio_cs && !mmio_we) begin
        case (mmio_addr[15:0])
            16'h0000: mmio_rdata = {18'd0, r_init_done, 1'b0, r_err, r_busy, 10'd0};
            16'h0004: mmio_rdata = {26'd0, r_tx_len};
            16'h000C: mmio_rdata = {26'd0, r_tx_ptr};
            16'hFFF0: mmio_rdata = 32'h5735_5544; /* "W5UD" */
            16'hFFF4: mmio_rdata = 32'h0000_0100;
            16'hFFF8: mmio_rdata = {31'd0, r_irq_st};
            16'hFFFC: mmio_rdata = {31'd0, r_irq_en};
            default:  mmio_rdata = 32'd0;
        endcase
    end
end

endmodule

/* tb_w5500_udp_tx.v — W5500 UDP TX IP 자체 점검 테스트벤치
 * Origin: capstones/mmio-w5500-udp-tx-ip/tb/tb_w5500_udp_tx.v
 * Verilog-2001.
 *
 * 시나리오:
 *   1. IP_ID 확인 (0xFFF0 == 0x5735_5544)
 *   2. TX_LEN = 4, TX_DATA 4바이트 적재 (0xDE, 0xAD, 0xBE, 0xEF)
 *   3. TX_PTR 확인 == 4 (go 전에 읽어야 함 — go가 ptr 초기화)
 *   4. CTRL bit1(init) → wait_not_busy → init_done(bit13) 확인
 *   5. CTRL bit0(go)  → wait_not_busy → err(bit11)==0
 *   6. IRQ_STATUS[0]==1 확인
 *   7. IRQ_ENABLE=1 → irq 선 == 1 확인
 *   8. IRQ_STATUS W1C → bit0==0 확인
 *
 * 가짜 W5500 SPI 슬레이브:
 *   - 모든 쓰기 프레임 수용
 *   - Sn_CR(addr=0x0001) SEND(0x20) 감지 → send_received=1
 *   - Sn_IR 폴(addr=0x0002, ctrl=0x08 read) → 0x10(SENDOK) 반환
 *   - 그 외 읽기 → 0x00 반환
 *
 * CLK_DIV = 20 (빠른 시뮬레이션; 실제 IP는 CLK_DIV=500)
 */
`timescale 1ns/1ps

module tb_w5500_udp_tx;

localparam CLK_DIV  = 20;
localparam CLK_HALF = 5;  /* 10 ns 주기 클럭 */

/* --- DUT 신호 --- */
reg         clk, rst_n;
reg  [15:0] mmio_addr;
reg  [31:0] mmio_wdata;
wire [31:0] mmio_rdata;
reg         mmio_we, mmio_cs;
wire        spi_sck, spi_mosi, spi_csn;
wire        irq;

/* --- SPI MISO (슬레이브 → 마스터) --- */
reg  spi_miso;

/* --- DUT 인스턴스 --- */
w5500_udp_tx_ip #(.CLK_DIV(CLK_DIV)) dut (
    .clk        (clk),
    .rst_n      (rst_n),
    .mmio_addr  (mmio_addr),
    .mmio_wdata (mmio_wdata),
    .mmio_rdata (mmio_rdata),
    .mmio_we    (mmio_we),
    .mmio_cs    (mmio_cs),
    .spi_sck    (spi_sck),
    .spi_mosi   (spi_mosi),
    .spi_csn    (spi_csn),
    .spi_miso   (spi_miso),
    .irq        (irq)
);

/* ============================================================
 * 가짜 W5500 SPI 슬레이브
 * 프레임: [addr_hi][addr_lo][ctrl_byte][data...]
 * ctrl_byte[2]=1: 쓰기, ctrl_byte[2]=0: 읽기
 * ============================================================ */
integer    slave_bit;
reg  [7:0] slave_rx;
integer    frame_byte;
reg [15:0] frame_addr;
reg  [7:0] frame_ctrl;
reg        send_received;       /* SEND 커맨드 수신 플래그 */
reg  [7:0] slave_tx_byte;      /* 읽기 응답 바이트 */
integer    slave_tx_bit;
reg        slave_tx_active;
reg        slave_tx_first_negedge; /* ctrl 바이트 마지막 negedge 건너뜀 */

initial begin
    spi_miso               = 1'b1;
    slave_bit              = 7;
    slave_rx               = 8'h00;
    frame_byte             = 0;
    frame_addr             = 16'h0000;
    frame_ctrl             = 8'h00;
    send_received          = 1'b0;
    slave_tx_byte          = 8'h00;
    slave_tx_bit           = 6;
    slave_tx_active        = 1'b0;
    slave_tx_first_negedge = 1'b0;
end

/* CSn 하강: 프레임 초기화 (send_received는 프레임 간 유지) */
always @(negedge spi_csn) begin
    slave_bit              = 7;
    slave_rx               = 8'h00;
    frame_byte             = 0;
    frame_addr             = 16'h0000;
    frame_ctrl             = 8'h00;
    slave_tx_active        = 1'b0;
    slave_tx_first_negedge = 1'b0;
    spi_miso               = 1'b1;
end

/* CSn 상승: 슬레이브 릴리즈 */
always @(posedge spi_csn) begin
    slave_tx_active = 1'b0;
    spi_miso        = 1'b1;
end

/* posedge SCK: MOSI 비트 샘플 */
always @(posedge spi_sck) begin
    if (!spi_csn) begin
        slave_rx[slave_bit] = spi_mosi;
        if (slave_bit == 0) begin
            /* 바이트 완성 처리 */
            case (frame_byte)
                0: begin
                    frame_addr[15:8] = slave_rx;
                end
                1: begin
                    frame_addr[7:0]  = slave_rx;
                end
                2: begin
                    /* ctrl 바이트 */
                    frame_ctrl = slave_rx;
                    if (!slave_rx[2]) begin
                        /* 읽기 모드: 응답 바이트 결정 */
                        if (frame_addr == 16'h0002 && slave_rx == 8'h08)
                            slave_tx_byte = send_received ? 8'h10 : 8'h00;
                        else
                            slave_tx_byte = 8'h00;
                        /* bit7을 지금 출력. 첫 번째 negedge(ctrl 마지막)는 건너뜀 */
                        spi_miso               = slave_tx_byte[7];
                        slave_tx_bit           = 6;
                        slave_tx_first_negedge = 1'b1;
                        slave_tx_active        = 1'b1;
                    end
                end
                default: begin
                    /* 데이터 바이트 (frame_byte >= 3) */
                    if (frame_ctrl[2]) begin
                        /* 쓰기: SEND 커맨드 감지 */
                        if (frame_ctrl == 8'h0C &&
                            frame_addr  == 16'h0001 &&
                            slave_rx    == 8'h20)
                            send_received = 1'b1;
                        frame_addr = frame_addr + 1'b1;
                    end
                    /* 읽기: 마스터가 dummy 송신, 슬레이브는 slave_tx_byte 송신 중 */
                end
            endcase
            frame_byte = frame_byte + 1;
            slave_bit  = 7;
        end else begin
            slave_bit = slave_bit - 1;
        end
    end
end

/* negedge SCK: MISO 비트 출력 (읽기 응답) */
always @(negedge spi_sck) begin
    #1; /* 경쟁 조건 방지 */
    if (!spi_csn && slave_tx_active) begin
        if (slave_tx_first_negedge) begin
            /* ctrl 바이트 마지막 negedge: bit7은 이미 세팅됨, 플래그만 해제 */
            slave_tx_first_negedge = 1'b0;
        end else begin
            spi_miso = slave_tx_byte[slave_tx_bit];
            if (slave_tx_bit == 0)
                slave_tx_active = 1'b0;
            else
                slave_tx_bit = slave_tx_bit - 1;
        end
    end
end

/* ============================================================
 * 클럭 생성
 * ============================================================ */
initial clk = 1'b0;
always #CLK_HALF clk = ~clk;

/* ============================================================
 * MMIO 태스크
 * ============================================================ */
task mmio_write;
    input [15:0] addr;
    input [31:0] data;
    begin
        @(posedge clk); #1;
        mmio_addr  = addr;
        mmio_wdata = data;
        mmio_we    = 1'b1;
        mmio_cs    = 1'b1;
        @(posedge clk); #1;
        mmio_we    = 1'b0;
        mmio_cs    = 1'b0;
    end
endtask

task mmio_read;
    input  [15:0] addr;
    output [31:0] data;
    begin
        @(posedge clk); #1;
        mmio_addr  = addr;
        mmio_we    = 1'b0;
        mmio_cs    = 1'b1;
        @(posedge clk); #1;
        data       = mmio_rdata;
        mmio_cs    = 1'b0;
    end
endtask

/* BUSY 폴링 태스크 */
task wait_not_busy;
    reg [31:0] ctrl_val;
    integer    timeout;
    begin
        timeout  = 0;
        ctrl_val = 32'h0000_0400; /* BUSY 비트 세팅 상태로 초기화 */
        while (ctrl_val[10] == 1'b1 && timeout < 200000) begin
            mmio_read(16'h0000, ctrl_val);
            timeout = timeout + 1;
        end
        if (timeout >= 200000)
            $display("FAIL: BUSY 타임아웃");
    end
endtask

/* ============================================================
 * 메인 테스트
 * ============================================================ */
integer fail_count;
reg [31:0] rd_val;

initial begin
    fail_count = 0;
    rst_n      = 1'b0;
    mmio_addr  = 16'h0000;
    mmio_wdata = 32'd0;
    mmio_we    = 1'b0;
    mmio_cs    = 1'b0;

    repeat(4) @(posedge clk);
    rst_n = 1'b1;
    repeat(2) @(posedge clk);

    /* --- 1. IP_ID 확인 --- */
    mmio_read(16'hFFF0, rd_val);
    if (rd_val !== 32'h5735_5544) begin
        $display("FAIL: IP_ID 기대값 0x57355544, 실제값 0x%08H", rd_val);
        fail_count = fail_count + 1;
    end

    /* --- 2. TX_LEN = 4 --- */
    mmio_write(16'h0004, 32'h0000_0004);

    /* --- 3. TX_DATA 4바이트 적재 --- */
    mmio_write(16'h0008, 32'h0000_00DE);
    mmio_write(16'h0008, 32'h0000_00AD);
    mmio_write(16'h0008, 32'h0000_00BE);
    mmio_write(16'h0008, 32'h0000_00EF);

    /* --- 4. TX_PTR 확인 (go 전에 읽어야 함 — go가 ptr 초기화) --- */
    mmio_read(16'h000C, rd_val);
    if (rd_val[5:0] !== 6'd4) begin
        $display("FAIL: TX_PTR 기대값 4, 실제값 %0d", rd_val[5:0]);
        fail_count = fail_count + 1;
    end

    /* --- 5. 초기화 (bit1=init) --- */
    mmio_write(16'h0000, 32'h0000_0002);
    wait_not_busy;

    /* --- 6. init_done 확인 (bit13) --- */
    mmio_read(16'h0000, rd_val);
    if (rd_val[13] !== 1'b1) begin
        $display("FAIL: init_done 비트 미세팅 (CTRL=0x%08H)", rd_val);
        fail_count = fail_count + 1;
    end

    /* --- 7. UDP TX 시작 (bit0=go) --- */
    mmio_write(16'h0000, 32'h0000_0001);
    wait_not_busy;

    /* --- 8. err 확인 (bit11 == 0) --- */
    mmio_read(16'h0000, rd_val);
    if (rd_val[11] !== 1'b0) begin
        $display("FAIL: err 비트 세팅됨 (CTRL=0x%08H)", rd_val);
        fail_count = fail_count + 1;
    end

    /* --- 9. IRQ_STATUS 확인 (bit0 == 1) --- */
    mmio_read(16'hFFF8, rd_val);
    if (rd_val[0] !== 1'b1) begin
        $display("FAIL: IRQ_STATUS done 비트 미세팅");
        fail_count = fail_count + 1;
    end

    /* --- 10. IRQ_ENABLE=1 → irq 선 확인 --- */
    mmio_write(16'hFFFC, 32'h0000_0001);
    @(posedge clk); #1;
    if (irq !== 1'b1) begin
        $display("FAIL: irq 선 Low (IRQ_ENABLE=1 후)");
        fail_count = fail_count + 1;
    end

    /* --- 11. IRQ_STATUS W1C → bit0==0 확인 --- */
    mmio_write(16'hFFF8, 32'h0000_0001);
    mmio_read(16'hFFF8, rd_val);
    if (rd_val[0] !== 1'b0) begin
        $display("FAIL: IRQ_STATUS W1C 실패 (bit0 여전히 1)");
        fail_count = fail_count + 1;
    end

    /* --- 최종 판정 --- */
    if (fail_count == 0)
        $display("PASS: W5500 UDP TX IP 검증 완료 (SENDOK 수신, IRQ 동작)");
    else
        $display("FAIL: %0d 항목 실패", fail_count);

    $finish;
end

/* 최대 실행 시간 보호 (CLK_DIV * 2000 프레임 여유) */
initial begin
    #(CLK_DIV * 2000 * 10 * 2);
    $display("FAIL: 시뮬레이션 타임아웃");
    $finish;
end

endmodule

TB       = tb/tb_w5500_udp_tx.v
SIM_OUT  = build/sim_w5500_udp_tx
SYNTH_LOG = build/synth_w5500_udp_tx.log

.PHONY: all lint sim synth clean

all: lint sim

## lint — RTL 문법 검사 (iverilog -tnull)
lint:
	@mkdir -p build
	iverilog -tnull -Wall -Wno-timescale -g2001 $(RTL_TOP)
	@echo "LINT OK: $(RTL_TOP)"

## sim — 가짜 W5500 슬레이브와 UDP TX 검증
sim:
	@mkdir -p build
	iverilog -g2001 -o $(SIM_OUT) $(TB) $(RTL_TOP)
	vvp $(SIM_OUT)

## synth — yosys로 자원 추정 (XC7A35T 기준)
synth:
	@mkdir -p build
	yosys -p "read_verilog -sv $(RTL_TOP); \
	           synth_xilinx -top w5500_udp_tx_ip -flatten; \
	           stat" 2>&1 | tee $(SYNTH_LOG)
	@echo "SYNTH LOG: $(SYNTH_LOG)"

clean:
	rm -rf build/

시뮬레이션 (iverilog)

  1. make lint — RTL 문법 검사 (iverilog -tnull)
  2. make sim — 가짜 W5500 슬레이브와 UDP TX SENDOK 검증; PASS 출력 확인
  3. make synth — yosys로 자원 추정 (XC7A35T 기준)

Vivado 합성

  1. Vivado에서 capstone.json의 sources 목록 파일을 프로젝트에 추가한다.
  2. constr/basys3_w5500.xdc를 제약 파일로 추가한다.
  3. top=w5500_udp_tx_ip으로 합성·구현한다 (SoC 통합 전 단독 검증용).
  4. 합성 후 LUT/FF/BRAM 사용량과 WNS를 기록한다.

위험·한계

  • mmio-lite 단일 사이클 응답: 긴 SPI 전송 중 BUSY=1이므로 CPU가 폴링 필요
  • init ROM 고정: 목적지 IP/MAC/포트를 바꾸려면 RTL 수정 필요
  • SENDOK 폴링 무한 루프 방지: poll_cnt == 16'hFFFF이면 ERR로 전환하므로 ~65535 사이클 대기
  • Pmod SPI 선로 용량: 긴 케이블이나 Pmod 체인 사용 시 타이밍 열화 가능
  • 단일 소켓: 여러 연결을 쓰려면 멀티 소켓 확장 필요
