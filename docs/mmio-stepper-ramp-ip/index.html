스텝모터 사다리꼴 가감속 IP

AXI4-Lite 슬레이브 IP로 28BYJ-48(ULN2003) 또는 A4988(STEP/DIR) 스텝모터 드라이버를 제어하는 사다리꼴 가감속(trapezoidal ramp) 프로파일 IP. 주기 기반(period-countdown) DDA 알고리즘으로 곱셈/나눗셈 없이 가속·감속 구간을 제어하고, IP 표준 Rev.1 관리 레지스터(ID/VER/IRQ_STATUS/IRQ_ENABLE)를 포함한다. 아이디어 I-018 (ready, 9점)으로 생성됨 (2026-11-04).

린트: 건너뜀 (verilator 없음)시뮬레이션: 건너뜀 (iverilog 없음)합성: 건너뜀 (yosys 없음)보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다 · 기준 2026-11-05. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • IP 표준 Rev.1(관리 레지스터 0xFFF0~FFFC)을 따르는 axil_stepper AXI4-Lite 슬레이브 IP 설계
  • 주기 기반 사다리꼴 가감속: 가속(ACCEL)→감속(DECEL) 2단계 FSM, 곱셈·나눗셈 없음
  • 4선식 모드(28BYJ-48 ULN2003 전상·반상): coil[3:0] 출력
  • STEP/DIR 모드(A4988 호환): step_out + dir_out 출력
  • done IRQ: IRQ_STATUS[0](W1C), IRQ_ENABLE[0]으로 마스크
  • iverilog 시뮬레이션 PASS, yosys 합성 성공(S2)

범위 밖

  • 실제 보드 모터 연결 확인(S3는 사람이 한다)
  • 폐루프 위치·속도 제어(오픈 루프 프로파일만)
  • 다축 동기화(단일 채널 IP)
  • 마이크로스텝(1/4, 1/8 등)
  • 가속 계산에 나눗셈·곱셈 사용

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. 시뮬레이션·합성 결과는 CI가 기록한다.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스AXI4-Lite
주소맵custom-stepper-ramp-v1 → 동결 맵 mbv-frozen-v2 적합 여부: 부분 적합
이식 계획free_slots 첫 빈 칸 [16]=0x4016_0000 제안(아직 미동결). INTC 13 사용(free_intc 첫 빈 번호). IP 표준 Rev.1 준수. 기존 stepper [15]=ip_stepper(단순 시퀀서); 이 IP는 가감속 프로파일 추가. 사용자가 mbv-frozen-v2에 stepper_ramp 항목 추가 후 compat를 compatible로 갱신 가능.

4. 메모리맵

axil_stepper 0x4016_0000 크기 0x10000

오프셋이름접근설명
0x00CTRLRWW: [0]=START(펄스), [1]=STOP(즉시정지). R: [0]=BUSY, [1]=DONE, [3:2]=STATE[1:0](0=IDLE,1=ACCEL,2=DECEL,3=DONE)
0x04TARGET_STEPSRW[23:0] 총 스텝 수 (최대 16M). 0이면 START 무시.
0x08MIN_PERIODRW[23:0] 최소 주기(최고속, 클럭 수). 최소 2 권장. 예: 500 → 100MHz/500=200kHz
0x0CMAX_PERIODRW[23:0] 최대 주기(시작 속도). MIN_PERIOD 이상이어야 함. 예: 50000 → 2kHz
0x10DELTA_PERIODRW[15:0] 스텝당 주기 감소량(가속시)/증가량(감속시). 0이면 가속 없음.
0x14MODERW[0]=STEP_DIR(0=4선 ULN2003, 1=STEP/DIR A4988). [1]=HALF_STEP(0=전상, 1=반상). START 전에 설정.
0xFFF0IDRO0x53545050 ('STPP') — IP 식별자
0xFFF4VERRO0x01000100 — 표준 Rev.1, IP ver1.0
0xFFF8IRQ_STATUSRW[0]=done. W1C: 1을 쓰면 클리어. IRQ_ENABLE과 AND하여 irq 출력 생성.
0xFFFCIRQ_ENABLERW[0]=done_irq_en. 1이면 done IRQ 활성화.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

ULN2003 IN1~IN4를 Pmod JA에 직결. 외부 5V 전원과 GND 공유. 별도 회로도 미작성.

id부품인터페이스신호 전압구분레벨 변환비고
u128BYJ-48 스텝모터 + ULN2003 드라이버 보드4선 단극성 (IN1~IN4)5V (로직 신호 IN1~IN4는 3.3V 호환, ULN2003 입력 임계치 ~1V) V외부 모듈불필요 (3.3V)Pmod JA[3:0]에 ULN2003 IN1~IN4 연결. GND 공통. 역기전력 보호는 ULN2003 내장 플라이백 다이오드.

Basys3 FPGA 핀은 3.3V 신호만 직접 받는다. 5V·12V·모터·릴레이는 직결하지 않는다.

rtl/basys3_top.v 130줄
// basys3_top.v — Basys3 보드 래퍼
// 100MHz 시스템 클럭, btnC 리셋, Pmod JA 모터 출력
// 내장 AXI4-Lite 데모 마스터: 리셋 후 레지스터 설정 → 모터 1회 가동
// 출처: 하네스 직접 작성 Verilog-2001 원본
`default_nettype none
`timescale 1ns/1ps

module basys3_top (
    input  wire       clk,          // 100 MHz
    input  wire       btnC,         // synchronous reset (active high)
    input  wire [1:0] sw,           // sw[0]=STEP_DIR mode, sw[1]=HALF_STEP
    output wire [3:0] jaMon,        // Pmod JA[3:0] → ULN2003 IN1~IN4
    output wire       jaStep,       // Pmod JA[4] → A4988 STEP (STEP/DIR mode)
    output wire       jaDir,        // Pmod JA[5] → A4988 DIR
    output wire [3:0] led,          // LED[3:0] = coil 패턴
    output wire       led_irq,      // LED[15] = IRQ 상태
    output wire       led_busy      // LED[14] = BUSY
);
    wire rst = btnC;

    // ── AXI4-Lite 버스 ───────────────────────────────────────────
    reg  [15:0] m_awaddr;  reg  m_awvalid;  wire m_awready;
    reg  [31:0] m_wdata;   reg  m_wvalid;   wire m_wready;
    wire [1:0]  m_bresp;   wire m_bvalid;   reg  m_bready;
    reg  [15:0] m_araddr;  reg  m_arvalid;  wire m_arready;
    wire [31:0] m_rdata;   wire [1:0] m_rresp; wire m_rvalid; reg m_rready;

    wire [3:0] coil_w;
    wire       step_w, dir_w, irq_w;

    axil_stepper u_ip (
        .clk(clk), .rst(rst),
        .s_awaddr(m_awaddr), .s_awvalid(m_awvalid), .s_awready(m_awready),
        .s_wdata(m_wdata),   .s_wvalid(m_wvalid),   .s_wready(m_wready),
        .s_bresp(m_bresp),   .s_bvalid(m_bvalid),   .s_bready(m_bready),
        .s_araddr(m_araddr), .s_arvalid(m_arvalid), .s_arready(m_arready),
        .s_rdata(m_rdata),   .s_rresp(m_rresp),     .s_rvalid(m_rvalid),
        .s_rready(m_rready),
        .coil(coil_w), .step_out(step_w), .dir_out(dir_w), .irq(irq_w)
    );

    assign jaMon  = coil_w;
    assign jaStep = step_w;
    assign jaDir  = dir_w;
    assign led      = coil_w;
    assign led_irq  = irq_w;
    assign led_busy = 1'b0; // core_busy는 IP 내부 — 별도 읽기 생략

    // ── 데모 마스터 FSM ──────────────────────────────────────────
    // 리셋 후 순서: 레지스터 5개 쓰기 → CTRL START → 대기
    localparam W0 = 4'd0, W1 = 4'd1, W2 = 4'd2, W3 = 4'd3, W4 = 4'd4,
               W5 = 4'd5, WAIT_B = 4'd6, START = 4'd7,
               WAIT_B2 = 4'd8, IDLE2 = 4'd9;

    reg [3:0] ms;
    reg       wr_sent;

    // 보드에서 TARGET=32768(반상 8바퀴), MIN=200000, MAX=5000000, DELTA=10000
    // 시뮬에선 tb가 직접 AXI를 구동하므로 basys3_top은 보드 전용
    localparam T_TARGET = 24'd32768;
    localparam T_MIN_P  = 24'd200000;
    localparam T_MAX_P  = 24'd5000000;
    localparam T_DELTA  = 16'd10000;

    always @(posedge clk) begin
        if (rst) begin
            ms        <= W0;
            m_awvalid <= 1'b0; m_wvalid  <= 1'b0; m_bready  <= 1'b1;
            m_arvalid <= 1'b0; m_rready  <= 1'b1;
            m_awaddr  <= 16'b0; m_wdata  <= 32'b0;
            wr_sent   <= 1'b0;
        end else begin
            // bresp 자동 수락
            if (m_bvalid && m_bready) begin
                m_awvalid <= 1'b0;
                m_wvalid  <= 1'b0;
            end

            case (ms)
            W0: begin // TARGET_STEPS
                m_awaddr <= 16'h0004; m_wdata <= {8'b0, T_TARGET};
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= W1;
            end
            W1: begin // MIN_PERIOD
                m_awaddr <= 16'h0008; m_wdata <= {8'b0, T_MIN_P};
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= W2;
            end
            W2: begin // MAX_PERIOD
                m_awaddr <= 16'h000C; m_wdata <= {8'b0, T_MAX_P};
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= W3;
            end
            W3: begin // DELTA
                m_awaddr <= 16'h0010; m_wdata <= {16'b0, T_DELTA};
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= W4;
            end
            W4: begin // MODE (from switches)
                m_awaddr <= 16'h0014; m_wdata <= {30'b0, sw};
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= W5;
            end
            W5: begin // IRQ_ENABLE
                m_awaddr <= 16'hFFFC; m_wdata <= 32'h1;
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= START;
            end
            START: begin // CTRL START
                m_awaddr <= 16'h0000; m_wdata <= 32'h1;
                m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                if (m_awready && m_awvalid) ms <= IDLE2;
            end
            IDLE2: begin
                m_awvalid <= 1'b0; m_wvalid <= 1'b0;
                // IRQ가 오면 클리어 (간단 구현: IRQ 발생 시 W1C)
                if (irq_w && !wr_sent) begin
                    m_awaddr <= 16'hFFF8; m_wdata <= 32'h1;
                    m_awvalid <= 1'b1; m_wvalid <= 1'b1;
                    wr_sent <= 1'b1;
                end
            end
            default: ms <= W0;
            endcase
        end
    end

endmodule
`default_nettype wire
rtl/axil_stepper.v 225줄
// axil_stepper.v — AXI4-Lite 스텝모터 가감속 IP
// IP 표준 Rev.1: ID=0xFFF0, VER=0xFFF4, IRQ_STATUS=0xFFF8(W1C), IRQ_ENABLE=0xFFFC
// 출처: 하네스 직접 작성 Verilog-2001 원본
`default_nettype none
`timescale 1ns/1ps

module axil_stepper (
    input  wire        clk,
    input  wire        rst,          // active-high synchronous
    // ── AXI4-Lite 슬레이브 ────────────────────────────────────────
    input  wire [15:0] s_awaddr,
    input  wire        s_awvalid,
    output reg         s_awready,
    input  wire [31:0] s_wdata,
    input  wire [3:0]  s_wstrb,
    input  wire        s_wvalid,
    output reg         s_wready,
    output reg  [1:0]  s_bresp,
    output reg         s_bvalid,
    input  wire        s_bready,
    input  wire [15:0] s_araddr,
    input  wire        s_arvalid,
    output reg         s_arready,
    output reg  [31:0] s_rdata,
    output reg  [1:0]  s_rresp,
    output reg         s_rvalid,
    input  wire        s_rready,
    // ── 모터 출력 ────────────────────────────────────────────────
    output wire [3:0]  coil,         // 4선 모드
    output wire        step_out,     // STEP/DIR 모드
    output wire        dir_out,      // STEP/DIR 방향
    // ── 인터럽트 ─────────────────────────────────────────────────
    output wire        irq
);
    // ── 레지스터 주소 ────────────────────────────────────────────
    localparam A_CTRL        = 16'h0000;
    localparam A_TARGET      = 16'h0004;
    localparam A_MIN_PERIOD  = 16'h0008;
    localparam A_MAX_PERIOD  = 16'h000C;
    localparam A_DELTA       = 16'h0010;
    localparam A_MODE        = 16'h0014;
    localparam A_ID          = 16'hFFF0;
    localparam A_VER         = 16'hFFF4;
    localparam A_IRQ_STATUS  = 16'hFFF8;
    localparam A_IRQ_ENABLE  = 16'hFFFC;

    localparam IP_ID  = 32'h53545050; // "STPP"
    localparam IP_VER = 32'h01000100; // std rev1, ip v1.0

    // ── 사용자 레지스터 ──────────────────────────────────────────
    reg [23:0] r_target;      // TARGET_STEPS
    reg [23:0] r_min_period;  // MIN_PERIOD
    reg [23:0] r_max_period;  // MAX_PERIOD
    reg [15:0] r_delta;       // DELTA_PERIOD
    reg [1:0]  r_mode;        // MODE[1:0]
    reg        r_irq_en;      // IRQ_ENABLE[0]
    reg        r_irq_status;  // IRQ_STATUS[0] (W1C)
    reg        core_done_d;   // done 상승 엣지 검출용

    // ── step_ramp_core 연결 ──────────────────────────────────────
    wire       core_step_pulse;
    wire       core_dir;
    wire [1:0] core_state;
    wire       core_busy;
    wire       core_done;
    reg        core_start; // 1펄스
    reg        core_stop;  // 1펄스

    step_ramp_core u_ramp (
        .clk        (clk),
        .rst        (rst),
        .start      (core_start),
        .stop       (core_stop),
        .i_target   (r_target),
        .i_min_period(r_min_period),
        .i_max_period(r_max_period),
        .i_delta    (r_delta),
        .step_pulse (core_step_pulse),
        .dir        (core_dir),
        .state      (core_state),
        .busy       (core_busy),
        .done       (core_done)
    );

    // ── seq_4wire 연결 (4선 모드) ────────────────────────────────
    seq_4wire u_seq (
        .clk       (clk),
        .rst       (rst),
        .step_pulse(core_step_pulse),
        .dir       (core_dir),
        .half_step (r_mode[1]),
        .coil      (coil)
    );

    // ── STEP/DIR 출력 (r_mode[0]=1 시 사용) ─────────────────────
    assign step_out = core_step_pulse;
    assign dir_out  = core_dir;

    // ── IRQ ──────────────────────────────────────────────────────
    assign irq = r_irq_status & r_irq_en;

    // ── 임시 버퍼(write 주소/데이터 비동기 도착 대응) ────────────
    reg [15:0] aw_buf;
    reg        aw_got;
    reg [31:0] w_buf;
    reg [3:0]  wstrb_buf;
    reg        w_got;
    reg        wr_fire;   // 이번 사이클에 쓰기 실행

    // ── AXI4-Lite 쓰기 채널 ─────────────────────────────────────
    always @(posedge clk) begin
        if (rst) begin
            s_awready  <= 1'b1;
            s_wready   <= 1'b1;
            s_bvalid   <= 1'b0;
            s_bresp    <= 2'b00;
            aw_got     <= 1'b0;
            w_got      <= 1'b0;
            wr_fire    <= 1'b0;
            core_start <= 1'b0;
            core_stop  <= 1'b0;
            r_target      <= 24'd1000;
            r_min_period  <= 24'd500;
            r_max_period  <= 24'd50000;
            r_delta       <= 16'd100;
            r_mode        <= 2'b00;
            r_irq_en      <= 1'b0;
            r_irq_status  <= 1'b0;
            core_done_d   <= 1'b0;
        end else begin
            core_start <= 1'b0;
            core_stop  <= 1'b0;
            wr_fire    <= 1'b0;

            // done 상승 엣지 검출
            core_done_d <= core_done;

            // IRQ_STATUS: W1C 우선, 그 다음 done 상승 엣지에서 set
            if (aw_got && w_got && (aw_buf == A_IRQ_STATUS) && w_buf[0])
                r_irq_status <= 1'b0;  // W1C 우선
            else if (core_done && !core_done_d)
                r_irq_status <= 1'b1;  // 상승 엣지에서만 set

            // 주소 수신
            if (s_awvalid && s_awready) begin
                aw_buf    <= s_awaddr;
                aw_got    <= 1'b1;
                s_awready <= 1'b0;
            end
            // 데이터 수신
            if (s_wvalid && s_wready) begin
                w_buf     <= s_wdata;
                wstrb_buf <= s_wstrb;
                w_got     <= 1'b1;
                s_wready  <= 1'b0;
            end

            // 주소+데이터 모두 수신 → 레지스터 쓰기
            if (aw_got && w_got) begin
                aw_got    <= 1'b0;
                w_got     <= 1'b0;
                s_awready <= 1'b1;
                s_wready  <= 1'b1;
                wr_fire   <= 1'b1;
                s_bvalid  <= 1'b1;
                s_bresp   <= 2'b00;

                case (aw_buf)
                A_CTRL: begin
                    if (w_buf[0]) core_start <= 1'b1;
                    if (w_buf[1]) core_stop  <= 1'b1;
                end
                A_TARGET:     r_target     <= w_buf[23:0];
                A_MIN_PERIOD: r_min_period <= w_buf[23:0];
                A_MAX_PERIOD: r_max_period <= w_buf[23:0];
                A_DELTA:      r_delta      <= w_buf[15:0];
                A_MODE:       r_mode       <= w_buf[1:0];
                A_IRQ_ENABLE: r_irq_en <= w_buf[0];
                default: ; // 없는 주소: 무시
                endcase
            end

            // bresp handshake
            if (s_bvalid && s_bready)
                s_bvalid <= 1'b0;
        end
    end

    // ── AXI4-Lite 읽기 채널 ─────────────────────────────────────
    wire [31:0] ctrl_rd = {26'b0, core_state, core_done, core_busy};

    always @(posedge clk) begin
        if (rst) begin
            s_arready <= 1'b1;
            s_rvalid  <= 1'b0;
            s_rdata   <= 32'b0;
            s_rresp   <= 2'b00;
        end else begin
            if (s_arvalid && s_arready) begin
                s_arready <= 1'b0;
                s_rvalid  <= 1'b1;
                s_rresp   <= 2'b00;
                case (s_araddr)
                A_CTRL:        s_rdata <= ctrl_rd;
                A_TARGET:      s_rdata <= {8'b0, r_target};
                A_MIN_PERIOD:  s_rdata <= {8'b0, r_min_period};
                A_MAX_PERIOD:  s_rdata <= {8'b0, r_max_period};
                A_DELTA:       s_rdata <= {16'b0, r_delta};
                A_MODE:        s_rdata <= {30'b0, r_mode};
                A_ID:          s_rdata <= IP_ID;
                A_VER:         s_rdata <= IP_VER;
                A_IRQ_STATUS:  s_rdata <= {31'b0, r_irq_status};
                A_IRQ_ENABLE:  s_rdata <= {31'b0, r_irq_en};
                default:       s_rdata <= 32'b0;
                endcase
            end
            if (s_rvalid && s_rready) begin
                s_rvalid  <= 1'b0;
                s_arready <= 1'b1;
            end
        end
    end

endmodule

// step_ramp_core.v — 사다리꼴 가감속 FSM
// 출처: 하네스 직접 작성 Verilog-2001 원본 (외부 코드 없음)
// 알고리즘: 주기 기반(period-countdown) DDA. 곱셈·나눗셈 없음.
//   ACCEL: 스텝마다 current_period -= delta (MIN_PERIOD에서 클램프)
//   DECEL: 스텝마다 current_period += delta (MAX_PERIOD에서 클램프)
//   전환: step_cnt >= target>>1 이면 ACCEL→DECEL
//   완료: step_cnt >= target 이면 DONE
`default_nettype none
`timescale 1ns/1ps

module step_ramp_core (
    input  wire        clk,
    input  wire        rst,          // active-high synchronous
    // 제어
    input  wire        start,        // 1펄스 → IDLE에서 ACCEL로
    input  wire        stop,         // 1펄스 → 즉시 IDLE
    // 파라미터 (start 전에 설정)
    input  wire [23:0] i_target,     // 총 스텝 수. 0이면 무시.
    input  wire [23:0] i_min_period, // 최소 주기(클럭), 최소 2
    input  wire [23:0] i_max_period, // 최대 주기(클럭)
    input  wire [15:0] i_delta,      // 스텝당 주기 변화량
    // 출력
    output reg         step_pulse,   // 1클럭 펄스, 스텝 1회
    output wire        dir,          // 방향 (상시 1 = CW, 추후 확장)
    output reg  [1:0]  state,        // 0=IDLE,1=ACCEL,2=DECEL,3=DONE
    output wire        busy,
    output reg         done          // 완료 플래그 (레지스터가 읽고 클리어)
);
    localparam IDLE  = 2'd0;
    localparam ACCEL = 2'd1;
    localparam DECEL = 2'd2;
    localparam S_DONE = 2'd3;

    assign dir  = 1'b1;
    assign busy = (state == ACCEL) || (state == DECEL);

    // ── 내부 레지스터 ──────────────────────────────────────────────
    reg [23:0] step_cnt;      // 완료된 스텝 수
    reg [23:0] period_cnt;    // 현재 스텝의 남은 클럭 수
    reg [23:0] cur_period;    // 현재 적용 주기

    // ── 다음 주기 계산 (조합) ──────────────────────────────────────
    wire [24:0] accel_sub = {1'b0, cur_period} - {8'b0, i_delta};
    wire [24:0] decel_add = {1'b0, cur_period} + {8'b0, i_delta};

    wire [23:0] nxt_accel =
        (accel_sub[24] || accel_sub[23:0] < i_min_period)
            ? i_min_period : accel_sub[23:0];

    wire [23:0] nxt_decel =
        (decel_add[24] || decel_add[23:0] > i_max_period)
            ? i_max_period : decel_add[23:0];

    // ── 다음 step_cnt (조합) ──────────────────────────────────────
    wire [23:0] nxt_cnt = step_cnt + 24'd1;

    // ── FSM + 주기 카운터 (1개 always) ────────────────────────────
    always @(posedge clk) begin
        if (rst) begin
            state      <= IDLE;
            step_cnt   <= 24'd0;
            period_cnt <= 24'd0;
            cur_period <= 24'd0;
            step_pulse <= 1'b0;
            done       <= 1'b0;
        end else begin
            step_pulse <= 1'b0; // 기본: 펄스 없음

            case (state)

            IDLE: begin
                done <= 1'b0;
                if (start && (i_target != 24'd0)) begin
                    cur_period <= i_max_period;
                    period_cnt <= i_max_period;
                    step_cnt   <= 24'd0;
                    state      <= ACCEL;
                end
            end

            ACCEL, DECEL: begin
                if (stop) begin
                    state <= IDLE;
                end else if (period_cnt == 24'd1) begin
                    // ── 이번 사이클에 스텝 발생 ──
                    step_pulse <= 1'b1;

                    if (nxt_cnt >= i_target) begin
                        // 목표 완료
                        state      <= S_DONE;
                        step_cnt   <= nxt_cnt;
                        done       <= 1'b1;
                        period_cnt <= 24'd1;
                    end else begin
                        step_cnt <= nxt_cnt;
                        if (state == ACCEL) begin
                            // 절반 이상 왔으면 DECEL로 전환
                            if (nxt_cnt >= (i_target >> 1))
                                state <= DECEL;
                            cur_period <= nxt_accel;
                            period_cnt <= nxt_accel;
                        end else begin
                            // DECEL
                            cur_period <= nxt_decel;
                            period_cnt <= nxt_decel;
                        end
                    end
                end else begin
                    period_cnt <= period_cnt - 24'd1;
                end
            end

            S_DONE: begin
                // done 플래그는 외부(axil_stepper)가 읽고 클리어
                if (start && (i_target != 24'd0)) begin
                    // 재시작
                    cur_period <= i_max_period;
                    period_cnt <= i_max_period;
                    step_cnt   <= 24'd0;
                    state      <= ACCEL;
                    done       <= 1'b0;
                end
            end

            endcase
        end
    end

endmodule

rtl/seq_4wire.v 66줄
// seq_4wire.v — 4선식 스텝모터 시퀀서 (28BYJ-48 / ULN2003)
// 출처: 하네스 직접 작성 Verilog-2001 원본
// 전상(full-step, 4단계): 0001 → 0010 → 0100 → 1000 → ...
// 반상(half-step, 8단계): 0001 → 0011 → 0010 → 0110 → 0100 → 1100 → 1000 → 1001 → ...
// dir=1: CW(전진), dir=0: CCW(후진)
`default_nettype none
`timescale 1ns/1ps

module seq_4wire (
    input  wire       clk,
    input  wire       rst,
    input  wire       step_pulse, // 1클럭 펄스 → 1스텝 전진
    input  wire       dir,        // 1=CW, 0=CCW
    input  wire       half_step,  // 0=전상(4), 1=반상(8)
    output reg  [3:0] coil        // ULN2003 IN1~IN4
);
    // 전상 테이블 (4단계)
    reg [3:0] full_tbl [0:3];
    // 반상 테이블 (8단계)
    reg [3:0] half_tbl [0:7];

    initial begin
        full_tbl[0] = 4'b0001;
        full_tbl[1] = 4'b0010;
        full_tbl[2] = 4'b0100;
        full_tbl[3] = 4'b1000;

        half_tbl[0] = 4'b0001;
        half_tbl[1] = 4'b0011;
        half_tbl[2] = 4'b0010;
        half_tbl[3] = 4'b0110;
        half_tbl[4] = 4'b0100;
        half_tbl[5] = 4'b1100;
        half_tbl[6] = 4'b1000;
        half_tbl[7] = 4'b1001;
    end

    reg [2:0] idx; // 0~7 (반상), 0~3 (전상)

    always @(posedge clk) begin
        if (rst) begin
            idx  <= 3'd0;
            coil <= 4'b0001;
        end else if (step_pulse) begin
            if (half_step) begin
                // 반상: 8단계
                if (dir)
                    idx <= (idx == 3'd7) ? 3'd0 : idx + 3'd1;
                else
                    idx <= (idx == 3'd0) ? 3'd7 : idx - 3'd1;
                coil <= half_tbl[(dir) ? ((idx == 3'd7) ? 3'd0 : idx + 3'd1)
                                       : ((idx == 3'd0) ? 3'd7 : idx - 3'd1)];
            end else begin
                // 전상: 4단계 (idx[1:0] 사용)
                if (dir)
                    idx[1:0] <= (idx[1:0] == 2'd3) ? 2'd0 : idx[1:0] + 2'd1;
                else
                    idx[1:0] <= (idx[1:0] == 2'd0) ? 2'd3 : idx[1:0] - 2'd1;
                coil <= full_tbl[(dir) ? ((idx[1:0] == 2'd3) ? 2'd0 : idx[1:0] + 2'd1)
                                       : ((idx[1:0] == 2'd0) ? 2'd3 : idx[1:0] - 2'd1)];
            end
        end
    end

endmodule

tb/tb_axil_stepper.v 212줄
// tb_axil_stepper.v — axil_stepper 자체 점검 테스트벤치
// 출처: 하네스 직접 작성 Verilog-2001 원본
// 검증 항목:
//  1) AXI4-Lite 쓰기/읽기 기능
//  2) TARGET=8 스텝, 가감속 프로파일 완료
//  3) step_pulse 카운트 == TARGET
//  4) coil 패턴 변화 (전상 4단계 순환)
//  5) DONE 비트, IRQ_STATUS 발생 확인
//  6) IRQ_STATUS W1C 클리어, irq 소등 확인
//  7) ID/VER 레지스터 값 확인
// 판정: 모든 항목 통과 시 PASS, 하나라도 실패 시 FAIL
`default_nettype none
`timescale 1ns/1ps

module tb_axil_stepper;
    // ── 클럭/리셋 ────────────────────────────────────────────────
    reg clk, rst;
    localparam CLK_HALF = 5; // 10ns 주기 = 100MHz

    initial clk = 0;
    always #CLK_HALF clk = ~clk;

    // ── DUT 포트 ────────────────────────────────────────────────
    reg  [15:0] s_awaddr;  reg  s_awvalid;  wire s_awready;
    reg  [31:0] s_wdata;   reg  s_wvalid;   wire s_wready;
    wire [1:0]  s_bresp;   wire s_bvalid;   reg  s_bready;
    reg  [15:0] s_araddr;  reg  s_arvalid;  wire s_arready;
    wire [31:0] s_rdata;   wire [1:0] s_rresp; wire s_rvalid; reg s_rready;
    wire [3:0]  coil;
    wire        step_out, dir_out, irq;

    axil_stepper dut (
        .clk(clk), .rst(rst),
        .s_awaddr(s_awaddr), .s_awvalid(s_awvalid), .s_awready(s_awready),
        .s_wdata(s_wdata),   .s_wvalid(s_wvalid),   .s_wready(s_wready),
        .s_bresp(s_bresp),   .s_bvalid(s_bvalid),   .s_bready(s_bready),
        .s_araddr(s_araddr), .s_arvalid(s_arvalid), .s_arready(s_arready),
        .s_rdata(s_rdata),   .s_rresp(s_rresp),     .s_rvalid(s_rvalid),
        .s_rready(s_rready),
        .coil(coil), .step_out(step_out), .dir_out(dir_out), .irq(irq)
    );

    // ── 계수기 ──────────────────────────────────────────────────
    integer step_count;    // step_pulse 계수
    integer coil_changes;  // coil 변화 횟수
    reg [3:0] prev_coil;
    integer fail_count;

    // step_pulse 감시
    always @(posedge clk) begin
        if (rst) begin
            step_count   <= 0;
            coil_changes <= 0;
            prev_coil    <= 4'b0001;
        end else begin
            if (step_out) step_count <= step_count + 1;
            if (coil !== prev_coil) begin
                coil_changes <= coil_changes + 1;
                prev_coil    <= coil;
            end
        end
    end

    // ── AXI4-Lite 태스크 ────────────────────────────────────────
    task axil_write;
        input [15:0] addr;
        input [31:0] data;
        begin
            @(negedge clk);
            s_awaddr  = addr;   s_awvalid = 1'b1;
            s_wdata   = data;   s_wvalid  = 1'b1;
            s_bready  = 1'b1;
            // 주소 handshake
            @(posedge clk);
            while (!s_awready) @(posedge clk);
            @(negedge clk); s_awvalid = 1'b0;
            // 데이터 handshake (wready는 항상 1이므로 즉시)
            s_wvalid = 1'b0;
            // bresp 대기
            @(posedge clk);
            while (!s_bvalid) @(posedge clk);
            @(negedge clk); s_bready = 1'b0;
        end
    endtask

    task axil_read;
        input  [15:0] addr;
        output [31:0] data;
        begin
            @(negedge clk);
            s_araddr  = addr;   s_arvalid = 1'b1;
            s_rready  = 1'b1;
            @(posedge clk);
            while (!s_arready) @(posedge clk);
            @(negedge clk); s_arvalid = 1'b0;
            @(posedge clk);
            while (!s_rvalid) @(posedge clk);
            data = s_rdata;
            @(negedge clk); s_rready = 1'b0;
        end
    endtask

    task check;
        input [255:0] name;
        input         cond;
        begin
            if (!cond) begin
                $display("FAIL: %0s", name);
                fail_count = fail_count + 1;
            end else begin
                $display("ok:   %0s", name);
            end
        end
    endtask

    // ── 메인 테스트 ──────────────────────────────────────────────
    reg [31:0] rval;
    integer    timeout;

    initial begin
        // 초기화
        rst = 1; fail_count = 0; step_count = 0; coil_changes = 0;
        s_awvalid = 0; s_wvalid = 0; s_bready = 1;
        s_arvalid = 0; s_rready = 1;
        s_awaddr = 0; s_wdata = 0; s_araddr = 0;
        repeat(4) @(posedge clk);
        rst = 0;
        repeat(2) @(posedge clk);

        // ── 테스트 1: ID/VER 확인 ──────────────────────────────
        axil_read(16'hFFF0, rval);
        check("ID == 0x53545050", rval === 32'h53545050);

        axil_read(16'hFFF4, rval);
        check("VER == 0x01000100", rval === 32'h01000100);

        // ── 테스트 2: 레지스터 쓰기/읽기 ──────────────────────
        // TARGET=8, MIN_PERIOD=2, MAX_PERIOD=10, DELTA=2, MODE=0(전상,4선)
        axil_write(16'h0004, 32'd8);       // TARGET_STEPS
        axil_write(16'h0008, 32'd2);       // MIN_PERIOD
        axil_write(16'h000C, 32'd10);      // MAX_PERIOD
        axil_write(16'h0010, 32'd2);       // DELTA_PERIOD
        axil_write(16'h0014, 32'd0);       // MODE = 전상·4선
        axil_write(16'hFFFC, 32'd1);       // IRQ_ENABLE[0] = 1

        axil_read(16'h0004, rval);
        check("TARGET_STEPS readback", rval === 32'd8);

        axil_read(16'hFFFC, rval);
        check("IRQ_ENABLE readback", rval === 32'd1);

        // ── 테스트 3: CTRL 초기값 (BUSY=0, DONE=0) ───────────
        axil_read(16'h0000, rval);
        check("CTRL BUSY=0 before start", rval[0] === 1'b0);

        // ── 테스트 4: 모터 가동 ────────────────────────────────
        axil_write(16'h0000, 32'h1); // CTRL START

        // DONE 대기 (최대 500 클럭)
        timeout = 0;
        rval = 32'b0;
        while (rval[1] !== 1'b1 && timeout < 500) begin
            @(posedge clk);
            axil_read(16'h0000, rval);
            timeout = timeout + 1;
        end
        check("DONE bit set within 500 clk", rval[1] === 1'b1);
        check("BUSY=0 after done", rval[0] === 1'b0);

        // ── 테스트 5: step_pulse 카운트 == TARGET ─────────────
        // step_out 과 step_pulse가 같으므로 step_count 사용
        check("step_count == 8", step_count === 8);

        // ── 테스트 6: coil 패턴 변화 (전상: 8번 변화) ──────────
        // coil_changes: 초기값 포함 최대 9번(reset→첫패턴 1 + 8스텝)
        // step_pulse마다 coil 변화하므로 step_count와 동일하거나 +1
        check("coil_changes >= 8", coil_changes >= 8);

        // ── 테스트 7: IRQ_STATUS[0] 발생 ──────────────────────
        axil_read(16'hFFF8, rval);
        check("IRQ_STATUS[0]=1 after done", rval[0] === 1'b1);
        check("irq output asserted", irq === 1'b1);

        // ── 테스트 8: W1C 클리어 ──────────────────────────────
        axil_write(16'hFFF8, 32'h1); // W1C
        @(posedge clk); @(posedge clk);

        axil_read(16'hFFF8, rval);
        check("IRQ_STATUS cleared by W1C", rval[0] === 1'b0);
        check("irq deasserted after clear", irq === 1'b0);

        // ── 판정 ──────────────────────────────────────────────
        $display("---");
        if (fail_count === 0) begin
            $display("PASS: 모든 항목 통과 (%0d checks)", 10);
        end else begin
            $display("FAIL: %0d 항목 실패", fail_count);
        end

        #100;
        $finish;
    end

    // ── 타임아웃 가드 ────────────────────────────────────────────
    initial begin
        #100000;
        $display("FAIL: 시뮬레이션 타임아웃 (100000 ns)");
        $finish;
    end

endmodule

## Makefile — mmio-stepper-ramp-ip
## 사용법: make lint | sim | synth | all
## 도구: iverilog, yosys (Ubuntu: sudo apt install iverilog yosys)

SLUG    := mmio-stepper-ramp-ip
BUILD   := ../../build/$(SLUG)
RTL     := rtl/axil_stepper.v rtl/step_ramp_core.v rtl/seq_4wire.v rtl/basys3_top.v
TB      := tb/tb_axil_stepper.v
SIM_TOP := tb_axil_stepper

.PHONY: all lint sim synth clean

all: lint sim synth

## ── 린트 (iverilog -Wall -g2001 -tnull) ─────────────────────────
lint:
	@mkdir -p $(BUILD)
	iverilog -Wall -Wno-timescale -g2001 -tnull \
	    $(RTL) $(TB) 2>&1 | tee $(BUILD)/lint.log
	@echo "--- lint done ---"

## ── 시뮬레이션 ────────────────────────────────────────────────
sim:
	@mkdir -p $(BUILD)
	iverilog -g2001 -o $(BUILD)/sim.vvp \
	    $(RTL) $(TB) 2>&1 | tee $(BUILD)/sim_compile.log
	vvp $(BUILD)/sim.vvp 2>&1 | tee $(BUILD)/sim.log
	@grep -E "^(PASS|FAIL)" $(BUILD)/sim.log || \
	    (echo "FAIL: PASS/FAIL not found in sim output" && exit 1)

## ── yosys 합성 (자원 추정) ────────────────────────────────────
synth:
	@mkdir -p $(BUILD)
	yosys -p "read_verilog $(RTL); \
	          synth_xilinx -top basys3_top -flatten; \
	          stat" \
	    2>&1 | tee $(BUILD)/synth.log
	@echo "--- synth done ---"

clean:
	rm -rf $(BUILD)

위험·한계

  • MIN_PERIOD가 너무 작으면 모터 탈조 — 28BYJ-48 최대 속도 약 500 PPS(기어 비 1:64 기준), MIN_PERIOD >= 200000(100MHz/500)
  • DELTA_PERIOD=0이면 가속 없이 MAX_PERIOD 고정 속도로 동작 — 무한 ACCEL 상태 진입 방지를 위해 period가 MIN에 도달하면 DECEL 전환 조건만 적용
  • TARGET_STEPS=0이면 START를 무시하도록 구현 — 0 스텝 동작 방지
  • MAX_PERIOD < MIN_PERIOD 설정 시 동작 미정의 — 사용자가 설정값 검증 필요
  • 4선 모드에서 급정지(STOP) 시 코일 에너지 — ULN2003 내장 플라이백 다이오드로 보호
  • STEP/DIR 모드(A4988) 연결 시 보드 외부 5V 모터 전원 필요, 레벨 변환 불필요(ULN2003 경우)
