캡스톤 패키지 · Basys3 · 단계 T3

VGA 타일맵 계기판 IP: 제어 루프 상태를 타일 글자와 막대로 표시 (프레임 버퍼 없음)

80×60 타일맵(256 타일, 16색 팔레트)을 AXI4-Lite 슬레이브로 노출한다. CPU가 타일 인덱스와 속성을 써넣으면 렌더러가 줄 단위로 화소를 만들어 VGA로 내보낸다. 프레임 버퍼 BRAM이 없어 자원을 절약하고, 프레임 끝 인터럽트로 제어 루프와 동기화한다.

린트: 건너뜀 (verilator 없음)시뮬레이션: 건너뜀 (iverilog 없음)합성: 건너뜀 (yosys 없음)보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다 · 기준 2026-11-05. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • AXI4-Lite 슬레이브로 80×60 타일맵과 8×8 폰트를 프로그래밍 가능하게 한다
  • 16색 팔레트 레지스터를 제공해 각 타일의 전경/배경색을 개별 설정한다
  • 스캔라인 렌더러로 프레임 버퍼 BRAM 없이 640×480 VGA를 출력한다
  • 프레임 끝(vsync 하강) 인터럽트를 intc 슬롯 13에 연결한다
  • 자체 점검 테스트벤치에서 AXI 레지스터 쓰기 → 화소 출력을 PASS/FAIL로 검증한다

범위 밖

  • 스프라이트, 스크롤, 하드웨어 커서
  • 32비트 프레임 버퍼(DRAM 없는 Basys3에서는 불가)
  • VGA 타이밍 외 디스플레이 표준(HDMI, DVI)
  • 폰트 비트맵 ROM 기본값 내장(소프트웨어가 초기화)

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. 아이디어 I-027 기반(차단조건재심사 2026-11-04, 10점). 시뮬레이션·합성 결과는 CI가 기록한다.

2. 계통도

클럭: 단일 25 MHz 클럭(clk_25m). Basys3 100 MHz 입력을 2비트 카운터로 분주. 프로덕션에서는 MMCM을 쓰고 AXI 버스(100 MHz)와 VGA 도메인(25 MHz) CDC를 추가한다.

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

VGA 출력은 Basys3 보드 내장 저항 DAC(12비트 R/G/B 각 4비트)이므로 외부 부품 없음. 미작성.

rtl/vga_timing.v 50줄
// vga_timing.v — 640×480 @ 60 Hz VGA 타이밍 생성기
// 픽셀 클럭: 25 MHz (25.175 MHz 공칭; 2비트 분주기로 25 MHz 사용)
// H: 640 가시 + 16 FP + 96 SYNC + 48 BP = 800
// V: 480 가시 + 10 FP +  2 SYNC + 33 BP = 525
// SYNC 극성: 양쪽 활성 로우 (CEA-861 표준)

module vga_timing (
    input  wire        clk_25m,
    input  wire        rst,
    output reg  [9:0]  h_count,   // 0..799
    output reg  [9:0]  v_count,   // 0..524
    output wire        hsync,     // 활성 로우
    output wire        vsync,     // 활성 로우
    output wire        active,    // 가시 영역
    output wire        frame_end  // vsync 하강 에지(1사이클 펄스)
);

localparam H_VIS  = 640, H_FP = 16, H_SYNC = 96, H_BP = 48;
localparam V_VIS  = 480, V_FP = 10, V_SYNC =  2, V_BP = 33;
localparam H_TOTAL = H_VIS + H_FP + H_SYNC + H_BP; // 800
localparam V_TOTAL = V_VIS + V_FP + V_SYNC + V_BP; // 525

// h/v 카운터
always @(posedge clk_25m) begin
    if (rst) begin
        h_count <= 10'd0;
        v_count <= 10'd0;
    end else begin
        if (h_count == H_TOTAL - 1) begin
            h_count <= 10'd0;
            if (v_count == V_TOTAL - 1)
                v_count <= 10'd0;
            else
                v_count <= v_count + 10'd1;
        end else begin
            h_count <= h_count + 10'd1;
        end
    end
end

assign hsync    = ~((h_count >= H_VIS + H_FP) &&
                    (h_count <  H_VIS + H_FP + H_SYNC));
assign vsync    = ~((v_count >= V_VIS + V_FP) &&
                    (v_count <  V_VIS + V_FP + V_SYNC));
assign active   = (h_count < H_VIS) && (v_count < V_VIS);

// frame_end: vsync 하강 에지 = v_count가 V_VIS+V_FP에 도달하고 h_count==0
assign frame_end = (v_count == V_VIS + V_FP) && (h_count == 10'd0);

endmodule

// tilemap_axil.v — AXI4-Lite 슬레이브 + 2단 스캔라인 VGA 렌더러
//
// 역할: 80×60 타일맵(256 타일, 16색 팔레트)을 AXI4-Lite 레지스터로 프로그래밍하고
//       VGA h/v 카운터에 맞춰 화소를 1클럭 지연으로 출력한다.
//
// 클럭: 단일 clk(25 MHz). 프로덕션에서는 AXI 버스(100 MHz)와 CDC 추가 권장.
//
// 메모리 모델:
//   tilemap[4800]  : tile_id[7:0] — row*80+col로 접근
//   attr[4800]     : {bg[3:0], fg[3:0]} — 같은 인덱스
//   font[2048]     : 8비트 비트맵 한 줄 — tile_id*8+row
//   palette[16]    : {R[3:0],G[3:0],B[3:0]}
//
// 렌더 파이프라인 (1 사이클):
//   입력 h_count,v_count → 타일 주소 계산 → 메모리 읽기(reg) → 화소 출력
//   출력은 h/v 입력보다 1사이클 늦으므로 h_count=1 위치의 화소가 h=0에 나옴.
//   테스트벤치가 이 오프셋을 감안한다.

module tilemap_axil (
    // ---- 공통 클럭/리셋 ----
    input  wire        clk,       // 25 MHz
    input  wire        rst_n,     // 활성 로우 리셋

    // ---- AXI4-Lite 슬레이브 ----
    input  wire [15:0] s_axil_awaddr,
    input  wire        s_axil_awvalid,
    output wire        s_axil_awready,
    input  wire [31:0] s_axil_wdata,
    input  wire [3:0]  s_axil_wstrb,
    input  wire        s_axil_wvalid,
    output wire        s_axil_wready,
    output reg  [1:0]  s_axil_bresp,
    output reg         s_axil_bvalid,
    input  wire        s_axil_bready,
    input  wire [15:0] s_axil_araddr,
    input  wire        s_axil_arvalid,
    output wire        s_axil_arready,
    output reg  [31:0] s_axil_rdata,
    output wire [1:0]  s_axil_rresp,
    output reg         s_axil_rvalid,
    input  wire        s_axil_rready,

    // ---- VGA 타이밍 입력 ----
    input  wire [9:0]  h_count,
    input  wire [9:0]  v_count,
    input  wire        active,
    input  wire        frame_end, // 1사이클 펄스

    // ---- VGA 화소 출력 (1사이클 지연) ----
    output reg  [3:0]  pix_r,
    output reg  [3:0]  pix_g,
    output reg  [3:0]  pix_b,

    // ---- 인터럽트 (level, 활성 하이) ----
    output wire        irq
);

// ================================================================
// 메모리
// ================================================================
reg [7:0] tilemap [0:4799];  // tile_id
reg [7:0] attr    [0:4799];  // {bg[3:0], fg[3:0]}
reg [7:0] font_rom[0:2047];  // tile_id*8+row → 8비트 비트맵
reg [11:0] palette[0:15];    // {R[3:0],G[3:0],B[3:0]}

// ================================================================
// 제어 레지스터
// ================================================================
reg [31:0] ctrl_reg;        // bit0=disp_en
reg [0:0]  irq_status;      // bit0=frame_end
reg [0:0]  irq_enable;      // bit0=enable
reg [12:0] tile_addr_reg;   // 간접 쓰기 주소
reg [10:0] font_addr_reg;   // 간접 쓰기 주소

// ================================================================
// AXI4-Lite 슬레이브 — AWVALID+WVALID 동시 수용
// ================================================================
assign s_axil_awready = 1'b1;
assign s_axil_wready  = 1'b1;
assign s_axil_arready = 1'b1;
assign s_axil_rresp   = 2'b00;

wire do_write = s_axil_awvalid && s_axil_wvalid;
wire [15:0] waddr = s_axil_awaddr;
wire [31:0] wdata = s_axil_wdata;

// BVALID 응답
always @(posedge clk) begin
    if (!rst_n) begin
        s_axil_bvalid <= 1'b0;
        s_axil_bresp  <= 2'b00;
    end else begin
        if (do_write)
            s_axil_bvalid <= 1'b1;
        else if (s_axil_bready)
            s_axil_bvalid <= 1'b0;
    end
end

// 레지스터 쓰기
always @(posedge clk) begin
    if (!rst_n) begin
        ctrl_reg      <= 32'h0000_0001; // disp_en 기본 1
        irq_enable    <= 1'b0;
        irq_status    <= 1'b0;
        tile_addr_reg <= 13'd0;
        font_addr_reg <= 11'd0;
        // 기본 팔레트: EGA 16색
        palette[ 0] <= 12'h000; // 검정
        palette[ 1] <= 12'h00A; // 파랑
        palette[ 2] <= 12'h0A0; // 초록
        palette[ 3] <= 12'h0AA; // 청록
        palette[ 4] <= 12'hA00; // 빨강
        palette[ 5] <= 12'hA0A; // 자홍
        palette[ 6] <= 12'hA50; // 갈색
        palette[ 7] <= 12'hAAA; // 밝은 회색
        palette[ 8] <= 12'h555; // 어두운 회색
        palette[ 9] <= 12'h55F; // 밝은 파랑
        palette[10] <= 12'h5F5; // 밝은 초록
        palette[11] <= 12'h5FF; // 밝은 청록
        palette[12] <= 12'hF55; // 밝은 빨강
        palette[13] <= 12'hF5F; // 밝은 자홍
        palette[14] <= 12'hFF5; // 밝은 노랑
        palette[15] <= 12'hFFF; // 흰색
    end else begin
        // IRQ_STATUS W1C
        if (frame_end)
            irq_status <= 1'b1;
        if (do_write && waddr == 16'h0008)
            irq_status <= irq_status & ~wdata[0:0];

        if (do_write) begin
            case (waddr)
                16'h000C: irq_enable    <= wdata[0:0];
                16'h0010: ctrl_reg      <= wdata;
                16'h0018: tile_addr_reg <= wdata[12:0];
                16'h001C: begin
                    if (tile_addr_reg < 13'd4800) begin
                        tilemap[tile_addr_reg] <= wdata[7:0];
                        attr   [tile_addr_reg] <= wdata[15:8];
                    end
                end
                16'h0020: font_addr_reg <= wdata[10:0];
                16'h0024: begin
                    font_rom[font_addr_reg] <= wdata[7:0];
                end
                default: begin
                    // 팔레트 0x0028..0x0064
                    if (waddr >= 16'h0028 && waddr <= 16'h0064) begin
                        palette[(waddr - 16'h0028) >> 2] <= wdata[11:0];
                    end
                end
            endcase
        end
    end
end

// 레지스터 읽기
always @(posedge clk) begin
    if (!rst_n) begin
        s_axil_rvalid <= 1'b0;
        s_axil_rdata  <= 32'd0;
    end else begin
        if (s_axil_arvalid && !s_axil_rvalid) begin
            s_axil_rvalid <= 1'b1;
            case (s_axil_araddr)
                16'h0000: s_axil_rdata <= 32'h544D_4150; // "TMAP"
                16'h0004: s_axil_rdata <= 32'h0001_0000; // VER 1.0
                16'h0008: s_axil_rdata <= {31'd0, irq_status};
                16'h000C: s_axil_rdata <= {31'd0, irq_enable};
                16'h0010: s_axil_rdata <= ctrl_reg;
                16'h0014: s_axil_rdata <= {31'd0, (v_count >= 10'd480) ? 1'b1 : 1'b0};
                default: begin
                    if (s_axil_araddr >= 16'h0028 && s_axil_araddr <= 16'h0064)
                        s_axil_rdata <= {20'd0, palette[(s_axil_araddr - 16'h0028) >> 2]};
                    else
                        s_axil_rdata <= 32'hDEAD_BEEF;
                end
            endcase
        end else if (s_axil_rready) begin
            s_axil_rvalid <= 1'b0;
        end
    end
end

// ================================================================
// 렌더 파이프라인 (1 사이클)
// ================================================================
// 타일 열/행 계산: tile_col = h_count[2:0+3..9] = h_count>>3, tile_row = v_count>>3
// tile_row*80 = tile_row*64 + tile_row*16 = (tile_row<<6)+(tile_row<<4)
wire [5:0] tile_col_w = h_count[8:3];  // 0..79 (h_count < 640)
wire [5:0] tile_row_w = v_count[8:3];  // 0..59 (v_count < 480)
wire [2:0] pixel_x_w  = h_count[2:0];
wire [2:0] pixel_y_w  = v_count[2:0];
wire [12:0] tile_base_w = {tile_row_w, 6'b0} + {2'b0, tile_row_w, 4'b0}; // *80
wire [12:0] tile_idx_w  = tile_base_w + {7'b0, tile_col_w};

wire disp_en = ctrl_reg[0];

// 1사이클 파이프라인: 등록된 메모리 읽기
reg [7:0] tile_id_q, tile_attr_q;
reg [2:0] pixel_x_q, pixel_y_q;
reg       active_q;

always @(posedge clk) begin
    if (!rst_n) begin

        @(negedge clk);
        araddr = addr; arvalid = 1'b1; rready = 1'b1;

    awvalid = 0; wvalid = 0; bready = 0;
    arvalid = 0; rready = 0;
    awaddr = 0; wdata = 0; wstrb = 4'hF;
    araddr = 0;

    // 리셋
    rst_n = 0;

    // T1: ID/VER 읽기

    axi_read(16'h0000);
    check32(0, rd_result, 32'h544D_4150);  // "TMAP"
    axi_read(16'h0004);
    check32(0, rd_result, 32'h0001_0000);  // VER 1.0

    // ============================================================
    // T2: 팔레트 쓰기/읽기
    //     PALETTE[0]=0x000(검정) → 0x248로 변경 후 읽기
    // ============================================================
    axi_write(16'h0028, 32'h0000_0248);
    axi_read (16'h0028);
    check32(0, rd_result[11:0], 12'h248);

    axi_read(16'h0064);
    check32(0, rd_result[11:0], 12'hFFF);
    // 팔레트를 EGA 기본으로 복원
    axi_write(16'h0028, 32'h0000_0000);

    // ============================================================
    // T3: 폰트 프로그래밍 + 타일 배치 + 화소 출력 확인
    //   - tile_id=0x01, 폰트 행 0 = 8'b1010_1010 = 0xAA
    //   - tile 위치: col=2, row=1 → idx = 1*80+2 = 82
    //   - fg=15(흰색=0xFFF), bg=0(검정=0x000)
    //   - 타일 행 1 위치: v_count=8, h_count=16
    //   - 1사이클 지연이므로 h_count=17에서 col=16의 화소가 출력됨
    //   - 화소 비트 0(h=16): font[0xAA] bit7=1 → fg=15=0xFFF → R=0xF
    //   - 화소 비트 1(h=17): font[0xAA] bit6=0 → bg=0=0x000 → R=0x0
    // ============================================================

    // 폰트 프로그래밍: tile_id=0x01, 행 0
    axi_write(16'h0020, 32'h0000_0008);  // FONT_ADDR = 0x01*8+0 = 8
    axi_write(16'h0024, 32'h0000_00AA);  // FONT_DATA = 0xAA = 10101010b

    // 타일 배치: col=2, row=1, idx=82
    axi_write(16'h0018, 32'h0000_0052);  // TILE_ADDR = 82
    axi_write(16'h001C, 32'h0000_F001);  // TILE_DATA: fg=0, bg=F(흰), tile_id=1

    // VGA를 v=8, h=16 위치까지 대기 후 화소 확인
    // 실제 화소는 h=16+1=17 클럭에서 나타남 (1사이클 렌더 파이프라인)
    // v=8, h=16이 되는 사이클 수 = (8*800+16) = 6416 사이클 (리셋 후)
    // 그러나 리셋 후 vga 카운터도 0부터 시작하므로 직접 대기한다.
    fork
        begin : wait_pixel
            // v_count==8, h_count==17 (h+1 오프셋) 가 될 때까지 대기
            // 최대 1 프레임(420000 사이클) 내에 도달해야 함
            repeat(420001) begin
                @(posedge clk);
                if (v_count == 10'd8 && h_count == 10'd17) begin
                    // 이 사이클에서 h=16 위치의 화소가 등록됨
                    // pix_r은 1사이클 더 지나야 확정되므로 다음 클럭에서 확인
                    @(posedge clk);
                    // TILE_DATA 를 {bg=0xF,fg=0x0, tile_id=0x01}로 설정했으므로
                    // font 비트=1 → fg_color=0x0(검정 아님... 수정: fg=[7:4], bg=[15:12])
                    // 실제 TILE_DATA[15:8] = attr = {bg[3:0], fg[3:0]}
                    // wdata=0x0000_F001 → wdata[15:8]=0xF0 → bg=0xF(흰), fg=0x0(검정)
                    // pix_bit=1 → fg=0 → palette[0]=0x000 → R=0, G=0, B=0
                    // pix_bit=0 → bg=F → palette[F]=0xFFF → R=F, G=F, B=F
                    // 0xAA=10101010: bit7=1(fg색), bit6=0(bg색)
                    // h=16(pixel_x=0): font_row[7]=1 → fg=0 → black R=0
                    // h=17(pixel_x=1): 이 사이클에서 h=17 → pixel_x_q=1(h=16에서 등록됨)
                    // → font_row[7-1]=font_row[6]=0 → bg=F → white R=F
                    if (pix_r !== 4'h0 || pix_g !== 4'h0 || pix_b !== 4'h0) begin
                        $display("FAIL T3a: pix@h16=%h%h%h exp=000", pix_r,pix_g,pix_b);
                        fail_cnt = fail_cnt + 1;
                    end
                    @(posedge clk);
                    // 다음 클럭: h=18에서 h=17(pixel_x=1)의 화소 → bg=0xF → white
                    if (pix_r !== 4'hF || pix_g !== 4'hF || pix_b !== 4'hF) begin
                        $display("FAIL T3b: pix@h17=%h%h%h exp=FFF", pix_r,pix_g,pix_b);
                        fail_cnt = fail_cnt + 1;
                    end
                    disable wait_pixel;
                end
            end
        end
    join

    // ============================================================
    // T4: 프레임 끝 인터럽트
    //   IRQ_ENABLE bit0=1 설정 → 프레임 끝 대기 → irq=1 확인
    //   IRQ_STATUS W1C → irq=0 확인
    // ============================================================
    axi_write(16'h000C, 32'h0000_0001); // IRQ_ENABLE bit0=1

    // frame_end 펄스 대기 (최대 1 프레임)
    begin : wait_irq
        repeat(421000) begin
            @(posedge clk);
            if (irq) disable wait_irq;
        end
    end

    // irq 활성 확인
    if (irq !== 1'b1) begin
        $display("FAIL T4a: irq=%b exp=1", irq);
        fail_cnt = fail_cnt + 1;
    end

    // IRQ_STATUS 읽기 — bit0=1 확인
    axi_read(16'h0008);
    if (rd_result[0] !== 1'b1) begin
        $display("FAIL T4b: IRQ_STATUS=%h bit0 exp=1", rd_result);
        fail_cnt = fail_cnt + 1;
    end

    // W1C: IRQ_STATUS bit0 클리어
    axi_write(16'h0008, 32'h0000_0001);
    @(posedge clk); @(posedge clk);
    if (irq !== 1'b0) begin
        $display("FAIL T4c: irq=%b after W1C, exp=0", irq);
        fail_cnt = fail_cnt + 1;
    end

    // ============================================================
    // 최종 결과
    // ============================================================
    @(posedge clk);
    if (fail_cnt == 0)
        $display("PASS tilemap_axil: T1(ID/VER) T2(PALETTE) T3(PIXEL) T4(IRQ) all ok");
    else
        $display("FAIL tilemap_axil: %0d 개 오류", fail_cnt);

    $finish;
end

Makefile 55줄
# Makefile — VGA 타일맵 계기판 IP
# 타깃: lint (verilator), sim (iverilog), synth (yosys)
# 사용: make lint | make sim | make synth | make all | make clean

SHELL   := /bin/bash
TOP     := basys3_top
TB      := tb_tilemap
RTL_DIR := rtl
TB_DIR  := tb
BUILD   := build

RTL_SRCS := $(RTL_DIR)/vga_timing.v \
            $(RTL_DIR)/tilemap_axil.v \
            $(RTL_DIR)/basys3_top.v

TB_SRCS  := $(TB_DIR)/tb_tilemap.v \
            $(RTL_DIR)/vga_timing.v \
            $(RTL_DIR)/tilemap_axil.v

.PHONY: all lint sim synth clean

all: lint sim synth

## ── lint: Verilator 문법 검사 ─────────────────────────────────────
lint: $(RTL_SRCS)
	@mkdir -p $(BUILD)
	verilator --lint-only -Wall --Wno-UNUSEDSIGNAL --Wno-UNUSEDPARAM \
	    -Wno-INITIALDLY \
	    $(RTL_SRCS) --top-module $(TOP) 2>&1 | tee $(BUILD)/lint.log
	@echo "lint done"

## ── sim: iverilog + vvp ───────────────────────────────────────────
sim: $(TB_SRCS)
	@mkdir -p $(BUILD)
	iverilog -g2005 -o $(BUILD)/$(TB).vvp $(TB_SRCS) 2>&1 | tee $(BUILD)/sim_compile.log
	vvp $(BUILD)/$(TB).vvp 2>&1 | tee $(BUILD)/sim.log
	@grep -E "^(PASS|FAIL)" $(BUILD)/sim.log || true
	@if grep -q "^PASS" $(BUILD)/sim.log; then \
	    echo "sim: PASS"; \
	else \
	    echo "sim: FAIL — see $(BUILD)/sim.log"; exit 1; \
	fi

## ── synth: Yosys synth_xilinx 자원 추정 ──────────────────────────
synth: $(RTL_SRCS)
	@mkdir -p $(BUILD)
	yosys -p "read_verilog $(RTL_SRCS); \
	          synth_xilinx -top $(TOP) -flatten; \
	          stat" \
	    2>&1 | tee $(BUILD)/synth.log
	@echo "synth done — see $(BUILD)/synth.log for LUT/FF/BRAM counts"

## ── clean ─────────────────────────────────────────────────────────
clean:
	rm -rf $(BUILD)

시뮬레이션 (iverilog)

  1. make lint — verilator --lint-only로 RTL 문법 검사
  2. make sim — iverilog -g2005으로 tb_tilemap.v를 컴파일하고 vvp로 실행. PASS가 출력되면 S1.
  3. make synth — yosys synth_xilinx으로 자원 추정. LUT/FF/BRAM 수를 build/synth.log에서 확인.

Vivado 합성

  1. Vivado 2024.2: 프로젝트 생성 → Basys3 xc7a35tcpg236-1.
  2. rtl/*.v와 constr/basys3.xdc를 소스로 추가한다.
  3. MMCM으로 25 MHz 생성 추천(clk_div는 jitter 큼).
  4. Generate Bitstream → Program Device.

위험·한계

  • clk_div 2비트 분주는 jitter가 커서 Vivado 타이밍 분석에서 경고가 날 수 있음. 프로덕션에서 MMCM 교체 권장.
  • 단일 클럭 설계(25 MHz 전체). 100 MHz AXI 버스와 연결 시 CDC(Gray-code BRAM 포인터 등) 추가 필요.
  • tilemap/font 메모리는 regs 배열 추론(LUTRAM 또는 BRAM). yosys 추정치와 Vivado 실제 사용량이 다를 수 있음.
  • TILE_ADDR 범위(0..4799)를 소프트웨어가 벗어나면 메모리 경계 밖 쓰기가 발생함. 하드웨어 클램핑 없음.
