2채널 속도 PID 모션 제어 IP

2채널 직교 엔코더(4체배)·고정소수점 속도 PI·10비트 PWM을 공통 1kHz 주기 트리거로 동기시키는 MMIO-lite IP. 채널 간 지터 없음과 출력 포화를 자체 점검 테스트벤치로 검증한다.

린트: 미실행시뮬레이션: 미실행합성: 미실행보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • 채널당 직교 엔코더 4체배 + 고정소수점 PI(Q4.12) + 10비트 PWM 한 세트 RTL
  • 공통 1kHz 주기 타이머로 채널 A·B PID 갱신 동기화(채널 간 지터 0 클럭)
  • 자체 점검 테스트벤치: setpoint=0·에러>0·긴급정지 세 시나리오 PASS/FAIL

범위 밖

  • 실 보드 엔코더·모터 연결(S3 보드 확인은 사용자 몫)
  • 부동소수점 연산
  • 3채널 이상 확장
  • 위치 제어 모드

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. 시뮬레이션·합성 결과는 CI가 기록한다. 아이디어 I-015 (ready, 차단조건재심사 7점)으로 생성됨 (2026-11-04).

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스mmio-lite
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 부분 적합
이식 계획free_slots [17]=0x4017_0000 사용(제안: [16]은 mmio-qenc-diag-checker에 배정됨). 프로젝트 측에서 동결 필요. IRQ 13 배정(intc_free 첫 번호). 동결 완료 시 address_map을 mbv-frozen-v2로 변경하고 frozen_mapping을 추가한다.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

레벨 변환과 Pmod 연결 회로도 미작성. external_parts의 전압·핀 메모 참조.

id부품인터페이스신호 전압구분레벨 변환비고
enc_a직교 엔코더 모터 Aquadrature (A/B 2신호)3.3V 또는 5V V외부 모듈5V 신호 사용 시 필요 (TXS0102 등)Pmod JA 핀 1-2 (ja[0]=ENC_A_A, ja[1]=ENC_A_B)
enc_b직교 엔코더 모터 Bquadrature (A/B 2신호)3.3V 또는 5V V외부 모듈5V 신호 사용 시 필요 (TXS0102 등)Pmod JB 핀 1-2 (jb[0]=ENC_B_A, jb[1]=ENC_B_B)
drv_a모터 드라이버 A (방향+PWM 입력)PWM + DIR 디지털 출력3.3V V외부 모듈불필요 (3.3V)Pmod JA 핀 3-4 (ja[2]=PWM_A, ja[3]=DIR_A). TB6612FNG 등 호환.
drv_b모터 드라이버 BPWM + DIR 디지털 출력3.3V V외부 모듈불필요 (3.3V)Pmod JB 핀 3-4 (jb[2]=PWM_B, jb[3]=DIR_B).

Basys3 FPGA 핀은 3.3V 신호만 직접 받는다. 5V·12V·모터·릴레이는 직결하지 않는다.

// multi_axis_motion_ip.v — 2채널 속도 PID 모션 제어 IP
// IP 표준 Rev.1 관리 레지스터(0xFFF0~0xFFFC) 포함
// MMIO-lite 버스 슬레이브 (1사이클 응답)
//
// 레지스터 맵 (바이트 주소, base+offset):
//   0x0000  CTRL       RW  [0]=enable, [1]=emstop
//   0x0004  PERIOD     RW  [19:0] 주기 클럭 수 (기본 100000 = 1kHz@100MHz)
//   0x0008  STATUS     RO  [0]=period_tick(셀프클리어) [1]=ch_a_sat [2]=ch_b_sat
//   0x0010  CA_SETPT   RW  [15:0] 채널A 목표 속도 (부호있는 카운트/주기)
//   0x0014  CA_KP      RW  [15:0] Kp Q4.12
//   0x0018  CA_KI      RW  [15:0] Ki Q4.12
//   0x001C  CA_CNT     RO  [15:0] 최근 주기 엔코더 카운트
//   0x0020  CA_PWM     RO  [9:0]  현재 PWM 듀티
//   0x0024  CA_ITERM   RW  [31:0] 적분항 (윈드업 클리어용)
//   0x0030-0x0044 채널B (CB_*), 동일 구조
//   0xFFF0  ID         RO  0x4D435431 ("MCT1")
//   0xFFF4  VER        RO  0x01000001
//   0xFFF8  IRQ_STATUS RW1C [0]=period_tick_event
//   0xFFFC  IRQ_ENABLE RW   [0]=period_tick_irq_en

`default_nettype none

// ============================================================
// qenc_4x: 4체배 직교 엔코더 디코더
//   - 2단 동기화 후 A·B 각 에지에서 +1/-1 계수
//   - cnt는 누적 (외부에서 필요 시 래치·클리어)
// ============================================================
module qenc_4x (
    input  wire       clk,
    input  wire       rst,
    input  wire       enc_a,       // 엔코더 채널 A (비동기)
    input  wire       enc_b,       // 엔코더 채널 B (비동기)
    output reg  [15:0] cnt,        // 누적 카운트 (부호있는, 2의 보수)
    input  wire        cnt_latch,  // 1클럭 펄스: cnt를 cnt_lat에 래치하고 cnt를 0으로
    output reg  [15:0] cnt_lat     // 래치된 직전 주기 카운트
);
    // 2단 동기화
    reg a1, a2, a3;
    reg b1, b2, b3;

    always @(posedge clk) begin
        if (rst) begin
            a1 <= 0; a2 <= 0; a3 <= 0;
            b1 <= 0; b2 <= 0; b3 <= 0;
        end else begin
            a1 <= enc_a; a2 <= a1; a3 <= a2;
            b1 <= enc_b; b2 <= b1; b3 <= b2;
        end
    end

    // 4체배 계수: A 에지와 B 에지 각각에서 방향 판정
    // 방향: (A XOR A_prev) XOR (B XOR B_prev) 패턴에서 결정
    // 간단 구현: 에지 감지 후 XOR(a2, b2)로 방향
    wire a_edge = a2 ^ a3;
    wire b_edge = b2 ^ b3;

    always @(posedge clk) begin
        if (rst) begin
            cnt     <= 16'd0;
            cnt_lat <= 16'd0;
        end else if (cnt_latch) begin
            cnt_lat <= cnt;
            cnt     <= 16'd0;
        end else begin
            // A 에지: B의 현재 값과 에지 방향으로 계수 방향 결정
            if (a_edge) begin
                if (a2 ^ b2)
                    cnt <= cnt + 16'd1;
                else
                    cnt <= cnt - 16'd1;
            end
            // B 에지: A의 현재 값과 에지 방향으로 계수 방향 결정
            if (b_edge) begin
                if (a2 ^ b2)
                    cnt <= cnt - 16'd1;
                else
                    cnt <= cnt + 16'd1;
            end
        end
    end
endmodule


// ============================================================
// pwm10: 10비트 PWM 생성기
//   - freq = clk / 1024 ≈ 97.6kHz @100MHz
//   - duty = 0 → 항상 0, duty = 1023 → 항상 1
// ============================================================
module pwm10 (
    input  wire       clk,
    input  wire       rst,
    input  wire [9:0] duty,   // 0~1023
    output reg        pwm_o
);
    reg [9:0] cnt;

    always @(posedge clk) begin
        if (rst) begin
            cnt   <= 10'd0;
            pwm_o <= 1'b0;
        end else begin
            cnt   <= cnt + 10'd1;
            pwm_o <= (cnt < duty) ? 1'b1 : 1'b0;
        end
    end
endmodule


// ============================================================
// multi_axis_motion_ip: 메인 IP
// ============================================================
module multi_axis_motion_ip (
    input  wire        clk,
    input  wire        rst,

    // MMIO-lite 버스
    input  wire        valid,
    input  wire        we,
    input  wire [31:0] addr,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,

    // 채널 A 엔코더 (비동기 입력)
    input  wire        enc_a_a,
    input  wire        enc_a_b,

    // 채널 B 엔코더 (비동기 입력)
    input  wire        enc_b_a,
    input  wire        enc_b_b,

    // PWM 출력 (방향+듀티 쌍)
    output wire        pwm_a_o,    // 채널 A PWM
    output wire        pwm_a_dir,  // 채널 A 방향 (0=정방향)
    output wire        pwm_b_o,    // 채널 B PWM
    output wire        pwm_b_dir,  // 채널 B 방향

    // IRQ
    output wire        irq_o
);

    // ---- 레지스터 -------------------------------------------------------
    reg         enable_r, emstop_r;
    reg  [19:0] period_r;        // 1kHz 주기 클럭 수
    reg  [15:0] ca_setpt_r, cb_setpt_r;
    reg  [15:0] ca_kp_r, ca_ki_r;
    reg  [15:0] cb_kp_r, cb_ki_r;
    reg  [31:0] ca_iterm_r, cb_iterm_r;
    reg         irq_status_r, irq_enable_r;

    // ---- 주기 타이머 (공통) --------------------------------------------
    reg  [19:0] period_cnt;
    reg         tick;           // 1클럭 펄스 (매 주기 시작)
    reg         tick_ev_r;     // IRQ용 이벤트 래치

    // PERIOD 레지스터 쓰기 감지 (조합 신호 — 타이머 즉시 리로드용)
    wire period_wr = valid && we && (addr[15:0] == 16'h0004);

    always @(posedge clk) begin
        if (rst) begin
            period_cnt <= 20'd1;   // 리셋 직후 첫 tick을 2클럭 뒤로 미룸
            tick       <= 1'b0;
        end else if (period_wr) begin
            // 새 주기값으로 즉시 리로드 (tick 없음)
            // wdata 는 combinational 이므로 다음 사이클부터 새 주기 적용
            period_cnt <= wdata[19:0] - 20'd1;
            tick       <= 1'b0;
        end else if (period_cnt == 20'd0) begin
            period_cnt <= period_r - 20'd1;
            tick       <= 1'b1;
        end else begin
            period_cnt <= period_cnt - 20'd1;
            tick       <= 1'b0;
        end
    end

    // ---- 엔코더 인스턴스 -----------------------------------------------
    wire [15:0] ca_cnt_raw, ca_cnt_lat;
    wire [15:0] cb_cnt_raw, cb_cnt_lat;

    qenc_4x enc_a (
        .clk       (clk),
        .rst       (rst),
        .enc_a     (enc_a_a),
        .enc_b     (enc_a_b),
        .cnt       (ca_cnt_raw),
        .cnt_latch (tick),
        .cnt_lat   (ca_cnt_lat)
    );

    qenc_4x enc_b (
        .clk       (clk),
        .rst       (rst),
        .enc_a     (enc_b_a),
        .enc_b     (enc_b_b),
        .cnt       (cb_cnt_raw),
        .cnt_latch (tick),
        .cnt_lat   (cb_cnt_lat)
    );

    // ---- PI 제어기 (tick마다 갱신) ------------------------------------
    // Q4.12 고정소수점: Kp·Ki의 상위 4비트=정수, 하위 12비트=소수
    // 연산: out = (err*Kp + iterm) >> 12, 클램프 [0, 1023]

    reg  [9:0] ca_duty_r, cb_duty_r;
    reg        ca_sat_r,  cb_sat_r;   // 포화 플래그

    // PI 갱신은 tick 다음 사이클 (엔코더 래치 직후)
    reg tick_d1;
    always @(posedge clk) tick_d1 <= rst ? 1'b0 : tick;

    // 중간 계산 신호 (combinational)
    wire signed [15:0] ca_err   = $signed(ca_setpt_r) - $signed(ca_cnt_lat);
    wire signed [15:0] cb_err   = $signed(cb_setpt_r) - $signed(cb_cnt_lat);

    // 32비트 고정소수점 적분항 갱신 + P항 계산
    wire signed [31:0] ca_p_raw = $signed({{16{ca_err[15]}}, ca_err}) * $signed({16'b0, ca_kp_r});
    wire signed [31:0] cb_p_raw = $signed({{16{cb_err[15]}}, cb_err}) * $signed({16'b0, cb_kp_r});

    // ki 곱 (적분 증가분)
    wire signed [31:0] ca_ki_inc = $signed({{16{ca_err[15]}}, ca_err}) * $signed({16'b0, ca_ki_r});
    wire signed [31:0] cb_ki_inc = $signed({{16{cb_err[15]}}, cb_err}) * $signed({16'b0, cb_ki_r});

    // 출력 계산 (>>12 → 10비트 클램프)
    wire signed [31:0] ca_out_raw = ($signed(ca_iterm_r) + ca_p_raw) >>> 12;
    wire signed [31:0] cb_out_raw = ($signed(cb_iterm_r) + cb_p_raw) >>> 12;

    always @(posedge clk) begin
        if (rst) begin
            ca_duty_r  <= 10'd0; ca_sat_r <= 1'b0;
            cb_duty_r  <= 10'd0; cb_sat_r <= 1'b0;
            ca_iterm_r <= 32'd0; cb_iterm_r <= 32'd0;
            irq_status_r <= 1'b0;
            tick_ev_r    <= 1'b0;
        end else begin
            // IRQ 이벤트 래치
            if (tick) begin
                tick_ev_r    <= 1'b1;
                irq_status_r <= 1'b1;
            end
            // IRQ_STATUS RW1C
            if (valid && we && addr[15:0] == 16'hFFF8)
                irq_status_r <= irq_status_r & ~wdata[0];

            // ITERM MMIO 쓰기 (윈드업 클리어용; PI 갱신보다 낮은 우선순위 — 같은 클럭이면 덮어씀)
            if (valid && we) begin
                if (addr[15:0] == 16'h0024) ca_iterm_r <= wdata;
                if (addr[15:0] == 16'h0044) cb_iterm_r <= wdata;
            end

            // PI 갱신 (tick 다음 클럭: 엔코더 래치 완료 후, MMIO 쓰기보다 높은 우선순위)
            if (tick_d1 && enable_r && !emstop_r) begin
                // 채널 A
                ca_iterm_r <= $signed(ca_iterm_r) + ca_ki_inc;
                if (ca_out_raw < 0) begin
                    ca_duty_r <= 10'd0;
                    ca_sat_r  <= 1'b1;
                end else if (ca_out_raw > 1023) begin
                    ca_duty_r <= 10'd1023;
                    ca_sat_r  <= 1'b1;
                end else begin
                    ca_duty_r <= ca_out_raw[9:0];
                    ca_sat_r  <= 1'b0;
                end
                // 채널 B
                cb_iterm_r <= $signed(cb_iterm_r) + cb_ki_inc;
                if (cb_out_raw < 0) begin
                    cb_duty_r <= 10'd0;
                    cb_sat_r  <= 1'b1;
                end else if (cb_out_raw > 1023) begin
                    cb_duty_r <= 10'd1023;
                    cb_sat_r  <= 1'b1;
                end else begin
                    cb_duty_r <= cb_out_raw[9:0];
                    cb_sat_r  <= 1'b0;
                end
            end
        end
    end

    // ---- 쓰기 레지스터 --------------------------------------------------
    // 주의: ca_iterm_r / cb_iterm_r 은 위의 PI 갱신 블록에서 관리 (다중 드라이버 방지)
    always @(posedge clk) begin
        if (rst) begin
            enable_r      <= 1'b0;
            emstop_r      <= 1'b0;
            period_r      <= 20'd100000;   // 1kHz
            ca_setpt_r    <= 16'd0; cb_setpt_r <= 16'd0;
            ca_kp_r       <= 16'd0; ca_ki_r    <= 16'd0;
            cb_kp_r       <= 16'd0; cb_ki_r    <= 16'd0;
            irq_enable_r  <= 1'b0;
        end else begin
            if (valid && we) begin
                case (addr[15:0])
                    16'h0000: begin enable_r <= wdata[0]; emstop_r <= wdata[1]; end
                    16'h0004: period_r <= wdata[19:0];
                    16'h0010: ca_setpt_r <= wdata[15:0];
                    16'h0014: ca_kp_r    <= wdata[15:0];
                    16'h0018: ca_ki_r    <= wdata[15:0];
                    16'h0030: cb_setpt_r <= wdata[15:0];
                    16'h0034: cb_kp_r    <= wdata[15:0];
                    16'h0038: cb_ki_r    <= wdata[15:0];
                    16'hFFFC: irq_enable_r <= wdata[0];
                    default: ;
                endcase
            end
        end
    end

    // ---- PWM 인스턴스 ---------------------------------------------------
    wire [9:0] ca_duty_gated = (enable_r && !emstop_r) ? ca_duty_r : 10'd0;
    wire [9:0] cb_duty_gated = (enable_r && !emstop_r) ? cb_duty_r : 10'd0;

    pwm10 pwm_a (
        .clk   (clk),
        .rst   (rst),
        .duty  (ca_duty_gated),
        .pwm_o (pwm_a_o)
    );

    pwm10 pwm_b (
        .clk   (clk),
        .rst   (rst),
        .duty  (cb_duty_gated),
        .pwm_o (pwm_b_o)
    );

    // 방향: setpoint 부호에서 결정 (음수=역방향)
    assign pwm_a_dir = ca_setpt_r[15];  // 1=음수=역방향
    assign pwm_b_dir = cb_setpt_r[15];

    // ---- 읽기 ----------------------------------------------------------
    always @(*) begin
        case (addr[15:0])
            16'h0000: rdata = {30'd0, emstop_r, enable_r};
            16'h0004: rdata = {12'd0, period_r};
            16'h0008: rdata = {29'd0, cb_sat_r, ca_sat_r, tick_ev_r};
            16'h0010: rdata = {16'd0, ca_setpt_r};
            16'h0014: rdata = {16'd0, ca_kp_r};
            16'h0018: rdata = {16'd0, ca_ki_r};
            16'h001C: rdata = {16'd0, ca_cnt_lat};
            16'h0020: rdata = {22'd0, ca_duty_r};
            16'h0024: rdata = ca_iterm_r;
            16'h0030: rdata = {16'd0, cb_setpt_r};
            16'h0034: rdata = {16'd0, cb_kp_r};
            16'h0038: rdata = {16'd0, cb_ki_r};
            16'h003C: rdata = {16'd0, cb_cnt_lat};
            16'h0040: rdata = {22'd0, cb_duty_r};
            16'h0044: rdata = cb_iterm_r;
            16'hFFF0: rdata = 32'h4D435431;  // "MCT1"
            16'hFFF4: rdata = 32'h01000001;
            16'hFFF8: rdata = {31'd0, irq_status_r};
            16'hFFFC: rdata = {31'd0, irq_enable_r};
            default:  rdata = 32'd0;
        endcase
    end

    // ---- IRQ -----------------------------------------------------------
    assign irq_o = irq_status_r & irq_enable_r;

endmodule

// tb_multi_axis_motion.v — multi_axis_motion_ip 자체 점검 테스트벤치
//
// 테스트 항목:
//   TC1: ID 레지스터 = 0x4D435431 ("MCT1")
//   TC2: 리셋 직후 PWM=0, 활성화 전 PWM=0
//   TC3: setpoint=0, enable → 1주기 후 PWM=0 (에러 없음)
//   TC4: setpoint>0, Kp>0 → 1주기 후 PWM>0 (비례 출력)
//   TC5: 긴급정지(emstop) → PWM=0 즉시
//   TC6: IRQ period_tick 발생 확인 (짧은 주기로)
//   TC7: 채널 A·B 독립 setpoint → 각 채널 별도 출력
//
// 비교: !== 사용 (X/Z도 실패로 센다)

`timescale 1ns/1ps
`default_nettype none

module tb_multi_axis_motion;

    // ---- 클럭 / 리셋 -------------------------------------------------------
    reg clk, rst;
    localparam CLK_PERIOD = 10;  // 10ns = 100MHz
    initial begin clk = 0; forever #(CLK_PERIOD/2) clk = ~clk; end
    initial begin rst = 1; #(CLK_PERIOD*5); rst = 0; end

    // ---- DUT ---------------------------------------------------------------
    reg         valid, we;
    reg  [31:0] addr, wdata;
    wire [31:0] rdata;
    reg         enc_a_a, enc_a_b;
    reg         enc_b_a, enc_b_b;
    wire        pwm_a_o, pwm_a_dir;
    wire        pwm_b_o, pwm_b_dir;
    wire        irq_o;

    multi_axis_motion_ip dut (
        .clk        (clk),
        .rst        (rst),
        .valid      (valid),
        .we         (we),
        .addr       (addr),
        .wdata      (wdata),
        .rdata      (rdata),
        .enc_a_a    (enc_a_a),
        .enc_a_b    (enc_a_b),
        .enc_b_a    (enc_b_a),
        .enc_b_b    (enc_b_b),
        .pwm_a_o    (pwm_a_o),
        .pwm_a_dir  (pwm_a_dir),
        .pwm_b_o    (pwm_b_o),
        .pwm_b_dir  (pwm_b_dir),
        .irq_o      (irq_o)
    );

    // ---- 헬퍼 태스크 -------------------------------------------------------
    integer fail_cnt;
    integer tc_num;

    localparam B = 32'h4017_0000;

    task mmio_write;
        input [31:0] a;
        input [31:0] d;
        begin
            @(posedge clk); #1;
            valid = 1; we = 1; addr = a; wdata = d;
            @(posedge clk); #1;
            valid = 0; we = 0;
        end
    endtask

    task mmio_read;
        input  [31:0] a;
        output [31:0] d;
        begin
            @(posedge clk); #1;
            valid = 1; we = 0; addr = a;
            @(posedge clk); #1;
            d = rdata;
            valid = 0;
        end
    endtask

    task check_eq;
        input [63:0] got;
        input [63:0] exp;
        input [127:0] msg;
        begin
            if (got !== exp) begin
                $display("  FAIL TC%0d [%s]: got=%0h exp=%0h", tc_num, msg, got, exp);
                fail_cnt = fail_cnt + 1;
            end
        end
    endtask

    task check_gt;
        input [63:0] got;
        input [63:0] threshold;
        input [127:0] msg;
        begin
            if (got <= threshold) begin
                $display("  FAIL TC%0d [%s]: got=%0d, expected >%0d", tc_num, msg, got, threshold);
                fail_cnt = fail_cnt + 1;
            end
        end
    endtask

    // 짧은 테스트용 주기 (100클럭 = 1μs@100MHz)
    localparam TEST_PERIOD = 20'd100;

    reg  [31:0] rd;
    integer i;

    // ---- 메인 테스트 -------------------------------------------------------
    initial begin
        fail_cnt = 0;
        valid = 0; we = 0; addr = 0; wdata = 0;
        enc_a_a = 0; enc_a_b = 0;
        enc_b_a = 0; enc_b_b = 0;

        @(negedge rst);
        repeat(3) @(posedge clk);

        // -----------------------------------------------------------------
        // TC1: ID 레지스터
        // -----------------------------------------------------------------
        tc_num = 1;
        mmio_read(B + 32'hFFF0, rd);
        check_eq(rd, 32'h4D435431, "TC1:ID=MCT1");
        mmio_read(B + 32'hFFF4, rd);
        check_eq(rd, 32'h01000001, "TC1:VER");

        // -----------------------------------------------------------------
        // TC2: 리셋 직후 PWM 출력 = 0
        // -----------------------------------------------------------------
        tc_num = 2;
        @(posedge clk); #1;
        check_eq(pwm_a_o, 1'b0, "TC2:pwm_a_rst=0");
        check_eq(pwm_b_o, 1'b0, "TC2:pwm_b_rst=0");

        // 활성화 전 (enable=0) PWM = 0
        mmio_write(B + 32'h0004, {12'd0, TEST_PERIOD});  // PERIOD=100클럭
        mmio_write(B + 32'h0010, 32'd50);                 // CA_SETPT=50
        mmio_write(B + 32'h0014, 32'd1024);               // CA_KP = 1.0 (Q4.12)
        repeat(TEST_PERIOD + 10) @(posedge clk); #1;
        // enable=0이므로 PWM은 게이트되어 0
        check_eq(pwm_a_o, 1'b0, "TC2:pwm_a_no_enable=0");

        // -----------------------------------------------------------------
        // TC3: setpoint=0, enable → 1주기 후 PWM=0 (에러 없음)
        // -----------------------------------------------------------------
        tc_num = 3;
        mmio_write(B + 32'h0010, 32'd0);       // CA_SETPT=0
        mmio_write(B + 32'h0030, 32'd0);       // CB_SETPT=0
        mmio_write(B + 32'h0014, 32'd1024);    // CA_KP=1.0
        mmio_write(B + 32'h0018, 32'd0);       // CA_KI=0
        mmio_write(B + 32'h0034, 32'd1024);    // CB_KP=1.0
        mmio_write(B + 32'h0038, 32'd0);       // CB_KI=0
        mmio_write(B + 32'h0000, 32'h1);       // enable=1

        // 2주기 대기 (에러=0 → PWM=0)
        repeat(TEST_PERIOD * 3) @(posedge clk); #1;
        mmio_read(B + 32'h0020, rd);
        check_eq(rd[9:0], 10'd0, "TC3:ca_pwm=0_when_sp=0");
        mmio_read(B + 32'h0040, rd);
        check_eq(rd[9:0], 10'd0, "TC3:cb_pwm=0_when_sp=0");

        // -----------------------------------------------------------------
        // TC4: setpoint>0, Kp>0 → 1주기 후 PWM>0
        // -----------------------------------------------------------------
        tc_num = 4;
        // iterm 클리어
        mmio_write(B + 32'h0024, 32'd0);    // CA_ITERM=0
        mmio_write(B + 32'h0044, 32'd0);    // CB_ITERM=0
        mmio_write(B + 32'h0010, 32'd20);   // CA_SETPT=20 카운트/주기
        mmio_write(B + 32'h0014, 32'd4096); // CA_KP=1.0 (Q4.12: 4096>>12=1.0)
        // 엔코더 입력 없음(cnt_lat=0) → error=20 → P=20*1.0=20

        repeat(TEST_PERIOD * 2 + 5) @(posedge clk); #1;
        mmio_read(B + 32'h0020, rd);
        check_gt(rd[9:0], 10'd0, "TC4:ca_pwm>0_when_sp=20");

        // -----------------------------------------------------------------
        // TC5: 긴급정지(emstop) → PWM 즉시 0
        // -----------------------------------------------------------------
        tc_num = 5;
        // 현재 CA_PWM > 0 상태에서 emstop 설정
        mmio_write(B + 32'h0000, 32'h3);  // enable=1, emstop=1
        @(posedge clk); #1;
        // 게이트 즉시 차단 (combinational)
        check_eq(pwm_a_o, 1'b0, "TC5:pwm_a_emstop=0");
        check_eq(pwm_b_o, 1'b0, "TC5:pwm_b_emstop=0");
        // 레지스터 읽기도 0
        mmio_read(B + 32'h0020, rd);
        // ca_duty_r 자체는 아직 남아있지만 출력은 0
        // emstop 해제
        mmio_write(B + 32'h0000, 32'h1);  // emstop 해제

        // -----------------------------------------------------------------
        // TC6: IRQ period_tick 발생
        // -----------------------------------------------------------------
        tc_num = 6;
        // IRQ_ENABLE 활성화
        mmio_write(B + 32'hFFFC, 32'h1);
        // IRQ_STATUS 클리어
        mmio_write(B + 32'hFFF8, 32'h1);
        // 1주기 대기
        repeat(TEST_PERIOD + 5) @(posedge clk); #1;
        // irq_o 확인
        check_eq(irq_o, 1'b1, "TC6:irq_fires");
        // IRQ_STATUS 클리어
        mmio_write(B + 32'hFFF8, 32'h1);
        mmio_read(B + 32'hFFF8, rd);
        check_eq(rd[0], 1'b0, "TC6:irq_status_cleared");

        // -----------------------------------------------------------------
        // TC7: 채널 A·B 독립 — 채널B setpoint=0이면 pwm_b=0
        // -----------------------------------------------------------------
        tc_num = 7;
        mmio_write(B + 32'h0024, 32'd0);    // CA_ITERM 클리어
        mmio_write(B + 32'h0044, 32'd0);    // CB_ITERM 클리어
        mmio_write(B + 32'h0010, 32'd30);   // CA_SETPT=30
        mmio_write(B + 32'h0030, 32'd0);    // CB_SETPT=0
        mmio_write(B + 32'h0014, 32'd4096); // CA_KP=1.0
        mmio_write(B + 32'h0034, 32'd4096); // CB_KP=1.0
        mmio_write(B + 32'h0000, 32'h1);    // enable=1

        repeat(TEST_PERIOD * 2 + 5) @(posedge clk); #1;
        mmio_read(B + 32'h0020, rd);
        check_gt(rd[9:0], 10'd0, "TC7:ca_pwm>0");
        mmio_read(B + 32'h0040, rd);
        check_eq(rd[9:0], 10'd0, "TC7:cb_pwm=0_when_sp=0");

        // -----------------------------------------------------------------
        // 최종 결과
        // -----------------------------------------------------------------
        if (fail_cnt == 0) begin
            $display("PASS: multi_axis_motion_ip 모든 항목(%0d개) 통과", 7);
        end else begin
            $display("FAIL: %0d개 항목 실패", fail_cnt);
        end
        $finish;
    end

    // 타임아웃 (15 µs) — 전체 TC1~TC7 완주에 약 10.1 µs 필요 (여유 추가)
    initial begin
        #15000;
        $display("FAIL: 시뮬레이션 타임아웃");
        $finish;
    end

endmodule
