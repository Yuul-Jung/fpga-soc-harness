AXI4-Lite 7세그 고급 IP — 자리별 blank·dp·PWM 밝기 레지스터 제어

MicroBlaze V에서 레지스터 2개(DATA, CTRL)로 Basys3 4자리 7세그먼트를 완전 제어하는 AXI4-Lite 슬레이브 IP. blank[3:0] 자리별 소등, dp[3:0] 소수점, 16단계 PWM 밝기를 단일 IP에서 지원한다.

린트: 건너뜀 (verilator 없음)시뮬레이션: 건너뜀 (iverilog 없음)합성: 건너뜀 (yosys 없음)보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다 · 기준 2026-11-05. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • AXI4-Lite 슬레이브 레지스터(DATA, CTRL)로 4자리 7세그먼트를 소프트웨어 제어
  • 자리별 blank(자리 단위 소등) 지원
  • 자리별 dp(소수점) 독립 제어
  • 16단계 PWM 밝기 제어(0=꺼짐, 15=최대)
  • Verilog-2001 iverilog·verilator·yosys 호환 RTL, 자체 점검 테스트벤치

범위 밖

  • BCD 자동 디코딩(16진수 입력만 지원)
  • 자리 수 4개 초과
  • 보드 동작 검증(S3): 시뮬레이션 S1까지만
  • MicroBlaze V 드라이버 C 코드 제공

이 패키지의 소스는 하네스가 직접 작성한 원본이며 외부 코드를 포함하지 않는다. 아이디어 근거 카드(byu-ecen320-seven-segment4, element14-arty-s7-7seg-brightness)의 패턴을 참고했으며, 코드는 복사하지 않았다. 시뮬레이션·합성 결과는 CI가 기록한다.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스AXI4-Lite

이식 계획mbv-frozen-v2 기준 free_slot [16] (0x4016_0000, 64KB)부터 차례로 배정 제안. 인터럽트 불필요(폴링으로 충분). 슬롯은 사용자가 프로젝트 인덱스 표에서 동결한다. 동결 전이므로 compat=partial.

4. 메모리맵

AXI4-Lite 슬레이브 레지스터 뱅크 0x4016_0000 크기 0x10000

오프셋이름접근설명
0x0000DATARW자리 값: [15:12]=d3, [11:8]=d2, [7:4]=d1, [3:0]=d0 (각 4비트 hex 0~F). [31:16]=reserved.
0x0004CTRLRW[3:0]=blank (1=해당 자리 소등, d3..d0 순), [7:4]=dp_en (1=소수점 표시), [11:8]=bright (0=꺼짐, 15=최대밝기), [12]=en (0=전체 꺼짐), [31:13]=reserved.

5. 외부 부품과 전기 회로도

// axil_7seg_ip.v
// AXI4-Lite 7-Segment Display Advanced IP for Basys3
// HARNESS: mmio-7seg-adv-ip (I-072), free_slot [1F] = 0x401F_0000
// License: MIT
// Features:
//   - Per-digit hex display (0-F) via AXI4-Lite registers
//   - Per-digit blank control (blank[3:0])
//   - Per-digit decimal point control (dp_en[3:0])
//   - 16-step PWM brightness control (bright[3:0])
//   - Parameterized refresh rate and clock
// Verilog-2001 only: compatible with iverilog, verilator, yosys
//
// Register map (base 0x401F_0000):
//   0x00: DATA  [15:12]=d3, [11:8]=d2, [7:4]=d1, [3:0]=d0  (hex 0-F)
//   0x04: CTRL  [3:0]=blank, [7:4]=dp_en, [11:8]=bright, [12]=en
//               reset = 0x00001F0F  (en=1, bright=15, blank=0xF, dp=0)
//
// Output:
//   an[3:0]  : anode select, active-low (Basys3 common-anode)
//   seg[6:0] : cathode bits {g,f,e,d,c,b,a}, active-low
//   dp_out   : decimal point, active-low

`timescale 1ns/1ps

module axil_7seg_ip #(
    parameter CLK_HZ     = 100_000_000, // 100 MHz
    parameter REFRESH_HZ = 1000         // per-digit refresh rate
)(
    // AXI4-Lite slave
    input  wire        aclk,
    input  wire        aresetn,
    // Write address channel
    input  wire [7:0]  awaddr,
    input  wire        awvalid,
    output reg         awready,
    // Write data channel
    input  wire [31:0] wdata,
    input  wire [3:0]  wstrb,
    input  wire        wvalid,
    output reg         wready,
    // Write response channel
    output reg  [1:0]  bresp,
    output reg         bvalid,
    input  wire        bready,
    // Read address channel
    input  wire [7:0]  araddr,
    input  wire        arvalid,
    output reg         arready,
    // Read data channel
    output reg  [31:0] rdata,
    output reg  [1:0]  rresp,
    output reg         rvalid,
    input  wire        rready,
    // 7-segment display outputs (active-low, Basys3 common-anode)
    output wire [3:0]  an,
    output wire [6:0]  seg,
    output wire        dp_out
);

    // ---------------------------------------------------------------
    // Register bank
    // ---------------------------------------------------------------
    reg [31:0] reg_data; // 0x00
    reg [31:0] reg_ctrl; // 0x04

    // Named fields
    wire [3:0] d3     = reg_data[15:12];
    wire [3:0] d2     = reg_data[11:8];
    wire [3:0] d1     = reg_data[7:4];
    wire [3:0] d0     = reg_data[3:0];
    wire [3:0] blank  = reg_ctrl[3:0];
    wire [3:0] dp_en  = reg_ctrl[7:4];
    wire [3:0] bright = reg_ctrl[11:8];
    wire       en     = reg_ctrl[12];

    // ---------------------------------------------------------------
    // AXI4-Lite write FSM
    // ---------------------------------------------------------------
    reg       aw_lat; // latch write address
    reg [7:0] aw_addr_lat;

    always @(posedge aclk) begin
        if (!aresetn) begin
            awready    <= 1'b0;
            wready     <= 1'b0;
            bvalid     <= 1'b0;
            bresp      <= 2'b00;
            aw_lat     <= 1'b0;
            aw_addr_lat<= 8'h00;
            reg_data   <= 32'h0000_0000;
            reg_ctrl   <= 32'h0000_1F0F; // en=1, bright=15, blank=0xF
        end else begin
            // Defaults
            awready <= 1'b0;
            wready  <= 1'b0;

            // Latch write address
            if (awvalid && !aw_lat) begin
                aw_lat      <= 1'b1;
                aw_addr_lat <= awaddr;
                awready     <= 1'b1;
            end

            // Write data
            if (wvalid && aw_lat) begin
                wready  <= 1'b1;
                aw_lat  <= 1'b0;
                bvalid  <= 1'b1;
                bresp   <= 2'b00;
                // Write to register (byte strobe)
                case (aw_addr_lat[3:2])
                    2'd0: begin
                        if (wstrb[0]) reg_data[7:0]   <= wdata[7:0];
                        if (wstrb[1]) reg_data[15:8]  <= wdata[15:8];
                        if (wstrb[2]) reg_data[23:16] <= wdata[23:16];
                        if (wstrb[3]) reg_data[31:24] <= wdata[31:24];
                    end
                    2'd1: begin
                        if (wstrb[0]) reg_ctrl[7:0]   <= wdata[7:0];
                        if (wstrb[1]) reg_ctrl[15:8]  <= wdata[15:8];
                        if (wstrb[2]) reg_ctrl[23:16] <= wdata[23:16];
                        if (wstrb[3]) reg_ctrl[31:24] <= wdata[31:24];
                    end
                    default: ; // ignore unmapped
                endcase
            end

            // Clear bvalid on handshake
            if (bvalid && bready)
                bvalid <= 1'b0;
        end
    end

    // ---------------------------------------------------------------
    // AXI4-Lite read FSM
    // ---------------------------------------------------------------
    always @(posedge aclk) begin
        if (!aresetn) begin
            arready <= 1'b0;
            rvalid  <= 1'b0;
            rdata   <= 32'h0;
            rresp   <= 2'b00;
        end else begin
            arready <= 1'b0;
            if (arvalid && !rvalid) begin
                arready <= 1'b1;
                rvalid  <= 1'b1;
                rresp   <= 2'b00;
                case (araddr[3:2])
                    2'd0:    rdata <= reg_data;
                    2'd1:    rdata <= reg_ctrl;
                    default: rdata <= 32'h0;
                endcase
            end
            if (rvalid && rready)
                rvalid <= 1'b0;
        end
    end

    // ---------------------------------------------------------------
    // Hex-to-7-segment encoder (combinational, active-low output)
    // Segment order: {g, f, e, d, c, b, a}
    // ---------------------------------------------------------------
    function [6:0] hex_to_seg;
        input [3:0] hex;
        case (hex)
            4'h0: hex_to_seg = 7'b100_0000; // 0: a,b,c,d,e,f ON  g OFF
            4'h1: hex_to_seg = 7'b111_1001; // 1: b,c ON
            4'h2: hex_to_seg = 7'b010_0100; // 2: a,b,d,e,g ON
            4'h3: hex_to_seg = 7'b011_0000; // 3: a,b,c,d,g ON
            4'h4: hex_to_seg = 7'b001_1001; // 4: b,c,f,g ON
            4'h5: hex_to_seg = 7'b001_0010; // 5: a,c,d,f,g ON
            4'h6: hex_to_seg = 7'b000_0010; // 6: a,c,d,e,f,g ON
            4'h7: hex_to_seg = 7'b111_1000; // 7: a,b,c ON
            4'h8: hex_to_seg = 7'b000_0000; // 8: all ON
            4'h9: hex_to_seg = 7'b001_0000; // 9: a,b,c,d,f,g ON
            4'hA: hex_to_seg = 7'b000_1000; // A: a,b,c,e,f,g ON
            4'hB: hex_to_seg = 7'b000_0011; // b: c,d,e,f,g ON
            4'hC: hex_to_seg = 7'b100_0110; // C: a,d,e,f ON
            4'hD: hex_to_seg = 7'b010_0001; // d: b,c,d,e,g ON
            4'hE: hex_to_seg = 7'b000_0110; // E: a,d,e,f,g ON
            4'hF: hex_to_seg = 7'b000_1110; // F: a,e,f,g ON
            default: hex_to_seg = 7'b111_1111; // all segments off
        endcase
    endfunction

    wire [6:0] seg_d0 = hex_to_seg(d0);
    wire [6:0] seg_d1 = hex_to_seg(d1);
    wire [6:0] seg_d2 = hex_to_seg(d2);
    wire [6:0] seg_d3 = hex_to_seg(d3);

    // ---------------------------------------------------------------
    // 4-digit multiplexer
    // Refresh at REFRESH_HZ per digit, cycle through 4 digits
    // ---------------------------------------------------------------
    localparam MUX_DIV = CLK_HZ / REFRESH_HZ;
    localparam MUX_BITS = 17; // ceil(log2(100000)) = 17

    reg [MUX_BITS-1:0] mux_cnt;
    reg [1:0]          digit_sel; // 0..3

    always @(posedge aclk) begin
        if (!aresetn) begin
            mux_cnt   <= 0;
            digit_sel <= 2'd0;
        end else begin
            if (mux_cnt >= MUX_DIV - 1) begin
                mux_cnt   <= 0;
                digit_sel <= digit_sel + 1'b1;
            end else begin
                mux_cnt <= mux_cnt + 1'b1;
            end
        end
    end

    // ---------------------------------------------------------------
    // PWM brightness generator
    // 16 levels: duty = (bright+1)/16 of each digit period
    // bright=0: 1/16, bright=15: 16/16=100%
    // PWM_STEP = MUX_DIV / 16 = 6250 cycles per brightness level
    // pwm_cnt increments every PWM_STEP cycles within each digit slot
    // ---------------------------------------------------------------
    localparam PWM_BITS = 4;
    localparam PWM_STEP = MUX_DIV >> PWM_BITS; // 6250 — no multiplier needed
    // ceil(log2(6250)) = 13 bits for step counter
    reg [PWM_BITS-1:0] pwm_cnt;
    reg [12:0]         pwm_step_cnt;

    always @(posedge aclk) begin
        if (!aresetn) begin
            pwm_cnt      <= 4'd0;
            pwm_step_cnt <= 13'd0;
        end else if (mux_cnt == 0) begin
            // Reset both counters at every digit boundary
            pwm_cnt      <= 4'd0;
            pwm_step_cnt <= 13'd0;
        end else begin
            if (pwm_step_cnt >= PWM_STEP - 1) begin
                pwm_step_cnt <= 13'd0;
                pwm_cnt      <= pwm_cnt + 1'b1;
            end else begin
                pwm_step_cnt <= pwm_step_cnt + 13'd1;
            end
        end
    end

    // PWM gate: HIGH when pwm_cnt <= bright (duty cycle)
    wire pwm_gate = (pwm_cnt <= bright);

    // ---------------------------------------------------------------
    // Anode and segment mux output
    // ---------------------------------------------------------------
    reg [3:0] an_reg;
    reg [6:0] seg_reg;
    reg       dp_reg;

    always @(*) begin
        // Default: all off
        an_reg  = 4'b1111;
        seg_reg = 7'b111_1111;
        dp_reg  = 1'b1;

        if (en && pwm_gate) begin
            case (digit_sel)
                2'd0: begin
                    an_reg  = blank[0] ? 4'b1111 : 4'b1110;
                    seg_reg = blank[0] ? 7'b111_1111 : seg_d0;
                    dp_reg  = blank[0] ? 1'b1 : ~dp_en[0];
                end
                2'd1: begin
                    an_reg  = blank[1] ? 4'b1111 : 4'b1101;
                    seg_reg = blank[1] ? 7'b111_1111 : seg_d1;
                    dp_reg  = blank[1] ? 1'b1 : ~dp_en[1];
                end
                2'd2: begin
                    an_reg  = blank[2] ? 4'b1111 : 4'b1011;
                    seg_reg = blank[2] ? 7'b111_1111 : seg_d2;
                    dp_reg  = blank[2] ? 1'b1 : ~dp_en[2];
                end
                2'd3: begin
                    an_reg  = blank[3] ? 4'b1111 : 4'b0111;
                    seg_reg = blank[3] ? 7'b111_1111 : seg_d3;
                    dp_reg  = blank[3] ? 1'b1 : ~dp_en[3];
                end
            endcase
        end
    end

    assign an     = an_reg;
    assign seg    = seg_reg;
    assign dp_out = dp_reg;

endmodule

// basys3_top_7seg.v
// Basys3 Board Top Wrapper for AXI4-Lite 7-Segment Advanced IP
// HARNESS: mmio-7seg-adv-ip (I-072)
// License: MIT
//
// AXI4-Lite loopback (write then read) for simulation and board smoke test.
// In a real SoC the master connections go to MicroBlaze V's M_AXI bus.
//
// Basys3 pin mapping:
//   clk      : W5  (100 MHz)
//   resetn   : T17 (btnC, active-HIGH → inverted internally)
//   an[3:0]  : U2  W4  V4  U4   (7-seg anodes, active-low)
//   seg[6:0] : W7  W6  U8  V8  U5  V5  U7   (CA..CG, active-low)
//   dp_out   : V7  (DP, active-low)
//
// Verilog-2001 only: compatible with iverilog, verilator, yosys

`timescale 1ns/1ps

module basys3_top_7seg (
    input  wire        clk,       // 100 MHz board clock
    input  wire        btnC,      // Centre button = active-HIGH reset
    // 7-segment outputs (active-low)
    output wire [3:0]  an,
    output wire [6:0]  seg,
    output wire        dp
);

    // Active-low reset for AXI
    wire aresetn = ~btnC;

    // ---------------------------------------------------------------
    // AXI4-Lite wires (loopback master stubs for standalone test)
    // All tied to sensible idle values so the IP powers up showing
    // the reset state: en=1, blank=0xF (all off), ready for DATA write.
    // ---------------------------------------------------------------
    wire [7:0]  awaddr  = 8'h00;
    wire        awvalid = 1'b0;
    wire [31:0] wdata   = 32'h0;
    wire [3:0]  wstrb   = 4'h0;
    wire        wvalid  = 1'b0;
    wire        bready  = 1'b1;
    wire [7:0]  araddr  = 8'h00;
    wire        arvalid = 1'b0;
    wire        rready  = 1'b1;

    axil_7seg_ip #(
        .CLK_HZ    (100_000_000),
        .REFRESH_HZ(1000)
    ) u_7seg (
        .aclk    (clk),
        .aresetn (aresetn),
        // Write address
        .awaddr  (awaddr),
        .awvalid (awvalid),
        .awready (),
        // Write data
        .wdata   (wdata),
        .wstrb   (wstrb),
        .wvalid  (wvalid),
        .wready  (),
        // Write response
        .bresp   (),
        .bvalid  (),
        .bready  (bready),
        // Read address
        .araddr  (araddr),
        .arvalid (arvalid),
        .arready (),
        // Read data
        .rdata   (),
        .rresp   (),
        .rvalid  (),
        .rready  (rready),
        // Display
        .an      (an),
        .seg     (seg),
        .dp_out  (dp)
    );

endmodule

// tb_axil_7seg_ip.v
// Self-checking testbench for axil_7seg_ip
// HARNESS: mmio-7seg-adv-ip (I-072)
// License: MIT
//
// Outputs "PASS" on success, "FAIL: <reason>" on first failure.
// Compatible with: iverilog, verilator (with --main --timing)
//
// Test plan:
//   T1  Reset state: an=1111 (all off), reg_ctrl reset=0x1F0F
//   T2  Write DATA=0x1234, CTRL enable+bright=15+blank=0
//       → after mux cycles: anodes toggle, seg patterns match hex encoder
//   T3  Blank digit 0 → an[0] stays high for digit 0's slot
//   T4  dp_en digit 1 → dp_out low during digit 1's slot
//   T5  en=0 → all outputs forced high (all off)
//   T6  Read back DATA and CTRL registers via AXI read

`timescale 1ns/1ps

module tb_axil_7seg_ip;

    // ---------------------------------------------------------------
    // Clock and reset
    // ---------------------------------------------------------------
    reg aclk;
    reg aresetn;

    initial aclk = 0;
    always #5 aclk = ~aclk; // 100 MHz

    // ---------------------------------------------------------------
    // DUT I/O
    // ---------------------------------------------------------------
    reg  [7:0]  awaddr;
    reg         awvalid;
    wire        awready;
    reg  [31:0] wdata;
    reg  [3:0]  wstrb;
    reg         wvalid;
    wire        wready;
    wire [1:0]  bresp;
    wire        bvalid;
    reg         bready;
    reg  [7:0]  araddr;
    reg         arvalid;
    wire        arready;
    wire [31:0] rdata;
    wire [1:0]  rresp;
    wire        rvalid;
    reg         rready;
    wire [3:0]  an;
    wire [6:0]  seg;
    wire        dp_out;

    axil_7seg_ip #(
        .CLK_HZ    (100_000_000),
        .REFRESH_HZ(1000)
    ) dut (
        .aclk   (aclk),    .aresetn(aresetn),
        .awaddr (awaddr),   .awvalid(awvalid),  .awready(awready),
        .wdata  (wdata),    .wstrb  (wstrb),    .wvalid (wvalid),   .wready(wready),
        .bresp  (bresp),    .bvalid (bvalid),   .bready (bready),
        .araddr (araddr),   .arvalid(arvalid),  .arready(arready),
        .rdata  (rdata),    .rresp  (rresp),    .rvalid (rvalid),   .rready(rready),
        .an     (an),       .seg    (seg),       .dp_out (dp_out)
    );

    // ---------------------------------------------------------------
    // Task: AXI4-Lite write (address + data in same cycle, wait done)
    // ---------------------------------------------------------------
    task axil_write;
        input [7:0]  addr;
        input [31:0] data;
        input [3:0]  strb;
        integer timeout;
        begin
            // Present address
            @(posedge aclk);
            awaddr  <= addr;
            awvalid <= 1'b1;
            wdata   <= data;
            wstrb   <= strb;
            wvalid  <= 1'b1;
            bready  <= 1'b1;
            // Wait for address handshake
            timeout = 0;
            while (!awready && timeout < 100) begin @(posedge aclk); timeout=timeout+1; end
            @(posedge aclk);
            awvalid <= 1'b0;
            // Wait for data handshake
            timeout = 0;
            while (!wready && timeout < 100) begin @(posedge aclk); timeout=timeout+1; end
            @(posedge aclk);
            wvalid  <= 1'b0;
            // Wait for response
            timeout = 0;
            while (!bvalid && timeout < 100) begin @(posedge aclk); timeout=timeout+1; end
            @(posedge aclk);
            bready  <= 1'b0;
        end
    endtask

    // ---------------------------------------------------------------
    // Task: AXI4-Lite read (return value via reg)
    // ---------------------------------------------------------------
    reg [31:0] rd_result;
    task axil_read;
        input  [7:0]  addr;
        integer timeout;
        begin
            @(posedge aclk);
            araddr  <= addr;
            arvalid <= 1'b1;
            rready  <= 1'b1;
            timeout = 0;
            while (!arready && timeout < 100) begin @(posedge aclk); timeout=timeout+1; end
            @(posedge aclk);
            arvalid <= 1'b0;
            timeout = 0;
            while (!rvalid && timeout < 100) begin @(posedge aclk); timeout=timeout+1; end
            rd_result <= rdata;
            @(posedge aclk);
            rready  <= 1'b0;
        end
    endtask

    // ---------------------------------------------------------------
    // Task: advance mux to target digit slot (approximate)
    //   MUX_DIV = 100000 cycles per digit
    // ---------------------------------------------------------------
    localparam MUX_DIV = 100000;
    task wait_digit;
        input [1:0] target;
        integer i;
        // Wait until digit_sel == target by scanning an bits
        // an[0]=low for digit 0, an[1]=low for digit 1, etc.
        // Run for up to 4*MUX_DIV cycles
        begin
            for (i = 0; i < 4*MUX_DIV; i = i+1) begin
                @(posedge aclk);
                // Check if the right anode is active
                if (target == 2'd0 && an[0] === 1'b0) i = 4*MUX_DIV; // break
                if (target == 2'd1 && an[1] === 1'b0) i = 4*MUX_DIV;
                if (target == 2'd2 && an[2] === 1'b0) i = 4*MUX_DIV;
                if (target == 2'd3 && an[3] === 1'b0) i = 4*MUX_DIV;
            end
        end
    endtask

    // ---------------------------------------------------------------
    // Expected segment patterns (active-low, {g,f,e,d,c,b,a})
    // ---------------------------------------------------------------
    function [6:0] exp_seg;
        input [3:0] h;
        case (h)
            4'h0: exp_seg = 7'b100_0000;
            4'h1: exp_seg = 7'b111_1001;
            4'h2: exp_seg = 7'b010_0100;
            4'h3: exp_seg = 7'b011_0000;
            4'h4: exp_seg = 7'b001_1001;
            4'h5: exp_seg = 7'b001_0010;
            4'h6: exp_seg = 7'b000_0010;
            4'h7: exp_seg = 7'b111_1000;
            4'h8: exp_seg = 7'b000_0000;
            4'h9: exp_seg = 7'b001_0000;
            4'hA: exp_seg = 7'b000_1000;
            4'hB: exp_seg = 7'b000_0011;
            4'hC: exp_seg = 7'b100_0110;
            4'hD: exp_seg = 7'b010_0001;
            4'hE: exp_seg = 7'b000_0110;
            4'hF: exp_seg = 7'b000_1110;
        endcase
    endfunction

    // ---------------------------------------------------------------
    // Fail counter and check macro
    // ---------------------------------------------------------------
    integer fail_count;
    reg [127:0] fail_msg;

    // ---------------------------------------------------------------
    // Main test sequence
    // ---------------------------------------------------------------
    integer i;
    initial begin
        fail_count = 0;
        // Initial values
        awaddr  = 8'h00;  awvalid = 1'b0;
        wdata   = 32'h0;  wstrb   = 4'h0;  wvalid  = 1'b0;  bready  = 1'b0;
        araddr  = 8'h00;  arvalid = 1'b0;  rready  = 1'b0;
        aresetn = 1'b0;
        repeat (10) @(posedge aclk);
        aresetn = 1'b1;
        repeat (5)  @(posedge aclk);

        // ============================================================
        // T1: Reset state — all anodes high, seg all high (all off)
        // ============================================================
        // After reset: en=1, blank=0xF → all digits blanked → an=1111
        if (an !== 4'b1111) begin
            $display("FAIL: T1 reset an expected 1111, got %b", an);
            fail_count = fail_count + 1;
        end

        // ============================================================
        // T2: Enable digits 0-3, DATA=0x1234, CTRL=bright=15, blank=0
        //   DATA: d3=0, d2=1, d1=2, d0=3  (reg_data[15:0]=0x0123... wait)
        //   Register map: [3:0]=d0, [7:4]=d1, [11:8]=d2, [15:12]=d3
        //   For digits d0=4, d1=3, d2=2, d3=1 → DATA=0x0001_2340...
        //   Let's use DATA=0x0000_4321: d3=4, d2=3, d1=2, d0=1
        //   CTRL: en=1 (bit12), bright=15 (bits 11:8), dp_en=0, blank=0
        //         = 0x0000_1F00
        // ============================================================
        axil_write(8'h00, 32'h0000_4321, 4'hF); // DATA
        axil_write(8'h04, 32'h0000_1F00, 4'hF); // CTRL: en=1,bright=F,blank=0,dp=0

        // Wait for digit 0 (d0=1 → seg=1)
        wait_digit(2'd0);
        if (an !== 4'b1110) begin
            $display("FAIL: T2 digit0 an expected 1110, got %b", an);
            fail_count = fail_count + 1;
        end
        if (seg !== exp_seg(4'h1)) begin
            $display("FAIL: T2 digit0 seg expected %b (hex 1), got %b", exp_seg(4'h1), seg);
            fail_count = fail_count + 1;
        end

        // Wait for digit 1 (d1=2 → seg for 2)
        wait_digit(2'd1);
        if (an !== 4'b1101) begin
            $display("FAIL: T2 digit1 an expected 1101, got %b", an);
            fail_count = fail_count + 1;
        end
        if (seg !== exp_seg(4'h2)) begin
            $display("FAIL: T2 digit1 seg expected %b (hex 2), got %b", exp_seg(4'h2), seg);
            fail_count = fail_count + 1;
        end

        // ============================================================
        // T3: Blank digit 0 → an[0] never goes low for one full mux cycle
        //   blank[0]=1 means digit 0 slot: anode never goes low.
        //   Strategy: scan 4*MUX_DIV cycles and confirm an[0] stays high.
        //   Then verify digit 1 (non-blanked) still shows normally.
        // ============================================================
        axil_write(8'h04, 32'h0000_1F01, 4'hF); // blank[0]=1, rest same
        // Scan one full mux cycle to confirm an[0] never goes low
        for (i = 0; i < 4*MUX_DIV; i = i+1) begin
            @(posedge aclk);
            if (an[0] === 1'b0) begin
                $display("FAIL: T3 blank digit0 an[0] went low (expected never), an=%b", an);
                fail_count = fail_count + 1;
                i = 4*MUX_DIV; // break on first failure
            end
        end
        // Digit 1 should still show (non-blanked)
        wait_digit(2'd1);
        if (an !== 4'b1101) begin
            $display("FAIL: T3 digit1 (non-blanked) an expected 1101, got %b", an);
            fail_count = fail_count + 1;
        end

        // ============================================================
        // T4: dp_en digit 1 → dp_out=0 during digit 1 slot
        //   CTRL: blank=0x1 (digit0), dp_en=0x2 (digit1), bright=15, en=1
        //       = [12]=1, [11:8]=0xF, [7:4]=0x2, [3:0]=0x1
        //       = 0x0000_1F21
        // ============================================================
        axil_write(8'h04, 32'h0000_1F21, 4'hF);
        wait_digit(2'd1);
        if (dp_out !== 1'b0) begin
            $display("FAIL: T4 dp digit1 expected 0, got %b", dp_out);
            fail_count = fail_count + 1;
        end
        // Digit 2 dp should be off (dp_en[2]=0)
        wait_digit(2'd2);
        if (dp_out !== 1'b1) begin
            $display("FAIL: T4 dp digit2 expected 1 (off), got %b", dp_out);
            fail_count = fail_count + 1;
        end

        // ============================================================
        // T5: en=0 → all outputs high
        // ============================================================
        axil_write(8'h04, 32'h0000_0F00, 4'hF); // en=0 (bit12 clear), bright=15
        // Wait a few mux cycles
        repeat (MUX_DIV * 2) @(posedge aclk);
        if (an !== 4'b1111) begin
            $display("FAIL: T5 en=0 an expected 1111, got %b", an);
            fail_count = fail_count + 1;
        end
        if (seg !== 7'b111_1111) begin
            $display("FAIL: T5 en=0 seg expected 1111111, got %b", seg);
            fail_count = fail_count + 1;
        end

        // ============================================================
        // T6: Read back registers
        // ============================================================
        // Re-enable to avoid confusion; write known values
        axil_write(8'h00, 32'h0000_ABCD, 4'hF);
        axil_write(8'h04, 32'h0000_1F00, 4'hF);
        repeat (5) @(posedge aclk);

        axil_read(8'h00);
        if (rd_result !== 32'h0000_ABCD) begin
            $display("FAIL: T6 DATA readback expected 0000ABCD, got %08h", rd_result);
            fail_count = fail_count + 1;
        end

        axil_read(8'h04);
        if (rd_result !== 32'h0000_1F00) begin
            $display("FAIL: T6 CTRL readback expected 00001F00, got %08h", rd_result);
            fail_count = fail_count + 1;
        end

        // ============================================================
        // Result
        // ============================================================
        if (fail_count === 0)
            $display("PASS: all tests passed (T1-T6)");
        else
            $display("FAIL: %0d test(s) failed", fail_count);

        $finish;
    end

    // ---------------------------------------------------------------
    // Timeout guard
    // T2: 2×4×MUX_DIV=800k, T3: 4×MUX_DIV+4×MUX_DIV=800k scan+wait,
    // T4: 2×4×MUX_DIV=800k, T5: 2×MUX_DIV=200k → ~2.6M cycles total
    // Allow 10M cycles (100 ms)
    // ---------------------------------------------------------------
    initial begin
        #100_000_000; // 100 ms sim time
        $display("FAIL: simulation timeout");
        $finish;
    end

endmodule

## ----------------------------------------------------------------
## lint — Verilator syntax and style check

lint:
	@mkdir -p $(BUILD)
	verilator --lint-only -Wall $(RTL) --top-module $(TOP) 2>&1 | tee $(BUILD)/lint.log

	vvp $(BUILD)/tb_$(SLUG) 2>&1 | tee $(BUILD)/sim_run.log
	@grep -E "^(PASS|FAIL)" $(BUILD)/sim_run.log || echo "FAIL: no PASS/FAIL line found"

	@echo "--- synth done (see $(BUILD)/synth.log) ---"
