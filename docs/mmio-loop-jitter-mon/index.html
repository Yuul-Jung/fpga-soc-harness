제어 루프 지터 측정 IP (Loop Jitter Monitor)

틱 입력의 주기를 클럭 카운터로 측정해 min/max/마지막 값·오버런 카운터를 mmio-lite 레지스터로 노출하는 경량 감시 IP. IP 표준(rev.1) 관리 레지스터(ID/VER/IRQ_STATUS/IRQ_ENABLE) 포함.

린트: verilator --lint-only -Wall -Wno-fatal --top-module basys3_jitter_mon_top rtl/*.v시뮬레이션: iverilog -g2005 -o build/sim.vvp tb/tb_loop_jitter_mon.v rtl/loop_jitter_mon.v && vvp build/sim.vvp | grep PASS합성: yosys -p 'read_verilog rtl/*.v; synth_xilinx -top basys3_jitter_mon_top -family xc7; stat'보드: pending

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • 틱 신호의 클럭 주기를 32비트 카운터로 측정
  • PERIOD_MIN / PERIOD_MAX / PERIOD_LAST 레지스터를 읽기 전용으로 제공
  • THRESHOLD 초과 시 OVERRUN_CNT 증가 및 IRQ_STATUS[0] 셋(W1C)
  • CTRL[0]=enable_meas, CTRL[1]=stats_clear(자동 복귀), THRESHOLD R/W 지원
  • IP 표준 rev.1 관리 레지스터(ID=JMON / VER / IRQ_STATUS W1C / IRQ_ENABLE) 포함
  • iverilog 시뮬레이션 PASS 확인(S1 목표)

범위 밖

  • 실제 MicroBlaze V CPU 연동 및 드라이버 작성
  • AXI4-Lite 래퍼 RTL(동결 맵 이식 시 별도 작성)
  • 보드에서 직접 검증(S3)은 사용자 담당
  • 지터 히스토그램, 고분해능 타임스탬프

이 패키지의 소스는 하네스가 직접 작성한 원본이며 외부 코드를 포함하지 않는다. 아이디어 I-039 기반. 외부 부품 없음(보드 내장 LED만 사용).

2. 계통도

클럭: 100 MHz 단일 클럭 (CLK_100, W5), 비동기 리셋 (BTNC, U18, 액티브 하이)

diagram.svg로 따로 받을 수 있다.

버스 규약: mmio-lite

신호방향설명
selmaster→slave슬레이브 선택 (이 사이클이 이 IP 대상)
wemaster→slave1=쓰기, 0=읽기
offsetmaster→slave16비트 오프셋 (addr[15:0])
wdatamaster→slave32비트 쓰기 데이터
rdataslave→master32비트 읽기 데이터 (sel=1 사이클 유효)

1사이클 완료. 미매핑 오프셋 읽기는 32'h0 반환. 쓰기 무시. 대기·오류 없음.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스mmio-lite (자체, 단독 실행용)
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 적합하지 않음
이식 계획이 패키지는 단독 시뮬레이션과 보드 합성 확인을 위해 mmio-lite 버스(offset[15:0] 직접 비교)를 사용한다. 동결 맵(mbv-frozen-v2) 슬롯 [16]=0x4016_0000 / intc=13 에 이식하려면 (1) IP 표준 래퍼(axil_slave 패턴, 64KB 창)를 추가 작성하고 (2) AXI Interconnect에 연결하며 (3) IRQ는 INTC 입력 13번으로 배선한다. 레지스터 오프셋(0x0000~0x0014, 0xFFF0~0xFFFC)은 그대로 유지된다.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

외부 배선이 없는 순수 디지털 IP. 모든 연결은 보드 내장 LED/버튼. 추가 회로도 불필요.

id부품인터페이스신호 전압구분레벨 변환비고
p_ledBasys3 LED 16개GPIO 출력3.3 V보드 내장불필요 (3.3V)보드 내장. LED[15]=irq, LED[7:0]=overrun_cnt[7:0] 표시

Basys3 FPGA 핀은 3.3V 신호만 직접 받는다. 5V·12V·모터·릴레이는 직결하지 않는다.

// loop_jitter_mon.v — 제어 루프 지터 측정 IP (Verilog-2001)
// 하네스 직접 작성 원본.
//
// 측정 원리:
//   tick_in의 상승 에지 사이 클럭 수를 세어 PERIOD_LAST에 기록.
//   PERIOD_MIN = min(전체), PERIOD_MAX = max(전체).
//   측정 주기 > THRESHOLD(0이 아닐 때)이면 OVERRUN_CNT++ 및 IRQ_STATUS[0] 셋.
//
// mmio-lite 슬레이브 인터페이스:
//   sel     : 이 슬레이브 선택 (상위 디코더에서 addr[31:16] 비교)
//   we      : 1=쓰기, 0=읽기
//   offset  : addr[15:0]
//   wdata   : 32비트 쓰기 데이터
//   rdata   : 32비트 읽기 데이터 (sel=1인 사이클에 유효)
//
// IP 표준 rev.1 관리 레지스터:
//   0xFFF0  ID         = 0x4A4D_4F4E ('JMON')
//   0xFFF4  VER        = 0x0100_0100  [31:24]=표준rev1, [15:8]=주1, [7:0]=부0
//   0xFFF8  IRQ_STATUS  W1C, bit[0]=overrun_irq
//   0xFFFC  IRQ_ENABLE  bit[0]=overrun_irq 활성화 (리셋 시 0)
//
// 기능 레지스터:
//   0x0000  CTRL         bit[0]=enable_meas, bit[1]=stats_clear(W만, 읽기=0)
//   0x0004  PERIOD_MIN   RO, 리셋/stats_clear 시 32'hFFFF_FFFF
//   0x0008  PERIOD_MAX   RO, 리셋/stats_clear 시 32'h0
//   0x000C  PERIOD_LAST  RO, 마지막 측정 주기
//   0x0010  OVERRUN_CNT  RO, 오버런 누적 횟수
//   0x0014  THRESHOLD    RW, 0이면 오버런 검출 비활성
//
`timescale 1ns/1ps
module loop_jitter_mon (
    input  wire        clk,
    input  wire        rst,          // 비동기, 액티브 하이
    // 측정 대상
    input  wire        tick_in,      // 주기 측정 대상 신호
    // mmio-lite 슬레이브
    input  wire        sel,          // 이 슬레이브가 선택됨
    input  wire        we,           // 1=쓰기
    input  wire [15:0] offset,       // 레지스터 오프셋
    input  wire [31:0] wdata,        // 쓰기 데이터
    output reg  [31:0] rdata,        // 읽기 데이터
    // 인터럽트
    output wire        irq           // 레벨, IRQ_STATUS & IRQ_ENABLE
);

    // ----------------------------------------------------------------
    // 오프셋 상수
    // ----------------------------------------------------------------
    localparam [15:0]
        OFF_CTRL        = 16'h0000,
        OFF_PERIOD_MIN  = 16'h0004,
        OFF_PERIOD_MAX  = 16'h0008,
        OFF_PERIOD_LAST = 16'h000C,
        OFF_OVERRUN_CNT = 16'h0010,
        OFF_THRESHOLD   = 16'h0014,
        OFF_ID          = 16'hFFF0,
        OFF_VER         = 16'hFFF4,
        OFF_IRQ_STATUS  = 16'hFFF8,
        OFF_IRQ_ENABLE  = 16'hFFFC;

    // ID, VER 상수
    localparam [31:0] CONST_ID  = 32'h4A4D_4F4E; // 'J','M','O','N'
    localparam [31:0] CONST_VER = 32'h0100_0100; // rev1, major1, minor0

    // ----------------------------------------------------------------
    // tick_in 2단 동기화 + 상승 에지 검출
    // ----------------------------------------------------------------
    reg tick_s1, tick_s2, tick_s3;
    always @(posedge clk or posedge rst) begin
        if (rst) begin
            tick_s1 <= 1'b0;
            tick_s2 <= 1'b0;
            tick_s3 <= 1'b0;
        end else begin
            tick_s1 <= tick_in;
            tick_s2 <= tick_s1;
            tick_s3 <= tick_s2;
        end
    end
    // 2단 동기화 후 상승 에지: tick_s2가 올라가고 tick_s3가 아직 낮은 순간
    wire tick_rise = tick_s2 & ~tick_s3;

    // ----------------------------------------------------------------
    // 버스 쓰기 디코드 보조 신호
    // ----------------------------------------------------------------
    wire wr_ctrl        = sel && we && (offset == OFF_CTRL);
    wire wr_threshold   = sel && we && (offset == OFF_THRESHOLD);
    wire wr_irq_status  = sel && we && (offset == OFF_IRQ_STATUS);
    wire wr_irq_enable  = sel && we && (offset == OFF_IRQ_ENABLE);
    wire do_stats_clear = wr_ctrl && wdata[1];

    // ----------------------------------------------------------------
    // 레지스터 선언
    // ----------------------------------------------------------------
    reg        enable_meas;
    reg [31:0] period_min;
    reg [31:0] period_max;
    reg [31:0] period_last;
    reg [31:0] overrun_cnt;
    reg [31:0] threshold;
    reg        irq_status;
    reg        irq_enable;

    // 주기 측정 카운터 및 상태
    reg [31:0] cnt;
    reg        first_tick;   // 첫 번째 에지는 카운터 초기화만

    // ----------------------------------------------------------------
    // 단일 always 블록: 버스 쓰기(우선) + 측정 로직
    // 버스 쓰기와 측정이 같은 사이클에 겹치면 버스 쓰기를 우선한다.
    // ----------------------------------------------------------------
    always @(posedge clk or posedge rst) begin
        if (rst) begin
            enable_meas  <= 1'b0;
            period_min   <= 32'hFFFF_FFFF;
            period_max   <= 32'h0;
            period_last  <= 32'h0;
            overrun_cnt  <= 32'h0;
            threshold    <= 32'h0;
            irq_status   <= 1'b0;
            irq_enable   <= 1'b0;
            cnt          <= 32'h0;
            first_tick   <= 1'b1;
        end else if (do_stats_clear) begin
            // CTRL[1]=1 쓰기: 통계 초기화 (enable_meas도 CTRL[0]으로 갱신)
            enable_meas  <= wdata[0];
            period_min   <= 32'hFFFF_FFFF;
            period_max   <= 32'h0;
            period_last  <= 32'h0;
            overrun_cnt  <= 32'h0;
            irq_status   <= 1'b0;
            cnt          <= 32'h0;
            first_tick   <= 1'b1;
        end else begin
            // --- 버스 쓰기 처리 ---
            if (wr_ctrl)       enable_meas  <= wdata[0];
            if (wr_threshold)  threshold    <= wdata;
            if (wr_irq_status) irq_status   <= irq_status & ~wdata[0]; // W1C
            if (wr_irq_enable) irq_enable   <= wdata[0];

            // --- 측정 로직 (enable_meas 중에만) ---
            if (enable_meas) begin
                cnt <= cnt + 32'h1;
                if (tick_rise) begin
                    if (first_tick) begin
                        // 첫 에지: 카운터만 초기화, 통계는 아직 없음
                        cnt        <= 32'h0;
                        first_tick <= 1'b0;
                    end else begin
                        // 두 번째 에지부터: 주기 기록 및 통계 갱신
                        period_last <= cnt;
                        if (cnt < period_min) period_min <= cnt;
                        if (cnt > period_max) period_max <= cnt;
                        // 오버런 검출: threshold!=0 && 주기 > threshold
                        if ((threshold != 32'h0) && (cnt > threshold)) begin
                            if (overrun_cnt != 32'hFFFF_FFFF) // 포화 방지
                                overrun_cnt <= overrun_cnt + 32'h1;
                            irq_status <= 1'b1;
                        end
                        cnt <= 32'h0;
                    end
                end
            end
        end
    end

    // ----------------------------------------------------------------
    // 읽기 MUX (조합)
    // ----------------------------------------------------------------
    always @(*) begin
        case (offset)
            OFF_CTRL:        rdata = {30'h0, 1'b0, enable_meas}; // bit[1]은 always 0
            OFF_PERIOD_MIN:  rdata = period_min;
            OFF_PERIOD_MAX:  rdata = period_max;
            OFF_PERIOD_LAST: rdata = period_last;
            OFF_OVERRUN_CNT: rdata = overrun_cnt;
            OFF_THRESHOLD:   rdata = threshold;
            OFF_ID:          rdata = CONST_ID;
            OFF_VER:         rdata = CONST_VER;
            OFF_IRQ_STATUS:  rdata = {31'h0, irq_status};
            OFF_IRQ_ENABLE:  rdata = {31'h0, irq_enable};
            default:         rdata = 32'h0;
        endcase
    end

    // ----------------------------------------------------------------
    // 인터럽트 출력 (레벨)
    // ----------------------------------------------------------------
    assign irq = irq_status & irq_enable;

endmodule
rtl/basys3_jitter_mon_top.v 135줄
// basys3_jitter_mon_top.v — Basys3 최상위 (합성·보드 시연용, Verilog-2001)
// 하네스 직접 작성 원본.
//
// 역할:
//   1. 100 MHz → 1 kHz 틱 발생 (100,000 클럭 분주, 보드 시연용)
//   2. 리셋 후 2클럭 동안 cfg_fsm이 jmon IP를 초기화:
//        - THRESHOLD = 150000 (1.5 ms @ 100 MHz)
//        - CTRL      = 0x1 (enable_meas=1)
//   3. 이후 idle: tick_in=tick_1khz, 출력 표시
//      LED[15]   = irq (오버런 감지)
//      LED[7:0]  = overrun_cnt 최하위 8비트 (읽기는 cfg_fsm이 하지 않음;
//                  보드 시연에서는 IRQ만 표시, overrun_cnt는 보드 연결에서 생략)
//
// 참고: LED[7:0]은 irq 신호와 1kHz 틱 토글로 단순 표시.
//       정밀한 보드 검증(S3)은 사용자가 Vitis/로직 애널라이저로 수행.
//
`timescale 1ns/1ps
module basys3_jitter_mon_top (
    input  wire        clk,    // W5, 100 MHz
    input  wire        btnC,   // U18, 센터 버튼 → 리셋 (액티브 하이)
    output wire [15:0] led     // 상태 LED
);

    // ----------------------------------------------------------------
    // 버튼 2단 동기화 → 리셋
    // ----------------------------------------------------------------
    reg btn_s1, btn_s2;
    always @(posedge clk) begin
        btn_s1 <= btnC;
        btn_s2 <= btn_s1;
    end
    wire rst = btn_s2;

    // ----------------------------------------------------------------
    // 1 kHz 틱 생성 (100,000 클럭 분주)
    // ----------------------------------------------------------------
    localparam integer TICK_DIV = 100_000;
    reg [16:0] tick_cnt;  // ceil(log2(100000)) = 17
    reg        tick_1khz;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            tick_cnt  <= 17'd0;
            tick_1khz <= 1'b0;
        end else if (tick_cnt >= TICK_DIV - 1) begin
            tick_cnt  <= 17'd0;
            tick_1khz <= ~tick_1khz;
        end else begin
            tick_cnt <= tick_cnt + 17'd1;
        end
    end

    // ----------------------------------------------------------------
    // cfg_fsm: 리셋 후 jmon IP 초기화 (2단계)
    // 상태:
    //   2'h0: THRESHOLD = 150000 쓰기
    //   2'h1: CTRL      = 0x1   쓰기
    //   2'h2: idle (버스 비활성)
    // ----------------------------------------------------------------
    reg [1:0]  cfg_state;
    reg        jmon_sel;
    reg        jmon_we;
    reg [15:0] jmon_offset;
    reg [31:0] jmon_wdata;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            cfg_state  <= 2'h0;
            jmon_sel   <= 1'b0;
            jmon_we    <= 1'b0;
            jmon_offset <= 16'h0;
            jmon_wdata  <= 32'h0;
        end else begin
            // 기본: 버스 비활성
            jmon_sel <= 1'b0;
            jmon_we  <= 1'b0;
            case (cfg_state)
                2'h0: begin
                    // THRESHOLD = 150000 (1.5 ms @ 100 MHz)
                    jmon_sel    <= 1'b1;
                    jmon_we     <= 1'b1;
                    jmon_offset <= 16'h0014; // OFF_THRESHOLD
                    jmon_wdata  <= 32'd150_000;
                    cfg_state   <= 2'h1;
                end
                2'h1: begin
                    // CTRL: enable_meas=1, stats_clear=0
                    jmon_sel    <= 1'b1;
                    jmon_we     <= 1'b1;
                    jmon_offset <= 16'h0000; // OFF_CTRL
                    jmon_wdata  <= 32'h0000_0001;
                    cfg_state   <= 2'h2;
                end
                2'h2: begin
                    // idle: 버스 접근 없음
                    cfg_state <= 2'h2;
                end
                default: cfg_state <= 2'h2;
            endcase
        end
    end

    // ----------------------------------------------------------------
    // loop_jitter_mon 인스턴스

// tb_loop_jitter_mon.v — 자체 점검형 시험 (Verilog-2001)
// 하네스 직접 작성 원본.
//
// 종료 조건:
//   "PASS" 로 시작하는 줄 출력 → vvp 종료 코드 0 (Makefile이 grep으로 확인)
//   "FAIL" 로 시작하는 줄 출력 → 오류로 처리
//
// 시험 케이스:
//   T01: 리셋 직후 초기값 확인
//   T02: enable 없이 tick을 넣어도 통계 불변 확인
//   T03: enable 후 첫 에지는 카운터만 초기화(통계 미갱신)
//   T04: 두 번째 에지에서 주기 기록 (PERIOD_LAST=99, MIN=99, MAX=99)
//        ※ RTL: cnt는 tick_rise에서 0 리셋, 다음 사이클부터 1씩 증가 → N클럭 간격=N-1
//   T05: 주기 측정 (버스 오버헤드 포함 210클럭) → MAX=210, MIN 유지(99)
//   T06: 주기 측정 (버스 오버헤드 포함 60클럭) → MIN=60, MAX 유지(210)
//   T07: THRESHOLD=120, 주기 200 → OVERRUN_CNT=1, IRQ_STATUS[0]=1
//   T08: IRQ_ENABLE=1 → irq 출력 활성 확인
//   T09: IRQ_STATUS W1C → irq_status 클리어 (enable 중 IRQ_ENABLE=1 유지)
//   T10: stats_clear(CTRL[1]=1) → min/max/overrun/irq_status 초기화
//   T11: stats_clear 후 측정 재시작 (PERIOD_LAST=79 확인)
//   T12: ID, VER 관리 레지스터 읽기 확인
//   T13: THRESHOLD=0 → 오버런 검출 비활성 (오버런 카운트 불변)
//
`timescale 1ns/1ps

module tb_loop_jitter_mon;

    // ----------------------------------------------------------------
    // 클럭·리셋
    // ----------------------------------------------------------------
    reg clk;
    reg rst;

    initial clk = 1'b0;
    always #5 clk = ~clk; // 100 MHz (주기 10 ns)

    // ----------------------------------------------------------------
    // DUT 포트
    // ----------------------------------------------------------------
    reg        tick_in;
    reg        sel;
    reg        we;
    reg [15:0] offset;
    reg [31:0] wdata;
    wire [31:0] rdata;
    wire        irq;

    loop_jitter_mon dut (
        .clk     (clk),
        .rst     (rst),
        .tick_in (tick_in),
        .sel     (sel),
        .we      (we),
        .offset  (offset),
        .wdata   (wdata),
        .rdata   (rdata),
        .irq     (irq)
    );

    // ----------------------------------------------------------------
    // 버스 접근 태스크
    // ----------------------------------------------------------------
    task bus_write;
        input [15:0] off;
        input [31:0] data;
        begin
            @(posedge clk); #1;
            sel    = 1'b1;
            we     = 1'b1;
            offset = off;
            wdata  = data;
            @(posedge clk); #1;
            sel = 1'b0; we = 1'b0;
        end
    endtask

    task bus_read;
        input  [15:0] off;
        output [31:0] data;
        begin
            @(posedge clk); #1;
            sel    = 1'b1;
            we     = 1'b0;
            offset = off;
            wdata  = 32'h0;
            #1; // rdata는 조합 출력이므로 같은 사이클에 유효
            data = rdata;
            @(posedge clk); #1;
            sel = 1'b0;
        end
    endtask

    // ----------------------------------------------------------------
    // tick 발생 태스크: 지정 사이클 후 상승 에지 발생
    // ----------------------------------------------------------------
    task send_tick;
        input [31:0] period_clk; // 이 사이클 뒤에 tick_in 토글 (상승→하강)
        begin
            repeat (period_clk) @(posedge clk);
            #1; tick_in = 1'b1;
            @(posedge clk); #1;
            tick_in = 1'b0;
        end
    endtask

    // ----------------------------------------------------------------
    // 검증 헬퍼
    // ----------------------------------------------------------------
    integer fail_count;

    task check;
        input [255:0] name;
        input [31:0]  actual;
        input [31:0]  expected;
        begin
            if (actual !== expected) begin
                $display("FAIL %0s: got 0x%08X, exp 0x%08X", name, actual, expected);
                fail_count = fail_count + 1;
            end
        end
    endtask

    // ----------------------------------------------------------------
    // 시험 본문
    // ----------------------------------------------------------------
    reg [31:0] rd;

    initial begin
        // 초기화
        fail_count = 0;
        rst     = 1'b1;
        tick_in = 1'b0;
        sel     = 1'b0;
        we      = 1'b0;
        offset  = 16'h0;
        wdata   = 32'h0;

        repeat (4) @(posedge clk);
        #1; rst = 1'b0;
        repeat (2) @(posedge clk); #1;

        // -------------------------------------------------------
        // T01: 리셋 직후 초기값
        // -------------------------------------------------------
        bus_read(16'h0000, rd); check("T01_CTRL",        rd, 32'h0);
        bus_read(16'h0004, rd); check("T01_PERIOD_MIN",  rd, 32'hFFFF_FFFF);
        bus_read(16'h0008, rd); check("T01_PERIOD_MAX",  rd, 32'h0);
        bus_read(16'h000C, rd); check("T01_PERIOD_LAST", rd, 32'h0);
        bus_read(16'h0010, rd); check("T01_OVERRUN_CNT", rd, 32'h0);
        bus_read(16'h0014, rd); check("T01_THRESHOLD",   rd, 32'h0);
        bus_read(16'hFFF8, rd); check("T01_IRQ_STATUS",  rd, 32'h0);
        bus_read(16'hFFFC, rd); check("T01_IRQ_ENABLE",  rd, 32'h0);
        check("T01_irq", {31'h0, irq}, 32'h0);

        // -------------------------------------------------------
        // T02: enable 없이 tick — 통계 불변
        // -------------------------------------------------------
        // tick_in=1 → 1 → 0 (에지 발생)
        @(posedge clk); #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;
        bus_read(16'h0004, rd); check("T02_PERIOD_MIN_unchanged", rd, 32'hFFFF_FFFF);
        bus_read(16'h000C, rd); check("T02_PERIOD_LAST_unchanged", rd, 32'h0);

        // -------------------------------------------------------
        // T03: enable 후 첫 에지는 카운터만 초기화
        // -------------------------------------------------------
        bus_write(16'h0000, 32'h1); // CTRL: enable_meas=1
        bus_read(16'h0000, rd); check("T03_CTRL_enabled", rd, 32'h1);

        // 첫 에지
        @(posedge clk); #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (3) @(posedge clk); #1;

        // 첫 에지 직후 — first_tick이므로 통계는 아직 갱신 안 됨
        bus_read(16'h000C, rd); check("T03_PERIOD_LAST_still0", rd, 32'h0);
        bus_read(16'h0004, rd); check("T03_MIN_still_max",      rd, 32'hFFFF_FFFF);

        // -------------------------------------------------------
        // T04: 두 번째 에지 (100클럭 후) — PERIOD_LAST=100, MIN=100, MAX=100
        // -------------------------------------------------------
        // 카운터는 첫 에지 이후 클럭 카운트 중. 아직 몇 클럭이 경과했으므로
        // 정확히 100이 되려면 카운터를 리셋 직후부터 맞춰야 함.
        // 여기서는 별도 주기를 보장하기 위해 현재 카운터 상태를 무시하고
        // 첫 에지를 기준으로 100클럭 후 두 번째 에지를 발생시킨다.
        // 위에서 첫 에지 발생 후 3+1(bus_read×2: 각 2클럭) = 약 7클럭 경과.
        // 단, bus_read가 2클럭씩 소비한다고 가정하면:
        //   첫 에지 후 경과 클럭 수 = 약 (1+1)×bus_reads + repeat = 모호
        // 따라서 T04는 고정 주기 대신 "2번째 에지를 적당히 늦게"로 구성.

        // 간단히: stats_clear 후 enable, 100클럭 정확히 맞추기
        bus_write(16'h0000, 32'h3); // CTRL: stats_clear=1, enable=1
        repeat (2) @(posedge clk); #1; // 클리어 적용 대기

        // 첫 에지
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        // 정확히 100클럭 대기 후 두 번째 에지
        repeat (99) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1; // 동기화(3클럭) + 여유

        // RTL P-1 특성: repeat(99)=100클럭 간격 → cnt=99
        bus_read(16'h000C, rd); check("T04_PERIOD_LAST_99", rd, 32'd99);
        bus_read(16'h0004, rd); check("T04_PERIOD_MIN_99",  rd, 32'd99);
        bus_read(16'h0008, rd); check("T04_PERIOD_MAX_99",  rd, 32'd99);

        // -------------------------------------------------------
        // T05: 주기 200 → MAX=200, MIN 유지 (100)
        // -------------------------------------------------------
        repeat (199) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;

        // 버스 오버헤드(repeat5+3reads=11사이클)+repeat(199)=210사이클 → cnt=210; MIN유지=99
        bus_read(16'h000C, rd); check("T05_PERIOD_LAST_210", rd, 32'd210);
        bus_read(16'h0004, rd); check("T05_MIN_still_99",    rd, 32'd99);
        bus_read(16'h0008, rd); check("T05_MAX_210",         rd, 32'd210);

        // -------------------------------------------------------
        // T06: 주기 60 → MIN=60, MAX 유지 (210)
        //      버스 오버헤드(repeat5+3reads=11사이클)+repeat(49)=60사이클 → cnt=60
        // -------------------------------------------------------
        repeat (49) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;

        bus_read(16'h000C, rd); check("T06_PERIOD_LAST_60", rd, 32'd60);
        bus_read(16'h0004, rd); check("T06_MIN_60",         rd, 32'd60);
        bus_read(16'h0008, rd); check("T06_MAX_210",        rd, 32'd210);

        // -------------------------------------------------------
        // T07: THRESHOLD=120, 주기 200 → OVERRUN_CNT=1, IRQ_STATUS[0]=1
        // -------------------------------------------------------
        bus_write(16'h0014, 32'd120); // THRESHOLD = 120

        repeat (199) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;

        bus_read(16'h0010, rd); check("T07_OVERRUN_CNT_1",    rd, 32'd1);
        bus_read(16'hFFF8, rd); check("T07_IRQ_STATUS_1",     rd, 32'h1);

        // -------------------------------------------------------
        // T08: IRQ_ENABLE=1 → irq 출력 활성
        // -------------------------------------------------------
        bus_write(16'hFFFC, 32'h1); // IRQ_ENABLE=1
        @(posedge clk); #1; // 반영 대기
        check("T08_irq_active", {31'h0, irq}, 32'h1);

        // -------------------------------------------------------
        // T09: IRQ_STATUS W1C → irq_status 클리어 (IRQ_ENABLE은 유지)
        // -------------------------------------------------------
        bus_write(16'hFFF8, 32'h1); // W1C: IRQ_STATUS[0] 클리어
        @(posedge clk); #1;
        bus_read(16'hFFF8, rd); check("T09_IRQ_STATUS_cleared", rd, 32'h0);
        check("T09_irq_low", {31'h0, irq}, 32'h0);

        // -------------------------------------------------------
        // T10: stats_clear(CTRL[1]=1) → 통계 초기화
        // -------------------------------------------------------
        // 먼저 IRQ 다시 발생시키기
        repeat (199) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;

        bus_read(16'h0010, rd); check("T10_pre_clear_overrun", rd, 32'd2); // 2번 오버런
        bus_read(16'hFFF8, rd); check("T10_pre_clear_irq_st",  rd, 32'h1);

        // stats_clear
        bus_write(16'h0000, 32'h3); // CTRL[1:0] = 2'b11 (stats_clear + enable)
        repeat (2) @(posedge clk); #1;

        bus_read(16'h0004, rd); check("T10_MIN_reset",          rd, 32'hFFFF_FFFF);
        bus_read(16'h0008, rd); check("T10_MAX_reset",          rd, 32'h0);
        bus_read(16'h000C, rd); check("T10_LAST_reset",         rd, 32'h0);
        bus_read(16'h0010, rd); check("T10_OVERRUN_CNT_reset",  rd, 32'h0);
        bus_read(16'hFFF8, rd); check("T10_IRQ_STATUS_reset",   rd, 32'h0);
        check("T10_irq_low", {31'h0, irq}, 32'h0); // IRQ_ENABLE=1이지만 irq_status=0

        // -------------------------------------------------------
        // T11: stats_clear 후 측정 재시작 (PERIOD_LAST=79 확인)
        //      stats_clear 직후 첫 tick_rise까지 카운터 누적: cnt=0 리셋 후 79클럭 증가
        // -------------------------------------------------------
        // stats_clear 직후 first_tick=1이므로 첫 에지를 발생시켜 카운터 초기화
        @(posedge clk); #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        // 80클럭 후 두 번째 에지 → cnt=79 (P-1 특성)
        repeat (79) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;

        bus_read(16'h000C, rd); check("T11_PERIOD_LAST_79", rd, 32'd79);
        bus_read(16'h0004, rd); check("T11_MIN_79",         rd, 32'd79);
        bus_read(16'h0008, rd); check("T11_MAX_79",         rd, 32'd79);

        // -------------------------------------------------------
        // T12: ID, VER 관리 레지스터 확인
        // -------------------------------------------------------
        bus_read(16'hFFF0, rd); check("T12_ID",  rd, 32'h4A4D_4F4E); // 'J','M','O','N'
        bus_read(16'hFFF4, rd); check("T12_VER", rd, 32'h0100_0100);

        // -------------------------------------------------------
        // T13: THRESHOLD=0 → 오버런 비활성 (카운트 불변)
        // -------------------------------------------------------
        bus_write(16'h0014, 32'h0); // THRESHOLD = 0 (비활성)
        bus_read(16'h0010, rd);
        // stats_clear 없이 현재 카운트 저장
        // 임의로 큰 주기 발생 (1000클럭)
        repeat (999) @(posedge clk);
        #1; tick_in = 1'b1;
        @(posedge clk); #1; tick_in = 1'b0;
        repeat (5) @(posedge clk); #1;

        // OVERRUN_CNT는 rd(이전값)와 같아야 함 (threshold=0이므로 증가 없음)
        bus_read(16'h0010, rd);
        // 여기서 rd가 0이면 PASS (stats_clear 후 카운트가 0 → threshold 비활성이면 그대로)
        check("T13_OVERRUN_CNT_unchanged", rd, 32'h0);
        bus_read(16'hFFF8, rd); check("T13_IRQ_STATUS_no_new_overrun", rd, 32'h0);

        // -------------------------------------------------------
        // 최종 결과
        // -------------------------------------------------------
        repeat (5) @(posedge clk);
        if (fail_count == 0) begin
            $display("PASS: 모든 시험 통과 (%0d개 항목)", 13);
        end else begin
            $display("FAIL: %0d개 항목 불일치", fail_count);
        end
        $finish;
    end

    // 타임아웃 (10 μs = 10000 ns)
    initial begin
        #100_000;
        $display("FAIL: 시뮬레이션 타임아웃 (100 us 초과)");
        $finish;
    end

endmodule

# 단계: lint(verilator) → sim(iverilog) → synth(yosys, 자원 추정). Vivado 빌드는 howto 참고.
RTL_ALL = rtl/loop_jitter_mon.v rtl/basys3_jitter_mon_top.v
RTL_IP  = rtl/loop_jitter_mon.v
TB      = tb/tb_loop_jitter_mon.v

.PHONY: lint sim synth clean
build:
	mkdir -p build

lint: build
	verilator --lint-only -Wall -Wno-fatal --top-module basys3_jitter_mon_top $(RTL_ALL) 2>&1 | tee build/lint.log

9. 참고 카드와 위험

참고 카드

  • circuitdigest-feroflyf405-open-source-fc — 제어 루프 타이밍 모니터링의 필요성과 오버런 검출 패턴 근거
  • pinkfluffyunic0rn-stm32flight — STM32 비행 제어기에서 루프 주기 계측 사례, THRESHOLD 아이디어 근거

위험·한계

  • tick_in은 2단 동기화 후 사용하므로 100 MHz보다 훨씬 빠른 틱(>40 MHz)은 측정 불가 — 대역외 사용 시 주의
  • THRESHOLD=0이면 오버런 검출이 비활성화됨. 초기값이 0이므로 반드시 활성 전에 쓸 것
  • stats_clear 사이클에 tick_rise가 겹치면 해당 에지 측정은 건너뜀(1샘플 손실) — 허용 가능한 측정 오차
  • OVERRUN_CNT는 32비트 포화(wraparound). 장시간 오버런 시 오버플로 주의
  • 동결 맵 이식(T3)에서 AXI4-Lite 래퍼 추가가 필요하며, IRQ 선번(intc=13)은 프로젝트에서 동결 전까지 제안값임
