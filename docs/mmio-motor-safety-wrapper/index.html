MMIO H-브리지 모터 안전 래퍼 자체 점검

PWM 출력 앞단에서 H-브리지 상보 신호에 데드타임을 삽입하고, 외부 과전류 입력 시 출력을 차단·래치하는 motor_safety_ip를 단일 IP로 구현한다. MMIO-lite 버스, IP 표준 Rev.1 관리 레지스터 포함. 슛스루 차단·과전류 래치를 PASS/FAIL 테스트벤치로 자체 점검한다.

린트: 건너뜀 (verilator 없음)시뮬레이션: 건너뜀 (iverilog 없음)합성: 건너뜀 (yosys 없음)보드: not-tested

검증 상태는 실행 기록이 있을 때만 표시한다 · 기준 2026-11-05. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • IP 표준 Rev.1(관리 레지스터 0xFFF0~FFFC)을 따르는 motor_safety_ip 단일 IP 설계: 2채널 H-브리지 상보 신호에 프로그래머블 데드타임 삽입, 외부 과전류 입력 시 출력 래치·차단
  • MMIO-lite 버스 주소 디코더로 GPIO/UART/MOTOR_SAFETY 3개 슬레이브 연결
  • 슛스루 차단(AH·AL 동시 ON 불가), 과전류 래치·해제를 PASS/FAIL 테스트벤치로 자체 점검
  • yosys 합성 성공, iverilog 시뮬레이션 PASS 확인(S2)

범위 밖

  • 실제 H-브리지·모터·전류 센서 하드웨어 연결(S3는 사람이 한다)
  • 속도·위치 제어(PI/PID) — 이 패키지는 출력 보호 레이어만 구현
  • 다채널(3채널 이상) 3상 인버터 — 이 패키지는 2채널(A/B 각 상보 1쌍) 구현
  • AXI4-Lite 완전 핸드셰이크(이 패키지는 mmio-lite 사용)
  • 동적 데드타임 적응(이 패키지는 레지스터로 고정 설정)

이 패키지의 소스는 하네스가 직접 작성한 Verilog-2001 원본이며 외부 코드를 포함하지 않는다. 시뮬레이션·합성 결과는 CI가 기록한다. 아이디어 I-014 (ready, 차단조건재심사 9점)으로 생성됨 (2026-11-04).

2. 계통도

클럭: 100 MHz (시뮬레이션에서는 10 ns 클럭)

diagram.svg로 따로 받을 수 있다.

버스 규약: mmio-lite

신호방향설명
validM→S트랜잭션 유효
weM→S쓰기=1, 읽기=0
addrM→S바이트 주소
wdataM→S쓰기 데이터
rdataS→M읽기 데이터 (버스 MUX 출력)
readyS→M항상 1 (1사이클 응답)

back-pressure 없음. valid 사이클에 always 응답. AXI4-Lite 비호환

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스mmio-lite
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 적합하지 않음
이식 계획mbv-frozen-v2 맵으로 이전 시 motor_safety=[18]=0x4018_0000 슬롯 사용(free_slots 제안). 이 패키지는 시뮬레이션 전용 주소(0x1000~0x1002 세그먼트)를 사용하므로 compat=incompatible. IRQ는 slot 13(free_slots 첫 번째)을 제안.

5. 외부 부품과 전기 회로도

2절의 계통도는 디지털 모듈 연결도다. 전압, 풀업, 커넥터 배선 같은 전기 사항은 이 절에서 따로 다룬다. 기계가 읽는 사본: bom.csv · connections.json

전기 회로도: 미작성

이 패키지는 시뮬레이션 전용이며 외부 부품이 없어 회로도 미작성. 실제 사용 시 H-브리지(TB6612FNG 또는 DRV8833), 전류 센서, 레벨 변환 회로 필요.

id부품인터페이스신호 전압구분레벨 변환비고

Basys3 FPGA 핀은 3.3V 신호만 직접 받는다. 5V·12V·모터·릴레이는 직결하지 않는다.

rtl/mmio_bus.v 72줄
// mmio_bus.v — MMIO-lite 주소 디코더 / 버스 MUX (3 슬레이브)
// addr[31:16] 기준 슬레이브 선택:
//   0x1000 → GPIO
//   0x1001 → UART
//   0x1002 → MOTOR_SAFETY
// ready는 항상 1 (1사이클 응답, back-pressure 없음)

`default_nettype none

module mmio_bus (
    // 마스터 → 버스
    input  wire        m_valid,
    input  wire        m_we,
    input  wire [31:0] m_addr,
    input  wire [31:0] m_wdata,
    output reg  [31:0] m_rdata,
    output wire        m_ready,

    // 슬레이브 0 — GPIO
    output wire        s0_valid,
    output wire        s0_we,
    output wire [31:0] s0_addr,
    output wire [31:0] s0_wdata,
    input  wire [31:0] s0_rdata,

    // 슬레이브 1 — UART
    output wire        s1_valid,
    output wire        s1_we,
    output wire [31:0] s1_addr,
    output wire [31:0] s1_wdata,
    input  wire [31:0] s1_rdata,

    // 슬레이브 2 — MOTOR_SAFETY
    output wire        s2_valid,
    output wire        s2_we,
    output wire [31:0] s2_addr,
    output wire [31:0] s2_wdata,
    input  wire [31:0] s2_rdata
);

    wire sel0 = (m_addr[31:16] == 16'h1000);
    wire sel1 = (m_addr[31:16] == 16'h1001);
    wire sel2 = (m_addr[31:16] == 16'h1002);

    assign s0_valid = m_valid & sel0;
    assign s1_valid = m_valid & sel1;
    assign s2_valid = m_valid & sel2;

    assign s0_we    = m_we;
    assign s1_we    = m_we;
    assign s2_we    = m_we;

    assign s0_addr  = m_addr;
    assign s1_addr  = m_addr;
    assign s2_addr  = m_addr;

    assign s0_wdata = m_wdata;
    assign s1_wdata = m_wdata;
    assign s2_wdata = m_wdata;

    assign m_ready  = 1'b1;

    always @(*) begin
        if      (sel0) m_rdata = s0_rdata;
        else if (sel1) m_rdata = s1_rdata;
        else if (sel2) m_rdata = s2_rdata;
        else           m_rdata = 32'd0;
    end

endmodule

rtl/gpio.v 46줄
// gpio.v — GPIO LED/SW 슬레이브 (MMIO-lite)
// 0x00: LED[15:0] RW  (복귀값 = 마지막 쓴 값)
// 0x04: SW[15:0]  RO  (2단 동기화)

`default_nettype none

module gpio (
    input  wire        clk,
    input  wire        rst,
    // MMIO-lite 슬레이브
    input  wire        valid,
    input  wire        we,
    input  wire [31:0] addr,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    // 보드 I/O
    output reg  [15:0] led,
    input  wire [15:0] sw
);

    reg [15:0] sw_s1, sw_s2;

    always @(posedge clk) begin
        if (rst) begin
            led   <= 16'd0;
            sw_s1 <= 16'd0;
            sw_s2 <= 16'd0;
        end else begin
            sw_s1 <= sw;
            sw_s2 <= sw_s1;
            if (valid && we && addr[7:2] == 6'd0)
                led <= wdata[15:0];
        end
    end

    always @(*) begin
        case (addr[7:2])
            6'd0:    rdata = {16'd0, led};
            6'd1:    rdata = {16'd0, sw_s2};
            default: rdata = 32'd0;
        endcase
    end

endmodule

rtl/uart_tx.v 102줄
// uart_tx.v — UART 8N1 송신 전용 슬레이브 (MMIO-lite)
// 0x00: DATA   WO  송신 바이트 [7:0]. busy=0 일 때만 유효
// 0x04: STATUS RO  bit0=busy
// CLKS_PER_BIT = 100_000_000 / 115_200 ≈ 868

`default_nettype none

module uart_tx #(
    parameter CLKS_PER_BIT = 868
) (
    input  wire        clk,
    input  wire        rst,
    // MMIO-lite 슬레이브
    input  wire        valid,
    input  wire        we,
    input  wire [31:0] addr,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    // UART 핀
    output reg         tx
);

    localparam S_IDLE  = 2'd0;
    localparam S_START = 2'd1;
    localparam S_DATA  = 2'd2;
    localparam S_STOP  = 2'd3;

    reg [1:0]  state;
    reg [9:0]  baud_cnt;
    reg [2:0]  bit_idx;
    reg [7:0]  shift_r;
    reg        busy;

    always @(posedge clk) begin
        if (rst) begin
            state    <= S_IDLE;
            baud_cnt <= 10'd0;
            bit_idx  <= 3'd0;
            shift_r  <= 8'd0;
            busy     <= 1'b0;
            tx       <= 1'b1;
        end else begin
            case (state)
                S_IDLE: begin
                    tx   <= 1'b1;
                    busy <= 1'b0;
                    if (valid && we && addr[7:2] == 6'd0) begin
                        shift_r  <= wdata[7:0];
                        busy     <= 1'b1;
                        baud_cnt <= 10'd0;
                        state    <= S_START;
                    end
                end
                S_START: begin
                    tx <= 1'b0;
                    if (baud_cnt == CLKS_PER_BIT - 1) begin
                        baud_cnt <= 10'd0;
                        bit_idx  <= 3'd0;
                        state    <= S_DATA;
                    end else begin
                        baud_cnt <= baud_cnt + 10'd1;
                    end
                end
                S_DATA: begin
                    tx <= shift_r[bit_idx];
                    if (baud_cnt == CLKS_PER_BIT - 1) begin
                        baud_cnt <= 10'd0;
                        if (bit_idx == 3'd7) begin
                            state <= S_STOP;
                        end else begin
                            bit_idx <= bit_idx + 3'd1;
                        end
                    end else begin
                        baud_cnt <= baud_cnt + 10'd1;
                    end
                end
                S_STOP: begin
                    tx <= 1'b1;
                    if (baud_cnt == CLKS_PER_BIT - 1) begin
                        baud_cnt <= 10'd0;
                        busy     <= 1'b0;
                        state    <= S_IDLE;
                    end else begin
                        baud_cnt <= baud_cnt + 10'd1;
                    end
                end
                default: state <= S_IDLE;
            endcase
        end
    end

    always @(*) begin
        case (addr[7:2])
            6'd0:    rdata = 32'd0;          // DATA WO
            6'd1:    rdata = {31'd0, busy};
            default: rdata = 32'd0;
        endcase
    end

endmodule

// motor_safety_ip.v — H-브리지 모터 안전 래퍼 IP
// IP 표준 Rev.1 관리 레지스터(0xFFF0~0xFFFC) 포함
// MMIO-lite 버스 슬레이브 (1사이클 응답)
//
// 레지스터 맵 (바이트 주소, base+offset):
//   0x00  CTRL       RW  bit0=enable, bit1=oc_clear(자동소거), bit2=dt_bypass
//   0x04  DT_CYCLES  RW  [15:0] 데드타임 클럭 사이클 (기본 10)
//   0x08  STATUS     RO  bit0=oc_latched, bit1=active
//   0x0C  PWM_IN     RW  [3:0]={BL_in,BH_in,AL_in,AH_in}
//   0x10  PWM_OUT    RO  [3:0]={BL_out,BH_out,AL_out,AH_out} (보호 적용 후)
//   0xFFF0 ID        RO  0x4D535731 ("MSW1")
//   0xFFF4 VER       RO  0x01000001
//   0xFFF8 IRQ_STATUS RW1C bit0=oc_event
//   0xFFFC IRQ_ENABLE RW  bit0=oc_irq_en
//
// 보호 기능:
//   1. 슛스루 차단: AH&AL 동시=1 → 둘 다 0
//   2. 데드타임: 한 쪽이 하강한 후 dt_cycles 사이클 동안 반대 쪽 상승 차단
//   3. OC 래치: oc_fault_i(2단 동기화 후) → 모든 출력 0, oc_latched 셋
//   4. dt_bypass=1: 데드타임/슛스루 차단 없음(디버그 전용)

`default_nettype none

module motor_safety_ip (
    input  wire        clk,
    input  wire        rst,

    // MMIO-lite 버스 슬레이브
    input  wire        valid,
    input  wire        we,
    input  wire [31:0] addr,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,

    // 외부 과전류 입력 (비동기, 2단 동기화 내부 처리)
    input  wire        oc_fault_i,

    // PWM 보드 출력
    output wire        pwm_ah_o,
    output wire        pwm_al_o,
    output wire        pwm_bh_o,
    output wire        pwm_bl_o,

    // IRQ 출력
    output wire        irq_o
);

    // ---- 레지스터 -------------------------------------------------------
    reg         enable_r;
    reg         dt_bypass_r;
    reg  [15:0] dt_cycles_r;
    reg  [3:0]  pwm_in_r;
    reg         oc_latched_r;
    reg         irq_status_r;
    reg         irq_enable_r;

    // ---- OC 2단 동기화 --------------------------------------------------
    reg oc_s1, oc_s2, oc_s2_prev;

    always @(posedge clk) begin
        if (rst) begin
            oc_s1 <= 1'b0;
            oc_s2 <= 1'b0;
            oc_s2_prev <= 1'b0;
        end else begin
            oc_s1 <= oc_fault_i;
            oc_s2 <= oc_s1;
            oc_s2_prev <= oc_s2;
        end
    end

    wire oc_rise = oc_s2 & ~oc_s2_prev;  // 과전류 상승 엣지

    // ---- OC 래치 --------------------------------------------------------
    always @(posedge clk) begin
        if (rst) begin
            oc_latched_r <= 1'b0;
            irq_status_r <= 1'b0;
        end else begin
            if (oc_rise) begin
                oc_latched_r <= 1'b1;
                irq_status_r <= 1'b1;
            end
            // oc_clear (bit1 of CTRL): 래치 해제 (유효 쓰기 시 1사이클 후 소거)
            if (valid && we && addr[15:0] == 16'h0000 && wdata[1]) begin
                oc_latched_r <= 1'b0;
            end
            // IRQ_STATUS RW1C
            if (valid && we && addr[15:0] == 16'hFFF8) begin
                irq_status_r <= irq_status_r & ~wdata[0];
            end
        end
    end

    // ---- 쓰기 레지스터 --------------------------------------------------
    always @(posedge clk) begin
        if (rst) begin
            enable_r    <= 1'b0;
            dt_bypass_r <= 1'b0;
            dt_cycles_r <= 16'd10;
            pwm_in_r    <= 4'b0000;
            irq_enable_r <= 1'b0;
        end else if (valid && we) begin
            case (addr[15:0])
                16'h0000: begin
                    enable_r    <= wdata[0];
                    // wdata[1] = oc_clear, 래치에서 처리
                    dt_bypass_r <= wdata[2];
                end
                16'h0004: dt_cycles_r  <= wdata[15:0];
                16'h000C: pwm_in_r     <= wdata[3:0];
                16'hFFFC: irq_enable_r <= wdata[0];
                default: ;
            endcase
        end
    end

    // ---- 데드타임 삽입 (채널 A) -----------------------------------------
    wire req_ah = pwm_in_r[0];
    wire req_al = pwm_in_r[1];
    wire req_bh = pwm_in_r[2];
    wire req_bl = pwm_in_r[3];

    wire safe_ah_a, safe_al_a;
    wire safe_bh_b, safe_bl_b;

    deadtime_ch dt_a (
        .clk       (clk),
        .rst       (rst),
        .bypass    (dt_bypass_r),
        .dt_cycles (dt_cycles_r),
        .req_h     (req_ah),
        .req_l     (req_al),
        .out_h     (safe_ah_a),
        .out_l     (safe_al_a)
    );

    deadtime_ch dt_b (
        .clk       (clk),
        .rst       (rst),
        .bypass    (dt_bypass_r),
        .dt_cycles (dt_cycles_r),
        .req_h     (req_bh),
        .req_l     (req_bl),
        .out_h     (safe_bh_b),
        .out_l     (safe_bl_b)
    );

    // ---- 최종 출력 게이트 (enable & !oc_latched) -----------------------
    wire active = enable_r & ~oc_latched_r;

    assign pwm_ah_o = safe_ah_a & active;
    assign pwm_al_o = safe_al_a & active;
    assign pwm_bh_o = safe_bh_b & active;
    assign pwm_bl_o = safe_bl_b & active;

    // ---- PWM_OUT 레지스터 (읽기용 스냅샷) ------------------------------
    wire [3:0] pwm_out_r = {pwm_bl_o, pwm_bh_o, pwm_al_o, pwm_ah_o};

    // ---- 읽기 ----------------------------------------------------------
    always @(*) begin
        case (addr[15:0])
            16'h0000: rdata = {29'd0, dt_bypass_r, 1'b0, enable_r};
            16'h0004: rdata = {16'd0, dt_cycles_r};
            16'h0008: rdata = {30'd0, active, oc_latched_r};
            16'h000C: rdata = {28'd0, pwm_in_r};
            16'h0010: rdata = {28'd0, pwm_out_r};
            16'hFFF0: rdata = 32'h4D535731;  // "MSW1"
            16'hFFF4: rdata = 32'h01000001;
            16'hFFF8: rdata = {31'd0, irq_status_r};
            16'hFFFC: rdata = {31'd0, irq_enable_r};
            default:  rdata = 32'd0;
        endcase
    end

    // ---- IRQ -----------------------------------------------------------
    assign irq_o = irq_status_r & irq_enable_r;

endmodule


// ============================================================
// deadtime_ch: 한 채널(H+L 상보 쌍)의 데드타임 삽입
// bypass=1 이면 슛스루 차단 없이 req를 그대로 출력(디버그)
// ============================================================
module deadtime_ch (
    input  wire        clk,
    input  wire        rst,
    input  wire        bypass,
    input  wire [15:0] dt_cycles,
    input  wire        req_h,
    input  wire        req_l,
    output reg         out_h,
    output reg         out_l
);

    // 상태: 0=IDLE, 1=DT_AFTER_H_FALL, 2=DT_AFTER_L_FALL
    localparam S_IDLE   = 2'd0;
    localparam S_DT_H   = 2'd1;
    localparam S_DT_L   = 2'd2;

    reg [1:0]  state;
    reg [15:0] cnt;
    reg req_h_prev, req_l_prev;

    always @(posedge clk) begin
        if (rst) begin
            state      <= S_IDLE;
            cnt        <= 16'd0;
            out_h      <= 1'b0;
            out_l      <= 1'b0;
            req_h_prev <= 1'b0;
            req_l_prev <= 1'b0;
        end else if (bypass) begin
            // 디버그 모드: 그대로 통과
            out_h      <= req_h;
            out_l      <= req_l;
            req_h_prev <= req_h;
            req_l_prev <= req_l;
            state      <= S_IDLE;
            cnt        <= 16'd0;
        end else begin
            req_h_prev <= req_h;
            req_l_prev <= req_l;

            case (state)
                S_IDLE: begin
                    // 슛스루 차단: 둘 다 high 요청 → 둘 다 0
                    if (req_h && req_l) begin
                        out_h <= 1'b0;
                        out_l <= 1'b0;
                    end
                    // H 하강 엣지 감지
                    else if (req_h_prev && !req_h) begin
                        out_h <= 1'b0;
                        out_l <= 1'b0;
                        cnt   <= dt_cycles;
                        state <= S_DT_H;
                    end
                    // L 하강 엣지 감지
                    else if (req_l_prev && !req_l) begin
                        out_h <= 1'b0;
                        out_l <= 1'b0;
                        cnt   <= dt_cycles;
                        state <= S_DT_L;
                    end
                    else begin
                        out_h <= req_h;
                        out_l <= req_l;
                    end
                end

                S_DT_H: begin
                    // H 측이 떨어진 후 대기: 아직 L 올리지 않음
                    out_h <= 1'b0;
                    out_l <= 1'b0;
                    if (cnt == 16'd0) begin
                        state <= S_IDLE;
                        // 다음 사이클 IDLE에서 req 반영
                    end else begin
                        cnt <= cnt - 16'd1;
                    end
                end

                S_DT_L: begin
                    // L 측이 떨어진 후 대기: 아직 H 올리지 않음
                    out_h <= 1'b0;
                    out_l <= 1'b0;
                    if (cnt == 16'd0) begin
                        state <= S_IDLE;
                    end else begin
                        cnt <= cnt - 16'd1;
                    end
                end

                default: state <= S_IDLE;
            endcase
        end
    end

endmodule

rtl/demo_master.v 116줄
// demo_master.v — 합성용 데모 마스터 FSM
// MMIO 버스를 통해 motor_safety_ip 초기화 및 PWM 패턴 출력
// 테스트벤치에서는 사용하지 않고, 보드 데모 용도.

`default_nettype none

module demo_master (
    input  wire        clk,
    input  wire        rst,

    // MMIO-lite 마스터 포트
    output reg         m_valid,
    output reg         m_we,
    output reg  [31:0] m_addr,
    output reg  [31:0] m_wdata,
    input  wire [31:0] m_rdata,
    input  wire        m_ready
);

    // 슬레이브 베이스 주소
    localparam BASE_SAFETY = 32'h1002_0000;

    // 레지스터 오프셋
    localparam OFF_CTRL      = 32'h00;
    localparam OFF_DT_CYCLES = 32'h04;
    localparam OFF_PWM_IN    = 32'h0C;

    // 상태
    localparam S_WR_DT   = 4'd0;   // DT_CYCLES=10 설정
    localparam S_WR_EN   = 4'd1;   // enable=1
    localparam S_WAIT1   = 4'd2;   // 간격
    localparam S_WR_AH   = 4'd3;   // AH=1
    localparam S_WAIT2   = 4'd4;
    localparam S_WR_AL   = 4'd5;   // AH→0, AL=1 (데드타임 발생)
    localparam S_WAIT3   = 4'd6;
    localparam S_WR_OFF  = 4'd7;   // 모두 0
    localparam S_WAIT4   = 4'd8;
    localparam S_IDLE    = 4'd9;

    reg [3:0]  state;
    reg [19:0] wait_cnt;

    localparam WAIT_CYCLES = 20'd200;

    task do_write;
        input [31:0] a;
        input [31:0] d;
        begin
            m_valid <= 1'b1;
            m_we    <= 1'b1;
            m_addr  <= a;
            m_wdata <= d;
        end
    endtask

    always @(posedge clk) begin
        if (rst) begin
            state    <= S_WR_DT;
            m_valid  <= 1'b0;
            m_we     <= 1'b0;
            m_addr   <= 32'd0;
            m_wdata  <= 32'd0;
            wait_cnt <= 20'd0;
        end else begin
            m_valid <= 1'b0;

            case (state)
                S_WR_DT: begin
                    do_write(BASE_SAFETY + OFF_DT_CYCLES, 32'd10);
                    state <= S_WR_EN;
                end
                S_WR_EN: begin
                    do_write(BASE_SAFETY + OFF_CTRL, 32'h1);  // enable
                    state <= S_WAIT1;
                    wait_cnt <= WAIT_CYCLES;
                end
                S_WAIT1: begin
                    if (wait_cnt == 0) state <= S_WR_AH;
                    else wait_cnt <= wait_cnt - 20'd1;
                end
                S_WR_AH: begin
                    do_write(BASE_SAFETY + OFF_PWM_IN, 32'h1); // AH=1
                    state <= S_WAIT2;
                    wait_cnt <= WAIT_CYCLES;
                end
                S_WAIT2: begin
                    if (wait_cnt == 0) state <= S_WR_AL;
                    else wait_cnt <= wait_cnt - 20'd1;
                end
                S_WR_AL: begin
                    // AH→0, AL=1 : 데드타임이 걸려 AL_out은 10사이클 뒤에 올라간다
                    do_write(BASE_SAFETY + OFF_PWM_IN, 32'h2); // AL=1
                    state <= S_WAIT3;
                    wait_cnt <= WAIT_CYCLES;
                end
                S_WAIT3: begin
                    if (wait_cnt == 0) state <= S_WR_OFF;
                    else wait_cnt <= wait_cnt - 20'd1;
                end
                S_WR_OFF: begin
                    do_write(BASE_SAFETY + OFF_PWM_IN, 32'h0);
                    state <= S_WAIT4;
                    wait_cnt <= WAIT_CYCLES;
                end
                S_WAIT4: begin
                    if (wait_cnt == 0) state <= S_WR_AH; // 반복
                    else wait_cnt <= wait_cnt - 20'd1;
                end
                default: state <= S_IDLE;
            endcase
        end
    end

endmodule

tb/tb_motor_safety.v 258줄
// tb_motor_safety.v — motor_safety_ip PASS/FAIL 자체 점검 테스트벤치
//
// 테스트 항목:
//   TC1: ID 레지스터 = 0x4D535731 ("MSW1")
//   TC2: 슛스루 차단 — AH_in & AL_in 동시=1 → 둘 다 출력=0
//   TC3: 데드타임 — AH_in 하강 후 AL_in 상승 시, AL_out은 dt_cycles 경과 후 등장
//   TC4: 과전류 래치 — oc_fault_i 상승 → 모든 출력=0, STATUS.oc_latched=1
//   TC5: 과전류 해제 — CTRL.oc_clear → oc_latched=0, 출력 복귀
//   TC6: dt_bypass — bypass=1 시 슛스루 차단 없이 그대로 출력
//
// 비교: !== 사용 (X/Z도 실패로 센다)

`timescale 1ns/1ps
`default_nettype none

module tb_motor_safety;

    // ---- 클럭 / 리셋 -------------------------------------------------------
    reg clk, rst;

    localparam CLK_PERIOD = 10; // 10 ns = 100 MHz
    initial begin clk = 0; forever #(CLK_PERIOD/2) clk = ~clk; end
    initial begin rst = 1; #(CLK_PERIOD*5); rst = 0; end

    // ---- DUT ---------------------------------------------------------------
    reg         valid;
    reg         we;
    reg  [31:0] addr;
    reg  [31:0] wdata;
    wire [31:0] rdata;
    reg         oc_fault;
    wire        pwm_ah, pwm_al, pwm_bh, pwm_bl;
    wire        irq_o;

    motor_safety_ip dut (
        .clk        (clk),
        .rst        (rst),
        .valid      (valid),
        .we         (we),
        .addr       (addr),
        .wdata      (wdata),
        .rdata      (rdata),
        .oc_fault_i (oc_fault),
        .pwm_ah_o   (pwm_ah),
        .pwm_al_o   (pwm_al),
        .pwm_bh_o   (pwm_bh),
        .pwm_bl_o   (pwm_bl),
        .irq_o      (irq_o)
    );

    // ---- 헬퍼 태스크 -------------------------------------------------------
    integer fail_cnt;
    integer tc_num;

    task mmio_write;
        input [31:0] a;
        input [31:0] d;
        begin
            @(posedge clk); #1;
            valid = 1; we = 1; addr = a; wdata = d;
            @(posedge clk); #1;
            valid = 0; we = 0;
        end
    endtask

    task mmio_read;
        input  [31:0] a;
        output [31:0] d;
        begin
            @(posedge clk); #1;
            valid = 1; we = 0; addr = a; wdata = 0;
            @(posedge clk); #1;
            d = rdata;
            valid = 0;
        end
    endtask

    task check_eq;
        input [63:0] got;
        input [63:0] exp;
        input [127:0] msg;
        begin
            if (got !== exp) begin
                $display("  FAIL TC%0d [%s]: got=%0h exp=%0h", tc_num, msg, got, exp);
                fail_cnt = fail_cnt + 1;
            end
        end
    endtask

    // 베이스 (DUT는 직접 연결이므로 주소 하위 비트만 사용)
    localparam B = 32'h1002_0000;
    localparam OFF_CTRL      = 32'h00;
    localparam OFF_DT_CYCLES = 32'h04;
    localparam OFF_STATUS    = 32'h08;
    localparam OFF_PWM_IN    = 32'h0C;
    localparam OFF_PWM_OUT   = 32'h10;
    localparam OFF_ID        = 32'hFFF0;
    localparam OFF_VER       = 32'hFFF4;
    localparam OFF_IRQ_STS   = 32'hFFF8;
    localparam OFF_IRQ_EN    = 32'hFFFC;

    localparam DT_CYCLES = 10;

    reg [31:0] rd;
    integer    i;

    // ---- 메인 테스트 -------------------------------------------------------
    initial begin
        fail_cnt = 0;
        valid = 0; we = 0; addr = 0; wdata = 0;
        oc_fault = 0;

        // 리셋 해제 대기
        @(negedge rst);
        repeat(3) @(posedge clk);

        // -----------------------------------------------------------------
        // TC1: ID 레지스터
        // -----------------------------------------------------------------
        tc_num = 1;
        mmio_read(B + OFF_ID, rd);
        check_eq(rd, 32'h4D535731, "ID=MSW1");
        mmio_read(B + OFF_VER, rd);
        check_eq(rd, 32'h01000001, "VER");

        // -----------------------------------------------------------------
        // TC2: 슛스루 차단 — AH&AL 동시=1 → 출력 둘 다 0
        // -----------------------------------------------------------------
        tc_num = 2;
        // DT_CYCLES=10, enable=1
        mmio_write(B + OFF_DT_CYCLES, DT_CYCLES);
        mmio_write(B + OFF_CTRL, 32'h1);           // enable
        // PWM_IN[1:0] = 2'b11 (AH=1, AL=1)
        mmio_write(B + OFF_PWM_IN, 32'h3);         // {BL,BH,AL,AH}=0011
        @(posedge clk); @(posedge clk); #1;
        // 슛스루: AH_out & AL_out 모두 0
        check_eq(pwm_ah, 1'b0, "TC2:pwm_ah=0");
        check_eq(pwm_al, 1'b0, "TC2:pwm_al=0");

        // 초기화 — AH→0 하강이 DT_CYCLES짜리 데드타임을 유발하므로
        //          FSM이 S_IDLE로 복귀할 때까지 충분히 기다린다
        mmio_write(B + OFF_PWM_IN, 32'h0);
        repeat(DT_CYCLES + 5) @(posedge clk);

        // -----------------------------------------------------------------
        // TC3: 데드타임 — AH_in 하강 후 AL_out은 DT_CYCLES 뒤에 등장
        // -----------------------------------------------------------------
        tc_num = 3;
        // AH=1 설정
        mmio_write(B + OFF_PWM_IN, 32'h1);         // AH_in=1
        @(posedge clk); @(posedge clk); #1;
        check_eq(pwm_ah, 1'b1, "TC3:AH_on");

        // AH→0, AL=1 로 전환
        mmio_write(B + OFF_PWM_IN, 32'h2);         // AL_in=1
        // 전환 직후(1사이클): AL_out 아직 0 (데드타임 중)
        @(posedge clk); #1;
        check_eq(pwm_al, 1'b0, "TC3:AL_still_0_dt");

        // DT_CYCLES+2 사이클 대기 후 AL_out=1 확인
        repeat(DT_CYCLES + 2) @(posedge clk);
        #1;
        check_eq(pwm_al, 1'b1, "TC3:AL_up_after_dt");

        // 초기화
        mmio_write(B + OFF_PWM_IN, 32'h0);
        repeat(DT_CYCLES + 5) @(posedge clk);

        // -----------------------------------------------------------------
        // TC4: 과전류 래치 — oc_fault_i 상승 → 출력=0, oc_latched=1
        // -----------------------------------------------------------------
        tc_num = 4;
        // BH=1 설정
        mmio_write(B + OFF_PWM_IN, 32'h4);         // BH_in=1
        @(posedge clk); @(posedge clk); #1;
        check_eq(pwm_bh, 1'b1, "TC4:BH_on");

        // 과전류 발생
        oc_fault = 1;
        @(posedge clk); @(posedge clk); @(posedge clk); #1; // 2단 동기화 + 1
        // 출력 모두 0
        check_eq(pwm_ah, 1'b0, "TC4:AH=0 on OC");
        check_eq(pwm_al, 1'b0, "TC4:AL=0 on OC");
        check_eq(pwm_bh, 1'b0, "TC4:BH=0 on OC");
        check_eq(pwm_bl, 1'b0, "TC4:BL=0 on OC");
        // STATUS.oc_latched=1
        mmio_read(B + OFF_STATUS, rd);
        check_eq(rd[0], 1'b1, "TC4:oc_latched=1");
        // IRQ_STATUS.oc_event=1
        mmio_read(B + OFF_IRQ_STS, rd);
        check_eq(rd[0], 1'b1, "TC4:irq_status=1");

        oc_fault = 0; // 외부 신호 해제 (래치는 소프트웨어 해제)
        repeat(3) @(posedge clk);

        // -----------------------------------------------------------------
        // TC5: 과전류 해제 — CTRL.oc_clear → oc_latched=0, 출력 복귀
        // -----------------------------------------------------------------
        tc_num = 5;
        // IRQ_STATUS RW1C 소거
        mmio_write(B + OFF_IRQ_STS, 32'h1);
        // oc_clear(bit1)=1 + enable(bit0)=1
        mmio_write(B + OFF_CTRL, 32'h3);
        @(posedge clk); @(posedge clk); #1;
        // oc_latched 해제 확인
        mmio_read(B + OFF_STATUS, rd);
        check_eq(rd[0], 1'b0, "TC5:oc_latched=0");
        // IRQ 소거 확인
        mmio_read(B + OFF_IRQ_STS, rd);
        check_eq(rd[0], 1'b0, "TC5:irq_cleared");
        // BH_in=1이 여전히 설정 → BH_out=1 복귀
        @(posedge clk); #1;
        check_eq(pwm_bh, 1'b1, "TC5:BH_restored");

        // 초기화
        mmio_write(B + OFF_PWM_IN, 32'h0);
        repeat(5) @(posedge clk);

        // -----------------------------------------------------------------
        // TC6: dt_bypass — bypass=1 시 슛스루 차단 없이 그대로 출력
        // -----------------------------------------------------------------
        tc_num = 6;
        // dt_bypass=1 (bit2), enable=1 (bit0)
        mmio_write(B + OFF_CTRL, 32'h5);
        // AH=1, AL=1 동시 (bypass 모드)
        mmio_write(B + OFF_PWM_IN, 32'h3);
        @(posedge clk); @(posedge clk); #1;
        // bypass 모드: 슛스루 허용 → 둘 다 1
        check_eq(pwm_ah, 1'b1, "TC6:bypass AH=1");
        check_eq(pwm_al, 1'b1, "TC6:bypass AL=1");

        // 최종 초기화
        mmio_write(B + OFF_CTRL,   32'h0);
        mmio_write(B + OFF_PWM_IN, 32'h0);
        repeat(5) @(posedge clk);

        // -----------------------------------------------------------------
        // 결과 보고
        // -----------------------------------------------------------------
        if (fail_cnt == 0) begin
            $display("PASS: motor_safety_ip 모든 항목(%0d개) 통과", 6);
        end else begin
            $display("FAIL: %0d개 항목 실패", fail_cnt);
        end

        $finish;
    end

    // 타임아웃 (5 µs)
    initial begin
        #5000;
        $display("FAIL: 시뮬레이션 타임아웃");
        $finish;
    end

endmodule

# Makefile — mmio-motor-safety-wrapper
# 타깃: lint, sim, synth, all, clean
# iverilog, verilator, yosys 필요

SLUG    := mmio-motor-safety-wrapper
RTL_DIR := rtl
TB_DIR  := tb
BUILD   := build

RTL_SRCS := $(RTL_DIR)/gpio.v \
             $(RTL_DIR)/uart_tx.v \
             $(RTL_DIR)/motor_safety_ip.v \
             $(RTL_DIR)/mmio_bus.v \
             $(RTL_DIR)/soc_top.v \
             $(RTL_DIR)/demo_master.v

TB_SRCS  := $(TB_DIR)/tb_motor_safety.v \
             $(RTL_DIR)/motor_safety_ip.v

TOP      := motor_safety_ip
TB_TOP   := tb_motor_safety

.PHONY: all lint sim synth clean

all: lint sim synth

$(BUILD):
	mkdir -p $(BUILD)

# ---- 린트 (verilator --lint-only) ------------------------------------
lint: $(BUILD)
	verilator --lint-only -Wall --top-module $(TOP) $(RTL_SRCS) 2>&1 | tee $(BUILD)/lint.log
	@echo "lint done"

# ---- 시뮬레이션 (iverilog + vvp) -------------------------------------
sim: $(BUILD)
	iverilog -g2001 -Wall -o $(BUILD)/sim.vvp \
	    $(TB_SRCS) 2>&1 | tee $(BUILD)/sim_compile.log
	vvp $(BUILD)/sim.vvp 2>&1 | tee $(BUILD)/sim.log
	@grep -q "^PASS" $(BUILD)/sim.log && echo "SIM: PASS" || (echo "SIM: FAIL"; exit 1)

# ---- 합성 (yosys 추정) -----------------------------------------------
synth: $(BUILD)
	yosys -p "read_verilog $(RTL_SRCS); \
	           synth -top $(TOP) -flatten; \
	           stat -tech xilinx; \
	           write_json $(BUILD)/synth.json" \
	    2>&1 | tee $(BUILD)/synth.log
	@echo "synth done (yosys 추정 — Vivado와 다를 수 있음)"

clean:
	rm -rf $(BUILD)

위험·한계

  • DT_CYCLES=10(100 ns@100MHz)은 DRV8833/TB6612FNG 최소 요구(100 ns)와 일치하나, 선로 지연이 큰 경우 더 늘릴 것 (Vivado 실측 필요)
  • OC 입력이 외부 아날로그 비교기에서 오므로 2단 동기화 필요 — 현재 motor_safety_ip 내에서 처리
  • dt_bypass=1 설정 시 슛스루 하드웨어 방지 없음 — 디버그 전용
  • PWM_IN 레지스터를 CPU가 쓸 때 MSB 부정확성 없음 확인 (1사이클 쓰기, 즉각 적용)
  • yosys 자원 추정은 Vivado와 다를 수 있음 (Vivado 미검증)
