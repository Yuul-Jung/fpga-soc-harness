캡스톤 패키지 · Digilent Basys3 (XC7A35T) · 단계 T2

PWM 음계 재생 + VGA 막대 표시 SoC: DDS 톤·음량 PWM·프레임 버퍼 없는 VGA (Basys3)

skeleton(T1)의 MMIO 버스에 톤 생성기(DDS 위상 누산기 + 8비트 PWM 음량)와 VGA 막대 표시기를 더한 T2 패키지. 데모 FSM이 도레미파솔라시도 8음을 재생하면서 음마다 VGA 막대를 하나씩 늘린다. 테스트벤치가 톤 주파수, PWM 듀티, VGA 동기 타이밍, 켜진 화소 수를 PASS/FAIL로 점검한다.

린트: 미실행시뮬레이션: 미실행합성: 미실행보드: 미실행

검증 상태는 실행 기록이 있을 때만 표시한다. 기록이 없으면 '미실행'이다.

목표계통도모듈 계층메모리맵외부 부품·전기기술 트리실행 소스검증참고·위험

1. 목표와 범위

목표

  • 32비트 위상 누산기로 INC 값에 비례하는 주파수의 사각파를 만들고, 8비트 PWM으로 음량을 조절한다.
  • 도 4(261.63Hz)부터 도 5(523.25Hz)까지 8음의 INC를 100MHz 기준으로 계산해 재생한다.
  • 프레임 버퍼 없이 카운터에서 바로 색을 정해 640x480@60Hz VGA에 막대 1~8개를 표시한다.
  • 테스트벤치로 톤 주파수, PWM 듀티 25%, 끄기 동작, hsync/vsync 주기·폭, 켜진 화소 수(153600), 프레임 카운터를 점검한다.

범위 밖

  • 사인표/BRAM 곡 재생(I-001 사다리의 뒤 단계)
  • I2S/Pmod I2S2 같은 디지털 오디오 출력
  • VGA 문자·이미지 표시, 프레임 버퍼
  • CPU 구현, 인터럽트, DMA

이 패키지의 소스는 하네스가 직접 작성한 원본이며 외부 코드를 포함하지 않는다(gpio.v는 이 저장소의 mmio-uart-gpio-skeleton 자체 원본 복사). 사용자 지시('무조건 실행', 2026-11-02)로 §13.7 게이트 3(ready 아이디어, 근거 카드 rechecked_at)을 건너뛰고 vetted 아이디어 I-001로 만들었다. 근거 카드의 재열람이 끝나지 않았으므로 카드 내용은 구조 착안으로만 쓰였고 수치는 인용하지 않았다.

2. 계통도

클럭: 100 MHz 단일 클럭 (clk, W5), 동기 리셋 (btnC, 2단 동기화). VGA 화소 enable은 이 클럭의 4분주(25 MHz 상당)

diagram.svg로 따로 받을 수 있다.

버스 규약: mmio-lite

신호방향설명

미매핑 주소 읽기는 0을 돌려주고 오류를 알리지 않는다. 대기 상태·오류 응답이 필요한 CPU로 바꿀 때 확장한다.

통합 선언 (SoC 적합성)

이 패키지는 MicroBlaze V 동결 주소맵과 호환되지 않는다 (파일럿). 아래 이식 계획을 따라야 SoC에 합칠 수 있다.

버스mmio-lite
주소맵custom → 동결 맵 mbv-frozen-v2 적합 여부: 적합하지 않음
이식 계획CPU 없이 시뮬레이션하려고 자체 버스 mmio-lite(0x1000_xxxx)를 쓴 파일럿이다. 동결 맵(mbv-frozen-v2)에는 pwm [07]과 vga [0A]가 구형 영역으로 이미 있으나 레지스터 배치가 달라 이 모듈을 그대로 꽂을 수 없다. 이식 때는 (1) 레지스터를 IP 표준(64KB 창, 0xFFF0 ID·VER·IRQ_STATUS·IRQ_ENABLE)에 맞춰 감싸고 (2) 구형 [07]·[0A]를 대체할지 빈 슬롯 [16]부터 새로 배정할지 사용자가 결정해야 한다(제안, 동결 아님). (3) mmio-lite→AXI4-Lite 마스터 다리는 아직 없다(gap). 오디오 PWM 쪽의 INC·VOL 레지스터와 VGA 타이밍 FSM은 CPU와 무관해 그대로 옮길 수 있다.

6. 기술 트리 (이 캡스톤의 확장 경로)

  • T1MMIO 버스 + GPIO + UART, 마스터는 FSM (mmio-uart-gpio-skeleton)
  • T2DDS 톤 + PWM 음량 + 프레임 버퍼 없는 VGA 막대 (I-001 1~2단계) 참고: zipcpu-pmodamp2-project-ladder, columbia-4840-audio-visualizer

rtl/gpio.v 34줄
// 원본: capstones/mmio-uart-gpio-skeleton/rtl/gpio.v (이 저장소의 자체 원본을 복사)
// GPIO: 0x00 LED(RW, 16bit), 0x04 SW(RO, 2단 동기화된 스위치 16bit)
module gpio (
    input  wire        clk,
    input  wire        rst,
    input  wire        sel,
    input  wire        we,
    input  wire [7:0]  off,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    input  wire [15:0] sw,
    output wire [15:0] led
);
    reg [15:0] led_r;
    reg [15:0] sw_s1, sw_s2;
    assign led = led_r;

    always @(posedge clk) begin
        sw_s1 <= sw;
        sw_s2 <= sw_s1;
        if (rst)
            led_r <= 16'h0000;
        else if (sel && we && off == 8'h00)
            led_r <= wdata[15:0];
    end

    always @* begin
        case (off)
            8'h00:   rdata = {16'h0000, led_r};
            8'h04:   rdata = {16'h0000, sw_s2};
            default: rdata = 32'h0000_0000;
        endcase
    end
endmodule
rtl/mmio_bus.v 25줄
// mmio-lite 버스: 단일 마스터, 주소 [31:12]로 슬레이브 선택(gpio/pwm/vga), 읽기 데이터 조합 경로, 항상 ready.
module mmio_bus (
    input  wire        valid,
    input  wire [31:0] addr,
    output wire        sel_gpio,
    output wire        sel_pwm,
    output wire        sel_vga,
    input  wire [31:0] rdata_gpio,
    input  wire [31:0] rdata_pwm,
    input  wire [31:0] rdata_vga,
    output reg  [31:0] rdata,
    output wire        ready
);
    assign sel_gpio = valid && (addr[31:12] == 20'h10000);
    assign sel_pwm  = valid && (addr[31:12] == 20'h10003);
    assign sel_vga  = valid && (addr[31:12] == 20'h10004);
    assign ready    = 1'b1;

    always @* begin
        if (addr[31:12] == 20'h10000)      rdata = rdata_gpio;
        else if (addr[31:12] == 20'h10003) rdata = rdata_pwm;
        else if (addr[31:12] == 20'h10004) rdata = rdata_vga;
        else                               rdata = 32'h0000_0000;
    end
endmodule
rtl/pwm_tone.v 56줄
// 톤 생성기: 32비트 위상 누산기(DDS)의 최상위 비트가 사각파 음높이, 8비트 캐리어 비교로 음량(PWM 듀티)을 만든다.
// 0x00 INC(RW)  주파수 = INC * CLK_HZ / 2^32     0x04 CTRL(RW) bit0=enable
// 0x08 VOL(RW)  하위 8비트, 캐리어 256 중 high 개수  0x0C STATUS(RO) bit0=현재 톤 비트
module pwm_tone (
    input  wire        clk,
    input  wire        rst,
    input  wire        sel,
    input  wire        we,
    input  wire [7:0]  off,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    output wire        pwm,
    output wire        amp_sd_n,
    output wire        tone
);
    reg [31:0] inc;
    reg        en;
    reg [7:0]  vol;
    reg [31:0] acc;
    reg [7:0]  car;

    assign tone     = acc[31];
    assign pwm      = en && acc[31] && (car < vol);
    assign amp_sd_n = en;

    always @(posedge clk) begin
        if (rst) begin
            inc <= 32'h0000_0000;
            en  <= 1'b0;
            vol <= 8'h00;
            acc <= 32'h0000_0000;
            car <= 8'h00;
        end else begin
            car <= car + 8'd1;
            acc <= en ? acc + inc : 32'h0000_0000;
            if (sel && we) begin
                case (off)
                    8'h00: inc <= wdata;
                    8'h04: en  <= wdata[0];
                    8'h08: vol <= wdata[7:0];
                    default: ;
                endcase
            end
        end
    end

    always @* begin
        case (off)
            8'h00:   rdata = inc;
            8'h04:   rdata = {31'h0, en};
            8'h08:   rdata = {24'h0, vol};
            8'h0C:   rdata = {31'h0, acc[31]};
            default: rdata = 32'h0000_0000;
        endcase
    end
endmodule
rtl/vga_bars.v 82줄
// VGA 640x480@60Hz 막대 표시(프레임 버퍼 없음, 카운터에서 바로 색 결정). 25 MHz 화소 enable은 100 MHz를 4분주.
// 0x00 NOTE(RW) 하위 3비트: 0..NOTE번 막대(80화소 폭)가 켜짐  0x04 COLOR(RW) 하위 12비트 {R,G,B}
// 0x08 FRAME(RO) 프레임 카운터(vsync마다 +1, 16비트)
module vga_bars (
    input  wire        clk,
    input  wire        rst,
    input  wire        sel,
    input  wire        we,
    input  wire [7:0]  off,
    input  wire [31:0] wdata,
    output reg  [31:0] rdata,
    output wire        hsync,
    output wire        vsync,
    output wire [3:0]  vga_r,
    output wire [3:0]  vga_g,
    output wire [3:0]  vga_b
);
    reg [1:0]  div;
    reg [9:0]  hcnt;
    reg [9:0]  vcnt;
    reg [2:0]  note;
    reg [11:0] color;
    reg [15:0] frame;

    wire pe     = (div == 2'd3);
    wire hlast  = (hcnt == 10'd799);
    wire vlast  = (vcnt == 10'd524);
    wire de     = (hcnt < 10'd640) && (vcnt < 10'd480);
    wire [2:0] col = (hcnt < 10'd80)  ? 3'd0 : (hcnt < 10'd160) ? 3'd1 :
                     (hcnt < 10'd240) ? 3'd2 : (hcnt < 10'd320) ? 3'd3 :
                     (hcnt < 10'd400) ? 3'd4 : (hcnt < 10'd480) ? 3'd5 :
                     (hcnt < 10'd560) ? 3'd6 : 3'd7;
    wire lit    = de && (col <= note);

    assign hsync = ~((hcnt >= 10'd656) && (hcnt < 10'd752));
    assign vsync = ~((vcnt >= 10'd490) && (vcnt < 10'd492));
    assign vga_r = lit ? color[11:8] : 4'h0;
    assign vga_g = lit ? color[7:4]  : 4'h0;
    assign vga_b = lit ? color[3:0]  : 4'h0;

    always @(posedge clk) begin
        if (rst) begin
            div   <= 2'd0;
            hcnt  <= 10'd0;
            vcnt  <= 10'd0;
            note  <= 3'd0;
            color <= 12'h0F0;
            frame <= 16'h0000;
        end else begin
            div <= div + 2'd1;
            if (pe) begin
                if (hlast) begin
                    hcnt <= 10'd0;
                    if (vlast) begin
                        vcnt  <= 10'd0;
                        frame <= frame + 16'd1;
                    end else begin
                        vcnt <= vcnt + 10'd1;
                    end
                end else begin
                    hcnt <= hcnt + 10'd1;
                end
            end
            if (sel && we) begin
                case (off)
                    8'h00: note  <= wdata[2:0];
                    8'h04: color <= wdata[11:0];
                    default: ;
                endcase
            end
        end
    end

    always @* begin
        case (off)
            8'h00:   rdata = {29'h0, note};
            8'h04:   rdata = {20'h0, color};
            8'h08:   rdata = {16'h0, frame};
            default: rdata = 32'h0000_0000;
        endcase
    end
endmodule

// SoC 코어: 마스터 포트(mmio-lite)를 밖으로 노출한다. 마스터는 데모 FSM, 테스트벤치, 나중에 CPU가 맡는다.
module soc_top (
    input  wire        clk,
    input  wire        rst,
    input  wire        m_valid,
    input  wire        m_we,
    input  wire [31:0] m_addr,
    input  wire [31:0] m_wdata,
    output wire [31:0] m_rdata,
    output wire        m_ready,
    input  wire [15:0] sw,
    output wire [15:0] led,

    output wire        vsync,

    output wire [3:0]  vga_b
);
    wire        sel_gpio, sel_pwm, sel_vga;

// 음마다 SW[7:0]을 읽어 음량으로 쓰고(0이면 64), 음높이 INC·VGA 막대 수·LED(원-핫)를 갱신한다. 끝나면 소리를 끈다.
module demo_master #(

) (
    input  wire        clk,
    input  wire        rst,
    input  wire        btn,
    output reg         m_valid,
    output reg         m_we,
    output reg  [31:0] m_addr,
    output reg  [31:0] m_wdata,
    input  wire [31:0] m_rdata,
    input  wire        m_ready
);
    localparam [3:0] IDLE = 4'd0, R_SW = 4'd1, W_VOL = 4'd2, W_INC = 4'd3, W_NOTE = 4'd4,
                     W_LED = 4'd5, W_EN = 4'd6, HOLD = 4'd7, W_OFF = 4'd8;
    localparam [31:0] A_LED = 32'h1000_0000, A_SW = 32'h1000_0004,
                      A_INC = 32'h1000_3000, A_EN = 32'h1000_3004, A_VOL = 32'h1000_3008,
                      A_NOTE = 32'h1000_4000;

    reg [3:0]  st;
    reg [2:0]  n;
    reg [7:0]  vol;
    reg [31:0] cnt;
    reg        b1, b2, b3;
    reg [31:0] inc_rom;

    always @* begin
        case (n)
            3'd0:    inc_rom = 32'd11237;
            3'd1:    inc_rom = 32'd12613;
            3'd2:    inc_rom = 32'd14158;
            3'd3:    inc_rom = 32'd14999;
            3'd4:    inc_rom = 32'd16836;
            3'd5:    inc_rom = 32'd18898;
            3'd6:    inc_rom = 32'd21212;
            default: inc_rom = 32'd22473;
        endcase
    end

    always @(posedge clk) begin
        if (rst) begin
            st <= IDLE; n <= 3'd0; vol <= 8'd64; cnt <= 32'd0; b1 <= 1'b0; b2 <= 1'b0; b3 <= 1'b0;
            m_valid <= 1'b0; m_we <= 1'b0; m_addr <= 32'd0; m_wdata <= 32'd0;
        end else begin
            b1 <= btn; b2 <= b1; b3 <= b2;
            m_valid <= 1'b0; m_we <= 1'b0;
            case (st)
                IDLE:   begin n <= 3'd0; if (b2 && !b3) st <= R_SW; end
                R_SW:   begin m_valid <= 1'b1; m_addr <= A_SW; st <= W_VOL; end
                W_VOL:  begin
                            vol <= (m_rdata[7:0] == 8'd0) ? 8'd64 : m_rdata[7:0];
                            m_valid <= 1'b1; m_we <= 1'b1; m_addr <= A_VOL;
                            m_wdata <= {24'd0, (m_rdata[7:0] == 8'd0) ? 8'd64 : m_rdata[7:0]};
                            st <= W_INC;
                        end
                W_INC:  begin m_valid <= 1'b1; m_we <= 1'b1; m_addr <= A_INC; m_wdata <= inc_rom; st <= W_NOTE; end
                W_NOTE: begin m_valid <= 1'b1; m_we <= 1'b1; m_addr <= A_NOTE; m_wdata <= {29'd0, n}; st <= W_LED; end
                W_LED:  begin m_valid <= 1'b1; m_we <= 1'b1; m_addr <= A_LED; m_wdata <= 32'd1 << n; st <= W_EN; end
                W_EN:   begin m_valid <= 1'b1; m_we <= 1'b1; m_addr <= A_EN; m_wdata <= 32'd1; cnt <= 32'd0; st <= HOLD; end
                HOLD:   begin
                            cnt <= cnt + 32'd1;
                            if (cnt == NOTE_CLKS - 1) begin
                                if (n == 3'd7) st <= W_OFF;
                                else begin n <= n + 3'd1; st <= R_SW; end
                            end
                        end
                W_OFF:  begin m_valid <= 1'b1; m_we <= 1'b1; m_addr <= A_EN; m_wdata <= 32'd0; st <= IDLE; end
                default: st <= IDLE;
            endcase
        end
    end
endmodule

// 자체 점검 테스트벤치(장치 수준): 톤 주파수, PWM 듀티, 끄기 동작, VGA 동기 타이밍, 켜진 화소 수, 프레임 카운터.
module tb_dev;
    reg         clk = 1'b0;
    reg         rst = 1'b1;
    reg         m_valid = 1'b0, m_we = 1'b0;
    reg  [31:0] m_addr = 32'd0, m_wdata = 32'd0;
    wire [31:0] m_rdata;
    wire        m_ready, pwm, amp_sd_n, tone, hsync, vsync;
    wire [15:0] led;
    wire [3:0]  vr, vg, vb;
    integer     errors = 0;
    integer     i, edges, tone_hi, pwm_hi, lit, bad_blank, f0, f1;
    reg         tone_q, hs_q, vs_q;
    time        t_a, t_b, t_c;

    always #5 clk = ~clk;

    soc_top dut (
        .clk(clk), .rst(rst),
        .m_valid(m_valid), .m_we(m_we), .m_addr(m_addr), .m_wdata(m_wdata),
        .m_rdata(m_rdata), .m_ready(m_ready),
        .sw(16'h00A5), .led(led), .pwm(pwm), .amp_sd_n(amp_sd_n), .tone(tone),
        .hsync(hsync), .vsync(vsync), .vga_r(vr), .vga_g(vg), .vga_b(vb)
    );

    task wr(input [31:0] a, input [31:0] d);
        begin
            @(negedge clk); m_valid = 1'b1; m_we = 1'b1; m_addr = a; m_wdata = d;
            @(negedge clk); m_valid = 1'b0; m_we = 1'b0;
        end
    endtask

    task chk(input [31:0] a, input [31:0] exp, input [8*16-1:0] name);
        begin
            @(negedge clk); m_valid = 1'b1; m_we = 1'b0; m_addr = a;
            #1;
            if (m_rdata !== exp) begin
                $display("FAIL: %0s 읽기 0x%08h 기대 0x%08h", name, m_rdata, exp);
                errors = errors + 1;
            end
            @(negedge clk); m_valid = 1'b0;
        end
    endtask

    // 한 구간(20 ms = 2,000,000 클럭) 동안 톤 상승 에지, 톤 high 클럭, PWM high 클럭을 센다
    task measure;
        begin
            edges = 0; tone_hi = 0; pwm_hi = 0; tone_q = tone;
            for (i = 0; i < 2000000; i = i + 1) begin
                @(posedge clk);
                if (tone && !tone_q) edges = edges + 1;
                tone_q = tone;
                if (tone) tone_hi = tone_hi + 1;
                if (pwm)  pwm_hi  = pwm_hi + 1;
            end
        end
    endtask

    initial begin
        repeat (4) @(posedge clk);
        rst = 1'b0;
        // 레지스터 읽기/쓰기
        wr(32'h1000_3000, 32'd42950);          // 약 1000 Hz
        wr(32'h1000_3008, 32'd64);
        chk(32'h1000_3000, 32'd42950, "INC");
        chk(32'h1000_3008, 32'd64, "VOL");
        chk(32'h1000_3004, 32'd0, "EN(리셋값)");
        if (amp_sd_n !== 1'b0 || pwm !== 1'b0) begin
            $display("FAIL: 꺼진 상태에서 amp_sd_n/pwm이 0이 아님"); errors = errors + 1;
        end
        // 켜고 1000 Hz, 음량 64/256 측정
        wr(32'h1000_3004, 32'd1);
        measure;
        if (edges < 19 || edges > 21) begin
            $display("FAIL: 20ms 동안 톤 에지 %0d (기대 20±1)", edges); errors = errors + 1;
        end
        if (tone_hi < 900000 || tone_hi > 1100000) begin
            $display("FAIL: 톤 high %0d클럭 (기대 약 1,000,000)", tone_hi); errors = errors + 1;
        end
        // PWM high / 톤 high ≈ 64/256 = 0.25 (허용 ±0.03)
        if (pwm_hi * 100 < tone_hi * 22 || pwm_hi * 100 > tone_hi * 28) begin
            $display("FAIL: PWM 듀티 %0d/%0d (기대 25%%±3)", pwm_hi, tone_hi); errors = errors + 1;
        end
        // 음량 0이면 PWM 항상 0
        wr(32'h1000_3008, 32'd0);
        pwm_hi = 0;
        for (i = 0; i < 200000; i = i + 1) begin @(posedge clk); if (pwm) pwm_hi = pwm_hi + 1; end
        if (pwm_hi != 0) begin $display("FAIL: VOL=0인데 PWM high %0d", pwm_hi); errors = errors + 1; end
        // 끄면 amp_sd_n=0, 톤 정지
        wr(32'h1000_3004, 32'd0);
        repeat (4) @(posedge clk);
        if (amp_sd_n !== 1'b0 || tone !== 1'b0) begin
            $display("FAIL: 끈 뒤에도 amp_sd_n/tone이 0이 아님"); errors = errors + 1;
        end
        // GPIO 스위치 읽기
        chk(32'h1000_0004, 32'h0000_00A5, "SW");

        // ---- VGA ----
        chk(32'h1000_4004, 32'h0000_00F0, "COLOR(리셋값)");
        wr(32'h1000_4000, 32'd3);                 // 막대 0..3 켜짐 = 4*80*480 화소
        wr(32'h1000_4004, 32'h0F0F);              // 하위 12비트 = 0xF0F
        chk(32'h1000_4000, 32'd3, "NOTE");
        // hsync 주기와 low 폭
        @(negedge hsync); t_a = $time;
        @(posedge hsync); t_b = $time;
        @(negedge hsync); t_c = $time;
        if (t_c - t_a != 32000) begin $display("FAIL: hsync 주기 %0d ns (기대 32000)", t_c - t_a); errors = errors + 1; end
        if (t_b - t_a != 3840)  begin $display("FAIL: hsync low 폭 %0d ns (기대 3840)", t_b - t_a); errors = errors + 1; end
        // vsync 주기와 low 폭, 프레임 카운터
        @(negedge vsync); t_a = $time;
        @(negedge clk); m_valid = 1'b1; m_we = 1'b0; m_addr = 32'h1000_4008; #1; f0 = m_rdata; @(negedge clk); m_valid = 1'b0;
        @(posedge vsync); t_b = $time;
        @(negedge vsync); t_c = $time;
        if (t_c - t_a != 16800000) begin $display("FAIL: vsync 주기 %0d ns (기대 16800000)", t_c - t_a); errors = errors + 1; end
        if (t_b - t_a != 64000)    begin $display("FAIL: vsync low 폭 %0d ns (기대 64000)", t_b - t_a); errors = errors + 1; end
        @(negedge clk); m_valid = 1'b1; m_we = 1'b0; m_addr = 32'h1000_4008; #1; f1 = m_rdata; @(negedge clk); m_valid = 1'b0;
        if (f1 - f0 != 1) begin $display("FAIL: 프레임 카운터 증가 %0d (기대 1)", f1 - f0); errors = errors + 1; end
        // 한 프레임 동안 켜진 화소 수와 블랭킹 구간 출력 확인
        lit = 0; bad_blank = 0;
        @(negedge vsync);
        for (i = 0; i < 1680000; i = i + 1) begin
            @(posedge clk);
            if (dut.u_vga.pe) begin
                if ({vr, vg, vb} !== 12'h000) begin
                    lit = lit + 1;
                    if ({vr, vg, vb} !== 12'hF0F) bad_blank = bad_blank + 1;
                end
                if (!dut.u_vga.de && {vr, vg, vb} !== 12'h000) bad_blank = bad_blank + 1;
            end
        end
        if (lit != 153600) begin $display("FAIL: 켜진 화소 %0d (기대 153600)", lit); errors = errors + 1; end
        if (bad_blank != 0) begin $display("FAIL: 색 불일치/블랭킹 위반 %0d", bad_blank); errors = errors + 1; end

        if (errors == 0) $display("PASS: tb_dev 톤 에지 %0d, VGA 켜진 화소 %0d", edges, lit);
        else             $display("FAIL: tb_dev 오류 %0d건", errors);
        $finish;
    end
endmodule

# 단계: lint(verilator) → sim(iverilog, 테스트벤치 2개) → synth(yosys, 자원 추정). Vivado 빌드는 capstone.json의 howto를 따른다.
RTL_ALL = rtl/gpio.v rtl/mmio_bus.v rtl/pwm_tone.v rtl/vga_bars.v rtl/soc_top.v rtl/demo_master.v rtl/basys3_top.v
RTL_SOC = rtl/gpio.v rtl/mmio_bus.v rtl/pwm_tone.v rtl/vga_bars.v rtl/soc_top.v

.PHONY: lint sim synth clean build
build:
	mkdir -p build

lint: build
	verilator --lint-only -Wall -Wno-fatal --top-module basys3_top $(RTL_ALL) 2>&1 | tee build/lint.log
	@! grep -q "%Error" build/lint.log

sim: build
	iverilog -g2005 -o build/sim_dev.vvp tb/tb_dev.v $(RTL_SOC)
	iverilog -g2005 -o build/sim_demo.vvp tb/tb_demo.v $(RTL_SOC) rtl/demo_master.v
	vvp build/sim_dev.vvp | tee build/sim.log
	vvp build/sim_demo.vvp | tee -a build/sim.log
	@test "$$(grep -c '^PASS' build/sim.log)" = "2" && ! grep -q "^FAIL" build/sim.log

synth: build
	yosys -q -l build/synth.log -p "read_verilog $(RTL_ALL); synth_xilinx -top basys3_top -family xc7; stat"
	@grep -E "LUT|FDRE|FDCE|FDPE|RAM|Number of cells" build/synth.log | tail -12

clean:
	rm -rf build

시뮬레이션

  1. iverilog, verilator, yosys 설치
  2. make -C capstones/mmio-pwm-tune-vga-bars lint sim synth
  3. sim은 tb_dev(장치 수준, 약 3.4M 클럭)와 tb_demo(8음 재생)를 차례로 실행하며 둘 다 PASS 줄을 내야 통과한다

Vivado 빌드 (Basys3)

  1. 새 RTL 프로젝트, 파트 xc7a35tcpg236-1
  2. rtl/*.v 추가 (tb 제외), constr/basys3.xdc 추가, 최상위 basys3_top
  3. Pmod AMP2를 JA 포트 위쪽 줄에 꽂고 스피커/헤드폰을 연결, VGA 모니터를 연결
  4. Generate Bitstream 후 Program Device, SW[7:0]으로 음량을 정하고 btnU를 누른다
  5. 도레미파솔라시도가 나오고 막대가 한 개씩 늘며 LED가 한 칸씩 움직이면 성공. 소리가 너무 크면 SW 값을 낮춘다

위험·한계

  • 이 패키지는 사용자 지시로 §13.7 게이트 3을 건너뛰고 만들었다. 근거 카드 2건의 재열람(rechecked_at)이 없다.
  • xdc의 VGA 핀(R: G19 H19 J19 N19, G: J17 H17 G17 D17, B: N18 L18 K18 J18, Hs P19, Vs R19)과 JA 핀(J1 L2 J2)은 Digilent 마스터 XDC와 대조하지 않았다.
  • 음정은 사각파 + 저주파 PWM 캐리어(약 390kHz)이며 사인표가 아니다. 음색은 거칠고 PWM 캐리어가 Pmod AMP2 입력의 저역 필터를 통과하는지 확인하지 못했다.
  • VGA 출력은 조합 논리로 카운터에서 바로 나간다. 25MHz 화소 enable이라 타이밍은 여유 있지만 Vivado WNS는 확인하지 않았다. 화소 enable 방식이라 정확한 25.175MHz가 아니라 25MHz다(모니터 호환은 보드에서 확인 필요).
  • 합성 자원은 CI의 yosys 추정만 기록되며 Vivado와 다를 수 있다.
  • RTL 합계가 약 364줄(gpio 34줄은 skeleton 재사용)로 400줄 기준 안이다.
