FPGA SoC 캡스톤 하네스

FPGA로 만든 SoC 자료를 모으고 검증해, Basys3에서 실행할 수 있는 캡스톤 패키지(문서, 계통도, 실행 소스)로 만든다. 수집은 1시간마다, 검증은 3시간마다, 과제화는 6시간마다 자동으로 돈다.

캡스톤 패키지

PWM 음계 재생 + VGA 막대 표시 SoC: DDS 톤·음량 PWM·프레임 버퍼 없는 VGA (Basys3)

Digilent Basys3 (XC7A35T) · 단계 T2

skeleton(T1)의 MMIO 버스에 톤 생성기(DDS 위상 누산기 + 8비트 PWM 음량)와 VGA 막대 표시기를 더한 T2 패키지. 데모 FSM이 도레미파솔라시도 8음을 재생하면서 음마다 VGA 막대를 하나씩 늘린다. 테스트벤치가 톤 주파수, PWM 듀티, VGA 동기 타이밍, 켜진 화소 수를 PASS/FAIL로 점검한다.

SD SPI 블록 리더 SoC: 초기화·CMD17 읽기 + 카드 모델 자체 점검 (Basys3)

Digilent Basys3 (XC7A35T) · 단계 T2

skeleton(T1)의 MMIO 버스에 SD 카드 SPI 컨트롤러를 더한 T2 패키지. 초기화(CMD0/8/55+41/58)와 512바이트 단일 블록 읽기를 직접 쓴 FSM으로 만들고, 테스트벤치의 간이 SD 카드 모델이 명령 순서·클럭 속도·주소를 PASS/FAIL로 검사한다. 데모 마스터는 블록 0의 첫 16바이트를 UART로 내보낸다.

MMIO 뼈대 SoC: GPIO + UART (Basys3)

Digilent Basys3 (XC7A35T) · 단계 T1

CPU 슬롯이 비어 있는 최소 SoC. 단일 마스터 버스(mmio-lite)에 GPIO와 UART 송신기를 붙이고, 마스터 자리에는 데모 FSM을 둔다. 이후 이 슬롯을 PicoRV32 같은 코어로 교체하는 것이 목표다.
