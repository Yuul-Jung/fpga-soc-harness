## FPGA·SoC 기술 트리

```
T0 ISA·도구 → T1 단일 사이클 코어 + MMIO → T2 SoC 접착
→ T3 프레임워크 기반 SoC → T4 가속기·영상/신호처리 → T5 OS 구동
```
