# BMP280 I2C/SPI 기압·온도 센서

갱신: 2026-11-03 · 등급: L3(데이터시트 1건 + 제조사 가이드 1건 열람) · 출처: Bosch BST-BMP280-DS001-26 rev.1.26 (제3자 사본 https://forums.parallax.com/uploads/editor/gm/8y6uzm9khhil.pdf — 공식 Bosch 사이트 원문은 열람하지 못함), Adafruit 가이드 (https://learn.adafruit.com/adafruit-bmp280-barometric-pressure-plus-temperature-sensor-breakout.md?view=all)

## 인터페이스 (데이터시트)
- I2C 7비트 주소: SDO=GND이면 0x76, SDO=VDDIO이면 0x77. SDO를 띄우면 안 된다. I2C 최대 3.4 MHz, SPI 3선·4선 최대 10 MHz.
- 전원: VDD 1.71–3.6 V, VDDIO 1.2–3.6 V (최대 3.6 V이므로 5 V 직결 불가). 모듈은 별도 레귤레이터·레벨 변환 회로가 있을 수 있다(Adafruit 보드는 3–5 V 입력과 신호 레벨 변환 서술). 보드 I/O 3.3 V에는 직접 연결 가능, 모듈 풀업이 3.3 V인지 확인한다(내 판단).
- Adafruit 보드의 기본 I2C 주소는 0x77로 서술됨.

## 레지스터 (데이터시트)
| 주소 | 이름 | 내용 |
|---|---|---|
| 0xD0 | id | 0x58 |
| 0xE0 | reset | 0xB6 쓰면 리셋 |
| 0xF3 | status | bit3 측정 중, bit0 NVM 복사 중 |
| 0xF4 | ctrl_meas | osrs_t[7:5], osrs_p[4:2], mode[1:0] (00 sleep, 01/10 forced, 11 normal) |
| 0xF5 | config | t_sb[7:5], filter[4:2], spi3w_en[0] |
| 0xF7–0xF9 | press | 20비트 |
| 0xFA–0xFC | temp | 20비트 |
| 0x88–0xA1 | calib | 공장 보정 계수 (dig_T1–T3, dig_P1–P9) |

- 데이터 6바이트는 0xF7부터 한 번의 연속 읽기로 가져와 일관성을 유지한다.
- 압력 측정 시간(전형/최대): ×1 5.5/6.4 ms, ×2 7.5/8.7 ms, ×4 11.5/13.3 ms, ×8 19.5/22.5 ms, ×16 37.5/43.2 ms.

## 보정 계산
- 온도를 먼저 계산해 t_fine을 얻고 압력 계산에 쓴다. 64비트 정수 방식이 가장 정확하고, 32비트 정수 방식은 전형 정확도 1 Pa(1σ)로 64비트 지원이 없을 때의 대안이다. Cortex-M3 기준 압력 약 112 사이클(32비트) 대 약 1400 사이클(64비트)(데이터시트 서술).
- 내 판단: 보정은 곱셈이 많아 RTL에 넣기보다 MicroBlaze V 펌웨어에서 32비트 방식으로 하고, IP는 원시 20비트 값과 상태만 레지스터로 노출하는 편이 IP 표준 분리에 맞다.

## 기타 (Adafruit 가이드)
- 정확도: 압력 ±1 hPa, 온도 ±1.0 °C. 마지막 측정값이 저장되므로 새 값을 원하면 두 번 읽고 첫 값을 버리라는 서술이 있다(데이터시트의 forced 모드와 별도 확인 필요, unverified).
- 고도는 해면 기압을 모르면 약 10 m까지 틀어질 수 있다.

## unverified
- 필터 계수별 응답 시간, 대기 시간(t_sb) 표, SPI 타이밍 표, Bosch 공식 최신판과의 차이.
